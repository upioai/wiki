03更新操作（同步给同事）

拿到今天的修复（多轮漏读 #776 + 回复发送切 DOM #778），需更新 2 个脚本 + 重启 agent。云电脑 PowerShell，一台一台来：

# 1) 停 agent
Get-Process python,py,pythonw -ErrorAction SilentlyContinue | Stop-Process -Force
cd C:\akke-wuying\wuying-dm
# 2) 下这 2 个文件（SHA 钉版 jsDelivr，稳、不吃缓存）
$b='https://cdn.jsdelivr.net/gh/upioai/wiki@d6c3a57ee99127e02372a82f32c58f8edcde41c5/public/akke/wuying-dm'
foreach($f in 'douyin_dm_web_reply.py','douyin_dm_web_send_dom.py'){ Copy-Item $f "$f.bak-778" -Force -EA 0; curl.exe -fsS --retry 5 --retry-delay 2 --connect-timeout 15 -o $f "$b/$f"; '{0,-30} {1}' -f $f,(Get-Item $f).Length }
# 3) 核对字节数：reply=4373  send_dom=19310（不对就单独重下那个）
# 4) 重启 agent
py -u wuying_poll_agent.py
核对：douyin_dm_web_reply.py → 4373；douyin_dm_web_send_dom.py → 19310。横幅 rc=off + 你的 account。
验证（别只信文档）：重启后盯几条真实自动回复——黑窗应出 DOM 的 [sent]，若出 [reply] DOM 连不上 CDP → 回退 VL 说明 Edge 没连上，检查调试版 Edge。

04保活铁律

规矩说明
① 黑窗（agent）别关关了＝收发全停；被鼠标点一下会假死 → 按回车恢复
② 最小化的调试版 Edge 别关关了＝DOM 收发全停；别在里面导航离开抖音
③ 云电脑重启后手动重拉Edge + agent 都要重起；Cookie 15–30 天过期后重扫码
④ 一台机一个号别和手机（ADB/WDA）同号同时发，会重复打扰客户
