云电脑二次触达 · 开启指南

你的云电脑已经在自动发 DM 私信了。这份指南让它同时也自动发「二次触达」公开评论——给「我们 DM 过、≥3 天没回」的人，在他视频下留一条唤回评论。

👤 适用：跑无影云电脑的同事（每台机做一次）

0先确认（30 秒）

你这台机已经在跑 DM 自驱（开机会自动发私信）。打开 C:\akke-wuying\wuying-dm 目录，确认两个文件都在：

# 在 PowerShell 里跑，两个都返回 True 才继续
cd C:\akke-wuying\wuying-dm
Test-Path .\wuying_poll_agent.py
Test-Path .\douyin_comment_grounded.py
有一个是 False → 说明这台机的部署不全，先找开发（@Claude）补，别往下做。

1更新 agent 到「带评论支线」的新版

把最新的 wuying_poll_agent.py 更新到 C:\akke-wuying\wuying-dm\。两种方式任选：

方式 A（仓库已 clone）：在仓库里 git pull，再把 worker/scripts/wuying-dm/wuying_poll_agent.py 拷到 C:\akke-wuying\wuying-dm\ 覆盖。

方式 B（最省事）：找开发（@Claude）要一个最新版下载链接，然后：

cd C:\akke-wuying\wuying-dm
curl.exe <开发给你的链接> -o wuying_poll_agent.py
怎么确认更新对了？看第 3 步启动后的 banner——有 second_touch=on 就是新版。

2开启评论开关（改 .env）

给这台机的 .env 加一行开关（其它配置不用动，账号绑定原样保留）：

cd C:\akke-wuying\wuying-dm
Add-Content .env "`nAKKE_SECOND_TOUCH_ENABLED=1"
这行的意思：允许 agent 在发完 DM 后，再去处理二次触达评论单。不加这行，agent 只发 DM、不发评论。

3重启 agent

先停掉正在跑的旧 agent：在它的黑窗口里按 Ctrl + C。然后重新启动：

cd C:\akke-wuying\wuying-dm
python wuying_poll_agent.py
看到这一行就成功了 👇
=== wuying_poll_agent account=… every 60s claim=3 second_touch=on ===
关键是末尾 second_touch=on（之前是 off）。这个窗口别关，关了 agent 就停。
显示的还是 second_touch=off？→ 第 2 步的 .env 没加成功，或没真重启。重做第 2、3 步。

4等开发/PM 打开「自动派单」

⚙️ 这一步不是你做，是 PM / 开发在后台设（让你心里有数）

你那边 agent 开好了只是「准备好接单」。真正每小时自动派单要 PM 在 Vercel 设两个开关：

SECOND_TOUCH_AUTOSEND_ENABLED= true 开自动派单
SECOND_TOUCH_DAILY_CAP先 = 5 单号日上限，灰度从低起

没设之前，你的 agent 是空转（没单可接）。设好后它就开始自动发了。

5每次开机的老规矩（跟 DM 一样）

  • 抖音 PC 客户端：已登录本机账号、窗口最大化、在最前台。
  • 关掉浏览器里的 douyin.com 网页版——它会抢焦点，导致发送落空（实测踩过）。要用的是桌面客户端。
  • 输入法切英文（Win+空格），中文 IME 会搜错人。

6常见问题

现象原因 / 怎么办
banner 还是 second_touch=off.env 没加对 / 没真重启 → 重做第 2、3 步
日志里 [focus] …'douyin'（不是'抖音'）前台是浏览器网页版，不是桌面客户端 → 关浏览器、把客户端拉到最前台
日志 OCR 判(非主页) / 身份门不过同上，窗口焦点不对；或这条搜不到人，会自动跳过，不影响别的
开着但一直不发评论① PM 还没开自动派单（第 4 步）；② 今天评论额度满了，到点自动续，正常
不确定有没有发出去「已点发送」只代表点了发送键，实发以抖音评论区气泡为准，去那条视频翻评论核对

7要知道的两件事

① 发的是公开评论，内容带「加微信 / 报价」。这是营销话术贴在对方视频评论区，抖音可能删评 / 折叠 / 严重时封号——而且会连带封掉同一个号的 DM 自驱。所以先小量灰度（日上限 5 起），发完去抽查评论用另一个号 / 无痕看是否还在（自己账号永远看得见，不算数）。有异常立刻告诉 PM。

② 评论和 DM 用同一个号、共享活跃额度。今天 DM 发多了，二次触达当天就会少发，这是设计内的，别奇怪。
一句话：更新 agent → .env 加 AKKE_SECOND_TOUCH_ENABLED=1 → 重启看到 second_touch=on → 等 PM 开自动派单。
