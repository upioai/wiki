B2企业大脑为什么调序（08-19 拍板）

调序前后

  • 线上现在：历史上传文件 → 企业大脑全景 → 上传资料 → 待我选择 → 处理冲突 → 版本与发布。 点「4 企业大脑」落在历史上传文件——一个纯回看的屏。
  • 本版改成：上传资料 → 待我选择 → 处理冲突 → 版本与发布 → 企业大脑全景 → 月度实战手册 → 历史上传文件。 按进料 → 加工 → 出料 → 回看排，落地屏变成上传资料。
  • 顺带修正：文档处理详情在线上是详情页（不在侧栏），从上传资料点进去。 上一版我把它当成 4.1 的一项摆在侧栏，是错的，已挪到「详情页」那一组。

还没定的一点：企微那边有一张显式的落地屏表（点模块直接落到「每天真要动手的那件事」＝抽检聊天）。 企业大脑要不要照做——有冲突待拍板时直接落到「处理冲突」？现在是按缺省规则落 4.1.1（＝上传资料）。这条留着，等你定。

C刻意没做的

这几样竞品有、我们这一版不做

  • 播放量 / 点赞 / 涨粉 / 主页访客：后台没有 content_posts 只存视频链接，没有回流指标列，抖音开放接口也不给。要显示得先在 Akke 侧加抓取和建表。
  • 多平台矩阵（快手 / 小红书 / 视频号）：后台没有 outreach_events.channel 真实枚举只有抖音私信 / 评论区回复 / 企业微信 / 图文 / 发布视频 / 量房券 / 海报 / 转人工八个。
  • 粘链接直接生成对标成片：我方判定变量太多、不保证复刻输出，只做到「拆解入池」。
  • 抖音 POI 门店挂载：值得排期评估，但不在这一版里，免得同事以为已排上。

怎么用这份原型 · 提意见的办法

这个页面没有评论功能（08-19 实测确认，不是没找到）。所以改用编号：
  • 每一块卡片和说明框的右上角都有一个编号，像 1.1.1-4、总览-3，点一下会整段选中，方便复制。
  • 在 Lark 里把意见写成「编号 + 想改成什么 + 为什么」，例如：2.1.0-3 AI 面板那四个格子，成交概率我们算不出来，去掉。
  • 饭粒把这些意见汇总给 Claude，改完还是这条链接，不换地址；版本记录里能翻到改了哪一版。
