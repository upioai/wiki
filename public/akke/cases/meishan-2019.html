模块 2 · 内容分析 触发评论 · LLM 评分 78 · 破冰 + 拆异议

一句「你做不」是极简购买信号，一句「太远了，谢谢」才是真正的战场

内容侧由评分模型 + 破冰话术 + 拆异议跟进三块共同决定。客户的评论很短，但跟进的回复（#2）才是这条 lead 的内容硬骨头 — 它把"距离异议"和"清水房黄金期"同时摆上桌。

2.1 触发评论 · 极简但明确的购买问句

在曾师傅装修日记（号源池里一位偏「业主日记」内容的本地装修号）发的水电施工视频底下，这位昵称「2019.8.11---9.17」的客户只打了 8 个字：「师傅，眉山的房子你做不」。看似随手一问，但它暴露了三件事：①有一套具体的房子（不是泛泛刷视频）；②房子在四川眉山（自带地理坐标）；③他在主动筛选能不能做的服务商 — 这是装修流量里典型的"问购"信号，只是问得极简。

客户问的是"能不能做"，破冰（#1）就该先把这个问号填平，再借视频主题（水电）建立专业感，最后用一个低门槛反问把对话往下推。

破冰文案 · "先答能做型"变体
当客户的核心评论就是一个能不能做的封闭问句，破冰策略不是绕开它问参数，而是先把"能做"两个字明确说出来（眉山 = 客户房子所在四川，号源也是本地装修号，承接逻辑成立），再用"几室几厅"这种最低门槛反问推进。这一拍打得没毛病。问题出在下一拍 — 客户没接户型，而是抛出了一个我方没预判的距离异议。

2.4 跟进文案 · 一次性拆"太远" + 借清水房 + 抛软钩

客户的回复（#2）是教科书级的"礼貌冷拒"：「我的是清水房，你 IP 浙江的，太远了，不方便。谢谢！」 — 一句话三个信号叠在一起：①透露清水房（开工黄金期）；②指出我方 IP 浙江（距离质疑）；③用"谢谢"礼貌收尾（婉拒姿态）。跟进（#3）必须在不逼单的前提下，把"太远"这个唯一的拒绝理由拆掉，同时把客户自己漏出来的"清水房"借成推进时机。

模块 4 · 地区分析 三层地区信号 · 海外 IP × 四川房产 × 我方称本地

这是一条三方地理坐标全都错位的 lead

模块 5 · 价格分析 本案对话未报价

全程没有出现任何价格话术

本案的破冰（#1）和跟进（#3）都没有给出任何报价 — 既没有总价、单价，也没有计价方式。原因合理：客户连户型都还没给，对话还卡在"能不能做、要不要继续聊"的破冰/拆异议阶段，此时主动抛价反而会把焦点从"信任"拽到"贵不贵"，得不偿失。

价格模块 · 本案跳过
据实记录：本案对话未涉及价格话术 — 模块跳过。#3 抛出的是"免费出个方案"这种零价格承诺的软钩，刻意把价格话题往后推 — 先用免费方案换取加微/留资，等拿到户型和需求后再谈钱。在"礼貌冷拒"的语境下不报价是对的：客户此刻的顾虑是"远不远、靠不靠谱"，不是"多少钱"，过早报价等于答非所问。

这条"礼貌冷拒"哪里接住了，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。这是一条客户已明确表态"嫌远"的悬而未决 lead，复盘重点是异议接得好不好，而不是有没有成交。

模块 1

时效性 · 触达 9 分钟 / 首响 19h41m

GOOD
✓ 做到位
  • 触达极快：评论到首条 DM 约 9 分钟，远在用户记忆鲜度窗口内。
  • 跟进接得稳：客户回复后 24 分钟内拆异议跟上（#3），没掉节奏。
✗ 不足
  • 首响 19h41m 不可控：客户人在海外作息错峰，这段无法压缩 — 只能靠话术一次到位弥补。
  • 建议：海外 IP lead 应自动放宽跟进窗口，避免国内时段反复追打打扰。
模块 2

内容 · 破冰 + 拆"距离异议"

GOOD
✓ 做到位
  • 破冰先答"能做"：直接填平客户的封闭问句，再低门槛反问户型。
  • 拆异议教科书级：客户唯一的拒绝理由"太远"被正面拆掉（全国→本地团队）。
  • 借清水房时机：把客户在拒绝语境里漏出的"清水房"反转成"定柜体黄金期"推进理由。
  • 全程不逼单：软钩"免费方案、定不定都不亏"降低门槛。
✗ 不足
  • 破冰没预判距离异议：客户 IP 海外 + 房在眉山，本可在破冰就先发制人提"本地团队"，少绕一拍。
  • #3 信息量偏大：一口气塞了拆异议+时机+软钩三件事，对海外慢回应客户合理，但有被略读风险。
模块 3

账号信任度 · IP 浙江成异议导火索

BAD
✓ 做到位
  • 身份方向对：一筑·全屋定制是装修号该有的样子。
✗ 不足
  • IP 浙江直接被客户当距离证据：客户在 #2 点名"你IP浙江的"，账号属地反成扣分项。
  • 无眉山/四川本地佐证：话术声称"本地团队"却没有任何主页本地案例支撑，异议拆得不彻底。
  • 主页画像未抓取：粉丝/作品/获赞均缺，需运营截图补数。
  • 本周建议：补一条眉山/四川本地落地案例置顶，加微后立刻发本地师傅工地实拍。
模块 4

地区 · 三层坐标全错位

MID
✓ 做到位
  • 识别出房产坐标：从评论文本抓到"眉山"，话术正确锚到房子所在地而非客户 IP。
  • 用本地团队重新对齐：把"浙江↔海外"的错位强行拉回"眉山本地"。
✗ 不足
  • 同城徽章未触发：号源服务市未入库 + 客户 IP 海外，is_same_city = null，本地化全靠人工话术。
  • 海外 IP 未被系统特殊标注：作息错峰、距离敏感这类海外特征没进策略，靠运营经验兜。
  • 建议：号源 source_accounts.city 补录；海外 IP lead 打专属跟进策略标。
模块 5

价格 · 本案未报价

GOOD
✓ 做到位
  • 不报价是对的：客户顾虑是"远不远、靠不靠谱"，不是"多少钱"，过早报价等于答非所问。
  • 用免费方案替代价格：零价格软钩把谈钱往后推，先换加微/留资。
✗ 不足
  • 缺价格预案：客户一旦接受本地团队、追问"眉山做大概多少钱"，目前没有预置的眉山本地口径报价。
  • 建议：备好"眉山本地全屋柜体"的报价区间，应对客户从异议转向问价那一拍。
模块 6

信息流转 · 本地→云电脑

MID
✓ 做到位
  • 三条消息全回写：破冰+客户回复+跟进都进了 messages 表，对话链路完整可追。
  • 云电脑迁移路径清晰：5 步拆解都能落到具体技术点。
✗ 不足
  • 子通道字段未入库：ADB / WDA 走的哪条没在 DB 留痕，事后审计要靠 grep 代码。
  • 云电脑仍是规划态：5 步迁移已画，实际未跑通；指纹和登录态风险未验证。
