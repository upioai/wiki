模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 一轮跟进

破冰引了视频里的具体数字，跟进给了一个他没想到的漏算项

客户全程只贡献了 2 个字 + 1 张图，所有的推进力都来自 AI 这一侧的两条消息。这两条写得都很扎实：破冰引用了视频里的具体案例（13w 四房两厅现代风），跟进抛出了一个他不会想到的成本陷阱（吊柜层板和五金最易漏算）。这是本批「用专业细节换联系方式」跑通得最利落的一次。

2.1 触发评论 · 8 个字，但意图非常干净

「可以给我发一份清单嘛」— 这句话短，但每个字都指向同一件事：①他要的是清单，不是问价、不是看热闹；②「发给我」是索取动作，意味着他默认自己会留下一个能接收的通道；③句尾的「嘛」把语气放软了 — 这是一个知道自己在麻烦别人、并且愿意配合的人。比起「多少钱一平」，这种索取型评论的转化路径其实更短：他已经想好要什么了，你只需要告诉他去哪儿拿。

78 分卡在中意向的上沿。扣分点在 specificity — 他没说户型、没说面积、没说预算，系统只能判「一般」。但结果证明这条评论被低估了：从评论到交出微信只用了 38 分钟，是本批最快的一条。「极简索取型」评论（来一份 / 发我一份 / 求清单）的共同特征是 specificity 天然偏低，但转化摩擦也天然最小 — 建议对这一类做单独回测，看是否值得在评分上给一个「索取动作」加分项。

2.3 破冰文案 · 引用视频里的真实数字

首条 AI DM 在 transcript（#1）。它的结构是标准的四段式，但第 ② 段有一个别的案例没做到的动作 — 引用了视频内容里的具体数字。

① 称呼
直呼昵称，不群发感
「你好，誓水怜心」
② 场景锚点
引用视频里的真实案例参数
「刷到你关注那套13w 四房两厅的现代风案例」
③ 兑现承诺
正面回应他要的东西
「清单我整理好发你」
④ 单一反问
一个只需两个字就能答的问题
「你家是新房还是翻新？」
「13w 四房两厅现代风」这一句，是这条破冰跟群发消息的分界线
同批很多破冰写的是「刷到你关注装修的视频」— 这种句子放在任何一条评论下都成立，客户一眼就知道是模板。本案写的是「那套 13w 四房两厅的现代风案例」，这是只有真的看过那条视频才写得出来的句子，客户读到时的第一反应是「他确实看了我在看的东西」。
第 ④ 步的反问也设计得很省力：「新房还是翻新」是一道二选一，回答成本只有两个字。客户果然就回了两个字。破冰阶段的反问，问题越好答，回复率越高 — 不要在第一条就问「你家多大面积、什么户型、预算多少」。

2.4 跟进 · 一个成本陷阱换一张二维码

客户只回了「新房」两个字，信息量几乎为零。跟进（#3）在这两个字上做了四件事：①抛专业细节 —「吊柜层板和五金最易漏算」，这是一个他大概率没想过、但一想就会紧张的点；②给相对价格锚 —「工厂直供比门店低」；③留活口 —「具体看户型才能给准」，为后面要资料铺路；④解释摩擦 —「整份带图表格，抖音发不了文件」，把「为什么非要加微信」这件事说成了平台限制，而不是销售套路。

「抖音发不了文件」是本批复用率最高、也最有效的一句摩擦解释
要微信这个动作天然让人警惕 — 除非你能给出一个不是为了推销的理由。「整份是带图的表格，抖音发不了文件」把索取行为的动机从「我想加你」偷换成了「平台不支持，不然我早发你了」。客户不需要信任你，只需要相信抖音确实发不了文件 — 而这是事实。
本案的结果非常直接：28 分钟后，客户没有报号，而是直接甩了一张二维码。这比报号更进一步 — 报号还需要销售手动搜索、还可能打错字；二维码是长按就能加。客户选择了对他自己最省事的给法，说明他此刻的配合意愿是高的。
不足 · 二维码来了以后，AI 一句话都没说
#4 之后，对话就停住了 — 客户交出了联系方式，却没有收到任何确认。这是本案唯一的内容缺口，而且是最不该缺的一句。
客户给完微信的那几分钟，是他心理上最紧张的时刻（我刚把联系方式给了一个陌生人，接下来会怎样）。此时一句「收到啦，我让设计师今天加你，备注小星就行」的成本是零，收益是把「等待未知」变成「等待一件确定的事」。本周建议：在 DM 侧加一条确定性应答 — 一旦客户消息里出现微信号 / 手机号 / 二维码图片，立刻回一句固定的收尾话术并置顶提醒运营，不要让客户对着空气等。

模块 4 · 地区分析 抖音 IP 山西 · 微信二维码显示广东深圳

抖音说他在山西，微信名片说他在深圳

Akke 的地区信号分三层：客户 IP 属地（省）、自报现居（市）、号源服务市。本案只拿到省级 — 山西。但客户交出的那张二维码上，微信名片的地区标注是「广东 深圳」。这是本批第一例「跨平台地区信号冲突」，而且直接影响销售接下来怎么开口。

加微之前必须先问清楚：房子在山西还是在深圳
微信名片写「广东 深圳」，抖音 IP 显示山西。常见解释有三种：①人在深圳工作，山西是老家 / 出差临时 IP；②微信地区是多年前随手填的、早就不准；③抖音 IP 是当次网络出口，跟常住地无关。无论哪种，都意味着我们现在不知道这套「新房」在哪个省。
这件事的代价很实在：全屋定制的报价、安装排期、能不能派本地设计师上门量房，全都取决于房子在哪里。销售如果一上来就按老思路说「我们本地仓」「安排师傅上门」，一旦地点判断错，第一句话就翻车。
本周建议：加微后的第一句话固定加一个地点确认 — 「房子是在山西还是深圳？我按当地的仓和安装队给你算」。把地区冲突当成一个自然的开场话题，而不是一个要藏起来的问题。
顺带说一句：本案破冰完全没提地区，这是对的
#1 和 #3 都没有出现任何省市名。在只有省级 IP、且这个省级 IP 本身就可能不准的情况下，不提地区是最稳的选择 — 对照本批另一条案例对山西客户说「成都这边我见过不少客户翻车」的翻车现场，本案的克制反而避开了一个雷。号源「苏等等的家」的 city 字段仍是空的，补录它能同时解掉同城判定和本地话术两件事。
模块 5 · 价格分析 零绝对数字 · 一个相对锚 + 一个漏算项

没报一个价，但把「便宜」和「怕多花钱」都说到了

两条 AI 消息里没有出现任何一个单价、总价或折扣数字。唯一沾价格的两处，一处是相对锚（工厂直供比门店低），一处是成本焦虑（吊柜层板和五金最易漏算）。破冰里那个「13w」是视频案例的参数，不是给这位客户的报价 — 这个区分很重要。

全屋定制的报价单是出了名的看不懂 — 同样一套柜子，A 家报 5 万、B 家报 6 万，差的往往不是单价，而是B 家把层板、五金、见光板都算进去了，A 家等你签了合同再补。「吊柜层板和五金最易漏算」这句话，等于告诉客户：我知道你担心什么，而且我懂到能说出具体是哪两项。
这比「我们很便宜」有效得多。说便宜是在跟所有同行比价，说漏算是在把自己放到客户这一边。而且它天然导向下一步 — 要看完整清单，就得留个能收表格的地方。
风险 · 「工厂直供比门店低」是一张迟早要兑现的空头支票
客户现在信了这句话才给的微信。销售加上他之后，如果实际报价并没有明显低于他问过的门店，这句话就变成了一个减分项 — 客户会觉得「说好的直供呢」。
更麻烦的是「低多少」完全没有口径：低 5% 和低 30% 是两回事。本周建议：交接给销售时，把 DM 里说过的每一句价格承诺原样带过去（本案是「工厂直供比门店低」+「吊柜层板五金不漏算」两条），让销售第一版报价至少在这两点上兑现得了。对照本批那些破冰就报「568 一平」却没说按投影还是展开面积的案例，本案至少没有把自己钉死在一个数字上。
模块 6 · 信息内部流转路径 云电脑通道 · 4/4 条入库，但关键内容丢在图片里

② 加一条兜底规则 — 只要客户消息包含图片或疑似联系方式，立刻把会话标成 pending_handoff 并停掉一切自动跟进，宁可漏跟进，也不能对已经给了微信的人再催一遍。

复盘 · 各模块做到位 / 不足

这条链路哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案前五个模块几乎无可挑剔，短板集中在最后一米 — 拿到微信之后，系统和人都没接住。

模块 1

时效性 · 凌晨全速，38 分钟走完全程

GOOD
✓ 做到位
  • 评论 → 破冰 3 分 42 秒：01:36:43 评论，01:40:25 送达，凌晨时段无衰减。
  • 首响 3 分 17 秒：破冰到达时客户还在刷同一条视频，记忆零损耗、无需唤醒。
  • 二轮跟进 2 分 23 秒：客户回「新房」后立刻接住，没有让他等。
  • 38 分钟拿到联系方式：本批最快的一条完整转化链。
✗ 不足
  • 客户交出二维码后，响应时效变成了无穷大：02:14 至今没有任何回应，前面攒下的速度优势在最后一步全部吐回去。
  • 本周建议：把「客户给出联系方式」当成一个需要秒回的事件，而不是一条普通消息 — 至少自动回一句确认。
模块 2

内容 · 视频细节 + 漏算恐惧 + 平台限制，三步换来二维码

GOOD
✓ 做到位
  • 破冰引用视频真实参数：「那套 13w 四房两厅的现代风案例」— 只有真看过才写得出，一句话把群发感洗掉。
  • 反问设计得极省力：「新房还是翻新」两个字就能答，客户果然只回了两个字。
  • 跟进抛的是「漏算」不是「便宜」：吊柜层板 + 五金，指向报价单完整性这个真痛点，把自己放到客户一边。
  • 「抖音发不了文件」摩擦解释生效：把要微信的动机从「我想加你」换成「平台不支持」，28 分钟后客户直接甩码。
✗ 不足
  • 拿到二维码后零回应：客户刚交出联系方式那几分钟心理最紧张，一句「收到，我让设计师今天加你，备注小星」成本为零却没有发。
  • 本周建议：DM 侧加确定性应答 — 客户消息命中微信号 / 手机号 / 图片时，立刻回固定收尾话术并提醒运营。
模块 3

账号信任度 · 过关了，但不知道靠什么过的

MID
✓ 做到位
  • 客户全程没查户口：没问「你哪家公司」「有没有门店」，直接给了微信。
  • 对话内持续背书：每条 AI 消息带「小星·全屋定制」金色徽章。
  • 账号健康：active、连续失败 0、日配额 30 条仅用 1 条，产能不是瓶颈。
✗ 不足
  • 粉丝数 / 作品数 / 播放量在 DB 里全空：客户沉默的 28 分钟大概率在看主页，而我们对他看到了什么一无所知。
  • 说不清成功归因：这次过关到底是靠主页扛住了，还是他压根没看，无法判断。
  • 本周建议：运营补一次「小星·全屋定制」主页截图入库 — 这是全批反复出现的同一个缺口。
模块 4

地区 · 抖音说山西，微信名片说深圳

MID
✓ 做到位
  • 话术完全不提地区：在只有省级 IP 且 IP 本身可能不准时，不提是最稳的选择，避开了「对山西人说成都经验」那类翻车。
  • 二维码意外补了一层信号：微信名片的「广东 深圳」是抖音侧拿不到的信息。
✗ 不足
  • 两个平台地区冲突且无人判定：抖音 IP 山西 vs 微信名片深圳，房子到底在哪没人知道 — 而报价、安装、量房全都取决于这个。
  • 市级两端全缺：客户市未公开 + 号源「苏等等的家」city 未入库 → is_same_city = null，本地仓 / 本地安装队这张牌打不出来。
  • 本周建议：加微第一句固定带一个地点确认「房子在山西还是深圳，我按当地的仓和安装队算」；同时补录号源城市字段。
模块 5

价格 · 零数字，但「怕漏算」这一刀切得准

GOOD
✓ 做到位
  • 全程零绝对报价：没有把自己钉死在任何一个数字上，对照本批「破冰即报 568/㎡ 却没说投影还是展开」的口径悬空风险，本案没这个坑。
  • 「层板五金最易漏算」比「我们便宜」高明：说便宜是跟同行比价，说漏算是站到客户一边，且天然导向「要看完整清单」。
  • 相对锚 + 留活口配合得当：「工厂直供比门店低」后面紧跟「具体看户型才能给准」。
✗ 不足
  • 「比门店低」是一张迟早要兑现的支票：低 5% 和低 30% 是两回事，销售第一版报价如果没体现出来，这句话反成减分项。
  • 本周建议：交接销售时把 DM 里说过的价格承诺原样带过去，让第一版报价至少在「直供价 + 不漏算层板五金」这两点上兑现得了。
模块 6

信息流转 · 条数满分，最关键那条等于没存

BAD
✓ 做到位
  • 回写 4/4 条不丢条：聊天页里几条，DB 里就是几条。
  • 通道有硬证据：channel_pref = cloud_pc，云电脑 GUI 自动化，≥30 秒/条节流，队列零报错。
✗ 不足
  • 微信二维码在 DB 里只是 [图片]：本案最有价值的那条消息，内容等于没存 — 二维码、微信昵称、地区全在运营截图里。
  • 系统认为这单还没成：stage = ice_break、handed_off_at = null，转化最好的一条在系统眼里和死单没区别。
  • 存在二次骚扰风险：自动跟进 / 二次触达若命中他，会在他已经给了微信之后再催一次微信，前面的专业感当场崩掉。
  • 本周建议：①客户图片过一遍 VL 读图，识别出二维码 / 名片 / 户型图就写进 content；②客户消息含图片或疑似联系方式时自动标 pending_handoff 并停掉所有自动跟进。
