3.4 跟进文案 · 风格菜单 + 同小区锚 + 效果图钩微信

跟进链在 transcript（#3 / #5）。客户问风格后，AI 三步走：①给风格菜单「现代简约/意式轻奢/新中式/北欧原木/法式奶油都做过整套」显示品类齐；②同小区社区锚「上周才交房一套和你同小区的、同款冷调意式、见光板倒角特别出片」—— 用最近、最本地、最具体的案例建立信任；③客户要效果图后，用"抖音图压糊、发不全"钩微信，诱因是"整套效果图+同小区实拍打包发你"。

"同小区实拍"是比通用案例强十倍的钩子
跟进里最亮的一笔是 "上周才交房一套和你同小区的" —— 同小区 = 户型相似 + 眼见为实 + 邻里背书，是全屋定制里最强的社会证明。加微钩子也顺势绑在它上面："整套效果图 + 同小区那套实拍打包发你"，让客户觉得加微信是为了拿到"专属于我这个小区"的东西，而不是被推销。friction 降到很低，客户主动要效果图正是被这套逻辑推着走。

风险 · "按平方算"是锚不是最终价
"全屋柜体按平方算 284 一平"是行业常见的引流报价 —— 按房屋建筑面积算的套餐价，实际成交往往因展开面积、板材升级、五金配置、造型工艺而显著上浮。加微后销售必须第一时间把口径讲透（这个价含什么、不含什么、怎么最终报量），否则客户拿着"284"的预期、看到真实报价会有落差，反而伤转化。给销售预置一份"284 起 → 实际报量"的解释话术是必需的。

复盘 · 各模块做到位 / 不足

这个项目哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案整体推进最顺，亮点在报价与同小区锚。

模块 1

时效性 · 评论→触达 ~5 分

GOOD
✓ 做到位
  • ~4m41s 触达：高意向 + urgent 问价，秒级把带报价的破冰送到。
  • 首条即报价：把客户唯一的问题"多少钱"在第一条就答了。
✗ 不足
  • 首响隔了 53 分：触达后客户 16:13 才回，确认环节不可控。
  • 建议：把这条自动链路稳定性常态化，速度已达标。
模块 2

内容 · 敢报价 + 同小区锚

GOOD
✓ 做到位
  • 破冰敢报价：直接给 284/平口径，避免"加微才告诉你"的套路感。
  • 同小区实拍是最强钩子："上周才交房一套和你同小区的"，社会证明拉满。
  • 加微钩子绑在实拍上：让加微像拿"专属素材"而非被推销。
✗ 不足
  • "同小区"须能兑现：若无真素材，加微后露馅反噬信任。
  • 建议："同小区/同款"话术要有可交付的实拍库支撑。
模块 3

账号信任度 · 有大有小

BAD
✓ 做到位
  • 本案信任没暴露：客户没去搜品牌，靠"同小区实拍"撑住。
✗ 不足
  • 账号资产全空白：简介/头像/获赞/粉丝/作品全未抓取。
  • 没暴露是运气：一旦客户加微前去搜"有大有小"，可能重蹈 kio 鱼"搜不出来"。
  • 本周建议：补主页资产 + 可搜官方落点 + 全屋定制人设。
模块 4

地区 · 打到"小区"级

GOOD
✓ 做到位
  • 小区级落地："上周才交房一套和你同小区的"，比省/市级更狠的社会证明。
  • 加微诱因绑本地实拍：把地区信号转成加微动力。
✗ 不足
  • 省级/同城徽章未用：贵州未显式提、号源 city 未入库。
  • "同小区"需真实：作通用话术有露馅风险，需素材兜底。
模块 5

价格 · 破冰即报价 284/平

GOOD
✓ 做到位
  • 敢报价：对直接问价的高意向客户，第一条就给口径 = 最优解。
  • 284/平是好引流锚：足够低、能勾兴趣，把客户从问价带到看图。
✗ 不足
  • "按平方算"是锚不是终价：实际展开面积/升级易上浮，落差伤转化。
  • 本周建议：给销售预置"284 起 → 实际报量"的口径解释话术。
模块 6

信息流转 · capture 回写漏 + draft 错位

BAD
✓ 做到位
  • opener 链路自动可追：抓取→评分→起草→派单→触达全程走自动链。
✗ 不足
  • 5 条只入库 4 行：客户要效果图 + AI 钩微信全漏，DB stage 失真。
  • opener draft/sent 错位：一条更长 draft 未发、实发靠 followup 位补。
