复盘 · 这条例外触达教会我们的

5 个可复用的话术 / 策略原则

1
分数 0 不等于不发。intent_reason 的「非业务品类」是按视频话题判定的（视频是瓷砖 → 判定柜体不相关），但客户在装修内容下问价 = 装修周期信号。运营有权基于评论语气 + 客户行为做策略性反规则触达。
2
视频跑题时跳过 §② video-hook。常规破冰会复述视频细节建立「我懂你」感，但本案视频不在业务边界 — 强行复述「这个瓷砖」会暴露答非所问。qwen3 学到的处理：跳过视频钩子，直接「IP 共情 → 业务锚价 → 反问」三段。
3
IP 共情是分数 0 时唯一的归属感杠杆。没有视频细节可复述、没有自报市级地名时，「广西南方梅雨季潮气重」是 LLM 能掏出的最稳的共情材料。SOUTH_WET / NORTH_DRY / SW_MOUNT 三档对应不同省份各自的标准模板 — 是「省级 NULL fallback」的护城河。
4
反问要给户型，不要给价格。「你家几室几厅？」让客户在最低成本下 disclose 户型信息。一旦她回答 — 就把分数 0 的标签彻底翻盘成「在装修中的具体客户」。比「您考虑下我们的方案吧？」回复率高 N 倍。
5
诚实当下状态 ≠ 案例没看头。本页 ACT 05/06 全部留白、status-pulse 是黄不是绿 — 这才是真实。例外触达的价值不在「100% 转化炫耀」，在于把「分数 0 也能尝试」的决策路径留下证据，下次类似 lead 来时有参考。
