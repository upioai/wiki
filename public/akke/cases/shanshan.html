模块 5 · 价格分析 「500 多一平 + 比门店省好几千」 · 价格锚 + 对比锚

「500 多一平 + 比门店省好几千」 · 价格锚 + 对比锚双重组合

客户问"多少一平方"，opener（#1）直接落"500 多一平"，并加了"大牌 ENF 级板材全包 比门店省好几千"——这是 Akke 报价话术里的价格锚 + 对比锚组合：先给数字，再给参照系。

"价格 + 质量 + 对比"三锚组合的优势
问价类客户最容易陷入"贵不贵"的孤立判断，三锚组合给客户三个心理参考点：①是不是市场价（500 多）；②质量是不是垫底（ENF 级）；③跟同类比贵还是便宜（省好几千）。三件事一起说让客户的预算判断有支撑，比单独报"500 多"信息密度高一倍。
风险 · 三锚 + 紧迫词混搭把营销味推满
"比门店省好几千" + "这月排单快满了" 同时出现，营销味过满：客户大概率把"省好几千"判定为话术、"排单快满"判定为催单——两件事互相强化营销感。如果只保留价格锚 + 质量锚 + 地区话术（删掉对比锚的模糊"好几千" + 紧迫词），破冰可能更稳。
建议：对比锚要么给具体数字（"门店同款 800 一平，我们 500 多"），要么不给（让客户自己问）。模糊的"省好几千"反而不可信。
