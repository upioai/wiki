这是本案最亮的一环。客户源自同行装修号、评论只有「可以给我一份清单吗」，破冰没有直接甩清单了事，而是顺着视频里的「四房两厅」问户型。客户一句「但是我想整3室」把真实需求纠了出来，跟进 #3 顺着三室认同 + 问面积 + 递同户型实拍，没有僵在四房、也没跳步。全程未报价。

2.1 触发评论 · 极简买家信号

在「苏等等的家」这个同行装修号的四房两厅视频底下，她只留了「可以给我一份清单吗」。这是抖音全屋定制里最典型的「求清单 / 求资料」极简购买信号 — 不啰嗦、直接要东西，通常是准备装修、正在收集参考的阶段。系统据此判成 product、active，78 分中意向。

2.3 破冰文案 · 顺视频问户型，全程零报价

2.4 跟进 · 接住「三室」纠偏，认同 + 问面积 + 递实拍

跟进的关键动作：不僵在四房，顺着客户的三室往下接
#3 是本案成败点，做得很稳：客户纠偏「三室」，跟进第一句就顺着认同「3室更省心了，空间利用率也能拉满」 — 没有为了推销原视频的四房去劝她、也没有无视纠偏继续甩四房清单。接着抛出「你家面积多大？我好给你算个准数」这个推进性问句，最后承诺「同户型的实拍方案一起发你」把兑现物再夯一遍。这一步把客户的主动纠偏转成了「一起把三室方案做实」的协作姿态。可拧紧的地方：#3 问面积很对，但也可以顺手确认一句「三室是打算全屋定制、还是先看柜体」，把意图颗粒度再拉细一档 — 目前意图停在户型，还没到用途 / 预算。本周建议：客户回面积后，第一时间递上三室同户型实拍兑现「实拍方案」的承诺，别让 #3 的钩子空转。

这条案例哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案的关键正例在破冰逼出客户纠偏、跟进顺着三室接住。

模块 1

时效性 · 8 分钟破冰 · 同一晚跑完三跳

GOOD
✓ 做到位
  • 8 分 17 秒首触达：入库 1m59s + 破冰 6m18s，两跳分钟级。
  • 整条同晚跑完：#2 破冰后 8m53s 回、#3 又 1m49s 接住，3 跳 19 分钟内无隔夜。
✗ 不足
  • #3 之后客户未回：待客户回面积，属客户侧决策节奏，我方无从提速。
模块 2

内容 · 破冰逼出纠偏 · 跟进接住三室

GOOD
✓ 做到位
  • 破冰顺视频锚户型：用「四房两厅」引出「你家几室几厅」，逼出客户「但是我想整3室」的主动纠偏。
  • 跟进接住纠偏：#3 顺着三室认同「3室更省心」+ 问面积 + 递同户型实拍，不僵在四房。
✗ 不足
  • 意图颗粒度未拉细：#3 问了面积，但没顺手确认「全屋定制 / 先看柜体」，意图停在户型。
  • 本周建议：客户回面积后补一句用途 / 预算的确认。
模块 3

账号信任度 · 够聊需求 · 底盘未补

MID
✓ 做到位
  • 客户没查身份就纠偏聊需求：话术专业感完成了到「说清三室需求」为止的背书。
✗ 不足
  • 发送号资产未抓：客户聊到给不给微信时可能回头看「文哥」主页，主页厚度是未知数。
  • 本周建议：趁客户还在对话里，补「文哥」主页截图落数。
模块 4

地区 · 辽宁省级未用 · 同行号无同城

MID
✓ 做到位
  • 省级不硬塞是对的：辽宁粒度太粗，opener 没提是合理的。
✗ 不足
  • 市未自报 + 同行号无同城：服务市未标，is_same_city = null。
  • 辽宁承接口径未备：推进到加微时「我这边能不能做」几乎必问，答不上会把已说清需求的中意向聊凉。
  • 本周建议：交接 SOP 里加地区承接一栏。
模块 5

价格 · 全程不报价 · 先问面积到位

GOOD
✓ 做到位
  • 破冰到接住纠偏零报价：三室面积未落地前不抛价，避开推销感。
  • #3 用「你家面积多大」铺垫：为后续报价埋了准数的钩子，节奏对。
✗ 不足
  • 兑现压力压在下一跳：客户回面积后要立刻给三室粗报价 + 同户型实拍，给不出会掉温。
  • 本周建议：备好「三室按面积区间粗报价 + 同户型实拍」承接素材。
模块 6

信息流转 · 3 条全回写 · 接住纠偏

GOOD
✓ 做到位
  • 回写完整：opener + 客户纠偏 + 跟进共 3 条全入库，客户「三室」在 #2 落库，无漏。
  • 接住纠偏：跟进顺着三室认同 + 问面积，自动通道不僵在原视频四房、不跳步报价。
✗ 不足
  • 推进停在等客户回：#3 抛出「你家面积多大」后客户未回，DB 抓不到后续进展。
  • 本周建议：客户回面积后及时兑现实拍，页面第 6-8 步随进展更新。
