模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 澄清文案

内容侧是评分模型 + 破冰话术生成共同决定的：客户留了什么、系统看到了什么、AI 写了什么。本案的看点是身份混淆 — 客户以为在跟号源博主旭东说话，AI 的澄清诚实但带了一句臆测，这是话术模板没吃到号源上下文的证据。

2.1 触发评论 · 一个带情绪的服务可达性问题

在旭东聊装修（号源池里类目「知识号」的全国装修知识号）的视频底下，她写下 「能不能推荐接外地[流泪][流泪]」。这条评论暴露了三件事：①核心顾虑是服务可达性 — 「接外地」说明她的项目（或她本人）不在服务商所在地，担心没人接；②两个[流泪]是情绪信号 — 找不到靠谱承接方的焦虑，配合「推荐」二字，她是在公开求一个可信的入口；③无面积、无预算、无城市 — 还在调研早期，变量全空。意愿有、变量空，这也是它拿 78 分（中意向）而非更高的原因。

2.4 跟进文案 · 澄清身份，诚实但带了一句臆测

跟进 DM 在 transcript（#3）。客户问「你是旭东？」（#2）后，AI 3 分钟内回应，做对了两件事：①不冒充 — 直接「不是哈」，没有顺着客户的误认去蹭旭东的信任；②给出身份 + 反问来源 — 自报「我叫小艳」，反问「你是不是在哪个案例里看到他了」把对话续上。

两处硬伤 · 臆测 + 品牌口径待核
①「旭东可能是设计师那边的同事名字」是一句臆测 — 旭东其实就是她留评那条视频的号源博主「旭东聊装修」，这个上下文就在 lead 数据里，AI 本可直接答"旭东是那位博主哈，我们是承接咨询的定制顾问"，一句话收掉疑虑；现在的猜测反而显得发信方连自己的来路都说不清。②自称「有大有小的定制顾问」— 但发送号「文哥」的抖音展示号名称待运营确认（见模块 3），若客户点开头像看到的号名不是「有大有小」，等于在身份已被质疑的对话里再叠一层口径不一致。

模块 1

时效性 · 3 分钟首触 + 3 分钟澄清

GOOD
✓ 做到位
  • 评论后 3 分钟破冰：11:43 评论 → 11:46:50 送达，抓取+派单+发送全链路无积压。
  • 身份质疑 3 分钟接住：客户 16:35 问「你是旭东？」，AI 16:38 澄清，敏感问题没被晾着。
✗ 不足
  • 客户 4h49m 才回：这段空窗里没有自动保温动作，疑虑发酵到质疑身份。
  • 本周建议：首触后 1-2h 未读/未回时补一条软触达，压短首响。
模块 2

内容 · 先答后问对路，澄清话术带臆测

MID
✓ 做到位
  • 「接外地」正面接住：第一句给结论「当然能做」，不绕弯。
  • 共情对上情绪：「怕被踩坑见得太多」呼应两个[流泪]的焦虑。
  • 被质疑时不冒充：「不是哈，我叫小艳」— 没有蹭旭东的信任。
✗ 不足
  • 澄清带臆测：把旭东猜成「设计师那边的同事」— 他其实是号源博主，上下文就在 lead 数据里。
  • 没问项目在哪个市：客户问的就是"接外地"，最核心的地理变量反而没索取。
  • 本周建议：澄清话术模板注入号源上下文（"旭东是你留言那条视频的博主"）。
模块 3

账号信任度 · 身份混淆实锤 + 口径链断裂

BAD
✓ 做到位
  • 发送有据可查：DB 标签「文哥」+ dispatch_queue 9123637c，通道明确。
  • 被问身份时没冒充：诚实否认 + 自报姓名。
✗ 不足
  • 身份混淆已发生：客户首响就是「你是旭东？」— 不是推演，是实锤。
  • 口径链断裂：展示号待确认，话术却自称「有大有小的定制顾问」— 若号名对不上就是跨账号品牌串台。
  • 本周建议：确认文哥展示号名称、统一话术自称口径，补主页资产截图。
模块 4

地区 · 地区型评论却零地区落地

MID
✓ 做到位
  • 顾虑本体被接住：「接外地当然能做」正面回应了她唯一的问题。
  • 省级"江西"在手：IP 属地明确，足够支撑破冰不犯错。
✗ 不足
  • 裸承诺无证据：没提江西、没给外地履约案例，说服力停在口头。
  • 没索取项目城市：「接外地」方案离了城市无从谈起，两条 DM 都没问。
  • 本周建议：外地类评论破冰模板固定带「你项目在哪个市」+ 一个同省履约锚。
模块 5

价格 · 有让利锚，无数字口径

MID
✓ 做到位
  • 模糊让利开场合理：变量全空时不报具体数字，避免日后圆价。
  • 钩子位置顺：紧跟「能做」的正面回答，给出行动理由。
✗ 不足
  • 「再让一档」无口径：让多少、相对什么、活动到几号，客户一追问就现原形。
  • 信任未立先谈钱：客户首响是质疑身份，让利钩的可信度打折。
  • 本周建议：预置活动口径三件套（基准/档位/期限），等面积和城市到手再报。
