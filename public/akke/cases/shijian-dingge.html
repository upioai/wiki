模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 跟进文案

内容侧的看点是一次信号错配：客户评论「河北干活么」最强的信号是地区，破冰却绕开地区、去谈产品和需求范围；结果客户回来第一句仍是「你是哪里的」。跟进这才正面答了地区 —— 对，但晚了一步。

2.1 触发评论 · 五个字，先卡地区

在石材橱柜板材批发（号源池里类目「工厂号」的建材号）发的石英石台面 + 橱柜安装视频底下，她只写了 「河北干活么」。五个字暴露 2 件事：①地区是首要门槛 —— 她先要确认"你能不能到河北干活"，而不是问产品；②对台面 / 橱柜有真实需求 —— 在工厂号视频下问服务范围，是准备做而非围观。但面积、房型、预算、风格全无 → 系统给 medium specificity、78 分中意向。

2.4 跟进文案 · 正面答地区 + 承诺上门 + 抛案例钩微信

跟进 DM 在 transcript（#4）。客户连问「你是哪里的？河北任丘做么」后，AI 一句话四件事：①正面答「河北任丘可以做」；②给服务承诺「量尺安装都上门」；③钩微信「图发+v看着清楚」；④给价值「让设计师发你整套案例先看看」。

地区答得干脆 —— 但加微钩子抛早了半步
面对她的地区顾虑，AI「河北任丘可以做，量尺安装都上门」答得利落，直接消解门槛，这是对的。风险在后半句：客户此刻只确认了地区、还没表达深度意向，紧接着就抛「+v 看图」+「让设计师发整套案例」，加微请求略早。更稳的做法是先在 DM 里发 1–2 张任丘 / 河北同城的实拍案例建立信任，让她"看到东西"后再顺势要微信 —— 而不是在她刚放下地区戒心时就索取联系方式。这也解释了为什么 #4 之后她暂时没回。

模块 4 · 地区分析 三层地区信号 · 省 / 市 / 号源市

地区就是本案的主轴 · 客户从评论到回复都在问「能不能到任丘」

Akke 的地区信号分三层：客户 IP 属地（省）、自报现居（市）、号源服务市。本案是三层地区模块里最"名副其实"的一个 —— 客户的每一句话都在确认地区：评论「河北干活么」、回复「你是哪里的 / 河北任丘做么」。地区不是背景板，是她愿不愿意继续的开关。

地区落地 · 本案对话里的使用情况
[省级] opener（#1）没有提河北 —— 而客户评论开口就是地区，这里是最该前置地区话术却没前置的一步，直接导致客户回来还要自己问「你是哪里的」。

模块 5 · 价格分析 本案对话未涉及价格话术

不谈价 · 用「上门量尺 + 整套案例」当推进钩子

本案对话全程未出现报价、计价方式或预算话题 —— 客户问的是地区和服务范围，AI 答的是"可做 + 上门 + 发案例"。价格 friction 被后置到加微之后，所以本模块按规范跳过价格拆解，只记录这条策略选择。

不谈价是对的 · 但"整套案例"是一张必须兑现的支票
ice_break 阶段不抛价格，避免在客户还在确认地区时制造成交压力 —— 方向正确。本案用「量尺安装都上门 + 让设计师发整套案例」作为推进钩子代替价格锚，对"先看看你靠不靠谱"的谨慎客户刚好够用。风险：客户看完案例后第一波问题大概率是「任丘全屋定制 / 石英石台面大概多少钱」，销售需预置好河北任丘的报价口径与上门量尺流程，否则案例看完就凉。

复盘 · 各模块做到位 / 不足

这个项目哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案的核心教训是一条：破冰没读懂评论里最强的"地区"信号。

模块 1

时效性 · 评论→触达 5m50s

GOOD
✓ 做到位
  • 评论→触达 5m50s 达标：采集→打分→生成→派单→发送五步分钟级串完。
  • 客户回来即接住：2.5 天静默后客户首响，AI 14 分内跟进，没错过窗口。
  • 发送环节仅 18s：派单到触达几乎无延迟。
✗ 不足
  • 采集周期占 5m32s：比标杆（4m 内）慢一档，瓶颈在评论采集入库。
  • 建议：破冰内容若更戳中地区顾虑，或能缩短客户 2.5 天的静默。
模块 2

内容 · 破冰漂亮但答非所问

MID
✓ 做到位
  • 破冰结构标准：呼应产品 + 抛专业观点「细节做好了厨房才经用」+ 反问需求范围。
  • 跟进正面答地区：「河北任丘可以做，量尺安装都上门」干脆消解门槛。
  • 给了价值钩子：让设计师发整套案例，代替生硬索取。
✗ 不足
  • 破冰忽略最强信号：评论「河北干活么」问的是地区，破冰却只谈产品 → 客户回来仍问「你是哪里的」，白等 2.5 天。
  • 加微钩子抛早半步：客户刚确认地区就被要 +v，宜先发案例再要微信。
模块 3

账号信任度 · 有大有小

BAD
✓ 做到位
  • 话术顶住了这一关：客户虽谨慎，但被地区正面答复暂时留住。
✗ 不足
  • 账号资产全空白：简介/头像/获赞/粉丝/作品全未抓取，无法评估信任。
  • "有大有小"命名工具化：对反复确认"你是哪里的"的谨慎客户尤其不利。
  • 本周建议：补抓主页资产 + 简介直接写明服务区域，比话术更早打消地区顾虑。
模块 4

地区 · 本案主轴、执行偏被动

MID
✓ 做到位
  • 跟进正面答地区：客户自报任丘后，AI 立刻「河北任丘可以做 + 上门」，话术层补齐同城信任。
  • 省级信号在库：河北 IP 入库，具备前置地区话术的数据基础。
✗ 不足
  • 地区响应被动：opener 未前置地区，逼客户自己追问两次才得到答复。
  • 同城徽章无法触发：comments.city 与号源 city 双缺，任丘只存在于对话文本、不在结构化字段。
  • 本周建议：地区型评论破冰前置"XX 接过单/能上门"；补录号源 city。
模块 5

价格 · 未涉价、案例代替锚

MID
✓ 做到位
  • ice_break 不抛价：客户还在确认地区，先谈价会制造压力，方向正确。
  • 案例 + 上门量尺代替价格锚：对谨慎客户刚好够用。
✗ 不足
  • "整套案例"是必须兑现的支票：加微后销售要立刻发河北/任丘同户型案例。
  • 本周建议：预置"任丘全屋定制 / 石英石台面报价口径 + 上门量尺流程"，接住客户看完案例必问的价。
