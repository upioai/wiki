模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 一轮跟进

昵称处理得漂亮 · 但「先要后给」把人吓退了

内容侧是评分模型 + 破冰话术生成共同决定的：客户留了什么、系统看到了什么、AI 写了什么。本案在称呼处理上有一个值得单独拎出来讲的正面细节，也在索要微信的时机上暴露了全批共性的病灶。

2.1 触发评论 · 姿态最低、最干脆的一条

在灿哥聊装修的开工准备视频底下，她写下 「求手册，麻烦给发一下」。这九个字里有三件事值得注意：①一个「求」字 — 索取意愿明确到不加掩饰，不是「有吗」「怎么领」这种试探；②一个「麻烦」 — 态度客气、零讨价还价，不带任何对抗性；③诉求单一且封闭 — 她要的就是那份手册，没有附加问题、没有比价、没有质疑。
这类客户是「资料换微信」打法的理想目标：动机纯粹、门槛低、只要东西到手就愿意继续。但硬币的另一面是 — 正因为诉求单一，一旦资料迟迟不到手，她也走得最快。她要的是手册，不是聊天。给不了手册，这段关系就没有别的支点。

🏆 本案最值得复用的细节 · 从一串乱码里抠出一个能叫的名字
客户的抖音昵称是 @℘₁̶₃̶₁̶₄̶এᰔᩚ傻丫 — 花体拉丁字母、带删除线的数字、孟加拉文和梵文异体字混在一起。机器很难解析，人眼也念不出来。
破冰的处理是：只取尾部唯一可读的两个字「傻丫」，写成「你好，傻丫」。这是正确解法，理由有两条 — ①避免了把乱码原样塞进话术，那会立刻暴露"这是台机器"；②「傻丫」是整个昵称里唯一有语义的部分，也是客户自己认的那个名，叫对了反而比不叫更亲近。
归纳成可复用规则：遇到含大量符号的昵称，抽取其中可读的中文片段作称呼；抽不出可读片段就干脆不带称呼（可对照同批 .Xun 案例 — 昵称完全无法入话术，改用「你这条评论我看了几遍」的情绪开场，同样成立）。
另有一条负面对照：同批的「小龙女哥」「冷静！姐」两次靠昵称赌性别，两次翻车。本案不加任何性别称谓、只用名字，是更稳的做法。
小瑕疵 · 「几室几厅 ？」中间多了一个空格
#1 结尾是 「你家几室几厅 ？」 — 「厅」和全角问号之间多了一个空格。这是模板拼接留下的痕迹：变量槽位后面跟了固定尾串，中间的分隔符没被吃掉。
问题很小，但真实用户看得见。中文聊天里没人会在标点前打空格，这一个字符就是一处"露出机器痕迹"的细节 — 不致命，但会在潜意识里扣分。
本周建议：在话术出口做一次空格 / 标点规范化（中文字符与全角标点之间的空白一律吃掉，连续空格折叠），成本极低，一次修完全批受益。

2.4 那一轮跟进 · 钩子很好，要价太早

唯一一条跟进（#3）在结构上其实写得不差，它做了三件事：接住户型 → 抛专业钩子 → 解释为什么要微信 → 索要微信。前两步是加分项，后两步是本案的转折点。

✓ 专业钩子写得好 · 点破一个行业隐性加价项
「见光板和封边这两项很多家是单收的，清单里我把它们拆开标了」 — 这句是本案文案里最有杀伤力的一句。它没有空泛地说"我们的清单很详细"，而是点破一个具体的、客户大概率不知道的行业隐性收费项，再暗示"别人藏着，我们拆开标"。
对一个还在调研阶段的客户来说，这种信息比任何形容词都更能建立"这人是懂行的"的判断。正面评价，值得进话术库。
顺带一提：这句钩子在同批 Xu- 案例里用的是同一版，说明它已经是话术库里的标准件 — 标准件质量不错，但同一钩子在多个客户身上原样复用，本案缺少针对「三室一厅」的个性化落地（比如"三室的话主卧和次卧的柜体见光板面积差挺大"）。
💥 本案核心病灶 · 她付出了两次，一份资料都没拿到
把三条消息的结构抽出来看，是这样一条链：她要资料 → 她给户型 → AI 要微信。
也就是说，客户已经付出了两次（在评论区开口求、在私信里交出户型），而系统承诺的东西从头到尾一直悬在半空。她开口的第一句是"求手册"，结果被要求先交出微信号才能拿到。这个交换在她的视角里是不对等的 — 凭什么我给了两次，你一次都没给？
更要命的是前面说过的那点：这类客户诉求单一，手册就是她和这段对话之间唯一的连接。连接一直不兑现，她没有任何理由留下来。她没有拒绝、没有反驳，只是安静地消失了 — 这是最典型的"承诺落空型流失"。
本周建议（全批共性，本案是最干净的样本）：在索要微信之前，先在抖音私信里兑现一小块。比如 #3 完全可以先发一句实打实的干货 — 「三室一厅这份里，见光板通常被单收 200-400，你签合同前一定要问清楚」 — 让客户先确认"这人真有货、真的会给"，再顺势说"完整那份是带图表格，抖音发不了，报个 vx 我让设计师发你"。
一句话概括这条规则：先给后要，而不是先要后给。

模块 4 · 地区分析 三层地区信号 · 省 / 市 / 号源市

地区落地 · 本案对话里的使用情况
[省级] opener（#1）与跟进（#3）都没有提「湖北」 — 不显式点破 IP 属地是标准做法，避免客户产生"被画像"的不适，这一点没问题。
[但也没有做任何补位] 对照同批案例：有的案例在打不了同城牌时，会用「外地也能发」这类话术把地理顾虑提前消掉。本案什么都没做 — 既没提同城，也没主动说"不同城也不影响"。对一个索要资料的客户来说这未必致命（发资料本来就不受地理限制），但如果后续要谈落地安装，这个缺口迟早要补。
[号源类型的连带影响] 号源「灿哥聊装修」是知识号而非本地号 — 知识号的观众天然全国分散，city 本来就难标。这意味着从知识号进来的 lead，结构性地拿不到同城信任锚，话术必须靠专业度而不是地缘来立信任。本案的「见光板单收」钩子恰好走的就是这条路，方向是对的。

对照同批报了 568/㎡、588/㎡ 的案例：那些案例一旦报价，就必须同步说清计价口径（投影面积还是展开面积、含不含五金安装），否则会埋下预期差的雷。本案连雷都没埋。
对一个还在调研期、只是想要份资料的客户，此时报价是纯负收益 — 她还没到能理解报价的阶段，任何数字都只会变成"贵"或"便宜"的粗暴标签。本案在这一点上处理得完全正确。
