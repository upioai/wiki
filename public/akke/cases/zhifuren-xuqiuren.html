模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 跟进文案

评论极简 · 破冰借视频补足 · 跟进一句钩住留资

内容侧是评分模型 + 破冰话术生成共同决定的：客户留了什么、系统看到了什么、AI 写了什么。本案特殊在评论信息量极低（只有两个字），破冰靠视频场景补足，跟进靠一句话钩留资 — 三块拼在一起看，能看出 85 分是怎么转化的。

2.1 触发评论 · 只暴露一件事：处于装修启动期

在装修帮（号源池里类目「知识号」的装修科普号）的视频底下，客户只写了 「我要装修」。和那些把面积、单价、房型一次给齐的高分评论不同，这条只暴露一件事：客户正处在装修启动阶段、有明确意愿。没有面积、没有预算、没有房型 — 三个决策变量都缺。它能拿 85 分，靠的是「装修」阶段词单独成句 + 评论很新（近窗）：意愿强、时机准，但规格信息要靠后续对话补。

2.4 跟进文案 · 一句话接住顾虑 + 钩留资

跟进 DM 在 transcript（#3）。客户回「小面积做不」（在问小面积做不做），AI 三件事一句话完成：①正面接住「做的」；②钩联系方式「方便给个联系方式我们详细聊聊吗」；③给钩子「给您最低优惠」。客户紧接着就甩出了手机号。

转化够快，但「最低优惠」是把双刃刀
跟进只用一句话就把客户从「问能不能做」推进到「给手机号」，效率很高 — 「做的」消解顾虑 + 优惠钩子降低留资门槛。但要警惕两点：①没解释「小面积」具体怎么算、为什么 5万起的套餐对小面积也合适，客户是被优惠钩走的、不是被价值说服的；②「最低优惠」会拉低客户的价格预期，销售加微后若给不出明显低价，容易产生落差。这单转化靠的是钩子力度，复盘时要看它是否可持续复用。

模块 5 · 价格分析 5万起套餐锚 + 最低优惠钩

破冰先抛「5万起」锚 · 跟进用「最低优惠」钩留资

本案的价格策略是「套餐起步价锚 + 优惠钩」：破冰直接报「全屋柜体5万起（含衣柜+电视柜+榻榻米）」立住价格区间，跟进用「给您最低优惠」做留资钩子。和「认可客户自带预算」的打法不同，这次是 AI 主动先抛价格锚 — 对只说「我要装修」、没给预算的客户，先给个数字让对方有判断依据。

为什么主动抛「5万起」对路
客户只说「我要装修」、没给任何预算，破冰直接给「5万起 + 套餐内容」相当于替客户建立价格坐标：知道大概多少钱、包含什么，客户才好判断要不要继续。这比含糊地「价格详聊」更能筛出真有预算的人 — 本案客户没被 5万起吓退、反而问「小面积做不」，说明价格锚没劝退、起到了筛选作用。
风险 · 「小面积」遇上「5万起」+ 「最低优惠」
客户问「小面积做不」很可能是担心自家面积小、达不到 5万起套餐的性价比。AI 回「做的」但没说清小面积怎么计价、5万起是否仍适用，是用「最低优惠」把这个问题盖过去的。加微后第一波追问大概率是「我家就 XX 平，到底多少钱、优惠到什么程度」。销售需预置小面积计价口径 + 优惠的真实底线，否则「最低优惠」的钩子会在落地报价时反噬成预期落差。
模块 6 · 信息内部流转路径 本地真机现状 · 云电脑迁移路线

模块 1

时效性 · 首触达快、中段跟进慢

MID
✓ 做到位
  • 首触达 ~1h48m：评论 12:31 → 落库 13:32 → 送达 14:19，高意向当天捕获，没进冷藏。
  • 当天闭环：评论到留资同一天完成，近窗评论的黄金窗口吃满了。
✗ 不足
  • 中段跟进空 5h27m：客户 15:15 抛顾虑、20:42 才回，侥幸没被晾走。
  • 本周建议：把「客户已回 → 跟进」这段也纳入时效监控，不只盯首触达。
模块 2

内容 · 极简评论 + 借场景破冰 + 一句钩留资

GOOD
✓ 做到位
  • 低信息量也评对了：「我要装修」靠阶段词+近窗拿 85，不误杀。
  • 破冰借视频补足：评论没给抓手，用「一儿一女共用房」场景撑起话题。
  • 跟进一句话转化：「做的+联系方式+优惠」把客户从问询推到留资。
✗ 不足
  • 「一儿一女共用房」是推断：客户没自报房型，贴对了是运气、贴错就尴尬。
  • 「小面积做不」没正面解答：用优惠盖过去，是钩走不是说服。
模块 3

账号信任度 · 「零星」主页未抓取

BAD
✓ 做到位
  • 没在验证环节掉链子：客户当天给手机号，账号至少没把人吓退。
✗ 不足
  • 主页资产 0 数据：昵称/简介/作品/粉丝/获赞全未抓取，信任链无法评估。
  • 本周建议：运营补一张「零星」主页截图回填本模块，否则同号源后续案例继续空白。
模块 4

地区 · 仅省级、全程未用

MID
✓ 做到位
  • 省级「广东」在手：足够支撑破冰阶段不犯错。
  • opener 没显式提省：避免了「被画像」反感。
✗ 不足
  • 市级两端缺位：客户没自报市、号源标全国，无同城徽章/本地仓锚。
  • 省级信号也没用上：连「广东接过几单」这种 micro-context 都没碰。
  • 建议：加微首轮先确认客户城市 + 安装覆盖，备好答复。
模块 5

价格 · 5万起锚 + 最低优惠钩

MID
✓ 做到位
  • 主动抛价格锚：对没给预算的客户，「5万起+套餐」建立价格坐标、筛真意向。
  • 锚没劝退：客户没被 5万起吓走、反而往下问，说明筛选有效。
✗ 不足
  • 小面积计价没说清：「小面积做不」只回「做的」，没讲怎么算。
  • 「最低优惠」会拉低预期：加微后给不出明显低价易生落差。
  • 本周建议：预置小面积计价口径 + 优惠真实底线给销售。
模块 6

信息流转 · 留资了但 writeback 漏

BAD
✓ 做到位
  • opener 链路跑通：评论入库→评分→起草→真机发送→回写，全程可追。
✗ 不足
  • 留资没回写：客户 2 条回复 + 跟进 DM + 手机号全丢，DB stage 失真为 ice_break。
  • 去重风险：该 user 未标 contacted-with-content，可能被重复 claim 触达。
  • 子通道未判定：无 error_message 证据，ADB/WDA 需手动确认；云电脑 5 步迁移仍是规划态。
