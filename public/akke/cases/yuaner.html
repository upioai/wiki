模块 2 · 内容分析 触发评论 · LLM 评分 · v42b (A1) 单价分支 · 总价计算 → 反钩加微

"多大平 + 多少钱"两个锚点，opener 一次到位

这条评论 9 个字，把面积和价格两个最硬的销售问题同时摆到桌面：「多大平」是问视频里的样板，「多少钱」是问购建议。LLM 评分 78 / 100 = 中意向 + product + medium specificity。opener 必须既答复视频面积又给出单价口径，最后反问客户家的面积，把"她在调研"这一拍接住。

2.1 触发评论 · 客户暴露了什么

她暴露了 2 件事：① 看视频时关心面积（"多大平" — 想知道这套是不是和她家差不多大的样板）；② 直接问价格（"花了多少钱" — 在做总价对比，不是问材料、不是问风格）。但她没自报面积、没自报城市、也没透风格倾向 — 比起兄弟 case「炒菜不要锅」的 160 平 + 意式轻奢明确锚点，园儿的暴露是"问购入门"，所以系统打了 78 分（中意向）而不是 90+。

2.3 破冰文案 · v42b (A1) 单价口径 + 反问面积

opener（#1）走的是 v42b (A1) 单价口径分支，专门处理"既问面积又问总价"类评论。这是 Akke 流量里占比最高的一类（~35%），过去 (A1) 容易栽在报死总价（如"5 万左右"）— v42b 改成 "按平方算 284 一平 + 反问面积"，把客户拉到下一句报数字。

破冰文案 · v42b (A1) 单价分支的活体范例
这条 opener 是 v42b (A1) 单价分支在野场跑通的样本。四个关键设计：(1) 不报总价、报单价 — "284 一平" 是柜体单价，是定制行业的最小可信价；(2) 主动加 "实际配置影响总价" 这句风险声明，让客户明白报价不是死数，避免后续"为什么和你说的不一样"的纠纷；(3) 反问 "你家是多大平" 是结构性钩 — 客户要么告诉你面积进入对话，要么沉默退出；(4) opener 全文没出现"加微信" — 加微是后一拍的事，破冰这一拍只做"把对话拉起来"。结果是客户次日早上确认聊天直接回了「200 平」— 钩子生效。

2.4 跟进文案 · 客户报面积后的三段链

客户 #2 只回 3 个字 "200 平" — 简短、不带情绪、纯报数据。这种回复对运营是好消息（客户接住了反问钩）也是坏消息（没暴露其他信号 — 风格、预算、时间表全没说）。AI 跟进 #3 三段链：① 软场承接（"200 平能做的搭配挺多的" — 接住面积、给安抚）→ ② 按单价算总价（"按 284 一平柜体大概 5.7w 左右" — 这是 (A1) 分支的第二拍计算，把单价口径落地）→ ③ 案例锚 + 反钩加微（"几套 200 平左右的实景案例和报价单 + 方便加个微信吗 + 我出个详细的清单给你"）。

⚠ 反钩加微 · 客户还没主动表态
200平能做的搭配挺多的，，按284一平柜体大概5.7w左右~我这边有几套200平左右的实景案例和报价单，方便加个微信吗？我出个详细的清单给你~
关键句是 「方便加个微信吗？我出个详细的清单给你～」 — 这是反钩加微的询问式而不是给号式。和兄弟 case「炒菜不要锅」#3 直接抛号 v→Homedz3791 不同，本案客户只报了面积没主动说"我加你"，所以 #3 还在试探加微意愿。下一拍取决于客户回"好"还是回"先发我看看"还是沉默。这是 v42b 报价分支跑到第二拍的典型 funnel 中段样本 — 加微闭环尚未完成。

模块 5 · 价格分析 单价口径前置 · 客户报面积 · 总价计算 → 反钩加微

v42b (A1) 报价分支跑到第二拍的标杆 — 单价 → 总价 → 推微

这是本案的核心亮点。和兄弟 case「炒菜不要锅」走 (R) 资料钩、全程不报数字不同，本案 opener 直接给了 284 一平 的柜体单价 — 因为客户问的就是"花了多少钱"。三条 DM 走完整个 (A1) 链路：opener 报单价 + 反问面积 → 客户报 200 平 → AI 跟进算出 5.7w 总价 + 案例锚 + 反钩加微。这是 v42b 在野场把"问价类客户"接住的完整两拍。

为什么这次 opener 必须报数字 · v42b (A1) 的设计意图
过去的旧 (A1) 分支会兜底报"5 万左右"这种死总价 — 是 6-21 红牌当天 27 次 selfCheckFail 的主因（Qwen3 还在落回旧模板）。v42b 改成「按平方算 284 一平 + 反问面积」，本质是把客户必报的下一个数字当钩子。园儿这条 case 是 (A1) 改造后跑通的活体范例：opener 报单价（不报总价）→ 客户报面积 → AI 跟进做乘法。这一拍解决的是过去的两个雷：① 报死总价被客户挑战"为什么和别家不一样"；② 完全不报价格被客户嫌"不真诚"。
风险 · 5.7w 这个数字落在客户预期哪一侧
AI 算出来的 5.7w 柜体 听着不贵，但全屋定制的总价大头在主材 + 安装 + 设计费。客户加微后大概率第一句是 "整套下来一共多少钱" — 销售要提前备好：① 200 平意式轻奢 standard 配置的全屋拆分（柜体 5.7w + 主材 12-18w + 设计费 1-2w + 安装 1-2w = 整套 20-28w）；② 三档配置上下浮动（板材 / 五金 / 柜门 / 台面石材升级各加多少）；③ 河北跨省接单的物流费 / 安装队差旅费是否单独算（号源是不是只服务本省？需要客户加微前核对）。这一拍不能让销售临场发挥，否则 opener 给了"284 一平"、销售微信里说"全屋 30 万"，客户会觉得"被骗了"。
模块 6 · 信息内部流转路径 云电脑通道 · channel_pref = cloud_pc · 双通道分裂

opener 走云电脑入库，客户回复 + 推微跟进 DB 没接住
