模块 2 · 内容分析 触发评论 · LLM 评分 · 反评 + DM 双套话术

「怎么拿到」是个低门槛伸手，反评用呼名接住，DM 用品牌矩阵报价

内容侧拆三段：客户留了什么、系统给了多少分、双通道分别用了什么话术。反评和 DM 是两套独立模板 — 反评走"叫名字 + 轻量接需求"，DM 走"品牌堆 + 索 v"。

2.1 触发评论 · 低门槛伸手

原视频是一条全屋装修方案分享类内容，张芷霖留下一句「需要，怎么拿到[尬笑]」 — 这是装修流量里典型的低门槛伸手：客户在意但不愿暴露具体诉求，"[尬笑]"emoji 进一步说明她承认自己需要、但又怕显得急切。06-10 她又在另一条号源视频留首评「什么板材？」，证实她在持续逛装修视频 + 在选品阶段。两条评论同源，意向连贯。

2.3 反评话术 · 叫名字 + 接住需求（#1）

反向评论是评论区公开喊话，不能写得像 DM 那样长。#1 的 3 段式结构是反评通用模板：①叫名字（建立"我看到你了"信号）；②复述需求（证明真读了评论）；③轻量收尾（不索 v、不报价，留空间）。

① 叫名字
直呼"张芷霖"
「张芷霖，」
② 复述需求
明确说"看你评论里"
「看你评论里问过怎么拿全屋装修方案」
③ 共情
"我们常遇到"建立同类感
「这种需求我们常遇到」
④ 留白
没索 v、没报价
（句末停在"我们常遇到"，留给客户主动来）
反评话术 · 这次成立的原因
反评的成功是"留白"赢的：没在评论区贴价格、没让客户加 v，只是叫了名字 + 接住需求 + 暗示"我们能给"。次日（06-08）她主动去小星账号点赞 + 比心 — 说明话术里那句「我们常遇到」触发了她"去看看这家有没有靠谱内容"的本能。这条点赞是反评话术成功最硬核的证据。

2.4 跟进 DM · 品牌矩阵 + 索 v（#4）

DM 通道#4 走的是另一套思路：堆品牌名 + 工艺标签建立专业感，紧跟索 v。结构是「打招呼 + 板材清单 + 五金 + 环保级 + 索 v + 价格承诺」5 段在一句话里，信息密度过满，留白比反评少很多。

为什么 DM 这次没接住客户
① 没接 06-07 评论的具体语境：客户问的是"全屋装修方案怎么拿"，DM 直接跳到"板材+五金+ENF"，跳过了"方案怎么拿"那一层 — 等于把客户问的问题忽略掉了。
② 06-10 的"什么板材？"才是这条 DM 触发的契机，但 DM 没说"看你刚问'什么板材'，我们用的是…"，断掉了语境。
③ "留 v"门槛太高：第一句 DM 直接索微信，越过了"先问户型 / 先发案例"等中间台阶；客户的反应（已读不回）说明她还没准备到这一步。
④ 表情破冰 #3 是噪声：先发一个 🤗 emoji 再发正文，对方手机会弹两次通知，反而拉低专业感。
