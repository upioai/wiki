模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 跟进文案

低价试探被识别 · 破冰主动 reframe 到「装修顺序」

内容侧是评分模型 + 破冰话术生成共同决定的：客户留了什么、系统看到了什么、AI 写了什么。本案三块拼在一起 = 这条 lead 的内容质量，也是它从"低价问询"被拉升到"全屋规划对话"的关键。

2.1 触发评论 · 一句话同时暴露 3 件事

在海哥—用心讲装修（号源池里类目「知识号 · 全国」的装修科普号）发的烟机灶具电源/烟道位预留视频底下，她写下 「太贵的我都买不起，能不能两三千的推荐一下？」。一句话同时暴露 3 件事：①预算极低 — 「两三千」对全屋定制是不可能的数字，对单品（烟机灶具）也偏低；②态度防御 — 「太贵的我都买不起」是先把价位天花板抛出来挡，避免被推大单；③但留了 hook — 「推荐一下？」带问号，说明她不是来拒绝、是来试水。这第三点是 78 分中意向的根因。

2.3 破冰文案 · 不接「两三千」 · 把对话拉到装修顺序

首条 AI DM 在 transcript（#1）。不报价、不否定预算、不推销 — 三个动作都没做。AI 把客户从「问产品价位」的角色升级到「装修规划者」的角色：视频里讲的是烟机烟道预留（装修阶段的事），AI 接住"装修时都能提前留准"，再反问"你家准备先动哪一组柜子？" — 把价格话题转成装修顺序咨询。

「低价试探」的破冰要 reframe 角色 · 不要接价
客户开口「两三千」+「太贵买不起」— AI 此时接价就死：①认可两三千 = 承认自己产品没两三千的、对话结束；②否定两三千 = 触发客户的"果然贵"防御、对话结束；③报新价 = 强卖、客户拉黑。
AI 选了第四条路：把"问产品价"的角色升级到"问装修顺序"的角色。「装修时都能提前留准」一句话切场景（购物 → 装修），「先动哪一组柜子」一句话切角色（顾客 → 规划者）。客户回「应该是橱柜吧」就证明她接受了角色升级 — 接下来对话的价格弹性自然就被打开了。

2.4 跟进文案 · 顺势钩布局 + 嵌入电器

跟进 DM 在 transcript（#3）。客户回「应该是橱柜吧」后，AI 三件事一句话完成：①承接 + 复确认「橱柜先做对了，水电点位跟着定」（把客户的犹豫"应该"转成肯定）；②抛 L 型 vs 一字型 — 二选一最低 friction 提问；③嵌洗碗机 / 蒸烤一体 — 钩出客户对中端电器的态度（是否买嵌入式 = 是否愿意装预算上的"中高"段）。整条跟进仍未谈价，但已经在用问题钓客户的真实预算阶层。

嵌入式电器问题 = 隐形价格试探
跟进里"有嵌洗碗机或蒸烤一体的打算吗？"看起来是问需求，实质是在测客户真实预算阶层 — 嵌入式洗碗机/蒸烤一体即便最低配也要 4-6k 起，能装嵌入 = 客户的"两三千"其实是个心理锚而非硬上限。客户怎么回答都有用：愿装嵌入 → 预算被自然拉高、不再卡在"两三千"；不装 → 也获得了装修配置画像。等客户回复就能继续下推。

这个项目哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。

模块 1

时效性 · 5 分钟全流程

GOOD
✓ 做到位
  • 评论 → 入库 → 起草 → 推送 5 分钟跑完：高 freshness 场景下接近实时。
  • 跨夜首响 1h52m 接力：客户次日 08:06 翻 inbox，AI 09:58 跟进，上午黄金窗口接住。
  • 对比 14 天延迟反面样本（denghuo-lanshan）：同一条流水线在另一个工况下的健康表现。
✗ 不足
  • 跟进时长 1h52m 还可压缩：早 8 点首响、10 点才跟进，更早 9 点跟进会更好。
  • 本周建议：早间 8-9 点 inbox 检查频率提高 — 跨夜回复占 active freshness 客户大头。
模块 2

内容 · 低价试探被 reframe 成功

GOOD
✓ 做到位
  • 不接「两三千」：避免认可/否定/报价三个死路。
  • 角色升级：把"问产品价"切到"问装修顺序"，对话价值瞬间打开。
  • 跟进嵌入式电器隐形测预算：用问题钓客户真实预算阶层，比直接问"你预算多少"高级。
  • 客户回「应该是橱柜吧」证明 reframe 接住：从产品咨询身份切到规划者身份成功。
✗ 不足
  • opener 没用省级"广东"钩子：是被 reframe 主诉覆盖了，可以接受但少一个 anchor。
  • "两三千"作为客户心理锚仍在：第三轮跟进必须直面，否则 reframe 会被识破。
模块 3

账号信任度 · 零星号池

BAD
✓ 做到位
  • 本案没出问题：客户被破冰内容质量说服，没纠结主页。
  • 已在多条 case 实证：zhengzhou-heikang / gangzi-daochang / laoxie 都用零星跑通。
✗ 不足
  • 主页快照未抓：粉丝/作品/简介/IP 全空 — 无法评估信任风险。
  • messaging 号池天然劣势：不是品牌运营号 · 客户反向核身份会减分。
  • 本周建议：抓零星账号主页快照入 DB；至少把简介改成与"装修咨询"沾边的人设。
模块 4

地区 · 省级回退路径未启用

MID
✓ 做到位
  • 省级"广东"在手：未来 nurture 阶段可用气候/工艺习惯升级话术。
  • 不强用省级钩子是对的：本案主诉是 reframe，省级回退会稀释。
✗ 不足
  • 客户自报市缺位 + 号源全国：同城判定不参与，缺少"本地仓"信任锚。
  • 建议：跟进中可顺势引"广东这边湿气重→板材选防潮"等省级 micro-context。
模块 5

价格 · 暂时绕开 · 第二轮必须直面

MID
✓ 做到位
  • 不报新价 + 不否定预算：避免开局触发客户防御。
  • 嵌入式电器问题隐形抬锚：用问题钓真实预算阶层。
  • 把价格 friction 后置：先建立装修规划话题信任，再回到价格。
✗ 不足
  • 「两三千」锚仍在客户心里：不直面 = 客户最终会觉得"被忽悠"。
  • 没预置价格答复套路：第三轮跟进就要给"低预算怎么花得值"方案，需立刻准备。
  • 本周建议：写一份"低预算客户标准答复包"（控预算思路认可 + 钱往哪花 + 不能省的钱）。
模块 6

信息流转 · writeback 漏（同 denghuo-lanshan）

BAD
✓ 做到位
  • ADB 通道跑通：opener 入库 → 评分 → 起草 → 真机发送全程可追。
  • 5 分钟链路时延：流水线工程指标健康。
✗ 不足
  • writeback 只覆盖 opener：客户首响 + 跟进 DM 全丢 · DB stage 失真为 ice_break。
  • 去重风险：该 user 未标 contacted-with-content，4h 后可能被重复 claim 触达。
  • 云电脑 5 步迁移仍是规划态：本周可优先把 writeback 链路单独打通，不用等整套迁移。
