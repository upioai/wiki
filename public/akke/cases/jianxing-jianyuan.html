2.3 破冰文案 · 没甩报价，给"全包不收额外费"承诺

首条 AI DM 在 transcript（#1）。他问"怎么收费"，但 opener 没甩具体数字 — 这是有意识的设计选择。报具体数字（如"5 万起步 / 568 一平"）容易让客户觉得"这是群发模板话术"；先给一个计价口径（按投影面积算 + 全包不收额外费）+ 反问户型，让客户感觉对面是一个真愿意算账的人。

模块 5 · 价格分析 opener 没甩数字，只给口径

故意不报数字 · 用「全包不收额外费」抢承诺锚而不是价格锚

客户问"怎么收费"，opener（#1）没甩具体数字，只给了"按投影面积算 + 设计量尺安装物流全包 + 不收额外费用"。这是 Akke 报价话术里的口径锚定派 — 跟小猪的"500 多一平、5 万起步"对照鲜明。

设计 + 量尺 + 安装 + 物流

让客户把焦虑落在"是真不是假"而不是"贵不贵"
为什么这条 case 故意不甩数字
"怎么收费"是纯净问价，没有任何 specificity 信号（不像小猪的"为我设计"带请求式紧迫感）。AI 判断：先甩数字会让客户秒进"贵不贵"的比价心态；先给"全包不收额外费"的口径承诺，把客户的注意力引到"承诺值不值得信"。再用反问"几室几厅"推进到具体场景，价格留到客户披露户型/面积之后再算。
风险 · 客户没回，口径策略失效
3 天未回 = 策略尚未验证：opener 没甩数字 + 反问户型，但客户没按反问回答户型，而是整个不回。可能原因：①不甩数字让客户失去比较锚点，无法判断"是不是有戏"直接走人；②"问收费"客户希望立刻看到数字，给口径反而像销售话术；③粉丝 21 的账号让"全包不收额外费"承诺缺乏可信度。
建议：对"怎么收费 / 多少钱"类无 specificity 的纯问价 lead，opener 应该同时给口径 + 一个区间锚（如"几室几厅看大小，5-15 万之间，按投影算"），不要纯口径无数字。

7.2 如果搬到云电脑 · 5 步迁移

云电脑不是"换个机器跑"，而是把账号、设备、截图和回写统一托管。一筑账号需要长期登录在固定环境里，由调度器按账号限额 claim lead。它的价值是可监控、可回放、可统一回写；风险是云 IP / 模拟器指纹 / 登录态失效更容易触发风控。

1 · 常驻环境
账号登录态固定
云电脑保存一筑账号 Cookie / App 登录态，避免每次重登
2 · 调度 claim
按 daily cap 排队
高意向 85 分 lead 抢占；同账号遵守发送间隔
3 · 执行发送
模拟器或远控真机

4 · 自动回写
messages / queue / events
sent_at、截图路径、失败原因统一写回
5 · 失败复核
截图 + status_code
遇到风控、输入失败、silent drop，转人工复核
收益 / 风险
统一监控 vs 风控指纹
