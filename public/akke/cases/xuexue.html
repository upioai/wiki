模块 2 · 内容分析 触发评论 · LLM 评分 100 · 破冰拆解

客户把求联系挑明到极致 · 破冰用「视频钩 + 微信 + 优惠」一把接住

内容侧是评分模型 + 破冰话术共同决定的。本案评论是教科书级的硬信号 — 不是暗示，是直接问「怎么联系你」。破冰则走「先用视频内容立同款感、再直接给微信、最后用活动优惠勾」的三段式，目标明确：尽快把人导到微信。

2.1 触发评论 · 直接问「怎么联系」

在米凌设计师_涂设计（号源池里类目「本地号」的意式极简大平层账号）视频底下，她写了 「我需要装修，怎么联系你呢」。这句几乎没有解读空间：①明确装修需求 — 「我需要装修」；②主动求联系方式 — 「怎么联系你呢」=已经准备走出抖音、加联系方式。没有面积、没有预算，但购买阶段比那些更靠后 — 她要的不是方案讨论，是直接对接。是典型的高意向 100。

2.3 破冰文案 · 视频同款钩 + 直接给微信 + 优惠勾

模块 4 · 地区分析 三层地区信号 · 广东 IP 在手、破冰没打地域牌

模块 6 · 信息内部流转路径 采集慢 + 重复 claim · 发送/回写本身没毛病

这条 DM 在内部走过的物理通道，以及它在哪一步掉了链子

这个项目哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案的结果是好的（换来微信），但那是被极强意向救回来的 — 时效和流转仍是真短板。

模块 1

时效性 · 采集拖 43h、发送只 3h

BAD
✓ 做到位
  • 发送侧很快：入库后 3 小时内破冰就送达，审批 + 手发没拖。
  • 没漏掉这条：哪怕迟到近两天，最终还是把 100 分信号发了出去。
✗ 不足
  • 采集入库拖 43h47m：评论躺了快两天才被抓进库，是迟到的全部来源。
  • 评论→触达 ~47h：对一条「怎么联系你」的 100 分信号，慢得离谱。
  • 本周建议：本地号提采集频次 + 给「求联系」评论加优先采集标签。
模块 2

内容 · 直接导微信，打法对路

GOOD
✓ 做到位
  • 100 分识别准：「需要装修 + 怎么联系」是漏斗末端硬信号，满分合理。
  • 不拖时间：破冰没再问户型预算，直接给微信 + 优惠勾，对路。
  • 结果验证：客户没纠结，直接回了自己的微信号。
✗ 不足
  • 方向小错位：让客户加我们，客户却给了自己的号 — 动作落到销售这边。
  • 建议：客户给己方微信时，立刻派销售主动加，别等。
模块 3

账号信任度 · 零星主页空白

MID
✓ 做到位
  • 账号活跃可发：零星 messaging · active，把破冰稳稳发出。
  • 破冰绕过部分验证：直接给微信号，客户注意力更多在「加微对接」而非扒主页。
✗ 不足
  • 主页资产全空白：昵称 / 简介 / 粉丝 / 作品都没抓取，扛不扛得住「点头像验证」没数。
  • 本周建议：补零星主页截图，给加微前的求证一步留个门面。
模块 4

地区 · 广东在手、没打出去

MID
✓ 做到位
  • 省级 IP 明确：广东信号清晰、可用。
✗ 不足
  • 破冰没用地域：全程围绕视频内容 + 导微信，一句广东 / 同城都没提。
  • 市级双向缺失：客户没自报城市、号源 city 空，无法触发同城徽章。
  • 建议：加微后摸清城市，落在本地就补一记同城信任。
模块 5

价格 · 留悬念、先导微信

GOOD
✓ 做到位
  • 不过早报价：抖音公开场不抛数字，避免被比价劝退。
  • 优惠钩留回访：「活动优惠再算一档」给了加微的理由。
  • 取舍对路：把价格博弈搬到微信私域，符合漏斗末端客户。
✗ 不足
  • 「活动优惠」要兑现：加微后没实在优惠，会有「被话术骗加」落差。
模块 6

信息流转 · 采集慢 + 重复 claim

BAD
✓ 做到位
  • 发送→回写干净：破冰 #1 落库 status = sent，发送侧无毛病。
✗ 不足
  • 采集入库慢 43h：评论排期太靠后，100 分信号在池子里压了快两天。
  • 重复 claim：同 user 6-5 又被 claim、起草冗余破冰（24h 过期），去重没拦住。
  • 客户回复靠截图：check-replies 没轮询到，微信号没自动落库 — 云电脑可根治。
