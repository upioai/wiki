模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰 + 一轮跟进

跟进那句「水电前定柜体能省后期改管钱」，是本案真正的胜负手

客户只说了「新房」两个字，跟进（#3）却没有停在"好的那我发你"，而是先讲了一条真实的工艺逻辑：新房开工阶段柜体要在水电之前定下来，否则管线预留不上、后期改管要花钱。这句话把"要一份清单"这件小事，变成了"再不定就来不及"的时间成本问题 — 而且它是真的，不是编出来的紧迫感。

3.1 触发评论 · 两个字，意图满格、信息为零

「跪求」— 全部内容就这两个字。①意图极强：不是「不错」「学习了」这类围观，是明确的索取动作，而且用了很重的措辞；②指向明确：他求的是视频里那份开工必备清单，我们知道该给什么；③信息为零：户型、面积、城市、预算、进度，一个字都没有。这是一条典型的「意图满格、画像空白」评论 — 好接，但接住之后要靠对话把画像一点点问出来。而本案没有问。

3.3 破冰文案 · 四段齐全，承诺物对得上他求的东西

它有三个优点：不预设房子是谁的（不像「你家几室几厅」默认是本人新房）、只有两个选项、打两个字就能答（本案客户直接点了抖音的快捷回复气泡）、答案能实质改变后续话术（新房走预留位逻辑、翻新走拆改逻辑）。本案客户 5 分钟就回了，正是因为回复成本几乎为零。
可复用：破冰的反问要满足"两个字能答完 + 答完就能分叉话术"这两条。问开放题（预算多少、什么风格）在陌生人首条 DM 里回复率明显更低。

3.4 跟进 · 一条真工艺逻辑，换来一个微信号

跟进（#3）是四段结构：工艺理由 → 承诺物具体化 → 要 vx → 摩擦解释。四段全部踩到点上，客户 4 分 25 秒就报了号。

① 工艺理由
真实且省钱，不是编的紧迫感
「新开工最要紧是预留位，水电前定柜体能省后期改管钱」
② 承诺物
从"避坑清单"具体化到可用清单
「含插座/管线预留的开工清单，按你户型可直接套用」
③ 要 vx
动作明确，且指向第三方（设计师）
「你报个vx号给我，我让设计师发你原图表格」
④ 摩擦解释
把要微信归因于平台限制
「抖音发不了文件、发图也会压糊」
✓ 为什么这条跟进比同批那些「柜体最晚这周得定」高一个档次
同批另一条对话用的是「柜体最晚这周得定，不然水电管线没法预留」 — 那是一个我们并不知道真假的时间断言：我们根本不清楚客户家水电走到哪一步，说"最晚这周"是硬造的紧迫感，客户一旦已经装完水电，这句话立刻穿帮。
本案说的是「新开工最要紧是预留位，水电前定柜体能省后期改管钱」 — 这是一条普适的工艺常识，对任何一个还没开工的新房都成立，不需要知道他家进度，也不会被证伪。同样是制造"现在就该聊"的理由，一个靠吓，一个靠讲道理，后者既安全又显专业。
可复用：紧迫感优先从工艺顺序里找（水电前定柜体、瓦工前定门槛石、木工前定吊柜），别从时间期限里编。
✗ 「按你户型可直接套用」— 我们并不知道他家户型
整段对话里，客户提供的房屋事实只有两个字：「新房」。几室几厅、多少平、哪个城市、是不是毛坯、什么时候交房，全部未知。而跟进里已经写下了「按你户型可直接套用」。
这句话在 DM 阶段没有代价 — 客户不会当场追问「你知道我家户型吗」。但它把风险推到了微信侧：销售加上之后如果直接甩一份通用清单，客户会立刻发现"这根本不是按我家户型做的"，第一印象就砸了；如果销售先回头问户型，客户又会想"那你抖音上说的按我户型是什么意思"。
本周建议：承诺物的定语只写我们真的知道的那部分。本案已知的只有"新房"，那就写「按新房开工顺序整理的清单」，稳且不失分量；要写"按你户型"，就得先问出户型 — 一句「几室几厅我按你家的标一份」既拿到了信息，又让承诺变得真实。
✗ 拿到的是「清单需求」，不是「柜子需求」
从头到尾，客户表达的都是对一份开工避坑清单的兴趣 — 那是装修前期的通用知识品，跟我们卖的全屋定制柜体之间还隔着一整段距离。他没说过要做柜子，也没问过价格。
跟进里那句「水电前定柜体能省后期改管钱」是目前唯一一处把清单和柜体挂上钩的地方，做得很巧，但客户有没有接住这个暗示，从两个字的回复里看不出来。
本周建议：这类「资料换联系方式」的 lead 在交接销售时应标注「资料型意向，柜体需求未验证」，别按已确认需求排产能。加微后的第一轮要尽快验一句「你家柜子这块打算做几个/找工厂还是门店」，验不出来就归到长期培育，别投入设计资源。

✗ 风险在下一棒：他对价格完全没有概念
客户现在心里对"全屋定制大概多少钱"是一片空白，而他即将在微信里见到销售。销售报出的第一个数字，无论多少，都可能和他脑子里凭空想象的数字对不上。本批已有案例证明这种落差会直接把人吓走。

模块 6 · 信息内部流转路径 云电脑通道 · 消息全落库，但字段没跟上

这是一个容易被"捕获率 100%"的好数字盖住的问题：微信号躺在一条普通消息的正文里，没有任何结构化字段承载它。对下游的派单逻辑、跟进 cron、二次触达来说，这条会话仍然是 stage = ice_break、handed_off_at = null —— 一个"聊过、没结果、可以再催"的对象。
具体的风险是：自动跟进或二次触达一旦命中他，他会在已经给过微信号之后，再收到一条催他给微信的消息。这种重复打扰对一个本来态度极好的客户是净损失。
本周建议（按优先级）：
① 联系方式识别 + 结构化落库 — 客户消息命中微信号 / 手机号 / QQ 号 / 二维码时，写进会话的联系方式字段，并立刻把 stage 推到 pending_handoff、停掉所有自动跟进；
② 给"已交出联系方式"加一个显式状态位 — 让派单侧一眼能看出这条不该再进任何触达池；
③ 加微结果回流 — 目前"销售有没有加上、客户有没有通过"完全靠人肉截图维护（见下方加微跟踪卡），这一段是整条链路上唯一没有数据的环节。

这条链路哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案是本批转化最快的一条，成功点集中在"讲工艺不吓人"和"承诺物对得上"；隐患则集中在"我们对他家一无所知，却已经承诺了按他家户型"。

GOOD

模块 2

内容 · 讲工艺不吓人，但承诺超出了已知信息

GOOD
✓ 做到位
  • 「水电前定柜体能省后期改管钱」是本批最好的紧迫感写法：靠工艺顺序讲道理，对任何未开工新房都成立，不像「最晚这周得定」那样可被证伪。
  • 承诺物与客户所求完全对齐：他求清单，我们发清单，没有偷换成"免费出方案""上门量房"。
  • 反问设计好答：「新房还是翻新」两个字能答完，且答完就能分叉话术，客户直接点了快捷回复。
  • 摩擦解释到位：「抖音发不了文件、发图也会压糊」把要微信的动机从"我想加你"换成"平台限制"。
✗ 不足
  • 「按你户型可直接套用」是一句兑现不了的承诺：客户只说过"新房"两个字，户型/面积/城市全未知，风险被推到了微信侧。
  • 只问了一个变量就要联系方式：拿到号很快，但画像近乎空白，销售接手时等于从零开始。
  • 拿到的是"清单需求"不是"柜体需求"：全程没有验证过他要不要做柜子。
  • 本周建议：承诺物的定语只写真的知道的部分（「按新房开工顺序整理」）；要写"按你户型"就先问一句「几室几厅我按你家标一份」，一句话既拿信息又让承诺成真。
模块 3

账号信任度 · 零试探通过，资产盲区照旧

MID
✓ 做到位
  • 信任阻力接近于零：从被要微信到报出号 4 分 25 秒，全程没有一句核实性提问。
  • 会话被抖音判为有效互动：显示"对方已确认聊天，可继续发送消息"，不是被拦截的骚扰关系。
  • 企微身份差异提前解释：先说清"是企业微信、要去服务号点通过"，避免好友申请被当成诈骗忽略。
  • 账号健康：active、连续失败 0、日限 30 条、节流 ≥30 秒/条。
✗ 不足
  • 粉丝数 / 作品数 / 播放量在 DB 里全空：客户压根没看主页，这一层完全没被检验 — 不是过关了，是没考。
  • 企微回执缺记忆锚：只说了"是企业微信"，没说"抖音上聊开工清单的"，隔夜后客户很可能认不出。
  • 本周建议：补一次主页截图入库；企微引导话术固定加一句来源说明。
模块 4

地区 · 只有省，连房子在不在贵州都没验

MID
✓ 做到位
  • 话术里一个地名都没提：号源是知识号（全国流量），本来就打不了同城牌，不提地区避开了"猜错城市"的翻车。
  • 号源类目判断清晰：is_same_city = null 是号源性质决定的，不是数据缺失。
✗ 不足
  • 施工地完全未知：量房、发货仓、安装队、运费全绑在施工地上，而 IP 属地只说明他发评论时人在贵州。
  • 市级两端全缺：客户市未公开、号源无城市，无法做任何本地化判断。
  • 本周建议：把城市问句缝进承诺物里 —「清单我按你当地的做法标一下，你家在哪个市？」，比干问自然得多。
模块 5

价格 · 该沉默时沉默，但下一棒不能再空着

MID
✓ 做到位
  • 信息空白时没有硬报数字：只知道"新房"两个字，不报价避免了后续兑现不了的风险。
  • 「能省后期改管钱」把价值定在省钱侧：没报价却完成了价值传递，比"厂家直供更便宜"这类无锚点低价暗示高明。
✗ 不足
  • 客户对价格毫无概念就进了企微：销售报的第一个数字无论多少都可能对不上他的想象，这个落差本可在 DM 阶段用区间熨平。
  • 本周建议：加微首轮先给带条件的数量级，或只报计价结构（按投影面积 / 按延米 / 板材分档）不报总价 — 同批「超哥」那条正是靠这招稳住的。
