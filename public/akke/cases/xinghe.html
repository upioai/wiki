模块 2 · 内容分析 触发评论 · LLM 评分 · 破冰规范 · 跟进抛满卖点

破冰切入点对路 · 跟进跨越了客户当前的决策阶段——利与弊都在这两条里

内容侧是本案的主戏。破冰 #1 共情"被装修公司背刺"、呼应避坑视频、末尾反问进度，火候还算克制（没报价没要 v）。重头戏在跟进 #3——客户明说"还没装、正在找装修公司、房子年底才拿到手"，跟进却一口气给品牌 + 报价 + 材料 + 保障，跨越了她"选装修公司"的当前阶段。逐层拆开看它做对了什么、又冒了什么险。

2.1 触发评论 · 一句话裹了两个信号

在旭东聊装修（号源池里"知识号"类目）的装修避坑视频底下，她只留了四个字 「甘肃什么来」。结合 IP 属地甘肃，这句白话是"甘肃你们能不能来做"——一句话里裹了两个信号：购买意图（想做定制）+ 地域顾虑（甘肃能不能落地）。系统归为 product，理由「含极简购买信号+地域询问」，specificity 因为极简、没暴露面积/预算给 low，评分落 68 中意向。这类客户的特点：她先要解决的是"你们够不够得着我"，再谈"做不做"。

2.3 破冰文案 · 共情 + 卖点 + 反问进度（克制，没要 v 没报价）

首条 AI DM 在 transcript（#1）。结构：带昵称招呼、呼应"装修避坑视频"、共情"被装修公司背刺确实闹心"、抛三个卖点（大牌直供 / ENF 环保不达标全额赔 / 活动价透明）、末尾一个开放式反问（"你家这装修走到哪一步了？"）摸进度。没伸手要微信、没报价，火候克制；而且这个反问是有效的——客户确实答了进度。

✗ 破冰的第一个缺口 · 没接住客户明着问的"甘肃能不能来"
客户评论就是一句地域问购「甘肃什么来」，最该被正面接住的就是"甘肃能到 / 我们甘肃有服务"。破冰却绕开这一句，转去讲直供、环保赔、活动价三个卖点 + 问进度——答非所问。共情"被背刺"和呼应避坑视频是对的，但客户抛来的第一个具体问题（够不够得着我）从头没被回应。次要瑕疵：「你这条装修避坑的视频」把评论者当成了视频作者（视频其实是号源"旭东聊装修"发的），属常见的 opener 代入，影响不大，但可校准。

跟进里最漂亮的一句是"柜体要按水电走位预留，晚了容易返工"——它恰好利用了客户"还没装、年底才交房"的时间差，给了一个"早点把定制排上更省事"的专业理由，而不是空喊"快定"。"假一赔三 + 无醛 + 直供品牌"也正对冲客户在避坑视频下的"怕被坑"心理，是对路的信任语言（价格锚点分析见模块 5）。
✗ 冒的险 · 跨越客户当前阶段 + 密度过大 + 仍没答地区
三个问题叠在这一条里：① 跨越决策阶段——客户刚说"想先找个好点的装修公司"，她还在择商这一层，跟进直接跳到"把定制定下来 + 报价"，越过了她的当前问题；② 密度过大——一句 9 字短答换来品牌 + 价 + 材料 + 保障一条塞满，早期客户消化不过来，最省力的反应就是先不回；③ 地区仍没答——从评论到这条，客户最在意的"甘肃能不能来"两轮都没被正面接住，只有"全国连锁"间接暗示。更稳的拆法：这轮先答"甘肃能落地"、顺"年底交房"给一条避坑价值点（如"交房前柜体按水电走位预留"），价格和加微等她表现出兴趣再谈——每条只推进一步。

跟进 #3 的信任构建走的是内容路线：连锁品牌背书（"有大有小，全国连锁"）+ 直供大牌板材（兔宝宝 / 千年舟）+ 强保障（无醛添加 / PUR 封边 / 假一赔三）——对一个在避坑视频下、看重"靠不靠谱、会不会被坑"的客户，这三层是对路的信任语言。风险有两点：一是信任只垫了破冰 + 一条跟进就抛了价格；二是"全国连锁"这句既是信任背书、又被当成对"甘肃能不能来"的间接回答，可它撑不住客户明着问的落地顾虑。如果她此刻点进主页、而主页资产又薄，"全国连锁"的说法反而可能被打折。建议运营补一张小星主页截图落实资产。

7.2 如果搬到云电脑 · 5 步迁移

云电脑不是"换个机器跑"，而是把账号、设备、截图和回写统一托管。小星账号需要长期登录在固定环境里，由调度器按账号限额 claim lead。它的价值是可监控、可回放、可统一回写；风险是云 IP / 模拟器指纹 / 登录态失效更容易触发风控。
