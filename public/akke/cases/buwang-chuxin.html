模块 2 · 内容分析 触发评论 · LLM 评分 · 两版破冰文案

跨品类问价 · 送达版聪明地绕开了比价，代价是没回答价

内容侧是评分模型 + 破冰话术生成共同决定的。本案的难点是品类错位 — 客户在门窗号下问窗价，但 Akke 做的是全屋装修。两版破冰对这个错位的处理方式正好相反：报价稿硬把窗价和装修价摆在一起比，送达版则干脆绕开比价、只讲自己能做的部分。这是一道「要不要跨品类报价」的判断题。

3.1 触发评论 · 问的是窗、不是装修

在孙姐聊门窗（号源池里类目「全屋定制」、但本身是门窗工厂号）视频底下，他写了 「老板帮忙看看这个 520 一平方」。意图很清楚：①在问价 — 520 一平方是系统窗单价；②在求评估 — 「帮忙看看」= 想让懂行的判断这个价贵不贵；③品类是门窗，不是全屋柜体。给了具体单价 + 求助意愿，评分高意向 93 —— 但评分没识别出品类错位，这是后面所有纠结的根源。

3.2 系统给他打了 93 分

3.3 报价稿（未送达）· 硬把窗价和装修价摆一起

报价稿在 transcript（✗稿）。它的策略是承接问价 + 引到自己品类：先接「看到你问 520 一平方」，再说「我们全屋装修按 284 一平算」，并说明门窗洞口能预留、品牌你自己挑。问题是 520 是窗价、284 是柜体装修价，两者根本不是一个东西 —— 摆在一起容易让客户误以为「你比那家便宜一半」，是个会引起误解的跨品类比价。这版没送出去，反而避免了一次误导。

3.4 送达版 · 绕开比价、只讲能做的

真正送达的破冰在 transcript（#1）。它不提任何价格，转而讲 Akke 真正能做的：系统窗洞口能精准测量预留、水电瓷砖防水吊顶配套做；并诚实地告诉客户「门窗品牌找做窗的师傅更准」，最后问几室几厅。这是一次聪明的避让 —— 既不跨品类乱报价，也不假装自己卖窗。

送达版的判断很成熟：客户问的窗价，Akke 没法也不该报。与其硬比一个误导性的 284 vs 520，不如老实说「窗找做窗的师傅、我帮你做装修配套」 —— 既守住了专业边界、又把话题引向自己能交付的部分。这种「不懂的不装懂」反而更可信。
代价 · 他问的价，一个字没回
绕开比价的代价是 —— 客户那句「520 一平方贵不贵」彻底没被回应。送达版直接跳到「我帮你做装修」，对一个还在纠结窗价的人来说，多少有点答非所问。更稳的中间地带：先轻轻接一句「520 的系统窗看断桥铝型材和五金，不算离谱」给个判断（哪怕不报自己的价），先回答他问的，再把话题引到装修。完全跳过问价，是这条送达版唯一的硬伤。

模块 4 · 地区分析 三层地区信号 · 只到省级，两版都没用

只知道他在安徽 · 市县和号源城市都缺，两版破冰都没碰地区

模块 6 · 信息内部流转路径 入库慢 + 报价稿没发 · 两处掉链子

这条 DM 在内部走过的物理通道，以及它在哪两步掉了链子

「评论入库 → 评分 → 起草 → 真机发送」在 DB 里是几行行变化，物理世界对应的是本地操作设备 + 人工审批 + 真机自动化。本案两个环节都掉了链子：采集回扫入库慢了 28h，起草好的报价稿又没发出去 —— 跟诚信案是同一类「手发链路无兜底」的病。

这个项目哪里做得好，哪里还能拧紧

给上面 6 个分析模块各打一个评价。good = 已达可复用标准；mid = 能用但有压缩空间；bad = 是这条链路的明显短板。本案是三条价格案例里短板最多的一条，但「绕开跨品类比价」的判断值得单独肯定。

模块 1

时效性 · 入库慢一天 + 报价稿没发

BAD
✓ 做到位
  • 没放弃：报价稿没发后有补发，lead 没彻底掉。
✗ 不足
  • 入库滞后 28h：早间评论隔天中午才入库，三条里最慢。
  • 报价稿没送达：起草后掉了，改发拖到第三天下午。
  • 评论→触达 ~56h：窗口凉透，几乎注定未回。
模块 2

内容 · 绕开比价对、跳过问价错

MID
✓ 做到位
  • 绕开跨品类比价：没硬报误导性的 284 vs 520，守住专业边界。
  • 诚实分工：「窗找做窗的师傅、装修我来」，不装懂、更可信。
✗ 不足
  • 评分没识别品类错位：门窗问价被当成全屋 lead 打 93。
  • 送达版完全跳过问价：他问 520 贵不贵，一个字没接，答非所问。
  • 建议：先懂行地轻判窗价，再引到装修。
模块 3

账号信任度 · 零星主页空白

BAD
✓ 做到位
  • 账号活跃可发：零星 messaging · active，最终把破冰发出去了。
✗ 不足
  • 主页资产全空白：昵称 / 简介 / 粉丝 / 作品都没抓取。
  • 跨品类更需主页背书：装修号回门窗问题，客户更想点头像搞清「这谁」。
  • 本周建议：立刻补零星主页截图。

BAD
✓ 做到位
  • 省级信号在手：IP 安徽已抓取。
✗ 不足
  • 三层缺两层：客户没自报城市、号源 city 未入库，is_same_city = null。
  • 两版都没碰地区：丢了「能上门服务你这片」的落地捷径。
  • 建议：跟进补「安徽哪边、能不能上门量房」。

BAD

✗ 不足
  • 问价完全没回应：客户问 520 贵不贵，送达版一个数字都没有。
  • 带价的那版没送达：284 报价稿掉了，客户更没拿到任何价格参考。
  • 建议：问价就该有回应 —— 懂行地轻判窗价，再引到装修。
