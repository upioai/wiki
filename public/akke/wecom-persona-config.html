配置你的销售身份（每人 3 分钟）

现在企微自动回复支持 4 个销售身份。你必须在自己云电脑上配一下"你是谁"，否则 AI 会用错身份（自称成都小艳、报错价）。
⚠️ 下面全部在你云电脑（远程桌面）里的 PowerShell 做，不是你本机电脑。

1先确认

云电脑上企业微信 已打开、已登录你的号、窗口没最小化到托盘（这是截屏自动化，看不见窗口就没法工作）。

2配置身份 + 开真发

把第 1 行的 key 改成你自己的，然后整段粘进 PowerShell 回车：

$MY_PERSONA = "xiaofan"    # ← 改成你的：野荞 xiaowen / Gus xiaowu / 夏夏 xiaoxia

$f = "C:\akke-wecom\.env"
Copy-Item $f "$f.bak" -Force
$L = Get-Content $f
$kv = @{ "AKKE_WECOM_PERSONA" = $MY_PERSONA; "AKKE_WECOM_DRY_RUN" = "0"; "AKKE_WECOM_DAILY_LIMIT" = "5" }
foreach ($k in $kv.Keys) {
  if ($L -match "^$k=") { $L = $L -replace "^$k=.*", "$k=$($kv[$k])" } else { $L += "$k=$($kv[$k])" }
}
$L | Set-Content $f -Encoding UTF8
Select-String $f -Pattern "PERSONA|DRY_RUN|DAILY_LIMIT"

✅ 最后应打印 3 行：你的 AKKE_WECOM_PERSONA=xxx / DRY_RUN=0 / DAILY_LIMIT=5。（前面会自动备份成 .env.bak，改坏能回滚）

3重启生效

整段粘进去：

Get-CimInstance Win32_Process | ?{ $_.CommandLine -like '*wecom_reply_loop*' } | %{ Stop-Process -Id $_.ProcessId -Force }
Remove-Item C:\akke-wecom\wecom_reply_STOP -ErrorAction SilentlyContinue
cd C:\akke-wecom; .\start-wecom-reply.bat
4验活

弹出的黑窗里看到 DRY_RUN=False + 在滚动扫描 = 成功。日限先 5 条小流量，盯前几条回复对不对（用"您"、说漳州、报 568）。把第 2 步的 3 行输出 + 黑窗截图发群，让夏夏/Claude 核一遍。

⚠️ 任何报错别硬来——找不到 C:\akke-wecom\.env（那台没部署过，要走首次部署）/ 401 / 连接超时，把报错发群 @夏夏 找 Claude。
