这份文档要回答什么:不是「AI 能不能做短剧」(能),而是——怎么用现成的开源工具,搭一条能批量产出「可投放广告素材」的流水线,且成本可控、数据私有、商用无 License 风险。GitHub / Huggingface 上的现成方案已经能拼出全链路,下面给出工具选型、两条落地路线与合规红线。

1广告 ≠ 短剧:四条硬约束

短剧重剧情连贯,广告重转化效率。这四点决定了工具选型和流程编排跟纯短剧不一样——照搬短剧流程会踩坑。

FIDELITY
产品必须保真

AI 最爱把产品画变形。真实产品外观 / LOGO / 包装不能出错,否则素材直接废。

广告:用真实产品图做参考,锁死外观
HOOK
前 3 秒定生死

投流靠完播和点击。开头 1 秒抓不住人就被划走,叙事必须「钩子前置」。

广告:痛点 → 产品 → 效果 → CTA
VOLUME
变体要量产

投放靠 A/B 海投测赢家,一条脚本要裂变成几十条变体,而非精修一条。

广告:hook × 口播 × 结尾 矩阵化
COMPLIANCE
投放要合规

平台审核、水印、商用授权、AIGC 标识。非商用 License 的模型碰不得。

广告:License 必须可商用

2端到端流水线 · 8 个环节

每个环节给出开源主选(带 License 徽章:绿=可商用 黄=受限/需授权 红=禁商用)与商业替代(质量 / 省事优先时)。紫色主线是数据流向。

01

策略与脚本

LLM · 钩子工厂

输入产品卖点 + 目标人群,产出多版「钩子脚本」(同一卖点 N 种开场角度),而非一个剧本。这一步就为变体埋种子。

DeepSeek / Qwen3 API/本地 本地 Ollama MIT Claude / GPT-5
02

产品与角色资产

保真 · 命门环节

用真实产品照片做参考图,靠编辑式模型把产品「贴」进场景而非重画;角色 / 模特用 LoRA 锁身份。产品保真度直接决定素材可用率。

FLUX.1 Kontext 非商需授权 Qwen-Image 编辑 Apache Character LoRA 随底模 Nano Banana / 即梦
03

分镜与编排

钩子结构

把脚本拆成 3–5 个短镜头,套广告结构:痛点镜 → 产品镜 → 效果镜 → CTA 镜。用编排框架自动管理资产与镜头一致性。

Jellyfish Apache-2.0 LumenX (阿里) MIT ViMax 编排层
04

出画 · 视频生成

I2V · 从产品图起

以第 2 步的产品 / 场景图做图生视频(I2V 比 T2V 更保真),生成每段 5–10 秒镜头;需要长镜头连贯接 SkyReels-V2。

Wan2.2 (I2V) Apache-2.0 SkyReels-V2 商用友好 即梦 Seedance2 / 可灵3
05

配音 · 口播文案

TTS · 卡时长

生成带情绪的口播 / 旁白。广告要精确卡时长对齐镜头节奏,多变体要快速换音色 / 语气。

IndexTTS2 (B站) MIT CosyVoice2 (阿里) Apache GPT-SoVITS v4 MIT
06

口型 · 数字人

带货口播

真人 / 数字人出镜口播带货:音频驱动口型,或单图生成半身说话人。追实时量产用 MuseTalk,追质感用数字人。

MuseTalk 1.5 MIT · 实时 EchoMimicV3 Apache · 12G HeyGem (硅基) 限商用上限
07

合成与包装

钩子字幕 · CTA · 品牌

拼接镜头,叠大字钩子字幕、CTA 按钮、品牌 LOGO、BGM、音效。广告的「包装层」往往比画面更影响点击率。

FFmpeg (脚本化批量) LGPL 剪映 / pyJianYingDraft 工具免费 Remotion (代码化)
08

变体量产 + 投放回收

矩阵化 · 数据闭环

同素材裂变多 hook × 多口播 × 多 CTA 批量出片 → 投 Meta / TikTok / 抖音 → 回收 CTR / 完播 / ROAS → 赢家素材反哺第 1 步迭代。

脚本批处理 (参数矩阵) 自建 Meta / 巨量 API 平台

3两条落地路线

A 路线全开源自托管,成本可控、数据私有、适合大批量投流;B 路线关键出画用商业 API,保真省事、适合高客单 / 精品素材。

TRACK A · 推荐主选

全开源自托管

无 License 顾虑 · 边际成本 ≈ 电费 · 适合海量 A/B 投流

  • 脚本本地 Qwen3 / DeepSeek 批量生成 hook 变体
  • 资产Qwen-Image 编辑 保产品 + Character LoRA 锁模特
  • 编排Jellyfish (Apache) 或 LumenX 管分镜与资产
  • 出画Wan2.2 I2V + SkyReels-V2 长镜头连贯
  • 配音IndexTTS2 卡时长 + CosyVoice2
  • 口型MuseTalk 1.5 实时 + EchoMimicV3 数字人
  • 合成FFmpeg 脚本化批量叠字幕 / CTA / BGM
硬件门槛:一张 24G 显卡 (4090) 全流程可跑;Wan2.2-TI2V-5B 版 8G 亦可
TRACK B · 混合

开源编排 + 商业出画

产品保真 / 音画同步交给闭源第一梯队 · 省折腾

  • 脚本Claude / GPT-5 出钩子脚本
  • 资产Nano Banana / 即梦 产品保真更稳
  • 编排ViMax (港大) 多智能体编排接 API
  • 出画即梦 Seedance 2.0 / 可灵 3.0 原生音画同步
  • 配音模型原生音频直出,省独立 TTS
  • 口型模型原生口型(可灵 5 语 / Seedance 8+ 语)
  • 合成剪映 / Remotion 模板化包装
成本参考:纯视频约 1 元/秒 (Seedance) · 但每条常需重抽 3–5 次

📋
AIGC 标识:《人工智能生成合成内容标识办法》2025-09-01 已施行,抖音等平台会读文件隐式标识自动打标。投放素材默认走「发布时主动声明 AI 生成」,不做规避——未声明会被检测强制加「疑似 AI」标,反而影响投放。
