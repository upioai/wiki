1 一次性准备每台机器配一次

和发私信（DM 通道）是同一台无影、同一抖音号。如果你的机器已经能发 DM，这步基本现成，只差脚本。

  1. 抖音 PC 客户端：登录你自己的抖音号、窗口最大化、放在最前台。
  2. 锁分辨率 2560×1600：Mac 无影客户端「显示设置」关掉分辨率自适应、全屏别缩放窗口。 最关键漂了的话所有坐标全偏。详见 锁分辨率教程。
  3. 输入法切英文（Win+空格）。中文 IME 会抢搜索词首字 → 搜错人。
  4. 确认 .env 有 OCR key：发 DM 用的那把（OpenRouter key 放在 ANTHROPIC_API_KEY 槽）。二次触达的身份门、开视频、定位发送键都要它。
  5. 部署脚本 douyin_comment_grounded.py 到 C:\akke-wuying\（必须和 douyin_dm_grounded.py 同目录）。
    怎么部署？不用自己弄。对 Claude 说「把二次触达脚本部署到无影」， Claude 会把一条 PowerShell 打包命令复制进你的剪贴板，你在无影 PowerShell 里 Ctrl+V → 回车， 看到 WROTE chars=... 就装好了。或者用 PM 的最新镜像（已含脚本）。

2 怎么触发 Claude说哪句话

这套流程封装成了 Claude 的 skill send-cloudpc-second-touch。你不用记命令，对 Claude Code 说下面任意一句，它就自动按流程带你走：

「云电脑二次触达」 / 「二触发一批」
「潜在用户二次触达」 / 「云电脑二触」
「用云电脑做二次触达」
「给已发过 DM 的再勾一次」

带上你的需求更省事，比如：

「云电脑二次触达，发 10 条」
「帮我准备一批二次触达文案，然后用云电脑发」
注意区分 只是想看数据（"今天发了多少评论"）→ 不用触发这个 skill，直接问 Claude 查就行。 这个 skill 是真的去发评论时才用。

3 日常操作 SOP每次发

触发后，Claude 做本机的活（备料 + 传文件），你只需在无影 PowerShell 跑一条命令 + 最后核对。

  1. 说要发几条（如「云电脑二次触达，发 10 条」）。Claude 自动从「已 DM、≥3 天没回的高/中意向」名单里取人（second-touch-worklist，触达前已确认对方真没回）、用 qwen3 生成二次触达话术，做成 contacts.csv（含去重要用的隐藏 ID 列）。
    别手打 CSV 走批量 Claude 出的 CSV 带 _comment_id/_sec_uid 两列——这是发完去重的命门。手打的 CSV 没这两列，发完无法回写去重账本，只能一次性临时用。
  2. Claude 把 CSV 传到无影，给你一条命令（进剪贴板）。在无影 PowerShell Ctrl+V → 回车，文件落到 C:\akke-wuying\contacts.csv。
  3. 在无影 PowerShell 跑（默认自动发，中间不打断，每条隔 60 秒）： 
    python douyin_comment_grounded.py contacts.csv
    想逐条人工把关（每条发前问你 y/跳过）就加 --confirm： 
    python douyin_comment_grounded.py contacts.csv --confirm

    它每条会走：搜人 → 身份门核对 → 点开第一条视频 → 暂停 → 切评论区 → 打字 → 发送 → 点左上角返回键回主页。

    跑起来后别碰鼠标和键盘！ 脚本全程在控鼠标搜人/点击/打字，你手一动就抢走焦点 → 点歪、字漏进 PowerShell、那条发不出去。 挂着让它自己跑完（4 条约 5 分钟）。脚本已加保护：抢不回焦点的那条会自动跳过（标 focus_fail）不会乱发。
  4. 把运行日志整段贴回给 Claude（每条的 ✅ 已点发送 / [跳过] 身份门未过 等），让它帮你判断哪些发了、哪些没发。
  5. 把 comment_log_日期.csv 拷回给 Claude 写回节奏状态别省。无影上跑完会生成这个日志；让 Claude 给你一条命令把它打包传回本机，Claude 跑 mark-second-touch.ts --from-comment-log 写回 second_touch_state。
    这步是去重命门 不回写的话，下次出二次触达名单会把这些刚发过的人当「从没触达」重新挑出来再评一次。回写后他们进节奏阶梯（隔 4 天才再触、对方一回复就停），不会重复骚扰。
  6. 核对实发（见下方铁律）：逐条刷新对方视频评论区，确认评论真出现了。

4 三条安全铁律必看

① 发完一定以「评论区气泡」为准核对 脚本里的「✅ 已点发送」只代表点了发送键，不等于真发出去。 收尾必须逐条刷新对方视频评论区，亲眼看到你那条评论才算数。
② 短名 / 大众名容易评错人 身份门对 3 个字以内的短昵称（小霞、东方、瑶…）可能放行到同名的另一个人。 这类名字用 --confirm 逐条确认，别塞进自动批；独特名（峥宇60km/小时这种）才放心自动发。
③ 别和发私信同时跑 二次触达和发 DM 是同一台无影、同一抖音号，同一时间只能跑一个脚本（一台机只有一个抖音 PC 前台）。 发 DM 的时候别开评论，反之亦然。
④ 发完一定回写节奏状态 把 comment_log 拷回给 Claude 跑 mark-second-touch.ts --from-comment-log。这是节奏去重唯一生效的一步——漏了 下次名单会把这批刚发过的人重新挑出来再评一次，对方体感是被反复骚扰。

5 排错速查

现象原因 / 处理
整批都被「身份门未过」拦下、发不出多半是分辨率漂了（用户 tab 点歪）→ 重新锁 2560×1600；或 CSV 昵称填了数字号 → 改真实昵称。
文字打到了 PowerShell / 桌面，没进评论框焦点没在抖音（脚本会打印前台窗口=，应为「抖音」）。一般脚本自己会修；反复出现就重启脚本、确认抖音在最前。
文字进了框但没发出去发送键没点中（长评论框会变高）。脚本已改成现场找「发送」二字；还不行就贴日志给 Claude。
评论发到了别的视频下视频播完自动跳了下一条。脚本已加「先暂停」；若仍发生，贴日志给 Claude。
第 2 条起搜到的是上一个人 / 日志 [复位] ⚠️ 未回主页发完没退出视频浮层。脚本已改成点左上角「返回」键回主页；若 VL 没认出返回键，让 Claude 量一个固定坐标 AKKE_C_BACK 写进 .env。
下载 CSV / 脚本卡死不动paste.rs 在国内偶发卡 → 让 Claude 改用剪贴板打包（gzip+base64）方式重发。
OCR 报 401 / 整批 wrong_user无影 .env 里那把 key 失效了 → 找 Claude / PM 换一把已验证可用的 key。
卡住别硬猜把 PowerShell 里的整段日志贴给 Claude，或截图发群找 PM。
