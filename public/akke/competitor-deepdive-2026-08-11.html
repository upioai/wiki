Verdict

总判断 + 三条关键修正
总判断 · 置信度 0.75

四家与 Akke 的正面重叠都不在「跨账号评论区高意向挖掘 + 主动冷触达」这个环节。

尘锋管私域内（流量进来之后）；螳螂 / 美洽承接进线私信（客户先开口）；来鼓最激进也只到「自家评论区主动私信」。Akke 的主动开源位置在四家产品面上均无对应物——但独有性表述必须收窄为：跨账号 / 竞品评论区挖掘 + 陌生人冷触达。

修正 1 · 厂商自述 0.85

来鼓有「评论追粉」：一轮「来鼓 = 纯被动承接」作废。

自动识别自家账号评论区高意向用户，1 分钟内主动私信 + 定时多次追踪。但限自家评论区、走官方授权通道，无跨账号挖掘、无陌生人冷启动。

修正 2 · 机制存在 0.85 / 全自动程度 0.5

尘锋 2025「AI 员工」宣称可 AI 代发激活沉默客户：一轮「尘锋只提醒人发」需软化。

按销冠 SOP 24h 二次触达、行为信号判断跟进时机；案例：某消费医疗 1 个月挖 120+ 沉默客户到店。但全部厂商自述，渠道限企微 / 外呼私域内（非平台侧触达），家装场景 AI 案例为零。功能③的领先窗口在收窄。

修正 3 · 第三方 0.8

抖音开放平台 2025-04-14 起收回私信开放能力——官方接口阵营的头顶悬剑。

新开发者永久停止申请私信/群聊 scope（im.direct_message 等），90 天无调用的存量应用回收。来鼓 / 美洽 / 螳螂靠存量服务商资质运营，政策再收一档即断粮。平台依赖性风险是它们的，通道自主性是我们的（代价是合规风险自担）。

Deep Dive 1

尘锋 SCRM（dustess.com）

底盘与家装叙事

SCRM 侧最贴身
底盘
2016 成立，约 900 人，4 轮融资超 2 亿元（含腾讯战投）；自称 30+ 行业 10,000+ 企业。家装是官网正式行业方案（0.9）。
家装叙事
获客引流 → 线索分配/回收/回传 → 离店客户自动回访 → 二次到店成交；抓的痛点是「首次到店难成交，二次到店/量房才是下定金节点」。实名案例爱空间：3000+ 素材、6 万转发、1 万+ 微信线索——全是运营动作量，无签单归因（0.6）。
抖音端
只有承接没有开源（0.8）：广告落地页表单→一键加企微（获客助手）+ 广告线索回传。不碰自然流量评论区、不主动私信。零假设：若有，家装方案页应出现「评论」「私信托管」字样——两轮搜索均未出现。
定价
【第三方 36dianping】标准版按坐席阶梯 840-1,200 元/人/年（100 人+ 议价）；标准版不含会话存档（AI 质检/摘要依赖它，实际总价更高）；AI 员工单独报价未查到。小装企 5-10 席年成本约 5-13k 起。
交付
直销为主 + 云巴巴等分销；有「运营顾问/代运营」议价服务——对不会做私域的传统客户的粘性来源。
弱点
①抖音无开源；②会话存档拆开收费；③AI 效果数字无家装样本（案例全是教育/医美）；④按席位计费与装企小团队/高流动错配（推断 0.6）。
确认合理 · 别在客户面前贬低的强项

36dianping 4.6 分 / 314 条，性价比与易用性同类靠前；企微私域基本盘真实成熟。打差异不打产品烂。

Deep Dive 2

螳螂科技（tlmantis.com / bjmantis.cn）

底盘与家装叙事

家装内容矩阵最厚 · 实锤最薄
底盘
2016 成立，100-499 人；教育 CRM 起家（新东方/沪江），双减后铺 30+ 行业；2021 A 轮近亿元后 5 年无新融资披露；猎聘当前 0 在招职位（投入强度信号偏弱 0.5）。客户数口径打架（5000+ vs 10000+，取低）。
家装叙事
十余篇「家居家装 AI 私信客服」SEO 专题页（多渠道接入 / 家装话术库六类：报价·户型·量房·风格·工期·售后 / 夜间追粉 / 合规留资 / CRM 联动）——四家里家装内容矩阵最厚。但全是软文体（真实深度 0.6），案例全部匿名零实名（0.8）。
能力边界
40+ 渠道进线私信统一承接；有「评论区感知」（识别用户从哪条视频/评论来，带上下文接待）、「主动推名片/智能唤醒」——但对象都是已进线/已互动访客。无扫评论区→打分→冷触达（0.75）。企微侧偏传统 SCRM，AI 代聊主战场在平台私信。
定价
零公开数字，纯询价制（基础/标准/定制三档）。招投标/代理价：未查到。
弱点
①家装案例零实名（零假设：若有可公开标杆，SEO 文海不可能一次都不点名）；②36dianping 综合分仅 2.1/5（8 条样本小，方向偏负，不当铁证 0.6）；③教育底色，「家装专属」深度存疑——无专职家装行业线招聘、无实名标杆。
确认合理 · 别硬顶的强项

多平台私信聚合接待 + 平台原生组件合规留资是真实能力，Akke 目前没有 40+ 渠道聚合。

来鼓 AI（laigu.com · 成都呼声科技 2021）

三 Agent 拆解与定价

机制最近邻 · 定价明码
三 Agent
增长获客 Agent 是主力（私信接待+意图识别+打标+追问留资 0.8）；内容营销 Agent 生成是真 LLM、「测试迭代」是报表能力（0.6）；成交转化 Agent 疑似最薄（企微聚合+提醒 0.55）。整体疑似「一个私信接待内核 + 三张营销皮」（推断 0.5，零假设：若各自独立成熟应有独立产品页/文档/案例——均未查到）。
评论追粉
自家账号评论区高意向 1 分钟内主动私信 + 定时多次追踪【厂商 0.85】。这是全部 42 家里离我们功能①最近的产品化。
家装
官网首页直接放家装销售主管角色案例；专题案例某头部家装品牌 30+ 小红书 KOS + 抖音企业号，宣称留资率 +38%、ROI +56%、开口率 75%+（匿名，数字 0.4）。
定价
官网明码（0.9）：入门 ¥1,688/年（1 账号/200 对话月）→ 专业 ¥6,888（5 账号/1000 对话月）→ 企业 ¥16,888（20 账号/3600 对话月）；预充值：开口 ¥0.8/个、留资 ¥2.0/个（各 ¥5 万/年起充）；企微专用 ¥6,888/年。超量计费规则未公开。
通道
小红书首家官方授权服务商（有官宣背书 0.85）；抖音依赖存量服务商资质（0.65，见修正 3）。
弱点
帮助文档（飞书 wiki）404、产品透明度低、评估全靠销售；零第三方评测零差评零投诉（声量小的信号）；招聘 JD 未查到。
别低估

¥2/留资对家装客单价极便宜，价格竞争力是真的（0.8）。但口径关键差异：它的「留资」是用户自己进线后留的（承接口径），我们交付的是主动挖掘的高意向触达（开源口径）——被拖进 ¥2 比价就输了，先立口径再谈价。

Deep Dive 4

美洽 Meiqia（meiqia.com · 13 年客服 SaaS）

抖音获客链路与边界

工程最成熟 · 完全被动
链路
仅支持认证企业号扫码授权接入（官方帮助文档原文 0.9）→ 评论区 AI 公开回评多轮引导进私信（不能主动私信任何用户，比来鼓更被动）→ 私信 AI 接待（情绪检测、负向转人工、一问多答）→ AI 自动打标（已留资/待跟进/高潜 + 顾客印象卡）→ 平台标准留资卡 API → 私域沉淀。
沉默回捞
5min/30min/2h 递进触发器自动追问——限已进线用户、短时间窗，无跨天老客召回（0.85）。
家装
零案例零模板（多轮检索无命中 0.7）；行业叙事集中在本地生活（餐饮/丽人/家政/教育/医美）。家装垂直是它的空白区。
定价
【第三方 36dianping 0.75】在线客服 ¥0-5,888/坐席/年；客服机器人 ¥3,888 / ¥16,888 每个/年；营销机器人 ¥8,888 / ¥22,888 每年；抖音获客机器人无公开单独标价（官网价格页 404）。
弱点
获客上限 = 自家进线流量——「线索遗漏率降 92%」恰好自证其价值定位是止损不是开源（0.85）；36dianping 评价两极（23 个 5 星 + 4 个 1 星）。
确认合理 · 别硬碰

13 年客服底盘、150+ API 对接、多渠道聚合工作台——「接得稳」大概率优于 Akke 当前水平（0.75）。打「开源 vs 止损」，不打接待体验。
