无影云电脑 · 自动发私信 · 日常操作指南

部署完之后,每天就只有「开机 / 关机 / 偶尔查一下」三件事。 电脑要关机没关系——云电脑关了只是暂停,不丢单,开机自动接着发。
面向 运营 配套 部署见 wuying-selfdrive-deploy.html 查状态 skill: cloudpc-selfdrive-ops

0 先记住一句话

云电脑开着 = 自动发;关了 = 暂停(不丢单);再开 = 自动续。

服务端(云上)一直在出单排队,云电脑只在开机时把队列里的单发出去。 所以你下班关电脑、云电脑跟着关,完全没问题:没发的单在队列等着,第二天开机自启的程序自动接着发。 发送只发生在「白天云电脑开着」的时段,正好也避开深夜打扰陌生人。

1 每天开机:确认 3 件事(约 1 分钟)

  1. 抖音 PC 开着、登录本账号、窗口最大化、在最前台
    抖音登录一般能撑十几天;掉登录了重新扫码。别让别的窗口盖住抖音(程序会自动把抖音置前,但起不了没开的抖音)。
  2. 输入法切到英文
    Win + 空格切「English」。中文输入法会抢走搜索词的第一个字 → 搜错人,这是最常见的翻车点。
  3. 不用手动开程序 —— 开机自启会自动跑
    登录后约 30 秒,自动发送程序会自己启动。想确认就看一眼日志:
    Get-Content C:\akke-wuying\wuying-dm\agent.log -Tail 8
    看到 === wuying_poll_agent account=... === 就是在跑了。万一没起来,手动开:
    cd C:\akke-wuying\wuying-dm
python wuying_poll_agent.py
就这样。剩下它自己按节奏发,你该干嘛干嘛,不用一直盯着。

2 下班 / 关机:直接关就行

不用做任何收尾,直接关。会发生什么:

没发完的单留在队列里等着,不丢、不重发,下次开机自动续
正发到一半被关的那条会被系统在 15 分钟后自动回收,下次重新领取,不会卡死
服务端照常一直在出单排队(顶多队列里压 1 条等你开机)
所以不挑关机时机,随时关都安全。深夜不开机 = 不打扰陌生人,反而更稳。

3 想知道「在发吗 / 怎么没发 / 还能发几条」

你在自己电脑上看不到云电脑内部,但可以用下面的 skill / 命令从后台反推。

SKILL · cloudpc-selfdrive-ops

直接问 Claude 就行(自驱通道·查看运维)

在 Claude Code 里这样说,它会自动查后台、告诉你状态和原因(只查看,不发消息):

云电脑在发吗今天发了几条云电脑怎么没发 还能发几条几点自动续云电脑开机后要做什么

它背后跑的是 scripts/cloudpc-status.ts。要手动逐条发请用另一个 skill send-cloudpc-dm(不同通道)。

也可自己在本机跑(读 .env.local 的账号):

pnpm tsx scripts/cloudpc-status.ts

输出示例(它会算出「几点自动续」):

=== 云电脑自驱状态 · 小文(野荞) ===
channel_pref = cloud_pc
今日真成功(滚动24h): 20/20   近1h: 1/10
判定:
  ⏸ 今日已满 20/20。最早约 06-06 14:53 滚出窗口、自动续(无需操作)。

4 它按什么节奏发(知道就行,不用改)

发送节奏每分钟 1 条 · 满 10 条停约 1 小时 · 当日封顶 20 条,慢是为了不被抖音限频封号
「20 条」算的是真成功的(被对方拒收/限频的不算,会自动跳过、把名额留给下一条)
跨通道合并同一账号若你白天也用手机/WDA 手发过,会和云电脑共用当天 20 条额度(防叠加触发风控)。所以手发多了,云电脑当天就少发
改节奏 / 上限由 PM 在后台改;你想调发多少,找 PM

5 排错速查

现象怎么办
开着但不发多半当日 20 条满了(含你手发的)→ 问 Claude「几点自动续」;或这账号没开 cloud_pc(找 PM)
搜错人 / 老是跳过八成输入法不是英文(切英文重开程序);或名字太大众撞了同名大号(跳过=安全,不会发错)
日志 agent.log 是空的程序可能没自启 → 手动 cd C:\akke-wuying\wuying-dm; python wuying_poll_agent.py;或刚开机还在 30s 倒计时
抖音掉登录了重新扫码登录本账号,最大化、置前,程序会继续发
不确定到底正不正常问 Claude「云电脑状态」,它一查就知道

6 怎么跟 Claude 开口(操作 / 修改 / 新增)

自驱通道平时它自己跑,你不用「调」它。想看 / 想改 / 想加时,跟 Claude 说一句即可:

你想干什么怎么说(例句)
看状态 / 排错「云电脑状态」「今天发了几条」「云电脑怎么没发」「还能发几条」「几点自动续」
手动即时多发一批「云电脑发 10 条」(手动通道,跟自驱并行;受当日上限 + lead 池限制)
改配置(节奏 / 上限 / 开关)「日上限改成 30」「每批 15 条」「先停自动 / 再开自动」
改 / 加文档页「改部署指南的 X」「进展页加一段」「新做一页 Z」(改完自动重发 upio.ai)
加机器 / 加账号「新开一台云电脑怎么配」「给 XX 的号也接上自动」
改逻辑 / 改代码直接说需求,如「拒绝识别再加一种提示」「派单只发高意向」
一句话记忆:想知道情况 → 「云电脑状态」;想多发 → 「云电脑发 N 条」;想改规则 → 「上限/节奏/开关改成…」;想改文档 → 「改/加某页」。改配置/代码这类由 PM 或开发确认后再执行。

日常 = 开机确认 3 件事 → 它自己发 → 下班直接关。不懂就问 Claude「云电脑状态」。
