⚡ 话术 critic workflow

挂在 → H1 话术审核（打分 / 派单之间）

现在 PM 每天肉眼核对生成的私信措辞、防 persona 跑偏和 tool-call 泄漏。改成发送前内联一道评审：生成 opener → 多 lens 并行 critic（合规 / 泄漏 / persona 一致 / 舞台指示）→ ≥2 过才放行，否则回炉重生。

judge panel · PM 从「每条都看」降到「只看 critic 拦下的 borderline」

⚡ 号源 LLM judge

挂在 → H2 号源确认（采集之前）

边缘号源现在推 Lark 等人点头，怕拉错同行。改成 judge agent 给每个边缘号打分（脉象明确度 / avgC / 是否同行）：高分自动入库、低分自动丢、只有真模糊的才推人。

扩源提速 · 阈值确定性走代码、judge 只啃模糊地带

⚡ 异常自愈 agent

挂在 → H3 云电脑执行 / 账号安全

现在验码、风控、cookie 过期、发送失败都是 cron 告警等人处置。升级成：告警同时 spawn 诊断 agent，读 log 判类型，走确定性 runbook 自恢复（换号 / 进冷却 / 重试 / 提醒重导 cookie），只有自愈失败才升级到人。

夜间无人扛 · 从「告警等人」到「先自救再升级」
