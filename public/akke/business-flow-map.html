⚡ 彻底无人化触达 + 自愈

挂在 → DM 一触 · 二次触达 · ④ 云电脑执行 / H3 风控

现在云电脑能自动发，但碰抖音验证、云电脑闪退仍要人盯。目标：DM（野荞）与潜在触达（范丽）都彻底自动发，遇验证 / 闪退 / 风控自动识别修复，全程不需人工监控。

提出：野荞 · 范丽 · 团队　|　现状 半自动盯屏 → 目标 0 人监控自愈

⚡ 话术云端自动生成

挂在 → ② 打分 / 话术（H1）

现在 opener 在本机生成、再经 paste.rs 导入云电脑。目标：话术直接在云电脑侧自动生成，免去本机→云电脑的导入环节（先核查现有话术机制），并叠加 critic 自审防泄漏。

提出：范丽　|　现状 本机生成 + 手动导入 → 目标 云端一步生成

⚡ 回执多 agent 验证真送达

挂在 → ⑤ 回执 / mark

现在靠 Vision OCR 判发送成功，但抖音 HTTP 200 ≠ 真送达（status_code 7911 静默丢）。目标：云电脑识别 dm / rc / 潜在触达后汇报成功，多 agent 交叉验证是否真的测试发送成功。

提出：范丽　|　现状 单点 OCR → 目标 多 agent 交叉验真

⚡ 爆款图文 / 视频全自动发布

独立内容通道（不在私信漏斗上，同属获客系统）

现在图文 / 视频要运营手机连 USB、人工发。目标：爆款图文 + 视频全自动生成 → 发送工作流，免手机连接、免人工（对应 douyin-tuwen / weekly-tuwen 通道升级）。

提出：夏夏　|　现状 手机 + 人工发 → 目标 全自动工作流
