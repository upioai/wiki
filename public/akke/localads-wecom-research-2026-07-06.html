调研：抖音本地推 → 企业微信，付费获客链路对「有大有小」是否可行

调研日期 2026-07-06 · 对象：有大有小（全屋定制/装修）· 方法：巨量学官方帮助中心 API 逐条核实 + 公开来源交叉验证 · 调研人 Claude（受 Gus 委托）
一句话结论：方向可行且是平台正推的路，但「广告一键跳企微加粉」组件是行业白名单制，家装是否在名单里官方没公开——唯一确定方式是让有大有小去问抖音直客。白名单没开也有等效兜底（表单拿手机号→企微按号加人），经济账对全屋定制客单价成立。

1. 调研什么问题

Akke 现在给有大有小跑的是免费自然流：抓评论 → 意向打分 → 主动私信/反评/企微承接。这条链成本≈0 但量受限（评论池就那么大 + 抖音陌生 DM 7911 限流）。本次调研的问题：用付费广告（抖音本地推）直接把用户导进企业微信，对全屋定制/装修行业走不走得通、划不划算、跟 Akke 现有链路怎么咬合。

2. 官方链路全景：平台正在把家装往这条路上赶

先看大背景——这不是灰路子，是巨量官方 2026 年的主推方向：

  • 巨量营销平台（旧巨量 AD）的「销售线索」营销目的正全线分批下线，强制迁往巨量本地推 / 抖音来客（2026 年 1 月起分批；官方通知原话「推荐您尽快入驻抖音来客和巨量本地推」，巨量学文档 id 145291 / 188710）。家居装修、家居建材都在迁移行业名单里。
  • 装修/全屋定制属于抖音来客的「线索商家」类目，可入驻（官方《抖音来客｜线索商家快捷入驻操作手册（对外版）》id 166286）。资质门槛：营业执照经营范围含「建材、装修、家具家居」等（官方资质文档 id 128051）——正规装企没有障碍。

「广告→加企微」在官方产品里是两条并行能力，行业口径不同：

① 巨量本地推【企业微信组件】（来客/本地推侧 · 本次调研主角）
   来客后台创建企微组件 → 本地推投放营销页
   → 用户点按钮一键拉起企微获客助手加粉（免扫码）
   → 后台默认回传「成功加粉」；API 可补确认意向/预付定金等深度回传

② 企业微信获客助手（巨量营销平台侧）
   获客链接配到抖音私信页 / 橙子落地页 → 用户 1 步加企微
   官方口径：「当前巨量营销平台支持部分客户使用」= 白名单/邀约制

4. 白名单没开也有等效兜底（家装商家实际在跑的路）

即使企微组件对家装暂未开放，链路照样成立，只是多一步：

本地推「表单留资 / 私信」投放 → 拿到手机号
   → 中国大部分人手机号 = 微信号（团队已验证的经验）
   → 企业微信按手机号搜索添加 → 进入 Akke 企微承接链路
  • 线索流出有官方对接口：本地推走巨量引擎插件授权自动同步 CRM；来客走开放平台「生活服务商家应用」（纷享销客官方帮助文档验证）。
  • 代价：从「用户点一下自己加进来」变成「我们拿号去加」——加得上率受对方手机号搜索开关影响，且是 outbound 动作，转化率低于 inbound 一键加粉。

6. 对 Akke 的意义：三个咬合点

#咬合点说明
1量的放大器自然流（评论→DM）成本≈0 但有天花板；付费本地推是给有大有小补量的官方正路。两条流互补，不是替代。
2护栏必须前置付费线索进企微后由 Akke 的 chatReply 承接——而企微通道目前是裸通路、没有抖音侧的 gateDraft 护栏。自然流乱回复丢的是免费线索，付费流乱回复丢的是 100 多块一条的真金白银。接付费流量前必须先给企微通道补上 gate。
3深度回传是差异化优势平台默认只回传「成功加粉」；API 支持「确认意向 / 预付定金」深度回传，回传越深投放模型跑得越准。Akke 的对话阶段机（ice_break/nurture/decision）+ 意向分析天然就是深度回传的信号源——这是一般装企和代运营做不到的。

7. 风险与红线

  • 白名单不确定性：企微组件对家装是否开放未确认（§3），推进前先问直客，别按「肯定能开」排期。
  • 线索质量水分：家装线索行业公认水分大（同行探价、装修中介填表）。小预算试投先验质量再放量。
  • 合规红线：本地推有《使用销售线索收集功能的本地推客户违规行为治理公告》（官方 id 143812）——用户信息泄露/兜售、仿冒身份沟通是封号级违规。Akke 自动化承接侧注意话术与数据使用合规。
  • 获客助手 ≠ 微信客服：加进来的是企微「外部联系人（好友）」，好友 1:1 自动回复没有干净的官方 API——正好由 Akke 已在生产的方案B（企微 GUI 自动化）承接。详见同日姊妹篇 《抖音商业获客到企微客服 API 方案》评审（那篇讲承接层的技术选型与 ICP 备案硬墙，本篇讲引流层的官方投放链路，两篇拼起来是完整闭环）。
