1 为什么买企业版 + 为什么必须 3 台

个人版 vs 企业版

核心：长时间挂机跑自动化脚本，企业版年包不限挂机更省；个人版按核时（灵豆）计费，长跑会扣爆。

场景推荐理由
每天脚本 <3.5h个人版按需付费更省
常驻长跑（≥6h / 24h）企业版不限挂机，年包更便宜
多账号 / 多机扩展企业版批量集中管控

临界点：每天挂机超过约 3.5 小时，个人版仅灵豆成本就已超过企业版全年费用。个人版黄金 14 元/月 + 灵豆（4核8G 经济模式 4 豆/小时，约 0.0387 元/豆），24h 挂机约 125 元/月。

为什么不能「1 台 + 3 用户」

结论：3 个号要同时发 → 必须 3 台，省不掉。
  • 无影云电脑是单用户独享：一台同一时刻只能一个用户连接登录，多账号只能轮流登，不能 3 会话同时跑。
  • GUI 自动化要独占桌面焦点：模板匹配 + SendInput 需独占键鼠，一台桌面跑 3 份脚本会互相抢焦点必崩。
  • 一台桌面 = 一个抖音客户端 = 一个号：3 个号同时在线发，就得 3 个独立桌面。

唯一省钱替代：若 3 个号不需要同时发、可错峰，可用 1 台分时串行（登 A 发完→退 A 登 B…）。但频繁切号登录招风控、总产能 = 1 台、稳定性差。3 个号常驻发送不建议这么省。

风控提示：无论个人版/企业版，出口均为阿里云 IP 段。升级版本不会降低平台风控风险，需持续监测 3 台各自的发送成功率。

0 阶段 0 · 企业实名认证 + 控制台授权 一次性

没通过企业实名前，4核8G 199 年包的企业 SKU 可能根本不出现，别急着买。

0.1 进实名认证页

  1. 登录 阿里云控制台 home.console.aliyun.com（用公司这个账号）。
  2. 右上角鼠标移到「会员名/头像」 → 下拉点「账号管理」（或直接开 account.console.aliyun.com）。
  3. 左侧导航点「实名认证」。
  4. 当前若显示「个人实名 / 未认证」→ 点「企业实名认证 / 切换为企业」开始。

0.2 选认证方式（3 选 1）

方式需要什么谁操作多久适合
① 法人扫脸 推荐 企业全称或统一社会信用代码 + 法人本人支付宝（已实名） 必须法人本人用支付宝扫脸 几分钟～1h（自动审） 法人能配合、求最快
② 企业支付宝授权 企业对公支付宝账号 + 营业执照照片 经办人即可 1～3 工作日 有企业支付宝、法人不便
③ 银行卡对公 营业执照照片 + 对公银行账户信息 + 法人身份证 任何经办人 1～7 工作日（等银行打款） 法人不便、只有对公账户

要尽快开机 → 选 ①法人扫脸：填「企业名称」或「统一社会信用代码」匹配工商信息 → 生成扫脸链接/二维码 → 法人用本人支付宝 App 扫脸 → 几分钟出结果。法人不在 → 退选 ② 或 ③，但要等 1～7 天会拖到开机。

0.3 等认证通过

实名认证页状态变「已认证（企业）」即可。

0.4 首次进无影控制台授权服务关联角色

  1. 认证通过后开 无影企业版控制台 gws.console.aliyun.com。
  2. 首次弹「创建服务关联角色 / 云资源访问授权」→ 点「同意授权 / 确认」。
  3. 不点这个，后面建办公网络、建云电脑会报权限错。

1 阶段 1 · 一次下单 3 台

导航：资源管理 → 云电脑企业版 → 创建云电脑。第一台买完办公网络自动生成，3 台都挂它下面。

字段填什么
区域华东1（杭州）或就近国内 region（定了不能改）
操作系统Windows Server 2022（含激活）
计算规格企业办公型 4核8G
计算套餐/时长注意不限时长（不要选 120 / 250 / 360 小时/月）
购买方式/付费注意包年（年付），不要选「按需 / 按小时」
系统盘80 GiB
数据盘0 GiB
公网带宽默认 5Mbps/台（共享）
数量3 ← 一次买 3 台同配置

分配用户区先点「创建并添加新用户」建 1 个管理账号（用户名如 yeqiao-cloudpc + 邮箱）→ 点「立即购买」付款。价格应为 199×3 = 597 元/年。

付款前再核一眼：3 台都是 包年 + 不限时长。漏 1 台选成「按需」会偷扣核时（灵豆），企业版就白买了。

2 阶段 2 · 用户分配（1 账号绑 3 台）

云电脑登录用户 ≠ 抖音号。用 1 个便捷账号绑全部 3 台最省心。

  1. 用户中心 → 用户管理 → 找到刚建的账号 → 操作列「查看/分配云电脑」→ 勾选 3 台全绑。
  2. 该账号收到邮件/短信：组织ID + 用户名 + 初始密码。
  3. 装无影客户端（Win/Mac）→ 输三件套登录 → 改密码 → 进去会看到 3 张桌面卡片。
脚本是在 VM 上跑的，不依赖你客户端是否在看那台。客户端同时只能"看"一台，但另外两台 VM 照常跑脚本，互不影响。所以 1 账号管 3 台、24h 无人值守 3 台同时发完全 OK。

想分人管也行：建 3 个便捷账号 1:1 绑。但单运营跑 3 号，1 个账号管 3 台最省事。

3 阶段 3 · 策略（自动发能否跑通全在这）关键

导航：运维管理 → 策略 → 创建策略 → 填名 → 配下面 → 确定 → 绑定时一次勾 3 台（建 1 份全生效）。

3a. 安全组规则（出方向 egress）——让 3 台都能出网到 paste.rs / 抖音

在「安全组管控」区点「添加安全组规则」，加两条：

规则方向出方向出方向
授权允许允许
优先级1（1~60，越小越高）2
协议类型TCPTCP
端口范围44380
授权对象0.0.0.0/00.0.0.0/0
描述egress httpsegress http
默认安全组「除流网关 ASP 外全遮断、无外网 IP」。只放 egress，别开 inbound。 发不出去先查这里。

3b. 同屏其余策略项

  • 剪贴板：双向允许（贴 CSV / 文案进去）
  • 本地磁盘映射 / 文件传输：双向允许（paste.rs 之外的保险通道）
  • 画质策略：流畅 / 标准（省带宽、稳模板匹配）
  • 防截屏：关闭、水印：关闭（开了会污染 GUI 模板匹配截图）
  • 登录方式管控：限单账号 / 关多端同登

4 阶段 4 · 逐台装环境（3 台各做一遍，不能批量）

客户端依次双击 3 张桌面卡片进每台 Windows：

  1. 装抖音 PC 客户端，每台登一个不同的抖音号（机1=号A，机2=号B，机3=号C，别在一台挂多号）。
  2. 装 Python + 依赖，部署 worker/scripts/wuying-dm/douyin_dm_grounded.py。
  3. 每台按自己的分辨率/DPI 重截模板图（发送键等）。3 台同镜像同规格通常分辨率一致、模板图可复用；只要有一台不同就单独重截，否则那台点空（与「固定座标漂移点空 tab」同类坑）。
  4. 起脚本常驻。3 台 VM 各自独立跑，互不抢焦点。

5 日常运维（3 台）

  • 批量开关机：资源管理列表页多选 3 台一起开机 / 重启。
  • 逐台自检（无法批量）：开机后每台各自确认「抖音号在线？脚本起没起？今天还能发几条？」——按 cloudpc-selfdrive-ops skill 逐台过。
  • 分别盯成功率：3 台同出阿里云 IP 段，要分别监测 3 个号的发送成功率。

! 最容易翻车的点

① 付费方式选错 有台没选成「包年 + 不限时长」→ 偷扣核时（灵豆），企业版白买。3 台逐台核对。
② 企业实名没切好 个人实名状态下，4核8G 199 年包企业 SKU 可能根本不出现。先过实名再买。
③ egress 安全组没放 客户端能登进去、能开机，但 paste.rs / 抖音发不出 —— 表现为「能开机不能发」。回阶段 3a 放行 443/80 出方向。
