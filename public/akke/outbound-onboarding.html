🪪0. 通用基础资质 · 三通道都要

下面 7 项是任何供应商对接 KYC 的最低门槛。先把这一组准备齐，后面三通道分头并行就快。

材料 用途 准备时间
营业执照（统一社会信用代码）扫描件 所有供应商 KYC 基础 现成
法人身份证正反面 同上 现成
对公账户银行开户许可证 短信/外呼计费 + 企微认证打款 现成
公章电子件 / 红头授权委托书 给 Akke 出具「代理触达」授权，证明 Akke 是合规服务商 起草半天
ICP 备案号 如有官网 / 落地页（用于表单收集 leads） 30 天审核
数据处理者承诺函（PIPL 第七章） 承诺合法获取 + 合理使用 + 不超授权范围转手 起草 1 天
公司基本信息表 业务场景 / 行业类目（装修建材）/ 预计每日触达量 半天

📞1. 电话外呼（AI 外呼）通道

1.1 合作伙伴自身资质

材料 必要性 说明
外显号码（400 / 95 / 1010 号段） 必须 营销/外呼不能用手机号外显（高频必封）。要么用合作伙伴企业已有的 400 号，要么新办（400 号 ¥1500-3000/年）
录音存档（≥3 年） 必须 供应商通常提供，但合作伙伴需要确认存储位置 + 合同明确所有权 + 应监管要求可调取
用户黑名单（DNC）接入 必须 Akke outbound_dnc 表已设计；合作伙伴需要把历史投诉号码导入
AI 身份告知话术 必须 2024 深圳 / 2025 北京已明文要求 AI 外呼开场必告知「我是 XX 公司的 AI 助手」。Akke generateOpener 已内置
增值电信业务经营许可证（呼叫中心类） 间接 一般由供应商持有；合作伙伴自己不需要办，但要选有牌照的供应商

1.2 供应商对接需提交的材料

以容联七陌 / 阿里云通信 / 移动云盘古为例，三家流程接近。

📄

主体材料

营业执照 + 法人证件 + 对公账户预存（容联 ¥5000 起 / 阿里云通信 ¥1000 起）。

📝

业务场景说明书

2-3 页：业务定位（装修行业潜客回访）+ 目标客户群 + 预计日呼量 + 转化目标。

💬

外呼话术样本（≥5 套）

每套含 AI 身份告知句 + 转人工触发词 + 退订话术。审核驳回每改一版要再审 3-5 天，预留时间。

🛟

投诉处理预案

含 SLA：投诉后 24 小时内拉黑 + 5 个工作日反馈处理结果。

1.3 频次 / 合规硬约束

⏰ 必守 3 条红线： 同一被叫每天 ≤ 3 次（行业默认；运营商内控更严的会封到 1 次/天） · 22:00-08:00 禁拨 · 用户说"投诉 / 不要再打 / 真人 / 转人工"立即挂断 + 全通道拉黑（Akke dispatcher.py 已内置触发词）。

💬2. 短信触达通道

2.1 合作伙伴自身资质

材料 必要性 说明
企业短信签名（如【XX 装饰】） 必须 报备签名 1-3 天审核；装修类容易被驳回，建议同时报 2-3 个备选名称
短信模板报备 必须 营销类、通知类要分开报；每条模板单独审；驳回后修改重报很常见
106 / SP 号段申请 供应商代办 选阿里云 / 腾讯云走 106 网关，不要走 1069 / 1062 平台号
用户授权来源凭证 必须 每个手机号必须有「用户同意被联系」的证据链（表单提交时间戳 + 勾选记录 + IP）

2.2 供应商对接需提交的材料（阿里云短信 / 腾讯云短信）

📄

主体材料

营业执照 + 法人证件 + ICP 备案号 + 对公账户验证（阿里云会打 1 分钱验证）。

🏷️

签名报备表

含使用场景：营销短信 vs 通知短信，分开报；签名审核驳回率高，备 2-3 个名称兜底。

📋

模板报备表

每条不超过 60 字，必带「回 T 退订」。

🚨

装修行业额外材料

属于「营销短信高敏行业」，可能需要额外提供"用户授权获取流程截图"（落地页表单 + 同意勾选 UI）。

2.3 内容硬约束（运营商拦截规则）

🛑 拦截率 90%+ 的雷区： 营销短信必含「回 T 退订」 · 感叹号 ≥ 3 个必拦 · 含「免费 / 中奖 / 特价」等价格诱导词必拦 · 含未报备的链接必拦（短链域名要 ICP 备案 + 加白） · 单号每天同类内容 ≤ 3 条。

🤝3. 企业微信（WeCom）触达通道

3.1 合作伙伴企业自身要做

动作 必要性 说明
企业微信认证（¥300/年） 必须 未认证版用不了「客户联系」模块；认证后才能拿到 corp_id + secret
开通「客户联系」应用 必须 企微后台 → 应用管理 → 自建应用或服务商应用
授权 Akke 服务商应用 必须 在企微管理后台扫码授权 Akke 拿「客户联系 API」权限
员工企业微信账号（按外联座席数） 必须 每个外联员工分配一个企微账号；单账号日加好友上限 200-300（更多必限）
会话内容存档加密机 / SaaS 推荐 法规层面「建议」留存；自购加密机 ¥2-5 万/年；服务商代管 SaaS ¥5000-2 万/年

3.2 Akke 侧要做的（合作伙伴知情即可，不在你方清单）

✅ Akke 申请成为「企业微信第三方服务商」—— 审核 7-14 天，要求营业执照 + 上线产品介绍 + 服务承诺。这是一次性动作；之后所有合作伙伴企业按服务商授权流程接入即可。

3.3 触达边界（合作伙伴要 acknowledge）

📵

① 不能用手机号自动加好友

企微「客户联系」API 没有「用手机号加好友」接口。必须有用户接入点：扫码（线下展会 / 落地页二维码） · 短信 / 邮件附带企微邀请链接（用户主动点） · 在抖音 DM 等其他通道里发企微号让客户主动加。

📊

② 加好友通过率随号源质量浮动

高意向客户（刚提交过表单还记得）通过率 60-80%；冷数据（半年前的名单）≤ 10%。预算和 KPI 要按这个区间订。

🚨4. 号源合规 · 最致命的独立大项

⚠️ 这是 PIPL（《个人信息保护法》）+ 工信部《通信短信息服务管理规定》+《电信和互联网用户个人信息保护规定》的硬约束。 违反不是被罚款的问题 —— 是会被工信部约谈 + 全行业拉黑供应商。

4.1 合法号源的「三同意」标准

对每个手机号 / 微信号，必须能举证：

①

来源同意

用户在合作伙伴企业的渠道（官网表单、抖音落地页、扫码表单等）主动填写。

②

用途同意

填写时勾选过明确的「我同意 XX 品牌通过【电话】【短信】【企微】联系我」。

③

行为留证

留存提交时间戳、IP、UA、勾选行为日志 ≥ 3 年。Akke outbound_forms.consent_text + outbound_leads.raw_payload 表设计就是为这个。

4.2 不能用的号源 · 合作伙伴必须自查

号源来源 能否用于电话/短信/企微
XHS / 抖音评论区扒下来的（即使有手机号） ❌ 不能用
同行 / 中介买的「装修意向客户名单」 ❌ 不能用
物业泄露的业主名单 ❌ 不能用
「扫码送礼品」换的、但礼品页面没写明触达授权 ❌ 不能用
「你的设计已生成，留电话查看」这类诱导式弱授权 ❌ 不能用

4.3 合规号源的 3 个标准来源

🌐

官网落地页表单

最干净
  • 含 explicit consent checkbox
  • 提交后留 IP / 时间戳 / UA
  • 建议接入 Akke outbound_forms
📱

平台广告投放留资

量大要核协议
  • 抖音 / 小红书 / 巨量引擎广告留资表单
  • 平台合规协议下默认有授权
  • 但要核对协议是否覆盖三通道
🏪

线下扫码登记

最传统
  • 门店 / 展会扫码登记
  • 纸质表 + 公章授权留底
  • 电子件每月归档

📅5. 资质准备时序 · 4 周路线图

把上述资质拆成 4 周并行推进，最快 3 周可完成所有审核。

通用基础 + 短信启动

⏱️ 行政对接为主
  • 提供营业执照 / 法人证 / 对公账户
  • 起草「数据处理者承诺函」+「Akke 代理触达授权」（公章版）
  • 申请阿里云 / 腾讯云短信账户
  • 报备短信签名（1-3 天审核）
  • 报备 2-3 个常用短信模板

电话外呼资质

⏱️ 1 周准备 + 1 周审核
  • 申请 / 复用 400 号外显（¥1500-3000/年）
  • 对接 1 家外呼供应商（容联七陌 / 阿里云通信）
  • 提交话术样本 + 投诉处理预案
  • 装修行业准入材料补齐

企业微信打通

⏱️ 1 周走流程
  • 完成企业微信认证（¥300/年，1-3 天审核）
  • 开通客户联系模块 + 授权 Akke 服务商应用
  • 配置 N 个外联座席员工账号
  • 决定是否上会话存档加密机

号源合规整改

⏱️ 最痛，但必做
  • 全量审计现有客户名单的获取渠道
  • 剔除不合规号源（XHS 抓的 / 中介买的）
  • 把表单接入 Akke outbound_forms
  • 新增 leads 自带 consent 证据链

📋6. 一页清单 · 直接发给行政/合规对接人

请准备以下材料发回 Akke 项目组

提交方式 / 加密渠道：与 Akke 项目经理另行约定（建议走腾讯文档加密链接或飞书云盘内部成员可见）

  1. 营业执照扫描件（PDF）
  2. 法人身份证正反面
  3. 对公账户银行开户许可证
  4. 公章电子件（用于「Akke 代理触达授权书」加盖）
  5. ICP 备案号（如有官网）
  6. 行业类目说明（一句话即可，如「全屋定制装修」）
  7. 预计触达规模：每日 leads 数 / 每日触达数 / 每日加企微数
  8. 现有 400 号 / 95 号 / SP 短信签名（如有，列出来；没有也说明）
  9. 企业微信认证状态：是 → 提供 corp_id 和 secret；否 → 启动认证
  10. 已有外联员工数（用于规划企微座席）
  11. ★ 现有客户名单的获取渠道说明（最重要，决定哪些号源能用）
