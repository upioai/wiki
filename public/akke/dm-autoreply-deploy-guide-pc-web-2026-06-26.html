DM 自动回复 · 部署指南（PC 客户端 + 浏览器 Edge）

云电脑自驱 DM 自动回复的端到端部署：客户在私信里回复 → 捕获写库 → chatReply 生成话术 → 就地发出。 两条通道：PC 客户端版（UIA 读私信列表）和浏览器 Edge 网页版（红点像素检测 + 视觉读取）。 本指南含两通道具体操作 + 通用诊断；并重点说明饭粒"部署了但没实现自动回复"的根因与修复。
更新 2026-06-26 通道 PC 客户端 / 浏览器 Edge agent 版本 ≥ v=2026-06-24 配置 C:\akke-wuying\wuying-dm\.env
一句话原理：poll agent 每轮串行跑「捕获(扫私信列表) → 生成草稿(后端 cron) → 发送(就地回复)」。 capture 模式 = 只捕获+生成草稿、不发（安全，供审）；both 模式 = 捕获+自动发。 判活只认 accounts.last_poll_at 心跳（≤5min=在线），不看窗口/进程。

★ 重点 · 饭粒"部署了但没实现自动回复"

饭粒（一筑·全屋定制，PC 客户端版，account c5d236e1…）的实测状态——部署其实到位且捕获很旺，问题出在"发送"那一环没开。

诊断结论：饭粒不是"没部署"，而是"捕获+生成都正常，但没自动发"。

✅ agent 在线（心跳 1min）、✅ 捕获在跑（7 天 461 条客户回复写库）、✅ 后端在生成草稿（55 条 approved + 52 条 needs_human）—— 但 实际只发出 3 条，55 条 approved 草稿全积压、没发给客户。

= 自动回复链路只跑通了前 2/3（捕获→生成），最后"发送"那 1/3 没开。

根因（按可能性排）

根因判别修复
① MODE=capture（只捕获不发）
最可能		有 === capture 日志、草稿一堆 approved，但 sent 几乎 0findstr AKKE_DM_AUTOREPLY_MODE .env；若 capture → 改 both 重启
② send 段报错/未起MODE 已 both，但 approved 仍不减、sent 不涨看日志 send 段是否报错（claim/就地回复/坐标）
③ 52 条 needs_human 是设计内命中护栏(价格/微信/负面)→转人工，本就不自动发这部分需人工，不是 bug；看 approved 那 55 条
④ 子进程挂死(凌晨8.5h案例)日志停在"收件箱捕获"不动、last_poll_at 心跳停 >20min杀进程重启 + 确认 AKKE_DM_AUTOREPLY_TIMEOUT_SEC=240 已配
饭粒的修复动作（按顺序）：
findstr AKKE_DM_AUTOREPLY_MODE .env 看是 capture 还是 both
先抽查那 55 条 approved 草稿质量（让 Claude 拉"客户原话→草稿"配对审）——确认话术对题再开自动发
质量 OK → .env 改 AKKE_DM_AUTOREPLY_MODE=both → Get-Process py,python|Stop-Process -Force; py wuying_poll_agent.py 重启
盯 Lark 回执卡，看 55 条积压开始被发出、sent 数上涨；发错立刻改回 capture 急停

3 通用诊断 · "部署了但没自动回复"决策树

Q1 agent 横幅有 v= 吗？(v=2026-06-24+...)
   否 → 旧版 agent,没有自动回复分支 → 更新 wuying_poll_agent.py 重启
   是 → Q2
Q2 日志有「=== capture」行吗？
   否 → 检查 AKKE_DM_AUTOREPLY_CAPTURE=1 + 重启(改 env 必重启)
   是 → Q3
Q3 capture 数字正常吗(列表 ≥1 行 / web 有红点)？
   否(0行) → PC:坐标/窗口前台; web:AKKE_WEB_C_DM_ICON 量准+私信打开
   是 → Q4
Q4 DB 该号近期有新 role=customer 消息吗？
   否 → 检查 AKKE_ACCOUNT_ID == 云电脑登录号
   是 → Q5  (捕获正常,问题在发送侧 ← 饭粒就卡这)
Q5 草稿 approved 一堆但 sent 不涨？
   是 → MODE=capture(只读不发) → 改 both 重启 / 或 send 段报错排查
   否 → 看 last_poll_at 是否心跳停(子进程挂死)
判活铁律：只认 accounts.last_poll_at 心跳（≤5min 在线）。进程活着、窗口开着也可能是子进程挂死冻了循环（饭粒凌晨 8.5h 一夜零发就是这个）——肉眼看不出，只有心跳停能暴露。
