企微加好友的打招呼话术

兔宝宝全屋定制 · 客户线索加微信 · 按线索从 3 条话术选最匹配的一条 · 2026-06-30

一句话：3 条话术，拉单时按每个客户的备注，自动挑最匹配的一条。

不用手打。备注里有真实装修线索的（想了解价格 / 新房毛坯 / 想对比品牌…）→ AI 选对应那条；没线索的 → 用通用的话术2。3 条全部压到 50 字内，发出去不会被截。

⏱ 话术什么时候定下来？（最容易问的一点）

第 1 步 · 你本机 · 拉单时
🎯 话术在这一步就选好

敲拉单命令的瞬间，去数据库读每个客户的备注，有线索的让 AI 从 3 条里挑最匹配的一条，一行一条写进名单（CSV）。名单里每个人后面已经跟好一条话术。

→
第 2 步 · 云电脑 · 执行加好友时
📤 不选了，照着名单发

发送脚本不再挑话术，只读名单里那条现成的 → 填进企微验证框 → 发出。这 3 条话术不带自称，云电脑只管照单发。

所以：话术 = 拉单时（本机）按备注选好 → 写进名单 → 云电脑加好友时照着发

不是加好友那一刻才现选。为什么分开？备注在数据库里、只有本机查得到；云电脑只有名单、连不到库，所以「选话术」放本机做，云电脑只管「照单发」。

② 怎么按线索选（逻辑）

每条线索按备注分情况处理
备注情况怎么处理
有真实装修线索
（面积/小区/毛坯/翻新/风格/想了解价格/想对比/闲鱼或装修客服安排…）		AI 选 1 条 读备注，从 3 条里挑最匹配的（价格→话术2、材料品牌→话术3、新房图优惠→话术1）。
没备注 / 垃圾痕迹
（归属地、未接电话、微信未通过…）		默认话术2 没线索可匹配，用最通用的话术2（有「您好」+明确报价+全包+保障）。
死号
（空号 / 无效 且没有微信号）		跳过不加 不导进名单、单独计数，省得白发。

想全员统一发同一条、不按线索选：拉单时加 --no-personalize，所有人都用默认话术2。

③ 完整设置流程

A. 一次性准备（云电脑，每台机做一次）
  1. 企业微信 PC 登录、最大化、前台；锁定分辨率（别开自适应缩放）。
  2. 输入法切 英文模式（中文 IME 会抢搜索词首字 → 搜错人）。
  3. worker/scripts/wuying-dm/.env 要有 OPENROUTER_API_KEY（搜到人后 AI 核身份用）。
  4. 双击 update.bat 拉最新脚本。
  5. 首次标坐标：python wecom_add_contact_grounded.py --calibrate（搜一个能加的人、把「发送添加申请」弹框开出来，依次点 5 个按钮）。

这 3 条话术不带自称，不用设账号名。（后续若改成带自称的话术，再设 AKKE_WECOM_SELF_NAME 或让脚本自动识别。）

B. 日常：拉单 → 加 → 回写
  1. 本机拉单（运营电脑）——话术在这步按备注选好、写进 CSV： 
    # 先预览每条选了哪句话术（不拉单、不占线索）
pnpm tsx scripts/claim-enterprise-leads.ts --limit=5 --by=你的名字 --dry-run
# 满意了正式拉：软认领 + 导出云电脑要吃的 CSV（带话术）
pnpm tsx scripts/claim-enterprise-leads.ts --limit=5 --by=你的名字
  2. 把 CSV 传到云电脑（paste.rs / 共享盘，放 worker/scripts/wuying-dm/ 下）。CSV 含手机号/微信号明文，别外发、别进 git。
  3. 云电脑自动加：python wecom_add_contact_grounded.py 那个CSV。发送时取该行话术 → 填进验证框发出。先看着跑前 2-3 条确认流程对。
  4. 回写：把 sent_log_wecom_*.csv 传回本机，pnpm tsx scripts/writeback-enterprise-lead.ts --from-sent-log=...。
想换话术 / 全员统一一句？
  1. 全员统一、不按线索选：拉单时加 --no-personalize，所有人都用默认话术2。
  2. 改这 3 条话术的文案：找 Claude 改 scripts/claim-enterprise-leads.ts 里的 T1 / T2 / T3 三个常量（注意每条 ≤50 字），推一下即可。
  3. 临时固定一句兜底：云电脑 .env 写 AKKE_WECOM_VERIFY_MSG=你的话术（CSV 没带话术时才用）。
选话术逻辑：scripts/claim-enterprise-leads.ts（T1/T2/T3 三常量）　发送：worker/scripts/wuying-dm/wecom_add_contact_grounded.py　详细 runbook：docs/runbooks/wecom-add-contact-cloudpc.md
PII（手机号/微信号/备注）只在 Supabase + 本机/云电脑，CSV / sent_log 全部 gitignore 不进代码库。
