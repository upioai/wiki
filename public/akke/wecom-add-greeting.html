企微加好友的打招呼话术

兔宝宝全屋定制 · 客户线索加微信 · 自动生成验证语 · 2026-06-30

一句话：话术不用手打，拉单时按每条线索的备注自动生成。

基础话术固定（兔宝宝样板房 568/598），备注里有真实装修线索的会自动揉进去一句；自称（你的企微名）自动识别。运营只管拉单→传云电脑→发，话术全自动。

⏱ 话术什么时候生成？（最容易问的一点）

第 1 步 · 你本机 · 拉单时
✍️ 话术在这一步就生成好

敲拉单命令的瞬间，去数据库读每个客户的备注，有装修线索的调一次 AI 揉进话术，一行一句写进名单（CSV）。名单里每个人后面已经跟着一条现成话术。

→
第 2 步 · 云电脑 · 执行加好友时
📤 不生成，照着名单发

发送脚本不再生成话术，只读名单里那条现成的：把自称 {me} 换成你的账号名（自动识别）→ 填进企微验证框 → 发出。

所以：话术 = 拉单时（本机）生成 → 写进名单 → 云电脑加好友时照着发

不是加好友那一刻才现生成。为什么分开？备注在数据库里、只有本机查得到；云电脑只有名单、连不到库，所以「生成」放本机做，云电脑只管「照单发」。

① 话术长这样

没特殊备注 / 垃圾备注 → 干净基础话术（话术1）
您好，我是兔宝宝的全屋定制小夏，给您发样板房568/598元产品的详细资料~
备注里有真实装修线索 → 自动揉进一句线索（绿色块=从备注提炼）
张女士您好，我是兔宝宝的全屋定制小夏，看您85平旧房想翻新自住，加微信发样板房资料参考~
王总您好，我是兔宝宝的全屋定制小夏，看您精装房要改造两个卫生间，加微信发样板房资料参考~
何先生您好，我是兔宝宝的全屋定制小夏，看您95平新房想了解材料价格，加微信发样板房资料参考~

黄块=你的企微账号名（自动填）　绿块=从该客户备注里提炼的线索（自动生成）。其余文字固定。

② 话术怎么生成的（逻辑）

每条线索按备注分四种情况处理
备注情况怎么处理
有真实装修线索
（面积/小区/毛坯/翻新/风格/需求/闲鱼或装修客服安排的…）		LLM 改写 把线索提炼成一句「看您…」，拼进基础话术（≤约50字防截断）。失败/太长自动回退干净话术。
没备注 / 垃圾痕迹
（归属地、未接电话、微信未通过…）		干净话术 直接用基础话术1，不调 LLM。
死号
（空号 / 无效 且没有微信号）		跳过不加 不导进名单、单独计数，省得白发。
称呼（姓名字段）姓名一半是「齐家/未命名」（平台名、不是人），默认「您好」；只有「杨先生/王女士」这种靠谱的才加称呼，单字真姓（王/陈）用「X总」。绝不硬造「齐总」。
自称 {me} = 你的企微账号名，自动识别

话术里的自称写成占位符 {me}，发送时自动换成你企微登录的显示名（如「全屋定制小夏」）。第一次发会自动 VL 识别一次、记到本机，之后不用管。换人/换账号都自动对得上，不用改话术。

前缀特意用「兔宝宝的{me}」而不是「兔宝宝全屋定制{me}」——账号名常自带「全屋定制」，否则会拼成「全屋定制全屋定制小夏」叠词（已自动去重兜底）。

③ 完整设置流程

A. 一次性准备（云电脑，每台机做一次）
  1. 企业微信 PC 登录、最大化、前台；锁定分辨率（别开自适应缩放）。
  2. 输入法切 英文模式（中文 IME 会抢搜索词首字 → 搜错人）。
  3. worker/scripts/wuying-dm/.env 要有 OPENROUTER_API_KEY（识别用）。
  4. 双击 update.bat 拉最新脚本。
  5. 首次标坐标：python wecom_add_contact_grounded.py --calibrate（搜一个能加的人、把「发送添加申请」弹框开出来，依次点 5 个按钮）。
  6. 自称账号名：不用管。第一次发送时脚本会自动识别你的企微名并记下来。（想固定就 .env 写 AKKE_WECOM_SELF_NAME=全屋定制小夏）
B. 日常：拉单 → 加 → 回写
  1. 本机拉单（运营电脑）——话术在这步自动生成进 CSV： 
    # 先预览每条话术（不拉单、不占线索）
pnpm tsx scripts/claim-enterprise-leads.ts --limit=5 --by=你的名字 --dry-run
# 满意了正式拉：软认领 + 导出云电脑要吃的 CSV（带话术）
pnpm tsx scripts/claim-enterprise-leads.ts --limit=5 --by=你的名字
  2. 把 CSV 传到云电脑（paste.rs / 共享盘，放 worker/scripts/wuying-dm/ 下）。CSV 含手机号/微信号明文，别外发、别进 git。
  3. 云电脑自动加：python wecom_add_contact_grounded.py 那个CSV。发送时自动：取该行话术 → 把 {me} 换成你的账号名 → 填进验证框发出。先看着跑前 2-3 条确认流程对。
  4. 回写：把 sent_log_wecom_*.csv 传回本机，pnpm tsx scripts/writeback-enterprise-lead.ts --from-sent-log=...。
想换话术 / 全员统一一句？
  1. 全员统一、不个性化：拉单时加 --no-personalize，所有人都用干净基础话术。
  2. 临时固定一句：云电脑 .env 写 AKKE_WECOM_VERIFY_MSG=你的话术（CSV 没带话术时的兜底）。
  3. 改基础话术本身：找 Claude 改 scripts/claim-enterprise-leads.ts 里的模板（一行），推一下即可。
