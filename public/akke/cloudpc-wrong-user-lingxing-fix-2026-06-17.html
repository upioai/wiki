1.2 三个确认的代码级卡点

卡点①实时昵称投递不可靠（最上游）

🌈我要做人间清醒 这行 CSV 的 nickname 列还是 DB 旧名（opener 也用的旧名），页面却显示"小星" → 说明 resolve_handles 这次没返回实时昵称，身份门拿旧名比页面"小星" → 失配。只要实时昵称送到，这条根本不会进 wrong_user。号兜底只是补丁，这才是大头。

poll agent 287-295 / 500-506：nick = fresh_nick.get(sec) or DB昵称。fresh_nick 空 = resolve 瞬时失败或该号反查不到昵称。

卡点②on_prof 闸误杀号-match（douyin_dm_grounded.py:559）

抖音号精确兜底被锁在 and on_prof 后面：VL 把"无作品/稀疏主页"误判 is_profile=False 时，哪怕正确的号已读到，兜底也不触发 → return (on_prof and matched) = False → wrong_user。这就是那 3 条的死因。

⚠️ 修它有回归面：抖音"用户"搜索结果列表卡片也显示"抖音号:"。若点击没进主页、停在列表，VL 判非主页（对的）却可能读到一致的号 → 盲信号会在列表页强发。所以号兜底必须带"确认主页头部在屏"的护栏，不能盲信。

卡点③网格过扫无空槽守卫（douyin_dm_grounded.py:772）

for i in range(scan_n) 盲点第 i 槽坐标、不校验这一槽有没有结果。号搜结果数 < SCAN_N 时多出的槽点进空白区 → 记成 bare (非主页)；而 seen 只留最后一槽 → 会掩盖"第一槽其实是近号别人(B类)"。这导致那 6 条 bare 无法从日志分类。

1.3 判不了、缺证据的地方

6 条 bare + 2 条白屏的真实归类，本地判不了，取决于两个看不到的东西：

  • 零星 .env 有没有开 AKKE_SEARCH_SCAN_N：开了(=5)→ 可能过扫掩盖；没开(=1)→ 就是第一条非主页/点空。
  • 现场 screenshots/_prof.png：那一刻屏上到底是主页 / 列表 / 视频页 / 白屏。

没这两样，对这 8 条的任何"修法"都是猜 → 所以先观测，别先改逻辑。

3.A 本机操作员 — 第一步：观测补丁（现在就做·零风险）

在 worker/scripts/wuying-dm/douyin_dm_grounded.py 的扫描循环里改两处。改 ① 让每槽轨迹都进 sent_log（治卡点③的失真）；改 ② wrong_user 时留底截图。都不碰任何判定逻辑。

改 ① — 累积每槽 seen（约 777 行）

# 找到这一行（原样）：
            c['_ocr_seen'] = seen   # 落 sent_log：wrong_user 时事后能分清「改名误杀」vs「真错人」
# 替换为：
            c.setdefault('_ocr_trace', []).append('第%d槽#%d:%s(conf%.2f)' % (i + 1, attempt + 1, seen, conf))
            c['_ocr_seen'] = ' || '.join(c['_ocr_trace'])   # 全扫描轨迹进 sent_log，不只最后一槽（治过扫失真）

改 ② — wrong_user 存截图（约 784-786 行）

# 找到这三行（原样）：
    if not m or conf < MIN_CONF:
        print('  [跳过] 前%d条都不是本人 → 不发' % scan_n)
        return 'wrong_user', conf
# 替换为：
    if not m or conf < MIN_CONF:
        print('  [跳过] 前%d条都不是本人 → 不发' % scan_n)
        try:   # 留底最后一张身份门截图，便于把那 6 条 bare 分清是主页/列表/白屏
            import shutil
            _tag = (str(c.get('_comment_id') or nick) or 'x').replace('/', '_')[:24]
            shutil.copy(os.path.join('screenshots', '_prof.png'),
                        os.path.join('screenshots', 'wronguser_%s.png' % _tag))
        except Exception:
            pass
        return 'wrong_user', conf

# douyin_dm_grounded.py 约 559-564，把原来的：
        if expected_number and on_prof and not (matched and conf >= 0.95):
