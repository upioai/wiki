共性问题 · 每条至少踩 1 个

① 问 A 答 B（最严重）

客户问 保温墙 / 瓦工 / 1.8m 阳台塞 4 电器，AI 全跳过原问题反问户型，第二轮还继续推开。8 条第二轮里只有 3 条真正接住了客户原议题（38%）。

② 第二轮抢跑加微（63%）

8 条第二轮里 5 条在第二轮就抛「+v / 加我微信 / 让设计师加你」。哪怕信任已建立的（强国久安、w@y）也抢跑了，结果都是已读不回。Camille_ 成功是同城+高意向叠加，不是话术胜利。

③ 钩子可取，但时机太早

强国久安「发图压缩看不清+v 一下我发同户型整套参考」是合理钩子（抖音确实压缩 + 有价值承诺），但客户才给 7 字户型就引导加 v 偏早。更稳做法：先发缩略图+关键文字版垫一层信任，再用 +v 承接「完整高清整套」。

④ 客户软拒后系统直接放弃

浩客户「还没考虑好」之后系统没任何跟进。这恰恰是最该走「降压」分支（见 §3 分支 B）的场景——给一段干货让客户感到"在帮我不是卖我"，而不是停手。

⑤ 一口气连问 3 个问题

转身第二轮一口气问「城市 / 户型 / 主要动哪块」——客户上一句才 2 字「翻新」，节奏完全不匹配。客户每句话的能量是 AI 下一句长度的天花板。

⑥ 答产品用 LLM 默认词而非 brand_profile 真实品牌（2026-06-24 新加 · 铁律）

jiandan #6 反例：客户问「你的是什么材质」，LLM 默认回「E0 颗粒板」（行业通用词，非「有大有小」实际在卖的产品）—— PM 手动按「有大有小」RAG 改成「18mm 多层板 + 兔宝宝/莫干山/千年舟 ENF + 悍高五金」才对上号。问题：不同号源（"有大有小" vs "一筑" vs "零星"）卖的板材牌子都不一样，答错品牌 = 客户加微到设计师那儿对不上号 = 信任崩。
修复（已落 nurture prompt 铁律）：客户 commit 问产品 → 必须从 system prompt 上方的【你能用上的品牌信息】段（brand_profile.productCategories / sellingPoints）取该号源实际产品答。brand_profile 字段缺失时才回退三档对比骨架（颗粒板/多层板/实木）+ 明说"让设计师按你户型拉具体清单"，禁硬编品牌。

第二轮话术原则

解决问题 + 深化信任 · 严禁联系方式
核心动作：先回到客户原问题给出可验证的具体回答，再抛细节问题（不抛大问题、一次只抛一个）。
两层决策：先用决策卡（4 档客户意愿）判 AI 该做什么；再翻分支 A/B/C/D（按场景）看典型改写示例。
📋 决策卡 · 先判客户意愿档 → 再决定 AI 怎么做

⏱ 4 轮兜底 hard gate · 凌驾 L0/L1/L2/L3 之上
触发条件：AI 已发 ≥ 4 条（破冰 + R2 + R3 + R4），下一条（R5）无论客户在哪档都强推 v。
为什么要这条：决策卡 L0/L1「绝不发 v」治的是"短期信任建设期"，但拖到 R5 后客户多半已读不回，长尾流失成本比一次推 v 翻车更高。所以两条规则是接力，不是冲突：前 4 条 AI 在建专业可信度（攒筹码），第 5 条把筹码换成兑现。
实现：shouldHardGateWechatPush() + buildHardGateWechatPushText() 在 src/lib/llm.ts，绕开 LLM 拼模板（零 token、零 reroll、确定性输出）。模板硬绑 7 个钩：信任承接 + 设计师加微 + 样板房专供 568 一平全包（原价 868 一平）+ 18mm 多层板柜体 + 兔宝宝/莫干山/千年舟 ENF 级板 + 悍高五金 + 免费定不定都不亏 + 微信号 Homedz3791 备注抖音名。
为什么硬绑具体价格：06-23 反例 — 提产品（多层板/三品牌 ENF）却不给 568/868 价格，客户落 DM 时拿不到决策锚 = 转化前空一截。Vitest 加了「提产品必带价」断言锁住这点，将来改模板想拆开提产品/提价格就会红。价格口径来自 opener prompt §H「按房产证平方：零售 868 一平、样板房专供 568 一平」—— 和 prompt 自洽。
反例：Case 13 #10「您主页视频拍得很不错哈哈 + 裸抛 Homedz3791」= 23 分翻车。时机对（正好是 R5），但模板要求的 7 个钩缺了 6 个 — 没接住前 4 轮、没价值钩、没具体价、没产品配置、没降压退路。新 hard gate 模板把这 7 个钩硬绑成确定性输出，预计 R5 落点 78-82 分（良好档）。

触发：「L型」「4 个房间」「顶复」等短答

❌ 现状

✅ 改法

改写示例 · 氡氟筱（L 型 7 米橱柜）

L 型 7 米转角通常浪费 0.8-1.2 米，做 U 型旋转拉篮能省 70cm 死角；还有个细节是烟道边的吊柜要做开放层不然操作时撞头。你家烟道在哪边墙？转角是 90° 直角还是带斜切？
分支 B

客户犹豫 / 惊讶

触发：「😮」「还没考虑好」「再看看」

❌ 现状

✅ 改法

降压不推进。给一段干货让客户感到「他在帮我，不是卖我」

改写示例 · 浩（"还没考虑好"）

还没定也好，定早了反而踩坑。全屋定制最容易翻车的 3 个点你先盯住：① 板材是不是同款（兔宝宝 / 莫干山有 E0 / E1 之分） ② 五金品牌（百隆 vs 国产差 5 倍价） ③ 安装后 7 天的复尺。这 3 点比急着下单稳。

第三轮 · 顺势加微

切勿操之过急
Camille_ 第三轮加微转接拿了本批唯一满分（100/100）——关键不是话术胜利，是客户已主动求加 + AI 直接给操作指引（备注规则 + 微信号 + 备用号 emoji 防风控），干净利落。第三轮要不要发联系方式由状态判断决定，不是由轮次决定。

✅ 触发条件（满足任一）

  • 客户主动问微信 / 联系方式 / 报价 / 设计师（如 Camille「我加你吧」）
  • 客户提了具体方案需求（"能不能出个方案" / "我想看看价格"）
  • 客户主动给了大量信息（地址 + 预算 + 户型）
  • 经过 2 轮已建立信任 + 客户明显在认真讨论（多句完整回复、主动反问）

❌ 禁止条款

  • 客户只 1-2 字配合就要 v
  • 第二轮就发 v（无论信任如何）
  • 用「方便加我微信吗」开头（销售话术）
  • 没"具体钩子"裸要 v（如"加我微信发你案例"——案例是什么？）

两道自检闸口

可写入 prompt 后置规则 / 人工复核 checklist

🟡 第二轮前自检

在 AI 起草 / 运营点发送之前，过这 4 道

  1. 我有没有正面回答客户的原议题？没回 → 必须先补
  2. 查节奏矩阵：客户在 L0 / L1 / L2 / L3 哪一档？挑对应 AI 推进档：
    · L0 抵触 → 只能 A0 纯陪伴或 A1 抛细节（绝不要 v，眉山就是 L0×A2 错位）
    · L1 试探 → 优先 A1 抛细节（满分 25）；要 v 必须 A2 钩子硬（如「同户型整套参考」），裸要 v 仅 3 分
    · L2 配合 → A1 继续挖 或 A2 钩子+v 都行
    · L3 明确意向 → A2 直接给联系方式（满分 25），别再绕
  3. 我抛的下一个问题是大问题（户型 / 面积）还是细节问题（墙在哪边 / 几口人住 / 主要功能）？只能抛细节，且一次只抛一个（转身 3 连问就是反例）
  4. 客户上句的能量（字数 / emoji / 反问）我有没有匹配？2 字短答不要回一长串

✅ 第三轮前自检

要发联系方式之前，必须 4 条全过

  1. 客户有没有主动提 v / 报价 / 设计师？没 → 不能要 v
  2. 我手上有没有【具体需求 + 户型 + 大致预算】3 件套？缺 1 件 → 不能要 v
  3. 我要发的联系方式带具体钩子吗（X 方案 / X 案例 / X 报价）？没钩子 → 重写
  4. 客户【已建立信任】吗？（至少 1 次主动加信息、多句完整回复、或主动反问）
