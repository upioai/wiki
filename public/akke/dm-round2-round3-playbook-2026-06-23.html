📉 新口径 · 节奏回退 = 信任度回退

正常一通对话里，客户的配合度应该一路往上爬 L0 → L1 → L2 → L3 —— 越聊越愿意给信息、越往加微方向走。
反过来，只要某一轮客户从高档掉回低档（L2→L1，甚至 L2→L0 / 直接沉默），就是一个预警信号：我们上一条回复大概率不合理，把客户的信任或继续聊的动机打回去了。

① 给每句标 L 档
客户每一条回复落到 L0 拒绝 / L1 试水 / L2 配合 / L3 求加（口径同 §1 决策卡），连成一条折线。
② 找"下台阶"
折线只要出现一次往下掉（含掉到沉默），就标红。上升或持平不用管，回退才是问题。
③ 回看上一条 AI
紧挨着"下台阶"前面的那条 AI 回复，就是嫌疑人。对照下方归因清单查它哪里不合理。

  • 该走资料钩，却把价算到底——单价+总价全交底，加微的理由没了（宋骁）。
  • 高意向不接价、不自报身份/地域——最强信号被晾着，客户从想买变成盘你是谁（1507）。
  • 问 A 答 B / 跳过原议题——客户问的没回，反问户型或硬转话题，被当成群发。
  • 错时机硬逼 v——客户还在 L0/L1 就让"加微让设计师加你"，直接把人吓退。
  • 机械重发 / 啰嗦——把破冰原样复读一遍，像机器人，配合度往下掉（铁匠铺掌柜的隐患）。
和 §1 五维打分怎么配合用：五维打分是"我们侧"的过程评估（这条 DM 写得好不好）；节奏回退是"客户侧"的结果信号（客户用脚投票）。两者对照成闭环——分数高但客户回退 = 我们的评分维度漏了东西，要补；分数低且客户回退 = 归因清单直接命中，照着改。所以每轮回复发出后，下一条客户回来时先标 L 档看有没有下台阶，再决定要不要复盘上一条。
🔧 从这些回退倒推的 6 个优化方向
每条都对应上面一个具体回退（或隐患），写清病根 → 怎么改 → 落到系统哪个环节。前 5 条是话术/规则修正，第 6 条是把这把尺子自动化。
1
客户问钱 / 给面积 → 走资料钩，禁把总价算到底宋骁 · 动机回退
病根客户给了面积，AI 顺手把单价 ×面积 = 总价当场算完（284 → 3 万 7），客户该知道的都知道了，"加微看完整报价单" 的钩子被自己拆掉，没理由继续聊。
怎么改问总价 / 报面积时，只给「算法或区间 + 加微出分区报价单」，不报精确总价。把破冰已有的报价后置 (R) 逻辑延伸到 R1+ 跟进，别只在第一条管用。
落点 · chatReply nurture prompt 加规则；可再做成确定性后置闸——同一条消息里单价数字 + 总价数字同时出现就重写（零 token、必拦）。
2
高意向强问价信号 → 破冰必带「接价 + 自报身份 + 地域锚」三件套1507 · 信任回退
病根"报规格问单价" 是最强问价信号，破冰却一个价格数字没给、也不自报是谁，客户只好反过来盘 "你是哪个 / 你是哪里了"，高意向被打成怀疑。
怎么改高意向分支的破冰强制三件套：① 落价格锚（区间或算法，不允许 0 数字）② 自报身份「我是 X 省做全屋定制的，本地接过 N 单」③ 用上 IP 属地（同省 = 归属感；跨省 / 西藏这种特殊地区 = 主动 disclose 本地设计师+施工队+案例数）。
落点 · generateOpener 高意向模板 + 发送前 self-check 增「价格锚 / 身份 / 地域」三道，缺一道就拦。
3
IP 属地是零成本锚 → 升成 opener 硬规本周连踩 4 次
病根客户 IP 属地天天在手，却整条话术不提——本周福建 ×2、湖北、西藏 4 个案例全没用上，白白浪费免费的同省 / 跨省破冰素材。
怎么改把 ip_location 列为 opener 必用字段：同省落归属感，跨省落"本地团队上门 + 案例数"；缺失则 self-check 拦截。
落点 · opener prompt + self-check（和方向 2 的地域锚同源，单列是因为这是跨案例连踩、不只高意向才需要）。
4
答疑型回复 → 必须接一个「向前一步」的升级钩范范 · 埋了回退种子
病根纯答疑太实诚，把问题解决了却淡化了自己的价值、没给继续聊的理由，这一轮没回退，下一轮容易滑回沉默。
怎么改self-check 加一道："这条给了客户继续回的理由吗？" 纯答疑必须顺一个升级钩（如"想隔音隔热更好，交房前还能提前规划柜体走位"），把答疑变成往前推一步。
落点 · nurture self-check 增一道「升级钩」检查。
5
资料钩换 v 成功后 → 必须补一个「价格/价值口径锚」，否则加微即凉果洛塔慕 · 加微成功但缺价锚
先肯定果洛塔慕是宋骁的正面镜像：同样客户 L1 给户型，这次跟进没去算价，而是用「资料太多发不全 + 挑同户型给你参考」的资料钩换 v，客户直接给手机号、加微成功——印证方向 ① 的资料钩是对的。
病根但全程没有任何价格/价值锚（案例页模块5 自评 MID）：客户加微后第一句大概率就是「136 平黑白极简大概多少钱」，销售若没预置报价口径，资料看完就凉。另：L1 阶段直接要 v 矩阵判偏早（节奏仅 12），发钩前先抛 1 张即时实拍/部分干货会更稳。
落点 · 生成资料钩时附带一句价格区间锚（算法/区间，不报精确总价）+ 给销售预置「同风格同面积报价口径」加微后即用；与方向 ① 形成「给面积 → 区间锚 → 资料钩」完整链。
6
节奏回退做成实时监控 → 不靠人工读折线把口径自动化
病根现在"回退"全靠人工逐轮标 L 档，漏看就错过复盘窗口；上面 4 个修正也没有一个客观信号来验证有没有真见效。
怎么改在 check-replies / analyze 里给客户每轮回复自动打 L 档，一旦"较上一轮下降"就标记该对话 + 拎出上一条 AI，推 Lark 进复盘队列。让节奏回退从"事后人工"变"实时告警"，和 §1 五维打分形成客户侧闭环。
落点 · cron（check-replies / analyze）落 L 档逐轮 + 回退检测；命中推 Lark alerts 群。
