DM 私信自动回复 · 无影部署指南

同事照着做 · 约 15 分钟 · 原理见 0→1 复盘 · 更新 2026-06-20（实机踩坑修正版）
一句话：gist+curl.exe 下脚本 → 量两个坐标(全局私信图标 + 私信面板第一个会话) → .env 加几行(含节流，先 capture) → 重启 agent(没有 start.bat，杀进程重跑) → 看日志 click_norm[DM收件箱] → click_norm[DM首会话] → === capture: 列表 N 行（N>0）→ 稳了改 both。
前提：这台无影已经在跑 DM 首触（有 wuying_poll_agent.py 黑窗口在滚动）。自动回复是叠加在上面，不是新装一套。云端开关 PM 已配好，你不用管。

步骤

1下载最新脚本（gist + curl.exe）

进工作目录 C:\akke-wuying\wuying-dm。向 PM 要 wuying_poll_agent.py + douyin_dm_autoreply.py 的 gist 短 raw 链接（形如 gist.githubusercontent.com/.../raw/xxx.py），用 短变量法下载（长链接直接粘会被 PowerShell 折行拆断）：

cd C:\akke-wuying\wuying-dm
$g="<gist_id>"
curl.exe -L -o wuying_poll_agent.py "https://gist.githubusercontent.com/<用户>/$g/raw/wuying_poll_agent.py"

下完验证（应打印出匹配行）：

Select-String AKKE_DM_AUTOREPLY_INTERVAL wuying_poll_agent.py
⚠️ 别用 raw.githubusercontent.com / iwr / update.bat / paste.rs。实测无影机房：① raw.githubusercontent.com 被连接重置（curl (56) / iwr「基础连接已关闭」）；② iwr 还撞 PowerShell 5.1 默认旧 TLS；③ update.bat 这台常没有、且清单里没 autoreply。只有 gist.githubusercontent.com 这个域能下（跟 github.com 不同域、没被墙）。
⚠️ 一行一行粘、单独回车。长命令一起粘 PowerShell 会用 >> 连断 → 报「缺少参数 / no URL specified」。所以把 gist_id 拆成短变量 $g。
2量坐标①：全局「私信」图标 → AKKE_C_DM_INBOX

找 PM 要 _cappos.py（gist 同样方式下），它直接打印千分比坐标（脚本内部用 0~1000 比例，不是像素）：

python _cappos.py        # 5 秒内/回车前把鼠标移到目标上

把鼠标停在抖音顶栏右上角的「私信」入口图标正中央 → 回车，记下 AKKE_C_DM_INBOX=890,12 这种值。

⚠️ 是「全局私信入口」（右上角那个消息图标），不是用户主页里「关注」旁边的私信按钮——后者是发 DM 给某人用的，两个完全不同位置，别量错。
⚠️ 别留模板占位符。有的 .env 出厂带 AKKE_C_DM_INBOX=<nx>,<ny> —— 这是没填，代码解析失败=当没设、不导航、扫到推荐 feed 噪音（视频标题）。必须换成真数字。
3量坐标②：私信面板第一个会话 → AKKE_C_DM_FIRST
抖音点开私信只是个空框，必须再点一个会话，左侧会话列表才会渲染出来（不点 = UIA 读到 列表 0 行）。所以要量「第一个会话条目」的位置，让脚本点完私信再点它一下撑开列表。

① 手动点右上角私信图标 → 再点一个人，让会话列表完整显示；② 保持这界面跑 python _cappos.py；③ 鼠标移到左侧/面板里最上面那个会话条目正中央 → 回车。取数字（务必和 INBOX 是不同位置——若两个值几乎一样，说明又量到私信图标了，重量）。

面板布局因机而异：若私信是从图标下拉的面板，第一个会话就在图标正下方（如 879,88）；若是整页消息视图，则在左侧（如 120,180）。按你这台实际样子量。
4改 .env（同目录 .env）

加/改这几行（占位符要替换、不是新增重复）：

AKKE_DM_AUTOREPLY_CAPTURE=1
AKKE_DM_AUTOREPLY_MODE=capture
AKKE_C_DM_INBOX=<坐标①>
AKKE_C_DM_FIRST=<坐标②>
AKKE_DM_AUTOREPLY_INTERVAL=43200

PowerShell 替换占位符行（避免重复）/ 追加新键：

(Get-Content .env) -replace '^AKKE_C_DM_INBOX=.*','AKKE_C_DM_INBOX=890,12' | Set-Content .env -Encoding utf8
Add-Content .env "AKKE_C_DM_FIRST=879,88"
Select-String "AKKE_C_DM_(INBOX|FIRST)" .env
AKKE_DM_AUTOREPLY_INTERVAL=43200（12h=每天 2 次）：捕获节流。默认每轮 loop 都扫私信会长时间占抖音前台、抢 DM/route-B 发送窗口；设了它就启动先扫一次、之后每 12h 一次。设 0 回退「每轮都扫」旧行为。
⚠️ 先用 capture（只抓不发），跑顺再改 both。both 才真发消息，别一上来就 both。改 .env 后必须重启 agent 才生效（启动只读一次 env）。
5重启 agent
⚠️ 本机没有 start.bat / 双击那套。重启二选一：

（推荐）直接重启这台云电脑 —— 开机自动重跑 agent + 读最新 .env。

（或）关掉 agent 黑窗口 / Ctrl+C → PowerShell 手动起：

python wuying_poll_agent.py
窗口锁机（小文/野荞，DM∥route-B 串行那台）起 DM 要带这两个 env：
$env:AKKE_WINDOW_LOCK='1'; $env:AKKE_REVERSE_COMMENT_ENABLED='0'; python wuying_poll_agent.py。普通机不用。
⚠️ 别只关黑窗口不杀进程——可能有幽灵旧 agent 在后台抢单。Get-Process py,python | Stop-Process -Force 杀透，或重启机器最干净。
6验证 + 转全自动

看 agent 日志，捕获那轮应依次出现：

[HH:MM:SS] 收件箱捕获(每12h一次) mode=capture
  click_norm[DM收件箱] -> (x,y)      ← 点了右上角全局私信
  click_norm[DM首会话]  -> (x,y)      ← 第二下点开第一个会话撑开列表
=== capture: 列表 N 行, 已发记录 M 人 ===
✅ N > 0 且是真会话名 + 偶尔 [inbound] xxx: 客户的话 = 正常在抓回复。

列表 0 行：① 没点第二下（AKKE_C_DM_FIRST 没设/坐标错）→ 步骤3；② 扫到「影视解说/千亿王者」这类 = 是推荐 feed 噪音、AKKE_C_DM_INBOX 没点对 → 步骤2。没 === capture 行 = flag 没设或没重启 → 步骤4/5。

capture 验稳后（跑半天、能抓真回复、不抓错）→ .env 的 AKKE_DM_AUTOREPLY_MODE 改 both（或删，默认 both）→ 重启 → 全自动捕获 + 发送。

常见问题速查

现象原因 / 处置
curl (56) Connection was reset / iwr「基础连接已关闭」下的是 raw.githubusercontent.com，被墙重置 → 改用 PM 给的 gist.githubusercontent.com 短 raw 链 + curl.exe
下载报「缺少参数 / no URL specified」长命令被 >> 连断 → 把 gist_id 拆短变量 $g、一行行粘
IndentationError（跑 python -c 时）同上，-c 长串被折行+前导空格 → 改成下 .py 文件再 python xxx.py
列表 0 行点了私信但没点第二下撑开列表 → 量 AKKE_C_DM_FIRST（步骤3）；或私信图标坐标不对（步骤2）
扫到视频标题/feed 内容当回复AKKE_C_DM_INBOX 没点对、停在推荐页 → 重量私信图标（步骤2）
两个坐标几乎一样量 AKKE_C_DM_FIRST 时又点到私信图标了 → 先把会话列表显示出来再量第一个会话
私信扫得太频繁、占窗口没设 AKKE_DM_AUTOREPLY_INTERVAL → 加 43200（每天2次）重启
发错人（同名）该客户没缓存到抖音号、回退按昵称搜了 → 找 PM 看号反查覆盖；别手动硬发
满屏乱码编码问题，停下找 PM，别继续跑

运行后每自动发一条，Lark 群机器人会推回执卡片（回复内容 / 客户抖音号 / 哪个号发的）。出 [err] 或不推回执 → 截图发 PM。
