DM 私信自动回复 · 无影部署指南

同事照着做 · 约 10 分钟 · 原理见 0→1 复盘
一句话：下 3 个文件 → 量私信图标坐标 → .env 加 3 行(先 capture) → 重启 agent(没有 start.bat，重启机器或杀进程重跑) → 看日志有 === capture → 稳了改 both。
前提：这台无影已经在跑 DM 首触（有 wuying_poll_agent.py 黑窗口在滚动）。自动回复是叠加在上面，不是新装一套。云端开关 PM 已配好，你不用管。

步骤

1下载 3 个最新脚本

进工作目录 C:\akke-wuying\wuying-dm。向 PM 要这 3 个文件的最新 paste.rs 链接，PowerShell 下载：

iwr <poll_agent链接>  -OutFile wuying_poll_agent.py  -UseBasicParsing
iwr <autoreply链接>   -OutFile douyin_dm_autoreply.py -UseBasicParsing
iwr <inbox_uia链接>   -OutFile douyin_inbox_uia.py    -UseBasicParsing
⚠️ 一行一行粘、单独回车。三行一起粘 PowerShell 会用 >> 连成一条 → 报「缺少参数」、文件没下到。
⚠️ 别用 update.bat 下这 3 个（它清单里没有、且私有库直连会 404）。只走 PM 的 paste.rs 链接（链接临时，过期找 PM 重发）。
2量「私信」图标坐标

让脚本能自己点开私信列表。PowerShell 跑下面这条读鼠标位置：

Add-Type -AssemblyName System.Windows.Forms; 1..15 | %{ Start-Sleep -Milliseconds 700; $p=[System.Windows.Forms.Cursor]::Position; "$($p.X),$($p.Y)" }

跑起来后把鼠标停在抖音顶栏「私信」图标上，记下打印的 X,Y，Ctrl+C 停。归一化(脚本用 0~1000 比例)：

nx = round(X ÷ 屏幕宽 × 1000)
ny = round(Y ÷ 屏幕高 × 1000)
⚠️ 屏幕宽高用这台机的实际分辨率（常见 2560×1600）。例：私信在 (2100,80) @2560×1600 → nx=820, ny=50。每台机分辨率可能不同，各量各的，别抄别人的坐标。
3改 .env（同目录 .env）

加这 3 行：

AKKE_DM_AUTOREPLY_CAPTURE=1
AKKE_C_DM_INBOX=<上一步的 nx,ny>
AKKE_DM_AUTOREPLY_MODE=capture
⚠️ 先用 capture（只自动抓、不自动发），跑顺了再改 both。both 才会真发消息，别一上来就 both。
⚠️ 改 .env 后必须重启 agent 才生效（脚本启动只读一次 env，热改无效）。
4重启 agent
⚠️ 本机没有 start.bat / 双击启动那套（agent 是开机自启）。重启二选一：

（推荐）直接重启这台云电脑 —— 开机自动重跑 agent + 读最新 .env。

（或）关掉 agent 黑窗口 → PowerShell：

Get-Process py,python | Stop-Process -Force
py wuying_poll_agent.py
⚠️ 别只关黑窗口不杀进程——可能有幽灵旧 agent 在后台抢单。用 Stop-Process 杀透，或直接重启机器最干净。
5验证 + 转全自动

看 agent 黑窗口日志，每轮(约60s)应出现：

=== capture: 列表 N 行, 已发记录 M 人 ===
✅ 有这行 + 偶尔 [inbound] xxx: 客户的话 = 正常在抓回复。

列表 0 行 = 抖音没停私信列表 / 坐标没量对 → 回步骤 2。没这行 = flag 没设或没重启 → 回步骤 3/4。

capture 验稳后（跑半天、能抓真回复、不抓错）→ 把 .env 的 AKKE_DM_AUTOREPLY_MODE 改成 both（或删掉，默认 both）→ 重启 agent → 全自动捕获 + 发送。

常见问题速查

现象原因 / 处置
列表 0 行抖音没在私信列表，或 AKKE_C_DM_INBOX 坐标不对 → 重量坐标（步骤2）
日志没 === captureflag 没设 / agent 没重启 → 步骤 3+4
发错人（同名）该客户没缓存到抖音号、回退按昵称搜了 → 找 PM 看号反查覆盖；别手动硬发
改了 .env 没生效agent 没重启 → 必重启
下载报「缺少参数」多行命令被 >> 连断 → 一行一行粘
满屏乱码编码问题，停下找 PM，别继续跑

运行后每自动发一条，Lark 群机器人会推回执卡片（回复内容 / 客户抖音号 / 哪个号发的）。出 [err] 或不推回执 → 截图发 PM。
