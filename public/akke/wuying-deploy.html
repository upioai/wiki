① 开始前 · 找 PM 要 2 样东西

因为所有云电脑配置统一，钥匙和程序都已由技术配好，你只需准备这 2 样：

#要什么长什么样
1你的账号编号（AKKE_ACCOUNT_ID）一串像 81cc9678-9b53-413b-… 的字符，PM 给你
2部署素材方案 A 给镜像名 / 方案 B 给脚本压缩包 / 方案 C 给程序文件夹
好消息：三把"钥匙"（数据库 + AI 接口密钥）已由技术烧进镜像/脚本包，你不用碰，本页也不会出现真钥匙。你只填账号编号。

② 选一个部署方案

三种方案做的是同一件事，区别只是"谁先把活干了"。绝大多数人用方案 A。

方案你要做的事难度适合谁
A. 黄金镜像克隆 ⭐导入镜像 → 登录抖音 → 填账号编号 → 启动最低所有人首选
B. 一键脚本包解压 → 双击一个 bat → 登录抖音低不想折腾镜像 / 镜像出问题时
C. 手动分步跟着图文一步步装中出问题排查 / 技术同事

③ 方案 A · 黄金镜像克隆

🥇 从"黄金镜像"开机，开机即就绪推荐

技术已在一台机器上把 Python、程序、依赖、坐标、钥匙全配好，存成"黄金镜像"。你的云电脑直接用它开机，省掉所有安装步骤。

1

记下镜像分享码

我们的黄金镜像分享码：

74869247

下面在你电脑上的 无影客户端 里用它导入。

2

用"变更镜像"把分享码导进你的云电脑

  1. 打开无影客户端，找到你那台云电脑卡片，点 「管理」
  2. 顶部切到 「镜像」 页签
  3. 点右下角 「变更镜像」 → 选 「通过分享码导入」 → 粘贴 74869247 → 确定
  4. 导入后按提示变更/重启，云电脑会变成镜像里的样子

变更完成后，云电脑里 Python、程序、依赖、钥匙、坐标全都已经配好了。

注意：变更镜像会重置这台云电脑的系统盘（C 盘原有东西会被镜像覆盖）。这台之前装过别的重要东西就先备份；新机/空机直接做没问题。
不确定怎么操作？把这个码发给 PM，请他帮你导一次，之后就归你用。
2

登录你的抖音 PC

打开桌面上的抖音 PC 客户端 → 用你负责的那个抖音号扫码登录 → 窗口最大化（占满全屏）→ 确认右上角是你的头像。

3

把账号编号改成你自己的（最关键，别跳过）

桌面左下角搜索 powershell 打开蓝色窗口，粘贴这两行（逐行回车）：

cd C:\akke-wuying
notepad .env

记事本里找到 AKKE_ACCOUNT_ID= 这行，把等号后面改成 PM 给你的编号，Ctrl+S 保存关闭。其它行不用动（钥匙镜像里已配好）。

这一步必须做！镜像里默认是别人的账号编号。不改成你自己的，发出去的私信会算到别人头上、并和别人抢同一批客户。改完务必核对这行是你的编号。
4

启动

回到刚才那个蓝色 PowerShell 窗口（没有就桌面左下角搜 powershell 再开），粘贴这两行、逐行回车：

cd C:\akke-wuying
py wuying_poll_agent.py

看到这样一行 = 启动成功 ✅：

=== wuying_poll_agent  account=xxxxxxxx…  every 60s  claim=3 ===

这个窗口一直开着别关、别按 Ctrl+C。

如果发送时鼠标点歪、消息没发出 → 见下方 ⑥ 发送异常，或直接发群找技术。

④ 方案 B · 一键脚本包

🥈 解压 + 双击一个 bat备选

不想折腾镜像、或镜像出问题时用这个。技术把钥匙和程序打进一个压缩包（akke-wuying.zip），你解压双击即可。

1

解压到固定位置

把 PM 给的 akke-wuying.zip 解压，里面有个 akke-wuying 文件夹，整个放到 C 盘根目录，最终路径是 C:\akke-wuying（里面应能看到 bootstrap.bat、start.bat、请先看我.txt 等）。

2

双击 bootstrap.bat 装环境

双击 bootstrap.bat，按提示输入你的账号编号回车。它会自动装依赖、写配置、设开机自启。等它跑完（约 2 分钟）。

双击没反应或一闪而过？改用 PowerShell：cd C:\akke-wuying 回车，再 .\bootstrap.bat 你的账号编号 回车，能看到报错信息。
3

登录抖音 + 启动

打开抖音 PC、扫码登录、最大化（同方案 A 第 2 步）→ 在 PowerShell 里 cd C:\akke-wuying 回车、py wuying_poll_agent.py 回车，看到 wuying_poll_agent account=… = 成功，窗口保持开着。

⑤ 方案 C · 手动分步

🛠️ 从零一步步装排查用

前两个方案出问题时，用这个定位是哪步坏了。技术同事也可直接走这个。

1

确认装了 Python

开 PowerShell，输入 py --version 回车。看到 Python 3.11.x = OK。报"找不到"就去 python.org 装，安装时勾选 Add Python to PATH。

2

放程序 + 装依赖

把程序文件夹放到 C:\akke-wuying，然后：

cd C:\akke-wuying
py -m pip install pyautogui pyperclip pillow supabase python-dotenv pygetwindow

看到一堆 Successfully installed = 成功。

3

填配置（.env）

notepad .env 回车（提示新建点"是"），贴进下面整段，把每个 填这里 换成 PM 给你的值：

SUPABASE_URL=填这里
SUPABASE_SERVICE_ROLE_KEY=填这里
OPENROUTER_API_KEY=填这里
ANTHROPIC_API_KEY=填这里
AKKE_ACCOUNT_ID=填这里
AKKE_POLL_INTERVAL=60
AKKE_CLAIM_LIMIT=3

OPENROUTER_API_KEY 和 ANTHROPIC_API_KEY 两行填同一把 PM 给的 sk-or- 开头钥匙。Ctrl+S 保存。

4

登录抖音 + 启动

抖音 PC 登录最大化 → py wuying_poll_agent.py 回车 → 看到 wuying_poll_agent account=… = 成功，窗口保持开着。

⑥ 发送异常怎么办

同款阿里云配置 + 镜像里已内置校准好的坐标，正常情况你什么都不用做。下面只在"发送点歪 / 消息没发出"时看。
1

先排除最常见的两个原因

  • 抖音不在前台或没最大化 → 把抖音点到最前面、最大化，再观察下一条
  • 抖音被登出 → 重新扫码登录
2

还是点歪 → 发群找技术校准

这说明你这台屏幕和镜像的坐标有差异，需要重新校准一次坐标（技术操作）。把现象 + 一张抖音私信界面的截图发群，技术会远程帮你校准，几分钟搞定。

技术侧：在该机跑 py douyin_dm_grounded.py --calibrate 自动量坐标（需镜像已更新到带校准的版本；旧镜像可手动改 .env 的 AKKE_C_INPUT/AKKE_C_SEND）。

⑦ 日常使用

场景怎么做
正常工作让抖音 + 那个黑窗口一直开着，它每 60 秒检查一次、有单就发
下班 / 不用了（省钱）关掉云电脑客户端，约 10 分钟后自动休眠停止扣费
重新开工开云电脑 → 打开并登录抖音 → PowerShell 里 cd C:\akke-wuying + py wuying_poll_agent.py
怎么知道它在干活有单时你会看到抖音自动搜人、打字、发送；黑窗口打印 ✅ 已确认发出
第一次发出后，肉眼确认一下：那条消息真的进了对方聊天框。确认 OK 之后就可以放心让它自动跑了。

⑧ 出问题了？对照排查表

现象原因 / 怎么办
启动报 env missing配置没填全 → notepad .env 检查每行都有值，尤其 AKKE_ACCOUNT_ID
发送点歪 / 消息没发出先确认抖音在前台+最大化；还不行见 ⑥ 发送异常，发群找技术校准
抖音被登出 / 要重新扫码正常（登录约 15–30 天过期），重新扫码登录即可
截图截到别的窗口把抖音点到最前面 + 最大化，再重试
提示发送频繁 / 受限账号触发抖音限频 → 停一停、告诉 PM，别硬发
其它看不懂的报错截图整个黑窗口发群，别自己改文件

⑨ 安全红线

三把钥匙绝不外发：不截图、不发群、不告诉无关的人。
.env 文件不外传：里面等于你账号的"密码"。
  • 控量：抖音禁止自动化批量私信，发太猛会被限流甚至封号。按系统派的节奏来，别手动加量。
  • 只发系统派的单：不要拿它去群发陌生人。

⑩ 给技术 / PM · 如何准备镜像和脚本包

这一节运营不用看。它写给负责"配第一台、做镜像、打脚本包"的技术或 PM —— 把上面三个方案的素材一次性备齐。

A) 先在一台机器上把"黄金母机"配通

三个方案都从这一步派生。在一台干净的阿里无影上：

1

装运行环境

REM 装 Python 3.11（python.org，勾选 Add to PATH）后：
cd C:\akke-wuying
py -m pip install pyautogui pyperclip pillow supabase python-dotenv pygetwindow
2

放程序 + 配 .env（含公用钥匙）

把 worker/scripts/wuying-dm/ 整个放到 C:\akke-wuying，notepad .env 填好三把公用钥匙（SUPABASE_URL / SUPABASE_SERVICE_ROLE_KEY / OPENROUTER_API_KEY，最后一把同时填给 ANTHROPIC_API_KEY）。AKKE_ACCOUNT_ID 这行留空或占位 —— 让每个运营各自填自己的。

钥匙烧进镜像 = 多人共用同一套钥匙。这是为省事做的取舍：钥匙会存在于每台克隆机上。若要更高安全等级，改成"镜像不含钥匙、PM 给每人单独下发"，对应方案 C 的 .env 填写法。
3

校准坐标（写进 .env 默认值）

打开任意私信窗口 → py douyin_dm_grounded.py --calibrate → 确认标注图红圈/绿圈无误。校准会把 AKKE_C_INPUT / AKKE_C_SEND 写进 .env。因配置统一，这组坐标所有克隆机通用。

4

设开机自启 + 冒烟

双击 bootstrap.bat <一个测试账号编号> 让它写好启动文件夹快捷方式；登录抖音后 start.bat 跑通一条，确认全链路 OK。这台就是"黄金母机"。

B) 方案 A 素材 · 制作自定义镜像 + 拿分享码

以下按 无影 PC 客户端 实际界面写（管理 → 镜像 页签，右下角有「恢复成初始镜像 / 变更镜像 / 新建镜像」三个按钮）。小程序入口类似。
1

从母机新建镜像

  1. 无影客户端找到母机卡片 → 点 「管理」 → 切到 「镜像」 页签
  2. 点右下角 「新建镜像」
  3. 填镜像名称（如 akke-wuying-golden）和描述，按提示选磁盘/确认
  4. ⚠️ 若出现 "协助清理个人数据" 之类开关：因为我们要把钥匙留在镜像里，建议关闭（开启可能抹掉 .env 钥匙）
  5. 确认创建（通常需要先关机），等镜像状态变可用
客户端没找到"生成分享码"入口？官方分享码也可能在小程序的「伙伴推广 → 镜像推广」里。两个客户端都翻翻，实在找不到联系阿里客服或发群。
2

拿到分享码并分发

镜像建好后复制它的分享码，发给运营（走私聊，别发公开群——凭它能复制出含钥匙的机器）。运营按本页方案 A：管理 → 镜像 → 「变更镜像」→「通过分享码导入」。

镜像含钥匙 + 分享码 = 任何拿到码的人都能复制出一台带你公司钥匙的机器。当前分享码 74869247 已写在本页（公网可见），等于把那套公用钥匙的门槛降低了。要收紧时：重做镜像换新码 + 轮换 Supabase/OpenRouter 钥匙，并更新本页。
关于抖音登录态：镜像要不要带母机的抖音登录态不稳定。最稳妥：镜像只含程序+钥匙+坐标，抖音让每个运营自己扫码登录自己的号（方案 A 第 3 步）——否则所有人会共用同一个抖音账号，那是错的。

C) 方案 B 素材 · 打一键脚本包

1

打包

基础脚本包已经打好（不含钥匙）：akke-wuying.zip，内含 douyin_dm_grounded.py / wuying_poll_agent.py / bootstrap.bat / start.bat / .env.example / contacts_example.csv / 请先看我.txt。

分发前：把 .env.example 改名为 .env，填好 3 把公用钥匙（AKKE_ACCOUNT_ID 留空），重新压包。这样运营双击 bootstrap.bat 填编号即可，不用碰钥匙。

2

分发

把 zip 发给运营（走内部渠道，别发公开群 —— 含钥匙）。运营侧解压到 C:\akke-wuying → 双击 bootstrap.bat 填编号（本页方案 B）。

zip 含钥匙，等同密钥文件。只走私聊/内部网盘，发完提醒对方别二次转发。

D) 维护要点

什么时候做什么
程序更新（改了 douyin_dm_grounded.py 等）更新母机文件 → 重做镜像 / 重打 zip；或用剪贴板投递命令热更已部署机器
钥匙轮换更新母机 .env → 重做镜像/zip；已部署机器逐台改 .env（这就是"烧公用钥匙"的代价）
抖音改版导致坐标失效母机重跑 --calibrate，新坐标随镜像/zip 下发；运营侧也可各自 自助校准

源码与设计：worker/scripts/wuying-dm/（Akke repo）。链路原理见 通道总览。

有任何一步卡住 —— 截图发群找技术，宁可问，不要猜。
