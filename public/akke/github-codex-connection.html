GitHub × Codex

通过 GitHub CLI 和 OAuth 登录，让 Codex 在获得授权的仓库中读取代码、检查项目结构、修改文件并协助开发。

GitHub CLI 已完成登录

连接流程

  1. 安装 GitHub CLI使用 gh 管理 GitHub 仓库。
  2. 完成 OAuth 登录在浏览器中登录 GitHub 并确认授权。
  3. 拉取仓库到本地通过 gh repo clone 获取项目代码。
  4. 在 Codex 中工作检查、修改、测试代码，并按需创建提交或 PR。
