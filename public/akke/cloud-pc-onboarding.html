为什么用云电脑

✘ 之前的痛点

本机 Mac 跑抖音 PC：需要装 Windows 模拟器/双系统，磁盘吃紧、风扇狂转；多账号还会跟自己日常号撞登录态；离线时也占资源。海外 IP/VPN 同事还会触发风控。

✓ 云电脑的解法

云端一台 4C8G Windows，国内 IDC 直连。本地装个轻量客户端就能"远程使用"。账号留在云端互不干扰；本机磁盘风扇都不动；不用时关客户端 10 分钟自动休眠，¥4.9/月封顶。

3

在本机装 wuying 客户端2 分钟

访问 wuying.aliyun.com/clients，下载对应版本：

  • Mac 用户：下载 .dmg，拖到 Applications，首次打开右键 → "打开"绕过 Gatekeeper。
  • Windows 用户：下载 .exe，正常安装。
  • iPad / iPhone（可选）：App Store 搜"无影云电脑"。手机端只适合临时查看，发 DM 还是用电脑端。

装完打开 wuying，用第 1 步的阿里云账号登录。左侧栏会列出你已购的云电脑。

登录方式：推荐扫码登录，免输密码，跟手机阿里云 App 联动最顺。
4

第一次连云电脑5 分钟

在 wuying 客户端里点云电脑卡片 → "连接"。第一次连接会进首次开机流程：

  1. 等 30-60 秒进入 Windows 桌面（首次启动慢，第二次会快）。
  2. 桌面右下角任务栏出现"开始"按钮 = 已就绪。
  3. 右上角 wuying 工具条可以：剪贴板同步 / 文件传输 / 全屏切换。剪贴板默认开启，本地复制的文字可以直接在云端粘贴。
  4. (推荐) 把客户端设成"全屏"，鼠标更自然，类似用一台 Windows 笔记本。
验证：能看到 Windows 桌面 + 任务栏 + 剪贴板能同步 = Step 4 完成。
常见小坑：云电脑 Edge 浏览器默认锁定 Bing，搜索质量差。建议在 Step 5 之前先装一个 Chrome（搜 "Chrome 下载" → 用浏览器装，不要走云电脑里 Edge 跳出来的小弹窗）。
5

在云电脑里装抖音 PC v7.8.03 分钟

在云端 Chrome / Edge 里打开抖音官方 PC 下载页：douyin.com/pc，下载安装包：

# 1. 浏览器打开
https://www.douyin.com/pc

# 2. 点击"下载电脑端"，得到 douyin_xxx_setup.exe
# 3. 双击 setup 默认安装，~30 秒完成
# 4. 桌面会有"抖音"图标，双击启动
不要装第三方版本：百度搜出来的"破解版/绿色版"会改启动参数、留后门，登录后立即触发风控封号。只用官方包。

启动后会停在登录二维码页面，先不要扫，进 Step 6。

6

扫码登录抖音3 分钟

这是历史上最担心的一步（"云端 IDC IP 会不会被风控？"）。5/21 实测：新号扫码登录无验证码、无异地警告、无封号。具体做法：

  1. 抖音 PC 显示二维码 → 用 messaging 账号对应那部手机的抖音 App 打开"扫一扫"。
  2. 手机端确认登录。云电脑桌面端会自动跳到抖音首页。
  3. 记下登录后头部显示的昵称和抖音号，确认确实是你想用的号（不是日常私号）。
判定通过：能看到"推荐 / 朋友 / 我的"三个主导航 = 登录成功。
登录失败处理：如果扫码后弹"异地登录""短信验证"，先关掉抖音 PC，去 wuying 客户端释放并重建云电脑（换个 IP）再试。同一个 IP 短期内重复触发 = 把号烧了，不要硬刚。
7

发出第一条破冰打招呼5 分钟

抖音 PC 主导航里没有独立的"消息"/"私信" tab（v7.8.0 改版了），DM 入口只能从对方 profile 进入。完整路径：

  1. 点顶部 搜索栏，输入目标客户的抖音号或昵称。
    本机复制 → 云端 Ctrl+V 粘贴最稳（剪贴板已同步）。
  2. 搜索结果页选 "用户" tab（不要点视频/直播）。
  3. 同名很多时（比如搜"小美"），优先点头像和昵称跟目标抖音号匹配的那个。双因子核对：抖音号 + 昵称两个一起对，避免点错人。
  4. 进对方 profile 页 → 头像旁找 「私信」按钮 点击。
    如果点一下没反应，再点一次（Electron 偶尔吞首次点击，二次必中）。
  5. 弹出 DM 对话框 → 输入框 Ctrl+V 粘贴你准备好的破冰话术 → 回车发送。
  6. 聊天列表出现你的消息 + 显示 "刚刚" = 发送成功。

破冰文案样例（套话 + 个性化锚点）：

你好，看到你主页内容很喜欢，请问做装修吗？

5/21 实测：用这条文案发给 messaging 号「一筑·全屋定制」（抖音号 54362559027），14:13 投递成功，对方手机收到。

陌生人 DM 是 1 条永久配额：同一个 sec_uid 在对方没回复/没互关之前，只能发一条，发第二条会返回 7462 错误码。规模触达只能扩号，不要在同一个号上反复试。
不能给自己发：云电脑上登录的号 ≠ 接收方。第一条想测试投递的话，找同事 / 备用号配合，让对方手机交叉确认收到。
8

用完关 wuying — 灵豆按需唤醒纪律10 秒

这一步看似最简单，但历史上灵豆烧光全是因为忽略这步。

关键陷阱：wuying 客户端开着 → 云电脑视为"使用中"不休眠 → 4 灵豆/小时全速扣。
5/22 PoC 实测：8 小时连续用 = 烧 95 灵豆（比初估 28 高 3 倍）。

正确姿势：

  • 用完关闭 wuying 客户端（不是关云电脑里的抖音 — 关本地 wuying app）。
  • 云电脑 10 分钟无连接自动休眠，灵豆停止扣费。
  • 下次用，重开 wuying → 重新连接，会从休眠状态唤醒（10-20 秒），所有已登录 app 状态保留。
这样算账：每天用 1 小时 = 4 灵豆 = 黄金 40/月 够 10 天。轻使用基本不会超量；超了再升白金（80/月）也只是 ¥10 差价。

常见问题速查

wuying 客户端连云电脑卡在"连接中"超过 30 秒
右键云电脑卡片 → 重启实例；如果一直卡，去阿里云控制台看实例状态，不在"运行中"就手动启动。
抖音 PC 安装时弹"不是有效的 Win32 应用"
下载到一半被打断了。删掉安装包，从云电脑里重新下（不要用本机下了 scp 过去，传输会被云端杀软误删）。
扫码后抖音弹"账号异常，请联系客服"
这个号已被风控（不一定是云电脑的锅，可能日常本机操作就已经标黄了）。换一个 messaging 号试。同号短期内反复登 ≥2 次会加速死亡，不要硬扫。
搜索栏粘贴中文出现 ???
用本机复制 → 云端 Ctrl+V，不要在云端直接打中文（云端输入法默认 IME 不灵），更不要让脚本"打字"。剪贴板是最稳的中文输入通道。
对方 profile 找不到「私信」按钮
检查是不是搜成了自己 — 给自己发 DM 不被允许，profile 显示"批量管理"而非"关注/私信"。换个号搜目标用户。
DM 发出去但对方手机没收到
先让对方查"消息请求"（聊天页右上角折叠）— 陌生人首条经常落折叠。如果折叠里也没有，多半是"静默丢失"风控，换号重试或改用本机 WDA 通道发。
灵豆耗尽不能用了
控制台 → 无影 EDS → 我的灵豆 → 立即充值（不升档），或升档到白金（¥19.9/月 80 灵豆）。新月会自动补送当月配额。

已知坑（5/21 PoC 实测）

这些是 5/21 实测期间踩过的 7 个 Electron + Windows 自动化坑，运营手动发 DM 不会全部遇到，但理解它们能帮你判断"是不是我操作错了"还是"系统就这样"。

1. 搜同名用户出来 25+ 结果，第一个不一定是目标

抖音搜索按"已关注 + 相关性"排序，但同名很多时随机性强。修法：用抖音号 + 昵称双因子核对，缺一不点。

2. 点「私信」按钮单击没反应

Electron 套壳偶尔吞首次点击。修法：再点一次（双击）。如果连续 3 次都不开，刷新 profile 页再试。

3. 抖音 PC 主导航里没"消息"tab

v7.x 改版把 IM 入口下沉到"我的 → 私信"和"目标用户 profile 的私信 Button"。不能从主导航直接进 DM。所有陌生人 DM 必须经过"搜索 → 用户 → profile → 私信"四级。

4. URL 链接 snssdk1128:// 在 PC 端不响应

抖音 PC 没注册这个协议（移动 App 才有）。点开会弹"需要新应用打开此链接"对话框抢焦点。修法：手动走搜索栏，不要尝试 URL 跳转。

5. 自己 profile 没「私信」按钮

抖音不允许给自己发 DM。自己的 profile 显示"批量管理"，不显示"关注/私信"。修法：测试时找同事或备用号配合。

6. profile 视频 grid 在自动化层不可见

profile 头部的「私信」按钮是 Electron native 组件，UIA 能拿到；但视频缩略图 grid 是 webview 里渲染的 React，UIA 拿不到。影响：脚本能找私信按钮，但不能"先点开视频再发评论"。手动操作不受影响。

7. 多 PowerShell 窗口干扰自动化窗口选择

只在跑脚本时遇到。手动发 DM 不涉及。详细见 仓库 memory 的 feedback_douyin_pc_electron_ui_gotchas.md。

可选 · 让 Claude 帮你远程发

如果你熟悉命令行，可以在云电脑里跑一个 HTTP server，让本机的 Claude 通过隧道远程驱动云电脑发 DM。这是 5/21 通过的链路，工程师向 path，运营同事跳过即可。

架构 · 三块拼图

① 云电脑里：cloud_pc_server.py（FastAPI + pywinauto + pyautogui），监听 :8765，暴露 /ping /send /screenshot 三个 endpoint，X-Secret header 鉴权。
② cloudflared 临时隧道：把云电脑 :8765 暴露成一个公网 HTTPS URL（每次启动会换 URL，免账号免域名）。
③ 本机 Mac：cloud_pc_client.py 通过 CLOUD_PC_URL + CLOUD_PC_SECRET 调远端 API；也可以直接让 Claude 用 curl 操作。

云电脑端启动命令 
# 在 PowerShell（管理员）
pip install fastapi uvicorn pywinauto pyautogui pillow pyperclip requests
$env:CLOUD_PC_SECRET="akke-poc-517"
python C:\akke\cloud_pc_server.py

# 另开一个 PowerShell 起隧道
cloudflared.exe tunnel --url http://localhost:8765
# 复制输出里的 https://xxx.trycloudflare.com URL
Mac 端调用 
# Mac terminal
export CLOUD_PC_URL=https://xxx.trycloudflare.com
export CLOUD_PC_SECRET=akke-poc-517

# 健康检查
python worker/cloud_pc_client.py --ping

# dry-run（只导航不发送）
python worker/cloud_pc_client.py --send \
  --sec-uid MS4wxxxxxxxxx \
  --content "你好，看到你主页内容很喜欢" --dry-run

# 真发
python worker/cloud_pc_client.py --send \
  --sec-uid MS4wxxxxxxxxx \
  --content "你好，看到你主页内容很喜欢"
什么时候用这条链路

三种场景值得开自动化：

  • 批量场景：今天要发 30+ 条破冰，手动点 30 遍受不了。
  • 跨时区：你想睡觉的时候 Claude 替你跑。
  • 跟 message_queue 集成：让 Akke 的 approved 队列自动通过云电脑通道送出（待集成）。

单条发或 5-10 条试水，直接 wuying 客户端手点更快，省去隧道波动 + 元素定位失败的折腾。

安全提示

X-Secret 是云电脑的唯一防线，拿到这个 token + 隧道 URL 的人能在云电脑跑任意命令。Secret 不要进 git；隧道 URL 不要发群里；用完关 cloud_pc_server.py 进程。
公司账号涉及多人协作时建议改成 VPN/堡垒机路径而不是 cloudflared 公网隧道。
