抖音去水印 使用指南

粘一条抖音分享链接 → 点解析 → 下载一份干净的无水印原视频。没有满屏飘的抖音 logo，没有 @作者号。

更新于 2026-07-06 面向运营 / 内容 团队内部使用，请勿外传
📌
这是给谁看的？ 给需要把抖音视频存下来当素材的运营 / 内容同学。看完你能独立跑：把一条抖音视频 → 拿到没有平台水印的原始文件 → 存到电脑/手机自用。

它跟「小红书 → 抖音 流水线」不是一回事。那套是把别人的视频二改后重发（翻转/变速/换文案规避查重）；这套只做一件事：下载干净视频。不翻转、不变速、不改文案。

1它在干什么 · 为什么抖音不用「抹」水印

抖音 App 里「保存本地」下下来的视频，会带一个满屏飘来飘去的抖音 logo + @作者号——这就是平台水印，拿去做素材很难看。市面上很多「去水印」工具是一帧帧把 logo 涂糊，复杂背景会留下模糊块。

我们这套不涂不糊，而是直接拿抖音自己的干净源。原理很简单：抖音网页版的视频接口，对同一条视频其实同时返回两个版本——

play_addr      → 干净的原始母版（没有任何平台水印）  ← 我们取这个
download_addr  → 带水印版（就是 App「保存本地」那版，飘着抖音 logo）

所以我们只是把那份本来就干净的母版取出来给你，画质无损、无模糊块、秒出。

✅
实测确认。 2026-07-06 拿一条真实装修视频跑通：取到的 play_addr 版本抽帧逐帧看，没有抖音 logo、没有 @作者号水印（视频里博主自己做的标题字幕属于内容本身，会保留，那不是平台水印）。

2入口（独立网址 + token）

一个能直接打开的网址，跟「小红书 → 抖音」那套一样，贴链接就用，不用登录后台：

项值
网址https://akke-worker-prod.fly.dev/dewm
访问 tokenakke-dewm-7c3f19a2
能下什么抖音视频（无水印 mp4）+ 图集（原图）

第一次打开，在「访问 token」框里粘一次，浏览器会记住，下次免填。

🔐
token 是简单防蹭，不是机密。只在 Akke 内部用，别贴到公开群 / 社交媒体 / 第三方 AI 工具。外传等于送给竞品。

3三步操作

第 1 步

在抖音 App 复制视频链接

抖音 App 打开目标视频 → 点右下角「分享 ➤」→ 选「复制链接」。剪贴板会得到类似这段（整段不用剪，系统会自动抽出链接）：

3.87 复制打开抖音，看看【XX的作品】新房刚拿到钥匙… https://v.douyin.com/xxxxxxx/

也支持直接粘完整视频链接（https://www.douyin.com/video/76xxxx）或纯视频 id。

第 2 步

打开网址 → 粘贴 → 点「解析」

打开 https://akke-worker-prod.fly.dev/dewm（首次填一次 token），把整段粘进输入框，点解析。1-3 秒后出预览：封面、作者、文案、时长，并判断是视频还是图集。

第 3 步

下载

  • 视频 —— 点「下载无水印视频」，浏览器直接存 mp4（文件名 douyin_<id>_nowm.mp4）
  • 图集 —— 会平铺所有原图，逐张右键「图片另存为」

4支持什么 / 不支持什么

能不能 / 暂不
抖音视频取无水印原片（画质无损）不做翻转 / 变速 / 换文案的二改（那是「小红书 → 抖音」那套的活）
抖音图集取原图不去除博主自己加的字幕 / 贴纸 / 品牌角标（那属于视频内容，不是平台水印）
贴分享口令 / 短链 / 完整链接 / 纯 id 都认不下需登录才可见 / 私密 / 已删除的视频
⚠️
拿去重发要留个心。 这套只给你干净素材，本身不做任何「防查重」处理。如果你打算把它重新发到抖音/别的平台，抖音的画面 + 音频指纹检测照样在——直接原样重发有限流风险。要规避查重是「小红书 → 抖音 流水线」那套二改在解决的问题，别把两者搞混。

5故障排查

症状原因修法
「no Douyin aweme_id found」粘的内容里没认出抖音链接/id从抖音 App「分享 → 复制链接」重新复制整段再粘
「image gallery, not a video」这条是图集不是视频正常——往下看图集区，逐张另存
解析转圈很久 / 报 502该视频私密 / 已删 / 抖音临时限流换条视频；仍不行找 Owner 上报
下载按钮点了没反应浏览器拦了下载 / 网络中断重点一次；或换个浏览器
文案 / 作者显示乱码极少数视频元数据编码异常不影响视频本身，照常下载即可

遇到表里没有的错误，截屏 + 把粘进去的链接一起发给 Owner，多半是某种没覆盖到的链接格式，加个 case 就能修。

6注意事项与红线

  • CDN 链接有时效：解析出来别拖太久再下，隔很久没下重新解析一次即可
  • 博主自加的字幕/角标会保留——工具只去平台水印，不动内容
  • 这是内部工具，本说明页可公开，但别把「怎么绕过水印」当卖点对外宣传
🚫
红线 · 不要做：
  • 不要拿去冒充原创搬运牟利——去掉平台水印≠拥有版权，视频著作权仍是原作者的
  • 不要下带真人肖像 / 品牌 / 隐私的内容做二次商用而不获授权
  • 不要把工具/接口外传给客户或第三方——账号和链路都是 Akke 资产
💬
