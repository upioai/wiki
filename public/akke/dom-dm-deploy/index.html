浏览器 DOM 版私信 · 从零部署指南

首触发 DM + 自动捕获客户回复 + 自动回复，全跑在一个调试版 Edge 里 · 无影云电脑 · 照着做即可，不需要问任何人拿材料
零坐标 · 零校准 · 零截图AI 2026-07-03

①这套是什么（3 分钟看懂再动手）

一台无影云电脑 = 一个抖音号。机器上跑两个东西：

  • 调试版 Edge：一个专用浏览器窗口（最小化放着就行），登着抖音网页版，脚本靠调试端口 9222 直接读写网页元素（DOM）——不需要它在前台。
  • poll agent（一个黑窗）：每 15 秒转一圈，做两件事——
发：服务端派单→ agent 领单→ DOM 进对方主页点「私信」→ 打字 → 发送 → 验气泡
收：DOM 读会话列表→ 红点 = 客户回了→ 写回库 → 秒级起草回复→ 过审后 DOM 自动回过去

发多少、发给谁、话术内容全部由服务端控制（每分钟最多 1 条、每小时满 10 停 1 小时、每日封顶）——这台机只是手。相比老的「抖音 PC 客户端 + 截图 AI 视觉」方案：不用量坐标、不用校准模板、不用切输入法、昵称读取精确到 emoji、读列表不烧一分钱 AI。

钥匙哪里来（不用找 PM）

3 把钥匙全公司所有云电脑同值。任何一台已经在跑 DM 的云电脑（饭粒 / 零星 / 小文 / 文哥 / 小胡 / 有大有小 任一台），打开它的 C:\akke-wuying\wuying-dm\.env（有的老机在 C:\akke-wuying\.env），把 SUPABASE_SERVICE_ROLE_KEY / OPENROUTER_API_KEY / AKKE_DM_DRAFT_SECRET 三行的值抄过来。

钥匙红线：这几把钥匙不许截图发群、不许发微信/Lark、不许贴 paste.rs。两台云电脑之间传，用无影自带的文件传输或 U 盘映射；实在要走网络就抄在纸上手敲（service_role 那把约 219 字符，认真核对）。
长钥匙粘贴坑：无影远程桌面粘长文本会从中间折行、行首加空格，钥匙就废了。稳妥做法：粘完在记事本里确认那一行没有断行、行首没空格；或者用 PowerShell 写入后核长度：(Select-String -Path .env -Pattern "SERVICE_ROLE").Line.Length（应 ≈ 245）。

⑤打开调试版 Edge + 登录抖音网页版（Cookie 撑 15–30 天）

1打开调试版 Edge（普通可见窗口，就是多了个调试端口） 
$edge="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
if(!(Test-Path $edge)){$edge="C:\Program Files\Microsoft\Edge\Application\msedge.exe"}
Start-Process $edge -ArgumentList '--remote-debugging-port=9222','--user-data-dir=C:\akke-edge-debug','https://www.douyin.com'
2在弹出的 Edge 里：扫码登录本机抖音号 → 登录后点开一次私信（右上角消息图标，确认能看到会话列表）→ 把窗口最小化放着

⚠️ 扫码用这台机对应的那个抖音号的手机扫，别扫成自己手机上登着的其他号。

这个 Edge 窗口的三条规矩：①别关（关了 = 收发全停，最小化没事）；②别在里面乱点、别导航离开抖音；③桌面别再开第二个登抖音的 Edge。
想彻底看不见也可以：关掉它后加 '--headless=new', 参数重起（隐形模式，登录态自动带着）。功能完全一样，纯看个人习惯。
3验证 Edge 通 + 能读私信 
cd C:\akke-wuying\wuying-dm
py douyin_dm_web_capture_dom.py
=== web capture[DOM] (COMMIT 写回) ===
  conversation-item 12 个
=== 完成: 命中客户回复 0 条 / 有红点 0 个 / 扫 12 人 ===

conversation-item N 个（N>0）= 通了。持续 0 = 私信面板没点开过或没登上 → 回第 1 步用可见窗口检查。全新账号从没发过 DM 的话 by_name 0 人 是正常的。

⑥启动 poll agent

1先杀残留旧进程（保证全机只有一个 agent），再启动 
Get-CimInstance Win32_Process | Where-Object {$_.CommandLine -like '*wuying_poll_agent*'} | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
cd C:\akke-wuying\wuying-dm
py -u wuying_poll_agent.py

启动横幅应长这样（必须有 v=，没有 = 脚本是老版本，回第③步重下）：

=== wuying_poll_agent v=2026-06-24+captcha-char-sample account=xxxxxxxx… every 15s claim=2 second_touch=off rc=off ===

这个黑窗保持开着别关。⚠️ 黑窗被鼠标点过会进「选择模式」冻结输出（看着像卡死）——按一下回车就恢复。

2（可选）开机自启：登录后自动拉 agent 
$s="$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\akke_wuying_agent.bat"
Set-Content -Path $s -Encoding ascii -Value @('@echo off','cd /d C:\akke-wuying\wuying-dm','timeout /t 30 /nobreak >nul','py -u wuying_poll_agent.py >> agent.log 2>&1')

注意调试版 Edge 不会自启——重启后仍要手动跑一遍第⑤步第 1 条命令（见下方「日常运维」）。

⑦验活（4 项对完才算部署完成）

#验什么怎么验 / 预期
1捕获在跑黑窗每轮出 web capture[DOM] … conversation-item N 个（不是 ECONNREFUSED、不是 0）
2真回复抓得到用测试号给本机账号发条私信（产生红点），下一轮日志出 [红点] 昵称: 内容 + [inbound] 昵称: 内容
3首触发得出等服务端派单（自动的），黑窗出 === DOM 批量发送: N 条 === + [sent] 昵称: 文案；再肉眼开抖音网页版私信列表确认真有气泡
4回写落库把 2、3 的日志整段发给 PM / 在群里说一声，让有库权限的人查一眼 messages/dispatch_queue 对上（部署期一次即可）
黑窗一直「无 approved 待发」「没领到单」= 不是坏了。派不派单由服务端控制：每小时发满 10 条会停约 1 小时、每日有封顶、你这个号有没有开派单由数据库配置决定。判断标准只有一条：有单来的时候发得出去。

⑧日常运维（云电脑重启后 / Cookie 过期 / 更新脚本）

云电脑每次开机 / 重启后（2 分钟）

两条命令拉起 Edge + agent（没配自启就都要手动） 
# 1) 调试版 Edge（起来后最小化放着；想隐形就在参数最前加 '--headless=new',）
$edge="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
if(!(Test-Path $edge)){$edge="C:\Program Files\Microsoft\Edge\Application\msedge.exe"}
Start-Process $edge -ArgumentList '--remote-debugging-port=9222','--user-data-dir=C:\akke-edge-debug','https://www.douyin.com'
# 2) poll agent（配了自启则跳过，注意别起两个）
cd C:\akke-wuying\wuying-dm
py -u wuying_poll_agent.py

Cookie 过期（15–30 天一次，症状 = 捕获持续 conversation-item 0）

关掉 Edge（Get-Process msedge | Stop-Process -Force）→ 回第⑤步：重新拉起调试版 Edge → 扫码登录 → 点开一次私信 → 最小化放着。

更新脚本（PM 说「升级到最新版」时）

先杀旧 agent，再重下，再起一个新的（顺序不能反） 
Get-CimInstance Win32_Process | Where-Object {$_.CommandLine -like '*wuying_poll_agent*'} | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
cd C:\akke-wuying\wuying-dm
$b='https://raw.githubusercontent.com/upioai/wiki/main/public/akke/wuying-dm'
foreach($f in $files){ Copy-Item $f "$f.bak" -Force -EA 0; curl.exe -fsS -o $f "$b/$f" }
py -u wuying_poll_agent.py

不先杀旧进程的话，后台旧 agent 还按旧代码抢单，新窗口看着零日志——经典假故障。回滚 = 把 .bak 改回原名。
