企微客户朋友圈 · 个人形象打造流程

半自动方案 · 一人建内容 → 三人手机确认 → 同步发到各自客户朋友圈
主角:夏夏 · fanny · 野荞　|　渠道:企业微信「客户朋友圈」

一次完整发布流程(5 步)

1
每天搬运样本账号内容 手动
每天打开样本账号(标杆同事),把当天发的内容(文案 + 图)搬过来作为选题素材。
⛔ 能否自动扒取样本账号内容?——不能。样本是朋友圈内容,别人的朋友圈没有任何官方接口能读取;硬爬属逆向、违规、封号风险,不碰。所以这一步只能每天人工去看 + 截图/复制,无法自动化。
(例外:若该样本账号在抖音/小红书/视频号另有公开内容,那部分可另议自动采集 —— 但朋友圈本身不行。)
2
后台建内容(照搬填入)夏夏操作
把从样本账号搬来的文案 + 图直接填进去,「谁可以看」按成员选 夏夏 + fanny + 野荞(= 选"谁的客户能看到",不是只给内部员工看)。
客户与上下游 → 客户联系 → 群发工具 → 企业发表到客户的朋友圈 → 新建内容
3
推送任务 系统自动
点「确认创建」后,系统自动把发表任务推到三人手机(此时还没真正发出)。
4
手机确认发表 三人各点一下
三人手机企微收到「待发表」通知 → 各自点「发表」→ 同步发到各自客户的朋友圈。这一下官方强制必须人点,免不掉。

前置准备(一次性,管理员配)

  • 形象对齐(一次性):三人统一改企微头像 + 昵称。
    · 头像:统一用「有大有小」品牌卡片图(youdayouxiao_card_clean.png)
    · 昵称:统一「全屋定制小X」格式 —— 样例账号「全屋定制小武」(微信号 Homedz3791),如 全屋定制小夏,fanny / 野荞 各自定一个
    · 改法:手机企微 →「我」→ 点头像/名字 → 分别换头像、改姓名/对外昵称
  • 管理员给夏夏开「客户联系」管理权限(我的企业 → 权限管理 → 管理组 → 勾「客户联系」)
  • 管理员把夏夏 / fanny / 野荞加进「客户联系使用成员范围」(客户联系 → 权限配置)
  • 确认 fanny、野荞 各自已有加过企微的客户(外部联系人),否则她们那边发了没人看
⚠️ 第一次先发测试:随便填一句话 + 一张图跑通全流程,确认三人手机都能收到「待发表」、都能点出去,再发正式内容。

三人企微个人形象卡

AI 职业形象照 + 「有大有小」品牌书房背景,统一风格(对齐样例「全屋定制小武」)。 生成方式:即梦出职业证件照 → 脚本 make_youda_card.py 一键抠图贴卡。

边界:哪些能自动 · 哪些不能

✅ 能自动

  • 系统自动把建好的内容推送到三人手机(建完即推)
  • (进阶可选,暂不做)AI 生成文案 / 头像

✕ 自动不了(官方限制)

  • 自动扒取样本账号朋友圈内容(无接口)
  • 最后「发表」确认 — 强制成员手机点
  • 每天有发表条数上限,以页面提示为准
  • 自动复制样本原文 — 没接口,只能每天手动搬
关于"纯无人值守全自动":需要 API(add_moment_task)+ 客户联系 Secret + 企业可信IP,且仍免不掉成员确认那一下。投入产出不划算,当前暂不做;等手点觉得烦了再回头评估。

每次发布速查清单

  • 打开样本账号,把当天内容(文案 + 图)照搬下来
  • 夏夏进后台:新建内容,填文案 + 传图
  • 「谁可以看」按成员选:夏夏 + fanny + 野荞
  • 确认创建,任务推送
  • 三人手机各点「发表」
  • 抽查一条客户朋友圈,确认真发出去了
