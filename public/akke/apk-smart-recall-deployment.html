AKKE · 召回部署方案 · 2026-09-06

用现有客户备注，
开启最多7次智能召回

销售已经有统一备注，系统直接用它筛选客户；再读历史判断是否适合召回，并结合地区生成对应内容。每次发一条，等待回复，客户新消息始终优先。

复用已有备注不逐客补标签仅匹配客户单聊每轮最多7次
客户范围执行逻辑企微节奏地区话术消息切换部署状态

本次方案变化

取消“客户 / 同事 / 无关人员”的模型分类，改成统一备注白名单。格式符合 → 允许读取历史；历史符合 → 才允许进入召回。不符合备注的联系人直接跳过。

“7天召回”在本方案中指最多7次召回，不是对沉默7天的人发一次，也不是固定连续7天发送。本次范围到第7次结束，不自动扩展低频培育。

01 · 客户备注白名单

闽D｜607101｜岩板示例｜13800000000（脱敏示例）

地区码 + 6位客户编号 + 业务/姓名 + 末尾11位手机号。默认按完整格式匹配；编号按业务编号处理，不解释成日期。

扫描列表时可能遇到被截断的备注。无法取得完整名称或唯一核对时跳过；不能只凭“闽D”或手机号就认定目标。

符合格式也要继续判断

必须是一对一会话、有客户原话、消息方向可信、最后不是客户在等回答，且没有拒绝、成交或履约等停止信号。

不符合格式直接跳过

不打开深读、不上传正文、不生成召回。群聊、系统号、身份无法核对也跳过。无需销售逐个审核。

02 · 从手机历史到7次召回

历史可能只存在于销售手机。云端没有记录时先建档，不能把“没有云端历史”解释成“没有客户回复”。

分批扫描列表空闲时读取可见会话，匹配统一备注。
完整核对目标标题、一对一身份、输入框与当前页面都要确认。
读取有限历史保留原话、角色与可信时间；不足就暂不发。
云端判断停止规则优先，再根据历史决定阶段和召回内容。
等待到期复用企微七话题与阶段间隔，一次只处理一条任务。
发前再次检查核对最新消息、人工接管、新通知和云端暂停。
确认气泡并记账真实发出才增加一次；回执重复不重复计数。
回复或结束客户回复取消旧任务；未回则等下次；满7次结束。

03 · 沿用企微的七话题和阶段间隔

话题顺序为：关注点选择 → 需求缺口 → 报价配置理解 → 比较清单 → 降低资料提交门槛 → 时间节点 → 温和收尾。实际内容承接客户历史，避免再问已回答的问题。

阶段下次间隔内容方向
冷启动完成触次少于3时1天，之后2天先确定关注点，逐步解释配置、需求和流程。
明确决策中2天承接真实报价、方案和待确认事项。
需求形成中3天结合已知户型、面积、风格、预算提供帮助。
轻互动 / 观望7天相关知识与比较方法，减少催促。
沉默30–60天 / 60–90天10天 / 15天降低频率，仍须与原需求有关。
90天以上 / 未来计划30天基础间隔结合真实时间约定判断；不擅自提前联系。
拒绝、成交、履约中或本轮满7次不再派发停止旧轮，不能以普通候选身份重新绕回。
复用企微的选题和节奏，不直接复制含“发群里”的群聊正文，也不把企微统一报价、活动或期限自动套到个人微信。

04 · 根据地区生成不同内容

地区来自配置

备注开头匹配服务端地区规则，例如闽D、闽C。地区码是客户线索，不能自动当成已经核实的装修地址；历史中客户明确的地址优先。

话术结合历史

本次话题 + 未完成事项 + 可用地区信息共同决定内容。仅使用已配置、可核实的服务范围或资料，不编造当地活动、样板间和可预约时间。

未知或冲突

无法确认地区时不猜。缺少地区业务资料时不能生成当地优惠；明确地址冲突则先停止地区化召回，等待可靠信息。

信息边界

手机号用于备注校验与身份核对，不写进召回话术。姓名与业务词不强行拆分，避免把“岩板”等词当成称呼。

05 · 新消息优先，切换前先确认现场

发生时机处理方式恢复条件
尚未输入，任何客户来消息取消本次发送机会，安全结束扫描或召回，优先回复。处理完待回复，再重新领取或核验任务。
已输入，尚未点击发送核对并清空本次草稿；无法确认清空则暂停待核对。不能带着旧草稿切到另一位客户。
已经点击发送先查新气泡并回执，不能立刻重试。不确定结果进入复核，不能自动补发。
召回对象回复旧轮剩余任务失效，先处理客户当前问题。只有新的正常对话和已确认回复才能作为新计划依据。
销售自己操作 / 风险提示 / 远程暂停停止新的扫描和发送许可，持久保存任务阶段。恢复后重新核对身份、最新消息与任务有效性。

系统通知不能覆盖“客户正在打开的聊天页里发来消息”的全部情况，因此发送前仍需检查最新一屏。正在执行的网络请求与点击结果核验也需要时间，不承诺零延迟切换。

北京时间09:00–21:00，每台每天最多5条主动召回，同一客户每天最多1条，主动消息至少间隔10分钟。普通新消息优先。

安装包交付

正式release包必须可追溯到提交，记录版本、SHA256与签名。带生产设备凭据的APK单独交付，不放到这个公开页面。

07 · 上线验收

  • 白名单外会话没有深读、上传或召回；相似名称、群聊与截断标题不会被放行。
  • 历史不足、最后是客户消息、明确停止或履约中的客户不召回。
  • 同一任务重复领取、重复回执和程序重启不会重复发送或重复计数。
  • 模拟7次成功后不再产生第8次；没有成功回执不推进下一触。
  • 本人和其他客户来消息时，尚未点击的召回被打断；恢复前重新检查。
  • 点击发送后故障不会自动补发；远程暂停阻止新发送许可。
  • 服务端版本、APK构建、手机心跳分别核对；真实气泡与服务端回执一致。
