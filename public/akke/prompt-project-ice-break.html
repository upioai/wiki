③ 每类问题的对应优化方式及进展

未根治 1. Missing credentials（apiKey 漏配）
现象v21 (18/77) / v23 (118/436) / v25 (27/610) 反复出现
根因OpenAI client 实例化路径漏传 apiKey，部分路径走独立工厂没接齐凭据
当前方案回滚 + 重发；调用路径未加凭据兜底
进展v25 仍 4.4% 失败 grep new OpenAI 找漏路径加兜底
部分缓解 2. JSON 截断（SyntaxError: Unexpected end of JSON input）
现象v17 (2 次) / v20 (1 次) 偶发；v25 暂未见
根因模型输出被截断没闭合 JSON（max_tokens 不够）
当前方案fb4f2ee max_tokens 1024 → 4096；8d9fcb8 reasoning.effort=low 配合
进展已大幅缓解 根治需 JSON 修复中间件 + <JSON_END> 哨兵
已修 3. Persona 漏改 / leak（小艾→小艳 / tool_call 字节）
现象DeepSeek V3 兼容 bug 把工具调用字节流当文本输出；persona 改名时 leak regex 漏同步

进展v17+ leak count = 0
守住每次 persona 改名要走 checklist 同步 leak regex
