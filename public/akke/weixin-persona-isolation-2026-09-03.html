个微人设隔离与分配：手机自己建，电脑端后台分

个人微信的人设改为服务端一张表。手机由本人填，电脑端由管理员分。机器从心跳回包里知道自己是谁，没分配就不回。人设 key 就是工作台的接待号，一个人设只绑一台机器。

人设表和配对码表的 DDL 
create table public.weixin_personas (
  id            uuid primary key default gen_random_uuid(),
  org_id        uuid not null,
  key           text not null,        -- wx_xiaoxia_01，服务端生成
  origin        text not null check (origin in ('self','assigned')),  -- 手机自建 / 后台分配
  host          text,                 -- 绑定的机器；未绑时为空
  display_name  text not null,
  gender        text not null check (gender in ('男','女')),
  style_preset  text not null,
  catchphrases  text[] not null default '{}',
  status        text not null default 'active' check (status in ('active','retired')),
  created_by    text not null,
  created_at    timestamptz not null default now(),
  updated_at    timestamptz not null default now()
);
create unique index on weixin_personas (org_id, key);
create unique index on weixin_personas (org_id, host)         where status = 'active' and host is not null;
create unique index on weixin_personas (org_id, display_name) where status = 'active';

create table public.weixin_persona_pairing_codes (
  code        text primary key,       -- 6 位数字
  org_id      uuid not null,
  persona_id  uuid not null references weixin_personas(id),
  expires_at  timestamptz not null,   -- 生成后 24 小时
  used_at     timestamptz,
  used_by     text
);

DDL 走 supabase/wecom-ddl/ 存档加 dashboard 执行，并补 wecom_ddl_applied 台账。

接口契约一览（八个 action）
action谁调做什么
persona_preview手机 / 工作台按表单字段临时装配人设，真模型回一句固定问价，不落库
persona_register手机建 origin=self 的行并绑 host，返回 key；同名或本机已有生效人设则拒绝并说明绑在哪台
persona_assign工作台 / 状态页建或改 origin=assigned 的行，绑到指定 host；管理员 token
persona_pairing_code工作台为一个未绑定的人设生成配对码
persona_claimWindows 边车拿配对码把本机 host 绑到预建的人设，配对码作废
persona_migrate_preview / _commit手机列旧 persona 下裸名候选（排除显式身份的），按勾选精确改绑
heartbeat（已有）手机 / 边车回包 desired.persona；telemetry 加 personaKey、personaName
generate / opener / confirm（已有）手机 / 边车新增 host 字段；服务端核对 (persona, host) 与登记一致

服务端认人设的函数从「查静态九人表」扩成「先查静态表，wx_ 前缀再查库」，命中后交给同一个骨架装配，回复生成、模型选择、个微输出闸一行不改。

09已定与待定

已定 · 风格不开自由文本九档预设加口头禅。
已定 · 旧会话只迁手机端的手机报名单、人勾选、精确改绑；电脑端不迁。
已定 · 配对码要做首装不用先等心跳再回状态页分配。
已定 · 企微不动企微云电脑仍用九个静态 key 和 .env，不进个微人设表。
待定 · 工作台接待号自动填还是手填默认手填：注册屏和分配页都把 key 显示出来给管理员抄。自动填要让 wecom-chat 的接口跨仓写工作台成员表，本次不碰。
