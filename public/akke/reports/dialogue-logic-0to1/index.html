SECTION 01

真实案例 · 按评论三类型各一条

第一步永远是给评论分类。同一条视频底下的评论,我们先判它是产品咨询、知识咨询还是纯分享/互动——类型不同,回复策略完全不同。下面三条都是生产库里的真实评论与真实话术。

① 产品咨询型 100 分 · 高意向

comment_type = product · 河南郑州 · 直接问价 = 最强购买信号
真实评论(🌼双双🌸):"郑州套内面积146老房翻新大概多少钱?"
AI 回复话术
🌼双双🌸,视频里老房改造那套施工流程挺实在。套内146平全屋柜子大概8-15万,看板材和五金。你家几室几厅,柜子打算做哪些?
策略 · 给区间报价(不回避)+ 反问户型套牢需求 钩子 · 先夸视频建立同频,再把话头引回"你家" 分类信号 · 含面积+地域+"多少钱",判 product 几乎无歧义

② 知识咨询型 85 分 · 高意向

comment_type = knowledge · 重庆 · "能做吗"= 探地域可行性
真实评论(帅哥烦恼多):"重庆能做吗"
AI 回复话术
你好,帅哥烦恼多,看到你评论问重庆能不能做。我们这边橱柜案例不少,像你视频里这种石英石台面+无挡水条的款式,重庆最近刚落地过两单。现在活动期价格还能再让一档,要不要先说说你家厨房尺寸?
策略 · 先正面答"能做",用"本地落地两单"打消跨省顾虑 钩子 · 复述视频里的具体款式证明真看过,再抛活动+反问 分类信号 · 问的是可行性/做法而非直接报价,判 knowledge

③ 分享 / 纯互动型 无关 · 不触达

comment_type = share · 多为点赞/捧场/同行,无任何需求信号
真实评论:"老王靠谱[赞]" · "赞一个" · "这是我家"
系统决策(无话术)
识别为纯互动 / 无购买意向 → 直接丢弃,不进对话池、不发 DM。同行、广告、"在哪买"的导流号也走这条分支过滤掉。
策略 · 不浪费账号配额去骚扰捧场用户,保护账号权重 分类信号 · 无面积/地域/价格/可行性问句,判 share/off_topic 风险 · 个别"这是我家"可能是潜在客户,误丢需后续靠阈值微调挽回
三类的分水岭:分类这一步决定了后面所有动作。产品型直接给区间报价 + 套需求,知识型先答可行性 + 用本地案例建立信任,分享型直接丢弃不触达。判错类型,后面的话术再好也是错的——这正是第 ② 段原理图里"分支判别"要和甲方一起校准的地方。
SECTION 02

0→1 逻辑原理图

对话项目的骨架是 4 步流水线。颜色 = 这一步谁在干:蓝 = 本机确定性代码、橙 = LLM 生成对话、绿 = 真机发送 + 人工核验。

本机确定性代码(采集/评分/锁定) LLM 生成(破冰/跟进/记忆) 真机发送 + 人工核验回写
① 采集 + 评分
看见一条评论
  • worker 拉视频评论入库
  • LLM 打意向分(0–100)
  • 三轴:类型 / 具体度 / 新鲜度
  • ≥ 阈值才进对话池
② 锁定 + 备料
认领这条线索
  • claim 按 (org,用户) 锁 4h
  • 去重:同人不被两人重复打
  • 起草破冰话术(opener)
  • 带地域 / 视频细节
③ 对话生成
有来有回
  • stage-aware 回复
  • 破冰→培育→决策 三阶段
  • 跨会话记忆(同人沉淀画像)
  • 人格"小艳",自然口吻
④ 发送 + 回写
发出去 + 记下来
  • 真机串发(WDA/ADB/云电脑)
  • mark-contacted 回写会话
  • 引导加微(给微信号)
  • 状态机推进 stage

子系统:我们到底怎么回复用户(③ 的核心)

不是看到评论就硬发一句。每条评论先过一道判别(三轴 + 是否本地业务),再按判别结果走不同的回复分支——什么样的评论,配什么样的话。

第一步 · 判别这条评论是什么

类型 type
product 购买信号 / knowledge 咨询求助 / share 纯互动
具体度 specificity
low / medium / high — 指向商品/工艺/方案越具体越高
新鲜度 freshness
urgent 正在装 / active 在看 / none 没动作
是否本地业务 category
home 全屋定制相关 / off_topic 无关 → 直接丢弃

三轴合成意向分(高 / 中 / 低 / 无关)。只有 home + 中高意向才进对话池触达,其余丢弃。

第二步 · 按判别结果选回复分支

分支 A · 客户已经主动要联系方式直奔加微
命中"加微信 / 留个电话 / 怎么联系"等词 → 不再绕暖场,直接反问客户要微信号(简化路径)。客户已经表态,寒暄反而拖慢。
回复策略
"好呀,方便直接发下你微信号吗?我加你发方案。"
分支 B · 强业务信号(报价/柜体/装修阶段词)4 段式破冰
招呼 + 视频/评论细节 + 地域接业务 + 一个开放反问。点中客户当下的具体动作,显得"懂行",再用反问把话头抛回去。
真实例 · 吕途有你("正准备装修")
"你好,吕途,瓦工进场这步最容易漏细节…你家现在装到水电阶段还是直接贴砖了?"
分支 C · 知识咨询型(knowledge · 求建议/求资料)先给真东西再接业务
客户在问"怎么做 / 要注意啥 / 发份资料",不是直接表达购买。先给一点真东西(简短专业回答或答应发清单),建立"懂行又愿意帮"的信任,再自然抛一个开放反问,不硬推销。
应然例 · 客户问"自己装水电要注意啥"
"水电主要盯三点:回路分配、强弱电间距、防水闭水。要不要我整理份分阶段避坑清单发你?你家现在到哪步了?"
分支 D · 带地域顾虑("X 地能做吗")先解地域再发问
第一句先明确"能服务你那",打消"你们是不是不到我这"的顾虑,然后才问户型/需求。顺序反了会被当成推销。
真实例 · 三少爷("盐津可以来装不?")
"你好 三少,盐津能做,宜宾周边县都送装。你家在盐津哪边?多大户型?"
分支 E · 询价但品类不明先确认,别假设
先问清这个价是什么品类再接话,不要替客户假设成自家品类。反例:忧郁的入把"668 系统窗"当成全屋定制报了价,被当面纠正——这条已在改 prompt。
应该怎么回
"这 668 是说窗户还是柜体呀?你这边主要想做哪块,我按这个给你算。"
分支 F · 纯互动 / 无关(share + off_topic)不触达 · 丢弃
"[赞]"、纯表情、广告、同行、与全屋定制无关的内容 → 不进对话池,直接丢弃,不浪费触达额度。

第三步 · 客户回了之后,按阶段推进(对话阶段机)

每段对话有"阶段",决定 LLM 用哪套系统提示、目标是什么。目前三条案例都停在第一阶段 ice_break——破冰发出、客户回了、还没推进到稳定加微。

破冰 ice_break

目标:让客户回第一句。用视频细节 + 地域接业务 + 一个开放反问。当前三案都在这。

培育 nurture

目标:建立专业信任、问清户型预算。多轮来回,给价值(避坑清单/方案预览)而非急着要微信。

决策 decision

目标:引导加微 / 留方案 / 转人工。给微信号 + 处理加微 friction(验证/备用号)。

SECTION 04

Badcase · 分类 · 根因 · 优化方式 · 进展

从三条真实案例 + 全量跑里归出的问题,按 A–F 六类。其中 A(回写)和 F(排队)是工程问题、在修;D(报价)、E(加微节奏)是业务规则问题,需要和业务一起定细则。

类别表现 / 根因优化方式进展
A数据回写 只存了 opener,客户回复 + 跟进 DM 没写回 DB。导致:统计失真(回复=0)、4h 后 claim 过期被他人重复 claim 重发。三条案例全中。 发完每条 DM 立即 mark-contacted;客户回复入库;补 check-replies 抓全 inbox。 待修 · 最高优
B账号信任 messaging 账号(零星/野荞)主页没粉丝/简介/作品,客户点进来看不到背书;忧郁的入还当面点破"你在云南我在江西"。 抓并展示账号主页资产;同城/跨省话术分支;号源与 IP 对齐策略。 设计中
C内容·品类误判 忧郁的入把"668 系统窗"误判成全屋定制(自家 568 品类),先入为主报了价。纠正得当但暴露"不确认就假设"。 破冰前先确认品类/需求,不替客户假设;评论语义不明时用开放反问。 prompt 调整中
D价格门槛 报价 100% 延后到加微(吕途"怎么收费"、忧郁询价都被挡)。早期保护合理,但全卡可能劝退。 给"方法/区间"预览而非精确价;留一档可在 DM 透露的范围。规则待定。 规则待定
E加微节奏 三少爷单轮回复后就急推加微,可能显得功利、转化反而低。 按 stage / 信号强度决定何时推加微;弱信号先培育。触发条件待定。 规则待定
F时效排队 采集→发送还有 1.6h 均值排队(忧郁的入 4h41m),新鲜度被稀释。 高意向优先队列;缩短 claim→发送间隔;高峰自动提速。 可优化
