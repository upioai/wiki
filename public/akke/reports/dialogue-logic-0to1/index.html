SECTION 01

真实案例 · 按评论三类型各一条

第一步永远是给评论分类。同一条视频底下的评论,我们先判它是产品咨询、知识咨询还是纯分享/互动——类型不同,回复策略完全不同。下面三条评论都是生产库真实评论;会触达的两条,话术已按「全链路三要素」标准写——每条都含 师出有名 + 产品优势(价格四元素) + 加微钩子。

① 产品咨询型 100 分 · 高意向

comment_type = product · 河南郑州 · 直接问价 = 最强购买信号
真实评论(🌼双双🌸):"郑州套内面积146老房翻新大概多少钱?"
AI 回复话术

SECTION 02

0→1 逻辑原理图

对话项目的骨架是 4 步流水线。颜色 = 这一步谁在干:蓝 = 本机确定性代码、橙 = LLM 生成对话、绿 = 真机发送 + 人工核验。

本机确定性代码(采集/评分/锁定) LLM 生成(破冰/跟进/记忆) 真机发送 + 人工核验回写
① 采集 + 评分
看见一条评论
  • worker 拉视频评论入库
  • LLM 打意向分(0–100)
  • 三轴:类型 / 具体度 / 新鲜度
  • ≥ 阈值才进对话池
② 锁定 + 备料
认领这条线索
  • claim 按 (org,用户) 锁 4h
  • 去重:同人不被两人重复打
  • 起草话术 = 三要素硬约束
  • 师出有名 + 价格四元素 + 加微钩子
③ 对话生成
有来有回
  • stage-aware 回复,每条带三要素
  • DM + 反向评论同一套模板
  • 跨会话记忆 · 人格"小艳"
  • reply-guard 校验三要素齐全
④ 发送 + 回写
发出去 + 记下来
  • 真机串发(WDA/ADB/云电脑)
  • mark-contacted 回写会话
  • 引导加微(给微信号)
  • 状态机推进 stage

子系统:我们到底怎么回复用户(③ 的核心)

不是看到评论就硬发一句。每条评论先过一道判别(三轴 + 是否本地业务),再按判别结果走不同的回复分支——什么样的评论,配什么样的话。

第一步 · 判别这条评论是什么

类型 type
product 购买信号 / knowledge 咨询求助 / share 纯互动
具体度 specificity
low / medium / high — 指向商品/工艺/方案越具体越高
新鲜度 freshness
urgent 正在装 / active 在看 / none 没动作
是否本地业务 category
home 全屋定制相关 / off_topic 无关 → 直接丢弃

三轴合成意向分(高 / 中 / 低 / 无关)。只有 home + 中高意向才进对话池触达,其余丢弃。

第二步 · 按判别结果选回复分支

所有会触达的分支(A 除外,A 已直奔加微天然命中钩子)都按「师出有名 + 产品优势(价格四元素:品牌配置 / 原价 / 样板房价 / 样板房唯一一套活动)+ 加微钩子」三要素硬约束来写;反向评论(公开回评)与 DM 共用同一套三要素模板。生成后过一道 reply-guard 校验三要素齐全度,缺项打标重写(类比价格逻辑页的 price-guard)。

分支 A · 客户已经主动要联系方式直奔加微
命中"加微信 / 留个电话 / 怎么联系"等词 → 不再绕暖场,直接反问客户要微信号(简化路径)。客户已经表态,寒暄反而拖慢。
回复策略
"好呀,方便直接发下你微信号吗?我加你发方案。"
分支 B · 强业务信号(报价/柜体/装修阶段词)三要素破冰
师出有名(视频/评论细节)+ 产品优势(价格四元素)+ 加微钩子。点中客户当下的具体动作显得"懂行",带出样板房四元素报价,再用加微钩子收口。
例 · 吕途有你("正准备装修")
"你好,吕途,瓦工进场这步最容易漏细节。你这套全屋我们××多层实木原价12.8万、样板房特价8.9万,全城限1套,我把方案发你,加个微信方便发?"
分支 C · 知识咨询型(knowledge · 求建议/求资料)先给真东西再带三要素
客户在问"怎么做 / 要注意啥 / 发份资料"。先给一点真东西(简短专业回答=师出有名+建立信任),再顺势带出样板房四元素,用"发清单/方案"作加微钩子,不硬推销。
例 · 客户问"自己装水电要注意啥"
"水电盯三点:回路分配、强弱电间距、防水闭水。我们做过的样板房××多层实木原价9.8万、特价6.9万全城限1套,顺带把分阶段避坑清单也发你,加个微信方便发?"
分支 D · 带地域顾虑("X 地能做吗")先解地域再带三要素
第一句先明确"能服务你那"(师出有名+打消跨省顾虑),再带样板房四元素报价,最后加微钩子收口。
例 · 三少爷("盐津可以来装不?")
"你好 三少,盐津能做,宜宾周边县都送装。这套样板房××多层实木原价9.8万、特价6.9万,全城限1套。你家多大户型?我发方案加个微信?"
分支 E · 询价但品类不明先确认,别假设
先问清这个价是什么品类再接话,不要替客户假设成自家品类。反例:忧郁的入把"668 系统窗"当成全屋定制报了价,被当面纠正——这条已在改 prompt。
应该怎么回
"这 668 是说窗户还是柜体呀?你这边主要想做哪块,我按这个给你算。"
分支 G · 反向评论(公开回评,非私信)同一套三要素
不私信、直接在评论区公开回复时,同样按三要素写:评论里点名复述对方的话(师出有名)+ 带价格四元素 + 引导私信/加微的钩子。与 DM 共用同一套模板,只是落地渠道是公开评论。
例 · 公开回评
"@双双 你问的146平老房,这套××多层实木样板房原价12.8万、特价8.9万全城限1套,私信发你整套方案~"
分支 F · 纯互动 / 无关(share + off_topic)不触达 · 丢弃
"[赞]"、纯表情、广告、同行、与全屋定制无关的内容 → 不进对话池,直接丢弃,不浪费触达额度。

第三步 · 客户回了之后,按阶段推进(对话阶段机)

每段对话有"阶段",决定 LLM 用哪套系统提示、目标是什么。目前三条案例都停在第一阶段 ice_break——破冰发出、客户回了、还没推进到稳定加微。

破冰 ice_break

目标:让客户回第一句。师出有名 + 价格四元素 + 加微钩子(强钩),三要素齐发。当前三案都在这。

培育 nurture

目标:建立专业信任、问清户型预算。多轮来回给价值(避坑清单/方案预览),三要素仍在,但加微钩子转轻钩不逼。

决策 decision

目标:引导加微 / 留方案 / 转人工。加微钩子升为强钩:给微信号 + 处理加微 friction(验证/备用号)。

加微钩子不再只在 decision 阶段出现——每个阶段每条都带钩子,只是按 stage 调强弱(破冰强 → 培育轻 → 决策强)。

SECTION 04

Badcase · 分类 · 根因 · 优化方式 · 进展

从三条真实案例 + 全量跑里归出的问题,按 A–F 六类。C(品类误判)/ D(报价门槛)/ E(加微节奏)已被「全链路三要素」模板(SECTION 05)直接覆盖;A(回写)和 F(排队)是工程问题、在修;B(账号信任)设计中。

类别表现 / 根因优化方式进展
A数据回写 只存了 opener,客户回复 + 跟进 DM 没写回 DB。导致:统计失真(回复=0)、4h 后 claim 过期被他人重复 claim 重发。三条案例全中。 发完每条 DM 立即 mark-contacted;客户回复入库;补 check-replies 抓全 inbox。 待修 · 最高优
B账号信任 messaging 账号(零星/野荞)主页没粉丝/简介/作品,客户点进来看不到背书;忧郁的入还当面点破"你在云南我在江西"。 抓并展示账号主页资产;同城/跨省话术分支;号源与 IP 对齐策略。 设计中
C内容·品类误判 忧郁的入把"668 系统窗"误判成全屋定制(自家 568 品类),先入为主报了价。纠正得当但暴露"不确认就假设"。 破冰前先确认品类/需求,不替客户假设;价格四元素绑定具体品牌配置字段,词对得上,减少"668 系统窗"式先入为主。 三要素覆盖
D价格门槛 报价 100% 延后到加微(吕途"怎么收费"、忧郁询价都被挡)。早期保护合理,但全卡可能劝退。 破冰即带产品优势=价格四元素(原价/样板房价是固定锚、不外推),报价不再全卡到加微后,门槛直接缓解。 三要素覆盖
E加微节奏 三少爷单轮回复后就急推加微,可能显得功利、转化反而低。 加微钩子每条标配但按 stage 分强弱(破冰强→培育轻→决策强),不再单轮急推显得功利。 三要素覆盖
F时效排队 采集→发送还有 1.6h 均值排队(忧郁的入 4h41m),新鲜度被稀释。 高意向优先队列;缩短 claim→发送间隔;高峰自动提速。 可优化
SECTION 05

后续待做 · 需求清单

和业务共创出的下一步需求。前 4 段(案例话术 / 原理图回复分支 / Badcase 进展)已按这条需求落地后的状态改写,这里给出需求本身的定义。

  • P0
    全链路三要素(含反向评论)
    对话的整个链路——无论是 DM 破冰、后续跟进,还是反向评论(公开回评)——每一条触达都要同时包含下面三大要素,作为"破冰 / 跟进 / 反评"的统一模板,缺项打标重写:
    ① 师出有名:提及之前的具体评论内容 / 视频细节,给出"为什么来找你"的由头,不做无名氏私信。
    ② 产品优势(价格四大要素):带出 品牌配置 + 原价 + 样板房价 + 样板房(唯一一套)活动,四者缺一不可(与价格逻辑页同一套四元素)。
    ③ 加联系方式的钩子:每条都要有引导加微的钩子(给微信号 / 要微信号 / 约方案),不止停在开放反问。
