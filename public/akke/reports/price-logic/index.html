4Bad Case 分类 · 根因 · 优化方式 · 进展

Bad Case根因优化方式进展
三档总价外推偏离公式森鹿案例：标配 3.4 万对、但高配/豪配被抬到 4.1/4.8 万（公式应为 3.7/4.1），模型自行外推报价话术直接套知识库公式取三档数；price-guard 从「只比范围」升级到「按公式校验每档」待修
报价口径错位（答非所问）阳光明媚：客户说「简装」，破冰报的是「标配」，词对不上价格意图分类增加预算档位词识别（简装/精装/豪装 → 映射 标配/高配/豪配）待优化
信息不足硬报全屋总价豆豆：客户只问「一屋子多少钱」没给面积，破冰用「5 万起步」兜底，锚点可能偏高缺面积时走「先反问面积、后报价」分支；或保留「起步」软锚但配低门槛钩子部分（已用「起步」）
活动优惠钩子空泛「再让一档/再压一档」没有具体促销、名额、截止，说服力弱接 active SKU 数据，需求 #19 的 4 段铺垫报价（促销价/名额/截止）上线部分（模板就绪·数据待供）
报价了但 0 回复（共性）2132 条价格招呼仅 0.2% 回——报完价对话就断了，缺少让对方「必须回一句」的钩子降低单条信息密度、报价后补低门槛 CTA；锚点形态待 A/B 验证待优化
落地后 · 四元素这五条 Bad Case 大半被四元素模型直接覆盖：
  • 三档外推偏离 → 改用固定原价/样板房价取数，根除模型外推。
  • 口径错位答非所问 → 品牌配置字段强制带出，词对得上。
  • 信息不足硬报总价 → 样板房价是固定锚，先抛样板房特价再反问面积，不依赖面积。
  • 活动钩子空泛 → 「样板房唯一一套」就是具体稀缺钩子，替代空泛「再让一档」。
  • 报价 0 回复 → 「限 1 套名额」制造紧迫，逼对方回一句「还有吗」。

5后续完善的办法 · 全库问价评论分成 8 类，每类一套细分策略

把全库 31,640 条评论过一遍问价词，命中 2,976 条真问价（9.4%），按真实问法单条归一类。 把这 8 类真问法对回现有 5 分支（A1–A4 + H），缺口就出来了：现有分支按「我们想怎么报」拆，而客户其实按「他怎么问」来——两者对不齐的地方，就是下一步要补的细分策略。

1523 条		 「多少钱」「什么价」「多钱啦」——零面积零品类 默认走 A1
直接甩三档		 一句锚 + 即反问：先给一个最低锚（「全屋 284 一平，标配 3 万起」），紧接反问面积 / 先动哪组柜，把对话接住，而不是甩完三档就断。这类占一半，是回复率地板的主因。

🔧 两个结构性缺口（下一步重点）：
缺口①　占一半的「极简零上下文问价」（51.2%）现在被直接甩三档总价 → 客户没头没尾收到一堆数字就断了。应统一改成「一句锚 + 反问面积/品类」承接——这一类直接决定整体回复率。
缺口②　「比价/价值异议」（4.0%）没有专门分支，现在落到 A1 硬报价、答非所问。需新增 B 价值锚定分支，把「贵不贵 / 品牌对比」从报价问题改成价值问题来接。
落地后 · 四元素8 类细分策略的「锚」统一换成四元素样板房锚：
  • 极简纯口语（51%）：一句锚 = 样板房特价锚（原价 X → 样板房价 Y · 限 1 套）+ 反问面积，替代甩三档。
  • 带面积/户型：直接取该面积档的原价/样板房价（固定取数），严禁外推。
  • 单组柜/单品：单组锚后引导「样板房全屋限一套更划算」转全屋线索。
  • 比价/价值异议：B 价值锚定叠原价对比，用样板房让利凸显价值，不比低价。
  • 其余类（单价 / 计价方式 / 硬装 / 预算先行）同理把锚换成四元素；硬装类仍不报数字。
