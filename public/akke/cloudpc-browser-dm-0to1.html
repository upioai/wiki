4 下一步待做的优化列表

NOW · 10min 唯一钥匙
  • S1 采集提频：把高意向 lead 的号源提到热门 tier + scrape-hot 覆盖，把「评论→抓取」从 14–45min 砍到 ~2min。这是 10min SLA 唯一杠杆，光调派单到不了。
  • 验证：砍 S1 后，时来运转那类「派+发 7.7min」的单就能压进 10min。
NEXT · 稳健性
  • agent 空闲心跳：让 agent 每轮写时间戳，监控能区分「空闲活着」vs「死了」（现在空闲=没单可抢，心跳指标会假❌）。
  • dm_panel_failed 无人值守成功率观察 + 必要时加 GUI 重试。
  • 镜像清理：把 bootstrap 自启的旧 agent 从镜像里清掉/改成 web 配置，避免新克隆机再踩「双 agent 抢窗口」。
LATER
  • fresh_window 调优：观察 15min 窗口的发送量 vs SLA 平衡（窗口太紧=空转，太松=超时）。
  • 7911 验真：GUI 测不到静默限频，靠回复率/对方已读侧证。
  • commit + 镜像固化 web 脚本 + poll agent 改动。
两条红线： ①「气泡发出」≠ 送达（7911 静默丢弃本地仍有气泡，真量以人工核对私信列表为准）。 ② 同物理号「有大有小」别同时跑 engagement（反评）与 DM，无共享 1h 活跃门，叠加高频触发风控。
