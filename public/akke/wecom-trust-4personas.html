林静标准·中△ 卡临门 · 25→75
T1
客户我预算就3万，110平全屋柜子能做下来吗
蓝方110平投影55平，568下来三万一，3万稍紧。卡死3万可换千年花488，也是ENF级，能省两千多。您看介不介意呀？🖼 checklist
A 25
报了 568/488 两个价，感觉后面还有操作空间，怕是套路。
✕ 口径不稳：一上来甩两个价（568 又蹦 488），价格敏感客户立刻觉得"有水分"。改：先一个口径说清——"110 平投影 55 平 × 568，柜体全包约三万一，写进合同不临时加"，别急着抛第二个价。
T2
客户两万九只是基础价吧？后面五金抽屉加起来肯定不止，怕你们低价切入后面全是增项。
蓝方您顾虑得对，基础价已含柜门柜体五金和抽屉，每3平送1个。增项明码标价：玻璃门280、灯带80…都写进合同，没写的绝不临时加。让设计师给您拉个带增项的明细单。
A 45+20
增项列明白、还说写进合同，这点不错。
✓ 做对：正面接住"怕增项"、逐项报死 + 写进合同，精准踩中她"认白纸黑字"的信任点。
T3–T5
客户明细单先发我看看…（后续）武汉的，先拿到带数量清单核对上再谈定金…量尺是要先交钱还是下定金？
蓝方488全包价…明细单得按户型才准，让设计师按三室两厅拉带数量清单发您、写进合同…量尺免费但先交定金确认意向、算总价里…武汉服务点能上门量尺。
A 58→68→66爬升
增项报死 + 写进合同 + 量尺费用诚实交底，信任一路涨。
✓ 做对：量尺费用诚实说"先交定金、算总价"（守住企微禁"量尺免费"红线）、顺序也让步给她"先清单后定金"。
T6
客户没看清单就先交定金？顺序不对。先把带数量的清单发我。
蓝方好嘞不催了，我这就让设计师按110平三室两厅拉份带增项清单发咱们企微里，您核完踏实咱再定金量尺。
A 75+9
终于把顺序摆对了、认我的规矩，就等清单真发到手。
✕ 空头支票（P0 天花板）：答应"拉份清单发企微里"，但 AI 根本发不出按户型定制的明细单（只能文字+固定海报）→ 林静永远卡在"等清单"。改：别承诺"发清单"，改"清单我让设计师整好，您到店/线上会议我当面把每一项跟您过一遍"，把她引到有真人能发文件的场景。

给公式还问面积、又问要不要明细，挤牙膏。
✕ 挤牙膏：爽快客户明说"就报个数我方便比"，蓝方却给公式/问面积/问要不要明细，把人磨在 25 分。改：识别"就报个数"=爽快高意向，直接给区间价（像 T4 那样），别绕。

✓ 做对：一口价三档直出、不挤牙膏——一句话把爽快客户从 25 拉过他 50 的接受线。
T5

A 53−2
我都说"有数了"你也没招呼我过去，就让我自己比——那我去比了。
✕ 收网时刻放人走（P1）：王磊 A=55 已过线、"行有数了"=教科书级收网信号，蓝方却回"您先比着看"把主动权交出去 → 最好成交的客户流失。改：收网信号必须当场约到店——"那您哪天过来店里，我给您留个样板间的位、当面把三档配置过一遍，您看着定"。

五条硬结论

四轮跑出来的东西

P0

产品天花板：poster 库是固定死图，接不住"要定制文件"的高意向客户

林静 + 陈教授双证：最高意向的两类都要「具体定制/参数文件」（林静要按户型定制明细单、陈教授要板材力学参数报告），但蓝方只能按触发词甩固定营销海报，custom 文件发不出、"让设计师/技术部发原件"是空头支票 → 直接卡死。最该修。

P1

advance 不会按客户类型调策略

王磊（高意向收网时没约到店、回"您先比着看"放人走）和小周（早期观望没切软邀约、走通用流程）两个方向都错。蓝方是"一套通用 nurture"，不识别客户类型。修：高意向收网信号 → 当场约到店；早期观望 → 软邀约看样板。

P2

开场答非所问是四人通病

林静/王磊/陈教授/小周四个开场蓝方全都先"问城市"而非正面接住开场问题——陈教授开场问"和欧派的区别"被反问城市，直接判 A=20。catch/advance 维的系统性毛病。

✓

红线守得意外地好

陈教授那轮不评竞品（"欧派听说过不太熟、不好乱评价"）+ 不瞎编力学数据（"这些数值我不给您现编"）。这是既有弱点 top4 里的两条，这次守住了 —— 说明 prompt 在这块 work。

图

图片双向都弱

蓝方实发的都是固定海报、触发词还常错位： checklist:general 通用配置清单 env-test-price 环保价格 ← 陈教授要力学参数、发来环保图 layout:3room 3室模板 ← 蓝方说"按你户型画的"其实是套模板 另外红方 VL 也漏读图（林静/陈教授的清单海报红方压根没读到）。红蓝双方读图都弱。

修法优先级

照着改什么

P0

补"发定制文件"能力 或 话术统一转真人

要么给系统加"发户型清单图/板材检测报告"能力，要么话术统一转"资料我让设计师整好、您到店/线上会议当面过"——把要文件的高意向客户引到有真人能发文件的场景。直接卡死最高意向的两类，收益最大。

P1

advance 按客户类型分策略

识别到"行有数了/我方便比"这类收网信号 → 当场抛到店钩子（治王磊）；识别到"还没交房/先看看"早期信号 → 切软邀约"先来逛逛看样板"（治小周）。

P2

开场别先问城市、先正面接住

客户开场的具体问题（对比/价格/工期）第一句必须正面接住，再顺势问城市/户型。治四人通病。
