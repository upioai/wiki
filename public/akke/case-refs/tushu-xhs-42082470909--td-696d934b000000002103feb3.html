一张「出版预告」汇总表：书还没出，评论里已经有 8 个人在等

结论

这一条卖的不是书，是「消息」。五张图里没有一张是作者自己拍的实物，正文是一份按出版社分组的书讯清单。评论区的购买意向全部指向「还没上市的书」：「王小波啥时候上」「请问湖南文艺的这几本已经出版了吗」「请问盖茨比的口袋书什么时候出呀」，作者回的是「还没还没 只是预告」「据说是过年后了」「@新经典 这要问新经典了」。所以这 8 条意向是真实的需求，但当下买不到——没有商品可挂，作者也没在这条下面放任何购买入口。

它为什么带来想买的人：口袋书 / 文库本是一个小而集中的兴趣圈，读者想知道「接下来有什么可买」，却要自己去十几个出版社账号里翻。作者把散落各处的预告收成一张清单，帮他们省了这件事；结尾一句「欢迎补充...」又把评论区变成补充书单的地方（作者自己补了「无界文库第三辑第五辑，未读第一本系列第二辑」）。藏赞比 44%——被当成工具帖收藏。

按案例口径要复核。入库判出「本行业主营内容、随身携带的使用场景」6 分，类型按行业默认推定「用户使用」。但这条既没有交易（书还没出），画面也不是自家的东西（全是出版社物料），更接近「行业资讯转述」——G3 那一关过不去。它能算作账号的获客内容，算不上一条案例。

可复制的结构

  • 「年度 / 月度书讯」这个栏目本身：同号的意向前三里两条是书讯（本条和「口袋书讯12月版」），固定栏目让人等着看
  • 按出版社分组的清单正文：读者能对着找自己关心的那家，评论也会按出版社追问
  • 结尾邀请补充，作者在评论区逐条回出版时间——回复本身就是第二份书讯
  • 首图只放大字不放书：同号三条首图里两条是纯文字卡，在一个封面全是书的品类里反而显眼

不可复制的运气

  • 「王小波文库本」这个具体消息：评论里最集中的追问就是它（「终于有王小波的文库本了」「王小波啥时候上」），是出版社给的料，不是作者做的
  • 发布在年初，正是「今年会出什么」最有人搜的时间点
  • 口袋书正处在上升期（热评「其实已经火了一段时间」），换一个品类同样的清单不一定有人收藏

商业环节

这一条没有商业环节。笔记没挂商品，作者在评论里没放链接、没导私信，回的全是出版时间。它的商业价值在后面：同号的另两条（「口袋书讯12月版」「译林也出口袋书啦」）作者在评论区放了商品（置顶评论和回复里只留下商品名文字，见那两份拆解）。预告帖攒下的是「等着买」的人，书上市那期再接住。

账号是谁要复核。这是一个口袋书博主（简介与昵称「口袋书猎人」），不是书店。它卖书的方式疑似是笔记评论里的商品卡带货。按 G2「必须是目标商家类型本身，不是测评号」，这个号要人看一眼再定。

这一篇的特殊处理

  • 素材不是拍的，是收的。流水线表第一行「现场照片」换成「从出版社公众号 / 小红书 / 微博收预告图」，每篇约 30–60 分钟，是这类帖子人工的大头；可以让 Claude 每周扫一遍出版社账号出候选清单（估 ¥0.5 / 周）
  • 版权与准确性要人把关：图是出版社的，消息也是出版社的。转载官方宣传图一般没人追究，但出版时间要标「预告」，错了评论区会立刻纠正
  • 首图模板化：同一张水纹底、换年份 / 月份即可，比实拍封面省事
  • 长表截图（图 3）在手机上看不清，等于浪费一张图位，可以换成作者自己整理的大字清单

方法

素材：小红书笔记接口（点赞 / 收藏 / 评论 / 分享、配文）、5 张原图与缩略拼图、页面文字（含作者回复）。购买意向来自账号页评论判定（Haiku 初筛 + Sonnet 复判）：平台显示 52 条评论，抓到 26 条，判出 8 条。点赞中位数取该号判出的 43 条案例。小红书拿不到阅读量。
