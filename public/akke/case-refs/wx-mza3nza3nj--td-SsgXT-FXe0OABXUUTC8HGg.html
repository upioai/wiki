五个房东、五个「之」字，结尾是官方订房指南

阿那亚订阅号 2026-10-08 发的「好民宿」第二期：编辑走访五间由一线民宿团队和创始人马寅筛选出的民宿，每间一个章节卡（半日浮生｜留白之美、阳阳亮亮的小院｜打磨之久、澜舍｜更新之好、山楂小院｜相遇之暖、木枫院｜维护之频），写房东怎么在一次次入住里把房子改好。全文约 8,200 字、35 张实拍，文末是「阿那亚民宿预订指南」：只推小程序和 APP 两个官方渠道，再征集读者推荐和房东自荐。这是这个号入库的唯一一篇，所以既是第 1 条，也是全部。

结论

这是一篇写给两拨人看的平台内容：对住客，它在卖「阿那亚的民宿有人用心经营」；对业主，它在示范「好房东是什么样」。编者按把目的说得很直白：「希望这些具体而真实的经营经验，能够为更多阿那亚民宿经营者带来一些启发」，文末又写「如果你是一位用心经营的房东，也欢迎自荐」。阿那亚在这里的身份是社区开发运营方和订房平台，房子是业主的，经营也是业主的；它交付的是官方订房平台上的房源和社区本身。

作为案例，它的强项是每一间都有「客人反馈 → 房东改」的具体事件：一层返潮加除湿、枕头加到 16 个、客人要全黑加百叶帘、三个卧室陆续换遮光帘、一位客人退房前花一晚擦大理石地面。这些都是真实入住留下的痕迹，比一句「口碑好」可信得多。弱项是没有价格、没有房型、没有某一位客人的完整入住，五间房只写了名字，读者想订要自己去小程序里搜。

两处待复核：类型按社区行业默认推定成「用户使用案例」，但五个章节的主角都是房东、写的是经营和改造，更像「商家经营日志」或「交付结果」；G2 / G3，阿那亚是平台不是房东，算不算「自家交付」要人定——房源走它的官方渠道预订，偏向算；内容是在讲业主的经营，又偏向「转述他人」。

图文怎么穿插。35 张正文实拍，约 235 字一张，比 DNCN 的住客长文密得多，而且照片几乎全是空的房间：没有人、没有房东、没有客人。图注一张也没有，照片只负责「好看」，故事全靠文字。每间之间用一张彩色章节卡隔开（数字 + 小房子 + 「民宿名｜x 之 y」+ 副标题），五个「之」字（留白、打磨、更新、相遇、维护）就是五种「怎么越来越好」的答案，读者扫章节卡就能看懂全文框架。署名页写「图片：在野照物所 / 各民宿受访者提供」，即一部分是专业摄影、一部分房东自己给，读的时候能看出两种风格（第一、三间偏杂志感，第二间偏明亮的家居照）。

可复制的结构

  • 一篇写五家，用章节卡隔开。每家一个「x 之 y」主题词，平台型商家可以照搬：一期一个问题，五位经营者各答一种
  • 每家都有一个「客人反馈 → 改了」的事件。返潮、枕头高度、全黑睡眠、儿童楼梯，这是证明「真实经营」最省字的写法
  • 每家都有一个住客小故事。擦地、收瓶罐留言、小姑娘住两次；放在章节后半，作为改造的回报
  • 房东的身份标签做开头。心理咨询师、理工科、清华校友、新手妈妈，一句话让读者记住这是谁的房子
  • 文末把订房写成教程。只给官方渠道 + 理由（价格规范、核销安全）+ 三步操作，适合有大量第三方中介的平台
  • 结尾征集自荐。把内容生产也变成运营：下一期的房东从读者里来

不可复制的运气

  • 阿那亚这个品牌。标题不需要钩子，读者本来就关注，孤独图书馆一张航拍就够了
  • 房东的故事都现成。五位都经营了三到八年，改造和住客故事是时间攒出来的，新开的民宿写不出来
  • 专业摄影和设计团队。在野照物所拍房、feelfew studio 做视觉、外包公司承办公众号，一个小商家没有这套配置
  • 创始人背书。「由一线民宿团队与创始人马寅共同筛选」，这句话的分量来自马寅本人
  • 阅读和订房数未知。公开页面拿不到阅读、留言，也没有单间的订房数据，这篇到底带来多少订单无从判断

商业环节

  • 卖的是什么：阿那亚民宿官方预订平台上的房源（小程序「阿那亚民宿官方预订平台」和阿那亚 APP）。正文五间房都给了名字，没给价格、房型、可住人数，也没给单间的直达链接。
  • 为什么只推官方渠道：第 106 段「官方平台房源齐全、价格规范、信息透明，无论是房态确认还是订单核销都更安全、有保障」，说明站外渠道（中介、OTA、私下转租）是它在抢的流量。
  • 文末的其他入口：APP 预订酒店赠专享入住礼、阿那亚文创商城、2026 全年活动、北岸 / 南区配套，以及置业热线 400-810-9988 和度假热线 400-115-5500。一篇民宿文同时挂着卖房的热线，说明读者里有潜在业主。
  • 供给侧的招募：编者按「为更多阿那亚民宿经营者带来一些启发」+ 结尾「如果你是一位用心经营的房东，也欢迎自荐」。对阿那亚来说，房东愿不愿意把房子放进官方平台、愿不愿意认真经营，和住客订不订同样重要。
  • 入住礼：五间都写到给客人准备礼物或备品（入住礼、云南茶叶和清华笔袋、玩沙工具和冲奶粉的水、整套儿童用品、应季小礼物），这是唯一接近「交付内容」的具体描述。

AI 制作流水线（图文）：选型、耗时与成本

图文和视频的做法完全不同：没有剪辑，成本在拍对照片、选图排序、写稿三处。目标同样是做成一个能自动跑的 skill，人只在三个检查点介入：审图序、改稿、发布。

测算口径：一篇图文（小红书 6–18 张图 + 300 字以内配文；订阅号 1500–9000 字、20–50 张图）。机器 是工具自己跑的时间；人工 是人操作或审核的时间，按 55 元/小时折算。单价为 2026-10 公开价（Sonnet 5.5 每百万 token 输入 $2 / 输出 $10，图片约 宽×高/750 token），这张表还没有一条实测，全部是「估」，跑过第一篇后回来改。

这一篇的特殊处理

  • 一篇是五次采访。流水线里「配文 / 正文」那一行要换成采访 × 5 → 转写 → 成稿：每位房东录音约一小时，Paraformer 转写约 ¥0.3 / 人，Claude 按「身份 → 买房起因 → 改造 → 客人反馈 → 住客故事 → 一句话」的固定提纲出每间初稿，再统一口吻、拟五个「x 之 y」主题词。人工估 8–12 小时（五次采访 5 小时 + 改稿），比单人访谈多一倍以上。
  • 摄影是外包的。「素材：现场照片」那一行用手机实拍做不出这个质感；要么按每间半天请摄影师（成本不在算力里，按当地行情另算），要么像这篇一样部分用房东自己的图，接受风格不统一。
  • 章节卡要做模板。五张卡同一个版式只换颜色和文字，适合一次设计、之后每期脚本替换文字出图，不用每期找设计。
  • 文末是固定模板。预订指南、署名、信箱、活动和配套横幅、热线，每期照抄；只要在发布前确认小程序码和热线还有效。
  • 事实核对。年份（2015、2016、2018、2019、2023）、「16 个枕头」「四套沙发套」这类数字，以及房东的职业和学校，发布前要逐条给房东过目。
  • 选房要过两道关。一是住客反馈和改造事件得是真的、能讲具体；二是房源必须在官方平台上能订，不然文末的预订指南接不住。
