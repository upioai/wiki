反面例子

查过，但不作为样板

这 6 个号都认真扫过全部作品，最后没有收录。把它们摆出来是因为——说清楚什么不算案例，比说什么算案例更有用。而且它们正好分成两类，这个分界是这套方法里最该讲清楚的一件事。

一、规则自己拦下来的

命中率算出来就很低。低本身就是结论——说明这个号的内容大部分不是在展示自家做出来的活。

账号与判定结果它说明了什么
左左讲招募【10月公会管理课+招募课】
品类 主播招募扫描 404 条判为案例 0 条命中率 99% → 0%拦下它的信号 培训课程 / 方法论，404 条（100%）

整号是讲给同行公会听的课——「公会人事主播拉新发什么内容」「公会经纪人如何提高入驻率」。讲服务流程、讲方法论，但从头到尾没有一个真实消费用户。主播招募属于服务结果型行业，案例必须是某一个具体主播的成长与结果。

服务型行业最容易混进来的就是培训课。它看起来很专业，但它卖的是方法，不是交付。
这个设计有点贵
品类 设计扫描 194 条判为案例 1 条命中率 1% → 1%拦下它的信号 转述他人作品，128 条（66%）

整号在转述别人的设计——「设计师：X」「抄作业」「get 到一个新思路」。内容质量很高，但画面里没有一件是自家做出来的活。

转述他人作品是最强的排除信号。别人的好作品替别人背书，不替你背书。
阿伟茶业·艾妃清舍舒雅
品类 茶叶扫描 139 条判为案例 0 条命中率 67% → 0%拦下它的信号 缺案例依据，127 条（91%）

店面生活片段、上游进货场景、摆拍引流，没有一条指向真实交易。茶叶属于商品交易型行业，画面里是商品不是交付物——一罐茶谁都能拍，必须另有发货、复购、评价、订制这类交易证据。第二轮抽的 3 条人工全判否。

「在店里」不等于「在交付」。进货是向上游买东西，和客户没有关系。
小志考研（上岸版）
品类 考公考研扫描 30 条判为案例 3 条命中率 73% → 10%拦下它的信号 缺案例依据，18 条（60%）

内容多是刷题技巧与备考方法，真正指向某个学员结果的只有 3 条，样本太小不足以作为样板。

讲题技巧不是案例。考公考研的案例是学员的结果：上岸、提分、录取。

二、规则拦不住，只能靠人看的

这两个号的内容完全真实，规则也确实判出了案例，判得并没有错。错在账号性质：主角是用户本人，而内容里看不到任何商业方——没提机构、课程、品牌或所购买的服务。没有商业方，它就只是一份个人记录，不能作为「商户如何用案例内容获客」的样板。这类问题正则一条都抓不到，必须收号时人工过一遍。
