00

一分钟看懂这是个什么东西

前几家都在解决同一个问题：怎么把机器伪装成人。尘锋直接绕过了这个问题——它是企业微信官方服务商，SCRM 以侧边栏形态嵌在企微客户端里；抖音那侧走蓝V企业号官方授权。所以它不需要被控设备、不需要常开电脑、封号风险接近零。代价是能力边界由平台划死：它自认拿不到抖音评论区。

本次拆解最重要的三条

  1. 它的 AI 平台叫 ChatDoing 开言万境，抖音走官方蓝V授权。渠道管理页有「+ 授权蓝V企业号」按钮，表头是 账号 / 企业号类型 / 接待状态 / 授权状态 / 授权到期时间。这与它自认的「无法通过抖音评论区私信获客」逻辑自洽——官方通道只给你「别人主动私信你」的会话。
  2. 同一屏上挂着一条对所有人都重要的平台公告：「抖音平台将逐步对私信中留资的手机号及固定电话进行加密处理，未重新授权的账号将无法查看客户联系方式」。这不是尘锋的问题，是平台在收口——直接影响我们主仓那条「评论 → 私信 → 要微信」的管线。
  3. 它的「潜客促到店 SOP」是九家里对家装做得最深的一套，而且分层条件里赫然有一条「未浏览任何素材」——正是我们缺的那一环（海报与量房券发出去之后没有回执）。
01

六段收口

按 08-14 机制页的固定六段填。①–③ 会显得很短，不是材料不够，而是这些问题对它不成立——这件事本身就是最重要的结论。

①

用什么设备

口径不依赖任何被控设备，移动端和电脑端都可以使用。

实证实际形态是三层：企业微信客户端里的侧边栏（服务总结 / 客户资料 / 内容中心 / 我的名片）+ 浏览器里的 SCRM Web 后台（*.qw-scrm-tx.dustess.com）+ AI 员工平台 ChatDoing 开言万境（ai.chatdoing.com）。

②

怎么控制 / 运行

实证它不「控制」任何东西——企业微信官方服务商，读写的是企微官方给的数据。

实证抖音走蓝V企业号官方授权（有授权状态与授权到期时间）。0.9

实证可接渠道：抖音 · 微信客服 · 官网在线咨询 · 小红书 · 快手 · 微信公众号 · 微信小程序 · 自定义渠道 · 第三方平台。

口径能力边界（自认）：无法通过抖音评论区私信获客。0.85

③

是否依赖电脑 / 插件 / 脚本

依赖企业微信：是——这是它的地基。甲方不用企微，这套就没了一半。

依赖抖音蓝V企业号：是，且有授权到期时间，要续。

依赖被控设备 / 刷机 / 脚本 / 插件：全都不依赖。电脑要不要常开：不用——服务端跑，这是它和前几家最省心的差别。

④

实际操作流程

在尘锋平台输入企业信息 → AI 助理抛出 7~8 个确认题逐个填（线索留下后怎么处理 · 开场白怎么说 · 说话风格 · 要不要开转人工 / 拟人化回复 / 拆句发送）→ 生成方案 → 训练对话 → 接入抖音 / 小红书账号 → 上线接待（可全托管，也可人机协作）→ 客户留资自动进 CRM 分配跟进 → 自动加企微好友 + 派员工打电话。

⑤

发送时间机制

九家里对家装最具体的一套：潜客按行为分三层，各挂 Day1 / Day3 / Day7 的内容序列。详见 第 04 节。

⑥

实测数据

营销评分 10；客户旅程时间线颗粒度到「访问文章 25 秒」；演示环境联系人 79（待跟进 54 / 跟进中 12）；已授权抖音号 0；AI 上下文「能很多轮」，现场演示看到七八轮。价格见 第 05 节。

02

官方通道长什么样：这是我们第一次看清

这一节的价值不止于尘锋本身——它给了我们一把验证其他家「我们是官方合作」说法的尺子。

03

平台在收口：抖音要给私信里的手机号加密

原文（渠道管理页顶部橙色公告）

  • 「重要：抖音平台将逐步对私信中留资的手机号及固定电话进行加密处理，未重新授权的账号将无法查看客户联系方式。请将 8月5日前授权的所有账号点击"授权蓝V账号"重新授权。」0.9

含义有两层，而且都指向我们：

层说明对我们的影响
① 路径本身在被掐靠「私信里让客户报手机号」这条路，抖音正在系统性收口直接影响主仓那条「评论 → 私信 → 要微信」的管线。要开始准备替代口子（表单、留资组件、引导到企微）
② 官方与非官方分岔走官方授权的还能重新授权拿回来；不走官方通道的连重新授权这个选项都没有这会拉大「官方派」与「伪装派」的能力差距。值得单独跟进抖音开放平台的变更

零假设：如果这只是尘锋的界面话术，其他家的抖音接入页不该出现同类公告，抖音开放平台也不该有对应变更记录。

可证伪方式（成本极低）：下次问任一家「抖音最近对私信留资加密这事你们怎么应对」——答不上来的，说明它压根不在官方通道里。这一问顺便验证了今立那句「我们是抖音官方合作商」。

04

潜客促到店 SOP：九家里对家装做得最深的一套

这一节最扎人——我在 08-14 机制页里建议我们做的事，尘锋已经做成产品了。

潜客类型设定条件激活策略（内容序列）
沉默客户跟进状态【邀约中】+ 14 天内无企微会话、未浏览任何素材、未接听电话 + 意向风格标签（广告表单信息）Day1 装修避坑指南

Day7 发送抽奖活动

两条我们该直接拿走的东西

  • 「素材有没有被打开」是可配置的分层条件。它区分沉默/活跃用三个信号：有没有企微会话 · 有没有浏览素材 · 有没有接听电话。中间那条正是我们缺的——我们的知识海报和量房券发出去之后没有回执。它把这三个信号 + 意向风格标签组合成进入条件，再挂 Day 级内容序列，是完整的一条产品化链路。
  • 业务节点定义值得校准我们的目标。它的原话是「做获客（争取首次到店）+ 首次到店客户的维护（争取二次到店，二次到店或者测量，才是付定金的关键节点）」。我们的「免费上门量房券」正好卡在这个节点上——方向是对的，但我们没有把「到店 / 量房」做成一个可跟踪的阶段字段。

零假设：如果这条不成立，我们的跟进池里应该已经有「是否到店 / 是否量房」这类状态，且海报与券的打开行为已经回流。可证伪方式：查 recall-poster / recall-coupon 两屏产出的到底是纯图片还是可追踪链接——如果是纯图，这条要先改成带链接才谈得上回收信号。

06

对我们意味着什么

一句话定位：它和我们是拼图关系，不是替代关系

  • 尘锋没有线索来源（拿不到公域评论区，只能接住主动私信进来的人），但它有 CRM 与客户旅程。
  • 我们有线索来源（公域语义打分 + 持续管道），但没有过程管理。
  • 两边很可能在同一个甲方那里共存。所以对尘锋不必打，要想清楚的是边界怎么划、数据怎么对接——它的智能体配置里第一个问题就是「线索要不要同步到外部系统，需要你们提供接口」。
维度尘锋我们判断
公域获客不能（自认）能（LLM 语义打分 + 持续管道）我们的护城河
封号风险接近零（官方通道）风险在甲方账号上它领先，而且这是结构性的
设备占用零，电脑都不用常开云电脑常驻它更轻
私域通道企业微信企业微信九家里唯一和我们同通道的，所以对接成本最低
跟进 SOPDay1/3/7 家装内容序列 + 行为分层单次生成，无节奏、无行为回执它领先，而且是可抄的
知识资产训练台 + 三开关，甲方看不到也改不了那份知识企业大脑 12 屏，含说法冲突 / 版本与发布我们领先——它把知识做成了供应商保管的黑箱
07

【08-15 补】通读 60 页《家装家居行业解决方案》后的五条新发现

此前只用了这份 PDF 里的一张 SOP 图。通读之后发现：它对家装的理解比我原先判断的还要深一层——不是「获客 + 到店维护」两段，而是完整的五个场景，而且每一段都有对应的产品动作。

五条新发现

  1. 业务框架是五场景，不是两段：获客 → 邀约到店 → 到店转化 → 交付 → 增长运营（老带新）。我们目前的四板块只覆盖了前两段半。
  2. 它和腾讯广告有家装行业专项数据合作——广告线索自动分配与深度回传，用于反向优化投放人群。
  3. 抖音侧有官方小程序组件：直播间与短视频挂「智能报价」小程序，这是我在第 02 节说的「官方通道才有的玩法」的具体形态。
  4. 「老带新」被做成了一整套长期机制，含积分奖励、分周期触发、积分兑换商城——这一块九家里只有它有产品化设计。
  5. 它与家装垂直系统（如设计软件）做了数据打通，设计方案与报价单能回流到客户档案。
场景它的产品动作我们现在
一、获客广告线索自动分配与回传 · 腾讯广告深度合作 · 抖音留资自动分配 · 抖音小程序智能报价 · AI 私信攀谈询问电话 · 多渠道分析公域评论语义打分 + 私信触达（它拿不到评论区，我们拿得到）
二、邀约到店电话配合微信邀约 · 侧边栏辅助沟通 · 装修案例库 · 智能名片 · 预约单降低失约率 · 邀约全程记录避免私单 · 潜客促到店 SOP基本空白——我们没有「邀约到店」这个阶段概念
三、到店转化离店客户当日回访 · 潜客按交房时间分类跟进 · 朋友圈内容营销 · 可配 SOP 流程 · 数据日报周报自动推送沉默客户跟进（有池子有排序，但没有"到店"这个状态）
四、交付专属服务群（销售+设计师+项目经理+客户）· 工单流程 · 共享项目进展零
五、增长运营老带新长期机制：服务回访卡 + 积分奖励 + 分周期触发 + 积分兑换商城 + 特别活动工具零

它引用的抖音家装行业数据（注意口径）

  • 抖音家装活跃粉丝数增长 68%（2020年9月 → 2021年9月）；家装行业品牌入驻率同比 +80%、家装类达人投稿量 +170%、家装类达人直播间 +82%、家装兴趣用户群体 +9%。
  • 但要看清口径：数据来源标的是「巨量算数 2021 年 1-9 月、2022 年 1-9 月」——这是行业大盘数据、不是尘锋的产品效果，而且已经是三四年前的了。可以引用来说明"抖音家装赛道在涨"，不能用来证明尘锋有效。0.9

这一节改变了我对尘锋的一个判断

  • 我原先在第 06 节写的是「它和我们是拼图关系，很可能在同一个甲方那里共存」。这条仍然成立，但要加一句限定：
  • 它在邀约到店、交付、老带新这三段上已经有成型的产品，而我们在这三段上是空白。如果甲方按「全流程」招标，尘锋覆盖的段数比我们多——我们的优势集中在最前面那一段（公域线索的语义打分）和知识资产那一层。
  • 所以正确的打法不是比覆盖面，而是把「线索质量」这件事讲透：它的五个场景全都建立在「线索已经进来了」这个前提上，而线索从哪来、准不准，正是它自认拿不到的那一段。0.7
08

还没问清的（下次沟通照着念）

对尘锋的 5 问

  1. 「10 个企微账号」是按人头还是按主体算？20 家店如果每店 3–4 人都要企微号，是不是要买 6–8 组（18–24 万）？——这是它对我们最大的价格风险。
  2. 抖音私信留资手机号加密这件事，你们怎么应对？重新授权蓝V之后还能拿到完整手机号吗？
  3. 既然拿不到评论区，那线索从哪来？是不是必须甲方自己先投流或发内容把人引进私信？
  4. 可追踪资料链接的「转发量」怎么统计？能不能看到转发给了谁？（家装是家庭共同决策，这个字段价值很高）
  5. 「客户SOP」的 Day1/Day3/Day7 内容序列是你们预置的行业模板，还是要我们自己配？能不能给一份家装行业的完整模板？

本页的证据分级：实证＝截图上直接读到的；口径＝销售在沟通里说的；推断＝组合判断，带置信度。一处必须说明的局限：演示环境的已授权抖音号是 0，所以它抖音侧的接待能力我们只看到了配置界面，没看到真的跑起来——「能接住主动私信」这条目前是结构推断，不是实测。
