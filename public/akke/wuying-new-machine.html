新云电脑配置指南

用「镜像克隆」开一台无影云电脑，换成你自己的身份，跑通抖音私信发送。已实测跑通（2026-06-02，小武机）。

适用：阿里无影云电脑「个人版」 · Windows · Akke 抖音 DM 通道（grounded 串发）
整体只有三大步（约 30–50 分钟，多数是等镜像）
  1. 无影侧 · 用镜像码克隆出一台云电脑
  2. Akke 侧 · 换成你自己的身份（关键：重登抖音）
  3. 验证 · 试发 1 条 → 确认气泡 → 开通完成
  4. 日常发送 SOP（开通后每天）
  5. 排错速查
为什么用镜像克隆？ 一台已配好的机器（含 Python、发送脚本、抖音客户端、已校准的坐标/模板）打成镜像，新机直接套用 → 零重新校准。你在新机上唯一需要做的"换身份"，就是 退掉别人的抖音、登你自己的抖音号。其余全是现成的。

1 无影侧 · 用镜像码克隆同事操作

PM 会把一台配好的"基线机"做成镜像，开启镜像码（一串数字，如 74869247）发给你。你用它克隆出自己的机器。

先认识两块盘（了解即可）

磁盘大小装了什么
系统盘 C:60 GiB系统、软件、环境变量、桌面 —— 发送脚本和校准都在这
数据盘 D:40 GiB独立存储，默认空。分享镜像一般只含系统盘，不带个人文件
🤖 推荐：让 cowork（电脑操作助手 / Computer Use）替你点 无影里的点击步骤可以全部交给 cowork 代操作，你只要把下面的提示词复制进 cowork 对话框，把里面的 <镜像码> 和 <我的云电脑名字> 换成真实值即可。 手动操作的步骤见下面 A/B 两节（作为对照或 cowork 卡住时的兜底）。

🤖 cowork 提示词（直接复制）

① 主流程 —— 收藏镜像码 + 变更到我的机器（机器已是「运行中」时用）：

请帮我在「无影云电脑」客户端完成一次镜像克隆，严格按顺序操作，遇到我标注「停下来确认」的地方先暂停问我：

1. 点左侧菜单「镜像管理」。
2. 点「通过镜像码收藏镜像」，在输入框填入镜像码：<镜像码>，确认收藏。收藏成功后它会出现在「收藏镜像」列表里。
3. 点左侧菜单「云电脑」，找到名字为「<我的云电脑名字>」的机器卡片，点它的「管理」。
4. 在管理面板点顶部「镜像」标签页，再点右下角「变更镜像」。
5. 点「选择镜像」，切到「收藏镜像」分页，选中第 2 步刚收藏的那个镜像，点「确定」。
6. 【停下来确认】此时会提示要关机并覆盖本机数据。先告诉我镜像名字和提示内容，等我回复「确认」后，你再点「确定关机并变更」、然后点「确定变更」。
7. 变更开始后告诉我，预计 5–30 分钟，期间机器不可操作。完成后通知我。

注意：全程不要修改分辨率、不要改任何其它设置；只做上面 7 步。

② 如果你的机器还是「待配置」新机，先用这条把机器开出来，再用上面 ① 变更镜像：

请帮我在「无影云电脑」客户端把一台「待配置」的新机器开出来：

1. 点左侧「云电脑」，找到状态是「待配置」的机器，点「立即配置」。
2. 配置方式选「配置全新电脑」，下一步。
3. 云电脑名称填：<我的云电脑名字>；部署区域选离我最近的；点确定。
4. 预装系统选「Windows Server 2022」，下一步。
5. 云电脑规格选「经济模式 4核8G」（黄金款），下一步。
6. 预装应用这一步直接跳过，点「完成配置」。
7. 提示配置成功后告诉我，机器开通约 1–10 分钟。开通后状态会变「运行中」，到时通知我，我再让你做变更镜像。
⚠️ 覆盖类操作让 cowork 停下来等你。「确定关机并变更」会清空机器原有数据，提示词里已让 cowork 在这步暂停 —— 由你亲眼确认镜像没选错、机器没装重要东西，再回复「确认」。

— 下面 A / B 是手动点击步骤，cowork 顺利的话可跳过，仅作对照 / 兜底。—

A · 收藏 PM 给的镜像码（手动）

  1. 打开无影客户端 → 左侧 「镜像管理」。
  2. 点 「通过镜像码收藏镜像」，输入 PM 给的数字码 → 收藏成功后会出现在 「收藏镜像」 里。

B · 把镜像变更到你的机器（手动）

分两种情况： 若你已有一台「运行中」的云电脑 → 直接做下面的"变更镜像"。
若你是「待配置」的新机器 → 先按 PM 的基础系统（如 Windows Server 2022 / 经济模式 4核8G）「立即配置 → 配置全新电脑」把机器开出来，等它变「运行中」，再做变更。
  1. 左侧 「云电脑」 → 找到你的机器卡片 → 点 「管理」。
  2. 进 「镜像」 标签页 → 右下角 「变更镜像」。
  3. 点 「选择镜像」 → 在 「收藏镜像」 里选中 PM 那个 → 点「确定」。
  4. 核对后点 「确定关机并变更」 → 再点 「确定变更」。等 5–30 分钟，期间机器不可操作。
⚠️ 变更镜像会覆盖这台机原有数据、清空历史还原点。确认机器上没有要保留的东西再操作。
变更完成 = 你的机器已和基线机一模一样：Python、发送脚本、抖音客户端、坐标/模板全在。接下来只剩"换身份"。
⚠️ 别动分辨率。镜像克隆同规格 → 分辨率和基线机一致，坐标/模板才能直接用。进系统后在无影显示设置里关掉自适应、锁死分辨率，一旦漂了发送会点偏，要重新校准。

2 Akke 侧 · 换成你自己的身份同事操作

镜像带来的是别人的抖音登录态。这一步把它换成你自己的。这是新机唯一必须改的身份。

① 重登你自己的抖音号（核心，必做）

  1. 打开抖音 PC 客户端 → 右上角头像 → 退出登录。
  2. 扫码登录你自己的抖音号 → 确认右上角昵称/头像是你本人。
  3. 窗口 最大化（不是窗口化）、保持在最前台、不被其它窗口挡住。

② 关于 .env —— 一般不用动

实测结论（2026-06-02 验证）：发送脚本 douyin_dm_grounded.py 不读取账号 UUID，只读 OCR key + 坐标。 所以"这条 lead 算谁发的"是 PM 那边拉单时就定好的，云电脑上不需要改 .env 的账号。镜像带来的坐标行（AKKE_C_* / AKKE_INPUT_OFFSET）一个字都别动，那是校准好的。

（若 PM 明确要求你改 AKKE_ACCOUNT_ID 为整洁，按 PM 给的 UUID 改即可；不改也不影响发送。）

③ 删掉基线机的发送残留

开始菜单搜 powershell 打开蓝窗，逐行跑：

cd C:\akke-wuying
del sent_log_*.csv
del contacts.csv
第一次跑可能提示 "找不到路径 contacts.csv" —— 正常，本来就没有旧文件可删，忽略即可。

3 验证 · 试发 1 条PM 备料 / 同事发

PM 这边

PM 用你的账号 claim 1 条 + 生成话术，host 到 paste.rs，把一个链接（形如 https://paste.rs/xxxxx）发给你。

你这边（云电脑 PowerShell）

确认抖音已登你的号、最大化、且 输入法切英文（Win+空格 → English；中文输入法会抢走搜索词首字，搜错人）后：

cd C:\akke-wuying
del sent_log_*.csv
Invoke-WebRequest -Uri PM给的链接 -OutFile contacts.csv -UseBasicParsing
(Get-Item contacts.csv).Length      # 字节数应和 PM 报的一致
py douyin_dm_grounded.py contacts.csv

盯日志应出现这串流程

[focus] 抖音主窗口已置前
click_norm[搜索框] → 键入 → 用户tab → 第一条
[OCR] match=True conf=0.98        ← 身份门核对昵称通过
私信 → input[锚定发送↑] → 键入文案
click[发送↑] → ✅ 已点发送
click_norm[关闭聊天窗口×]
⚠️ ✅ 已点发送 不等于真发出！ 必须用眼睛到你抖音的「私信」列表里确认那条对话真出现了文案气泡。这才算发送成功。
发完

把 运行日志整段 + 气泡有没有出现 发回给 PM：

  • 气泡出现了 → PM 标记去重，开通完成 ✅ 这台机正式可用。
  • 没出现 / 私信窗口没正常打开 → PM 释放回池；多半是分辨率没锁/点偏，回第 1 节锁分辨率，必要时联系 PM 重新校准。

4 日常发送 SOP（开通后每天）

开跑前 4 件前置（缺一不可）

  1. 抖音 PC 已登你自己的号、窗口最大化、在最前台。
  2. 聊天窗口都关掉，回抖音主界面。
  3. 输入法切 英文（Win+空格 → English）。
  4. 分辨率别动（保持镜像里那个）。

发送（PM 给链接，你下载跑）

cd C:\akke-wuying
del sent_log_*.csv
del contacts.csv
Invoke-WebRequest -Uri PM给的链接 -OutFile contacts.csv -UseBasicParsing
py douyin_dm_grounded.py contacts.csv

默认每条间隔 60 秒。发完肉眼核对私信列表气泡，把日志发回 PM 收尾去重。

陌生人私信有频率风险（抖音对陌生人 DM 限频，触发会冷却约 24h）。新号头几天量压小一点，节奏听 PM 安排。

5 排错速查

现象原因怎么办
跑了脚本一直不动 / 20 分钟没反应跑成了 wuying_poll_agent.py（另一个轮询器）Ctrl+C 停掉，确认跑的是 py douyin_dm_grounded.py contacts.csv
搜索框点了但字没进去输入法是中文，抢了首字Win+空格切英文，重跑
搜索 / 用户tab / 发送点偏点空分辨率漂了 / 没锁无影显示设置锁死分辨率；仍不行联系 PM 重新校准
日志 ✅ 已点发送 但私信列表没气泡脚本不做发送校验以肉眼为准，没气泡的别报"已发"，告诉 PM 释放回池
OCR match=False（非主页）搜到同名大号 / 卡在上个用户页正常，身份门拦下没发，自动跳过下一条
抖音弹「需要重新登录」Cookie 过期（15–30 天）在云电脑里手机扫码重登你的号
突然弹验证码触发风控立刻把鼠标甩到屏幕左上角（紧急停）→ 任务管理器关 python.exe → 联系 PM
灵豆掉得飞快下班没关无影客户端下班 Cmd+Q 完全退出客户端，10 分钟后自动休眠停扣

✓ 开通核对清单

  • 已收藏 PM 镜像码，变更镜像完成，机器「运行中」
  • 分辨率已在无影显示设置里锁死
  • 抖音 PC 已退别人号、登上我自己的号、最大化、前台
  • 已 del sent_log_*.csv / del contacts.csv 清掉基线机残留
  • 输入法切到英文
  • 试发 1 条，肉眼在私信列表看到气泡，PM 确认去重 → 开通完成
