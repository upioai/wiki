真正「装 Windows 客户端控制个微」的只有水流和鲲炬，而且两家界面哲学相反：水流把微信包进自己的壳里（你看到的是它的聚合界面，微信被藏在后面），鲲炬不给微信套壳（你看到的就是微信官方客户端，AI 像个隐形人在你眼前点它）——注意这只说执行层：08-20 更正鲲炬的配置层是一整套自研控制台，「零界面」的旧判断已推翻，见 02 节。亿销云与亿量都以工作手机为个微通道，但差一档：亿销云给了一个能直接聊天的自研聚合界面（还有 AI 自动发送开关，默认关），亿量的界面只看不聊（分析与话术生成，发送回到手机上由人来）。对我们：这两种界面哲学正对应「重界面研发」和「零界面研发」两个极端，各自的演示说服力和风控暴露面完全不同。0.75

01 · 水流

聚合壳路线——微信被包进它自研的界面里，人只看它的面板　✅ 本专题已完成

个微全托管是水流投入最重的板块。形态：本地 Windows 客户端里一块自研微信聚合壳——多个微信号聚合到一个会话面板，右侧挂 AI 标签表（意向程度/价格接受度自动填充），下挂 6 节点客群链路（新客开场白 → 痛点 → 激活需求 → 产品介绍 → 营销 → 成交）。RPA 分软/硬两模，硬件模式跑起来屏幕顶部常驻红字「模拟操作中，请暂停操作键盘鼠标」（浮层写 Ctrl+Alt+Del 解除锁定）——这行红字本身就是「界面」的一部分：它明确告诉你这台电脑此刻不是你的。

完整机制拆解见 手册 · 水流档案 与 水流单页；官方演示视频（03:16）在档案内。

02 · 鲲炬

08-20 重写——它不是「零界面」：有一整套自研控制台，之前的判断被 3-2 演示录屏推翻　✅ 界面已实证（17 分钟逐屏录屏）
更正 · 本节 08-18 版有两条结论是错的

错 ①「零界面路线——不做壳，没有任何鲲炬自己的软件界面」。实际：鲲炬有一套完整的自研桌面控制台（粉色主题、K logo、左侧 11 项固定导航）。08-18 那版是只看了 85 秒官方宣传片就下的判断——而那支宣传片刻意只拍 RPA 执行画面（微信绿气泡、小红书粉界面），一帧后台都没给。我们把「宣传片的取景」当成了「产品的事实」。0.97

错 ②「没有任何用户可见的频控配置界面，参数全在黑箱里」。实际：每天次数限制、每人每天查看条数、关键词条数上限、评论时效窗口、地域 IP 过滤——全部是界面上的普通表单项，甚至配了「确保设置 10-50 条，过多可能影响操作自然度」这样的人味提示。0.95

新证据：3-2 演示录屏（17:14，1280×720，录制于 2026-04-02 09:33–09:50），已抽帧入库；下述截图均取自该片。

修正后的鲲炬形态：一套自研 Windows 桌面控制台 + 一层桌面 RPA 执行器。甲方在控制台里配置（关键词、频控、提示词、话术流程、知识库），控制台把任务派给 RPA；RPA 再去操作官方微信 PC 客户端和浏览器里的抖音/快手/视频号/小红书。所以「AI 像隐形人一样操作你的微信」这句仍然成立——它描述的是执行层；但「没有界面」这句不成立——配置层重得很。两层之间的接缝就是 Agent 页：打字下自然语言指令，AI 拆任务清单，回「确认」开跑。

一 · 控制台全貌：左侧 11 项导航，全部自研

二 · 获客配置：频控 / 时效 / 地域 / 过滤开关，全是明面上的表单

对我们的直接刺

它的候选过滤粒度比我们细：时效窗口（1天/7天/1个月/自定义）+ 省份级 IP + 跳过作者评论 + 仅私信企业号，全在一屏里。对照我们：claim-leads.ts 只有 --since-hours 一个时间维度，地域靠 city enrich 事后补，没有「跳过作者 / 只要企业号」这类过滤。这不是技术差距，是产品化差距——同样的过滤我们在 SQL 里能写，但没做成甲方能点的表单。0.8

03 · 亿销云

个微不装在电脑上，但聊微信在电脑上——自研「亿销云CRM」聚合聊天界面 + 刷机工作手机通道　✅ 本专题已完成

亿销云对「个微 + Windows 客户端」这个命题给出的答案是换一条通道：个微登录在厂商刷机的工作手机上（系统级权限），但销售日常聊微信是在电脑上它自研的「亿销云CRM」聚合聊天界面里进行的——一个像微信一样的会话窗（多号聚合、直接打字回复、语音/视频通话转文字、AI 回复侧栏），消息经工作手机通道收发。它不控制、不模拟微信客户端，而是自己造了一个聊天面（录屏里是独立窗口、未见浏览器地址栏，是桌面客户端还是网页封装待核；管理与分析后台为 Web，域名 xxl.xxlcrm.com）。它的合规 PDF 正是把「协议 / 模拟器方案」（即水流那类聚合壳路线）列为高封号风险。看它的价值在于：这是「同一个需求、界面做在另一端」的完整样本，而且是九家里界面完成度最高的。

怎么生长动态运营：AI 在日常沟通分析里发现高频问题就引用进来；某个销售答得好、客户反馈正向的答案会被收成标准答案（或 AI 润色）——原话「系统用得越久，知识库里问题和答案就越多」批量蒸馏的快照：对一段时期的录音整体分析后生成（亿量自己那份：10,000 条录音采样 · 6,342 唯一线索 · 43 名销售 · 2026-05 采集期），出一版是一版
给谁用 / 什么场景销售日常随手查：聊客户时碰到棘手问题当场找答案（谈单助手同源）；运营负责更新培训与管理：新销售入职速读、管理层看团队打法全貌、话术禁区当红线清单
对我们的对照这两层正好对应我们企业大脑的两个面：活知识库 ≈ 我们的 kb_entries + 说法审核（但它没有「说法冲突」语义，好答案靠人挑）；playbook ≈ 我们还没有的「阶段性蒸馏交付物」——把一段时期的真实对话炼成一份给人读的手册，这个交付形态值得抄。0.75

界面③ · 经营洞察报告（HTML 交付物，二手车客户案例）

对本专题主问题的最终回答

亿量版答案：个微上 Windows？——不上。

个微登录在刷机工作手机上（采集载录），人看的是 Web 后台（分析与辅助），AI 生成的话术由人手动发。这与亿销云同属「手机采集 + Web 分析」路线，但比亿销云更保守——亿销云的 AI 回复侧栏有「自动发送」开关（默认关），亿量连开关都不做。三家口径梯度成型：心动「AI 直接代发」→ 亿销云「可开自动但默认建议」→ 亿量「只分析绝不代发」——风险水位从高到低，正好给甲方讲清我们把自己放在哪一档、为什么。0.85

合作案例口径（置信度 0.5，logo/口述未独立核实）：家居装修行业称合作过欧亚达、红星美凯龙、欧派、北京上屋装饰。价格三口径至此对齐：playbook 页 1,380/1,980 元/人/年为准，08-10 全景表「1,500/账号/年」是同一价格带的旧口径，正文「5,000 元≈900 分析小时」是算力包（另一种计费）。

05 · 零一万物

待调研——公开产品线里没有个微自动化　🔄 还会有进一步更新（渠道接触中）

零一万物（01.AI，李开复 2023 年创立）当前主线是企业级 Agent 平台「万智」：「超级员工」序列里的「超级销售」做的是 ToB 销售协作——线索分析、商机质量判断、售前方案与报价跟进，面向销售团队内部流程，不是个微触达自动化。公开材料未见任何「控制个人微信」的产品或功能（检索于 2026-08-18；ToC 端「万知」只是问答助手）。0.7

本专题对它的处理

列入待调研：若接触渠道拿到的是「万智超级销售」，那与我们的对位在销售过程协作层（类亿量），与个微 PC 自动化无关；若对方声称有个微能力，先要一张后台实拍再谈。参考：零一万物·企业级 Agent 发布稿 · 万智平台介绍（第三方）。
