03 · 运营看这里

更新后，大家要部署什么？

✅
话术 / 大脑类优化（GLM-4.6、门店、SPIN、人设、署名…）= 服务器上的，PR 合并就自动生效，运营什么都不用做。
⚠️
读屏 / 发送 / 心跳类优化（loop 的九连修 + 心跳）= 跑在你云电脑上的程序，必须手动更新才生效——不更新，你就还在跑旧版、这周修的读屏问题一个都没吃到。

① 更新云电脑上的 loop（每台机都要做）

在云电脑打开 PowerShell，整段复制粘贴运行——自动备份旧版、拉取最新（token-free，不用找 PM）：
cd C:\akke-wecom
Copy-Item wecom_reply_loop.py wecom_reply_loop.py.bak -Force   # 备份，出错可改名回滚
iwr https://raw.githubusercontent.com/upioai/wiki/main/public/akke/wecom-chat/wecom_reply_loop.py -OutFile wecom_reply_loop.py
拉取失败等 30s 重试；持续失败才找 PM（可能 GitHub 被挡）。#760 合并后会多一个 update-wecom.bat，双击即自动完成这步。

② 重启 + 验证

  • 关掉正在跑的黑窗 → 双击 start-wecom-reply.bat 重新拉起。
  • 看启动行版本号：… 主循环启动 v2026-07-02.11 …——对上才算更新成功（#761 合并后会到 v2026-07-05.x）。
  • 确认 wecom_reply_status.json 心跳在动 / 日志在滚。卡住走 /cloudpc-wecom-autoreply-restart。

③ 首次装机 / 换机才要配的（老机器已配好，跳过）

WECOM_CHAT_ENDPOINThttps://akke-worker-prod.fly.dev/wecom/chat/reply（固定别改）
AKKE_WECOM_PERSONA本机绑的销售号：xiaoxia / xiaofan / xiaowen
WECOM_CHAT_SECRET大脑端点密钥——真值不公开，找团队内部（Lark）取，所有机器同一个值
ANTHROPIC_API_KEY你的 OpenRouter key（sk-or-v1-…，给 AI 读消息用）
坐标 C_INPUT / C_SEND / C_SESSION1本机跑 measure_wecom_coords.py 量（每台分辨率不同，必须量自己的）
AKKE_WECOM_DRY_RUN1=空跑验证（只读不发）/ 0=真发
新机器完整装机流程（装企微 / Python / bootstrap / 量坐标）→ 部署手册。
一句话给运营：话术升级你们自动就有；在每台云电脑跑一次上面①的命令 + ②重启，这周的读屏/心跳升级才真吃到——不做就还是旧版。
