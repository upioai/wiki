1价格体系构建方案

核心思路：把所有价格 / 配置 / 信任 / 钩子数据结构化到 brand_profile，LLM 不再凭记忆生成数字。

2破冰提示词优化方向（话题 1-5 逐一映射）

当前生产 v25（95.6% 成功率 · 27/610 missing credentials）整体稳定。下述改动以 v26 草稿提出，不动 v25。

2.1 话题 ① · §③ 业务边界 + §(H) 报价类放行

问题：v25 §③ 只说"全屋装修"，配置颗粒度为 0；客户问"什么板"模型只能模糊回答 → 容易飘出 brand_profile 外的品牌。

改法

  • 加 slot {{configMatrix}} ← brand_profile.config
  • §(H) 报价放行内增加 trigger：客户问板材 / 品牌 / 五金 / 环保才引用 → 1 行短答，不堆参数；没问绝不主动罗列（防破冰即推销）
  • ban list 加："禁止编造未列在 {{configMatrix}} 中的品牌或规格"
  • 阻尼抽屉作为"近下定"nudge，ice_break 阶段不透（限定 nurture / decision）

2.2 话题 ② · 新增 §(T) Trust 信任锚段

问题：v25 没有标准信任背书短语库。模型自由发挥时两个极端都出现过 —— 堆"国家级 / 十大品牌 / 行业第一"（合规风险），或只字不提（错失锚点）。

改法

  • 新增 §(T) Trust 段，slot {{trustClaims}} ← brand_profile.trust
  • 引用规则写死在 prompt：
    • 客户提环保 / 甲醛 / 小孩 / 孕妇 / 健康→ 引用 env_test
    • 客户质疑真的吗 / 靠谱吗 / 信不过→ 引用 fake_compensation
    • 客户问什么牌子→ 引用 brand_choice
  • 同一轮回复最多引用 1 条 trust 短语（防堆砌）
  • ban list 加：「行业第一」「全国唯一」「最便宜」「绝对环保」「100% 无甲醛」等不合规绝对化表述

2.3 话题 ③ · 新增 §(C) Closing 钩子收口段

问题：v25 收口 CTA 是泛化"加微发资料"，没把「样板房征集 = 直降 300 + 名额限量」这套稀缺钩子用上。

改法

  • 新增 §(C) Closing 段，slot {{showroomHooks}} ← brand_profile.showroom.perks
  • 按客户信号挑 1 条收口：
    • 比价信号（"别家""更便宜""贵了"）→ "样板房征集每㎡立减 300，外面拿不到这个价"
    • 品质质疑 → "样板房是脸面工程，配更深资的设计师 + 最优工艺"
    • 拖延（"再看看""不急"）→ "名额按小区限量，加微我先帮您锁个码"
  • "抢码 / 24H 联系当地销售"作为破冰阶段 soft CTA（替代生硬的"加微发资料发您可以吗"）

2.4 话题 ④ · 新增 §(B) Budget 预算计算段

问题：v25 §(H) 报价放行只是允许报价，没有结构化预算逻辑。客户报房产证面积时模型瞎算或拒答。

改法

  • 新增 §(B) Budget 段，slot {{budgetTable}} ← brand_profile.pricing.examples
  • 破冰阶段 short version：
    • 客户消息含 (\d+)\s*(平|㎡|平米|平方) → 取 N
    • 走查表（100㎡ 已有）/ 现算（其它面积）
    • 输出："您家 N㎡，投影约 N/2 ㎡，标配约 X 元 / 高配 Y / 豪配 Z，实际以方案为准"
  • 公式不让模型自己写推导，改成 prompt 内置 few-shot examples（防数学错误）
  • decision 阶段（dm.decision.system）走 full version，加配置系数解释 + 加价项

2.5 话题 ⑤ · generateOpener + (W) 联系方式

观察：合作方 4 套 opener + 3 套兜底 + 1 套挽回，质量明显高于当前 LLM 自由生成的 opener。建议落 opener_pool。

方案做法优点缺点推荐
A 保守 4 套模板进 brand_profile.openers，generateOpener 改造：按 video signal 挑模板 → LLM 只微调称呼 + 接 1 句视频引用 合规、稳定、可 A/B 失个性化深度 先走 A
B 中庸 4 套模板作为 few-shot examples 注入 system prompt，LLM 学风格仍生成 保留个性化 仍可能飘 v26 稳到 99%+ 后

兜底话术（3 套犹豫接话 + 1 套温柔挽回）→ 落 brand_profile.fallback_lines，§softening / bail-out（v23）改成从池中挑，不再 LLM 自由发挥。
