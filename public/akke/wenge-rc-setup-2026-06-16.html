文哥云电脑 · RC 反向评论开通手册

在文哥这台已经跑通 DM 的云电脑上,再开「RC 反向评论」支线。RC = 当天 DM 发满后,去用户那条意向评论下回复,捡放久了的旧 lead(评论已 >15min)。

适用:文哥 cloud_pc(已跑 DM) ｜ 2026-06-16 ｜ 约 15-30 分钟(多数是看第一批)
整体 4 步(都在云电脑里做)
  1. 确认 RC 执行脚本在机器上
  2. 改 .env 打开 RC 开关
  3. 重启无影,让 poller 带上 RC 支线
  4. 盯第一批 RC,肉眼核对评论区回复气泡
先搞清楚 RC 和 DM 的区别 DM=搜到人 → 进主页 → 发私信(一对一)。RC=搜到那条源视频 → 进评论区 → 在用户那条评论下面公开回复。 RC 更显眼(发在别人视频评论区),所以放在 DM 发满之后才接力,且只挑放久了的旧 lead。两条共用去重池,同一个人不会既被私信又被回复。
PM 侧已就绪(你不用管) 代码已上线、文哥 RC 日限 5、只挑 >15min 旧 lead、试点只对文哥。真发总开关(AKKE_RC_DISPATCH_LIVE)PM 先压着,等你把这台机器弄好、回报「RC 装好了」,PM 再翻开 → 才真正开始发。所以你照下面做完即可,发不发由 PM 控。

1 确认 RC 执行脚本在机器上

RC 用的是另一个执行脚本 douyin_rc_reply_grounded.py,poller 启动时会检查它在不在。

开始菜单搜 powershell,跑:

cd C:\akke-wuying\wuying-dm
dir douyin_rc_reply_grounded.py
看到文件名 = 在 ✅ 跳到第 2 步。
提示「找不到」= 缺脚本。说明镜像/拷贝时没带全。让 PM 把最新 wuying-dm 整个目录重新同步进来(或按《更新到最新版》文档拉一次),确保这台有 douyin_rc_reply_grounded.py,再继续。

2 改 .env 打开 RC 开关

同目录 .env 里加两行,告诉 poller「这台也跑 RC」。

cd C:\akke-wuying\wuying-dm
notepad .env

在文件末尾加这两行(原有的 AKKE_ACCOUNT_ID / Supabase / OCR key 一个字都别动):

AKKE_REVERSE_COMMENT_ENABLED=1
AKKE_REVERSE_COMMENT_CLAIM_LIMIT=3

存盘关闭。

AKKE_REVERSE_COMMENT_ENABLED=1 = 开 RC 支线;CLAIM_LIMIT=3 = RC 每轮最多拉 3 条。日上限(5 条)由 PM 端控,这里不用管。

3 重启无影,让 poller 带上 RC 支线

  1. 确认 抖音 PC 已登文哥号、最大化、前台、输入法切英文、分辨率没动(跟跑 DM 时一样)。
  2. 完全注销 / 重启无影一次(开始菜单 → 注销),重新登录等 ~60s,让自启的 poller 用新 .env 重新跑起来。
  3. 看任务栏的 poller 黑窗 / agent.log,启动应不再报 douyin_rc_reply_grounded.py 不存在;每轮会在 DM 批之后多出 RC 批的日志。
启动若报红 ❌ AKKE_REVERSE_COMMENT_ENABLED=1 但 douyin_rc_reply_grounded.py 不存在 → 回第 1 步把脚本补进来。

4 盯第一批 RC,肉眼核对回复气泡

PM 翻开真发总开关后,RC 批会自动跑。第一批必须盯着看——RC 比 DM 显眼,点错地方更要紧。

poller 里 RC 批正常长这样

[..:..] claimed N RC dispatches
  → wrote ...contacts-rc-reply.csv
=== douyin_rc_reply_grounded ===
搜视频标题 → 视频tab → VL 定位视频卡片(标题+作者) → 点开 → 核作者
→ 评论楼 VL 定位用户那条评论 → 点「回复」→ 粘贴文案 → 发送 → 复核气泡
  ✓ completed ... → sent
⚠️ 日志写 sent 也要肉眼复核! 去那条源视频的评论区,找到用户那条评论,确认下面真出现了文哥发的回复气泡。这才算成功。RC 是公开回复,发错楼/发错视频比私信更要命。

RC 坐标怎么办(可能要微调)

RC 大部分靠 Qwen 视觉定位(VL) 找视频卡片/评论/发送键,少数锚点用固定坐标。文哥这台是同分辨率镜像,DM 坐标已校准,RC 大概率能直接用。但第一批盯着看:如果出现「点了视频 tab 没反应」「回复框点空」,把日志发 PM,可能要单独校准 RC 的几个锚点坐标。

5 RC 排错速查

日志 status含义怎么办
sent已发 + 复核到回复气泡正常。仍以肉眼评论区气泡为准
video_not_found搜不到那条源视频正常跳过(视频可能删了/搜索词不匹配),不用管
wrong_video作者核对不上,防发错视频身份门拦下了,正常跳过
comment_not_found / wrong_floor评论楼里没找到那条 / 回复框 @ 的人对不上「错楼铁门」拒发,正常跳过,不会乱回复
panel_fail / focus_fail评论面板没打开 / 窗口没置前确认抖音前台最大化;偶发重试即可,连续多条 fail 找 PM
点视频 tab / 回复框点偏点空RC 锚点坐标没对上把日志发 PM,单独校准 RC 坐标
弹验证码 / 滑块风控立刻鼠标甩屏幕左上角(急停)→ 任务管理器关 python.exe → 找 PM

✓ 开通核对清单

  • douyin_rc_reply_grounded.py 在 C:\akke-wuying\wuying-dm\
  • .env 已加 AKKE_REVERSE_COMMENT_ENABLED=1 + AKKE_REVERSE_COMMENT_CLAIM_LIMIT=3
  • 抖音登文哥号、最大化、前台、输入法英文、分辨率没动
  • 重启无影,poller 启动不报「RC 脚本不存在」
  • 回报 PM「RC 装好了」→ PM 翻开真发开关
  • 盯第一批 RC,评论区肉眼看到文哥的回复气泡 → 开通完成 ✅
