新人入职手册 · 全团队唯一标准版

第一周
走完这条入职动线

写给刚加入 Akke 的实习生——尤其是非技术出身的你。不需要会写代码，按顺序走完 5 步：第 1 天知道 Akke 是什么，第 3 天听得懂团队语言，第 5 天知道自己该做什么。

Akke 已经不只是「抖音发私信」那一条线。门店侧现在同时跑四条产线——短视频获客 · 微信接待 · 沉默客户跟进 · 企业大脑，外加一个统一审核台——注意它的边界：被动回话不拦（客户问什么答什么是直接发的，等人点一下对话就断了），机器人主动出手才要批（主动私信、评论区回复、发图文视频、量房券、海报、转人工）。本手册按这个形态重排，口径对齐产品完整介绍（08-12）与工作台角色权限（08-25）。

03
Day 2–3 · AI Literacy

补齐 AI 通识与工具 · /learn 精选

Akke 是 AI 驱动的产品。你不需要懂技术实现，但需要听得懂团队的日常语言。/learn 讲解中心的文章全部为小白友好写作，第一周要求 4 篇必读 ＋ 1 组工具上手，每天 1–2 篇。必读书单已按现在的主力产线换过一轮——微信接待这条线是新加的。

优先级文章读它解决什么
MUST 大模型术语图鉴 给运营与产品的可视化术语手册。读完群里聊的模型 · prompt · token 你都接得住。
MUST 表征学习 AI 怎么「读懂」一条抖音评论——理解意向打分的原理，含 Akke 业务实例。
MUST 让 AI 像金牌销售一样说话 机器人替我们跟客户聊天，什么算聊得好。微信接待现在是主力产线，这篇是它的方法论底座。
MUST 企微自动回复的「眼睛」· VL 读屏 本轮新增必读。系统不是「读」聊天记录、是「看」截图。群里天天说的 VL · 读屏 · 它卡住了 到底指什么，含给运营的三步判断。
工具 Claude Code 终端读屏手册 · 技能体系团队上手 · 新 Mac 开荒手册 团队干活的主力工具。先读读屏手册——终端上那些符号、转圈词、「卡住了怎么办」它都讲了；技能体系那篇讲怎么直接复用团队写好的 skill，不要自己从零来。
WEEK 2 Next.js · Node.js · Python · Vercel × Supabase · Fly.io 是什么 不写代码也能看懂技术同事每天在改什么，以及我们的产品「跑在哪里」。
WEEK 2 芒格逆向思维 · 马斯克五步法 · WBS 任务拆解 团队共同的思维模型，开会讨论时经常直接引用这三篇的说法。
按方向 短视频复刻产线 · 现状全景 · AI 内容生成四件套 · SQL 与 Python 入门 · 数据库与存储全景 短视频产线方向读前两篇，企业大脑 / 数据方向读后两篇（对应第 04 步的分支）。
Gate · 完成标准

每读完一篇，在飞书群发 3 行读后感（讲给完全没读过的人听）。4 篇必读全部发完，且 Claude Code 已经在你手上跑完过一件真事——哪怕只是让它读一页文档讲给你听。

Day 5 · Work Loop

建立你的工作循环

从第二周起，你的日常按这个循环走。四件事都不难，难在每天都做。

✅

LOOP-01 · TASK任务落飞书

所有待办记进飞书任务（Lark Task），不要只记在脑子里或私人备忘录。mentor 和你看到的是同一份清单。

📮

LOOP-02 · DAILY每日 3 行日报

下班前群里发 3 行：今天做了什么 / 明天做什么 / 卡在哪里。卡住的事永远放第一行。

🗂️

LOOP-03 · ARCHIVE产出沉淀成链接

做出来的文档发飞书云文档，或让同事帮你放上 upio.ai。群里发链接，不发文件附件。发给客户的资料走系统里的内容分享链接——系统只负责挑内容、生成专属链接、记录看没看，粘进微信按发送那一下永远是人做的。（该入口目前限店长 / 运营，销售找店长发。）

📚

LOOP-04 · LEARN持续补课

每周从 /learn 自选 1–2 篇继续读，读后感照发。检索能力比记忆重要。

Gate · 完成标准

06
House Rules

团队规矩 · 非技术同学也要遵守

六条里有两条是红线（🔒 与 ⚠️），第一次踩之前一定先问 mentor。

🔍

Rule-01先查再问，问带上下文

顺序：① 知识库目录和踩坑速查搜关键词 → ② 查不到再去群里问。提问说清三件事——想做什么 · 试了什么 · 卡在哪一步，别只发一句「这个怎么弄」。

🔒

Rule-02 · 红线客户信息绝不外泄

upio.ai 大部分页面公开可访问。客户姓名、手机号、微信号、聊天截图、账号密码，绝对不能写进任何公开页面或发到外部。站内有几页（客户旅程时间轴等）本身带客户身份、已设 noindex——链接也不要往群外贴。拿不准一律先问。

📎

Rule-03链接文化

团队用链接传递信息：发飞书云文档链接或 upio.ai 链接，不甩 Word / PDF 附件。你收到的也大多是链接——点开读，别攒着。

🧾

Rule-04说结论要带依据

区分「我看到的数据」和「我猜的」。说「客户不回复了」之前先看对话记录和看板；说「效果变差了」之前先有对比数字。这条在系统里是硬机制——企业大脑有「出处闸」：挂不上原文出处的内容整条删掉，人写东西也照这个标准。

⚠️

Rule-05 · 红线碰账号先报备

抖音、企业微信账号是生产资料，有风控红线（详见防风控指南）。任何在客户 / 公司账号上的操作，第一次做之前必须先跟 mentor 过一遍。另外记住审核台的边界：被动回话不进审核台，是直接发的；进审核台的是机器人主动出手那一类。在审核台点「通过」＝ 真的发到客户那里，撤不回来，发布、发资料同理，都有副作用。

🙋

Rule-06主动是最大的加分项

没活了不要干等：把读后感写完、案例库补一条、去踩坑页找一个你能验证的条目。每天让 mentor 看得见你在推进什么。

Week-1 Self Check

第一周结束 · 七项自检

全部能打勾，你的第一周就合格了。打不了勾的项，下周一主动找 mentor 补。

CHK-01我能不看笔记用 3–4 句话讲清 Akke 是做什么的、客户为什么付钱。
CHK-02我能说出四条产线各自解决什么问题，以及一个客户从被看见到被跟进大致怎么走。
CHK-03看到 DM · 开场白 · 意向分 这类词，我知道去 intro 术语速查确认含义。
CHK-044 篇必读 /learn 文章读完、读后感都发过群，Claude Code 也在我电脑上跑起来了。
CHK-05我知道自己在四支里的哪一支，读完了本分支的材料。
CHK-06我有 mentor 看过的飞书任务清单，日报已成习惯。
CHK-07我知道求助顺序：知识库搜索 → 踩坑速查 → 群里带上下文提问。
CHK-08我知道哪些动作有副作用、撤不回——统一审核台上的「发出」、发布、给客户发资料，做之前会先确认一遍。
08
FAQ

常见问题

🤯

技术内容完全看不懂怎么办？

正常，手册就是按「非技术出身」设计的。所有指定阅读里，代码块和架构图可以直接跳过，只读文字和比喻部分。你的目标是「听得懂团队在聊什么」，不是「能自己实现」。

🧠

信息太多，记不住怎么办？

手册只要求你记住两个入口：upio.ai/akke 和 upio.ai/learn。其余一切都是「用的时候能找到」即可。检索能力比记忆重要。

💻

我是技术背景，也走这条动线吗？

是，前两步相同。从第 03 步起加读：系统架构详解、踩坑速查（百条）、Akke 技术全景、PR 与 Git Worktree、团队 Git 提交规范、模型与 effort 怎么拧，并向 mentor 申请代码仓库权限。跨境网络走团队 VPN 架构那页，别自己乱配。

🛠️

手册内容和实际对不上怎么办？

项目迭代很快，页面一定会滞后。本页口径同步到 2026-08-30，基线是产品完整介绍（08-12）与工作台角色权限（08-25）——这两页比本页新时，以它们为准。发现过期内容是贡献不是麻烦：截图发群里 @ mentor，注明哪一页哪一段。这是全团队唯一标准版，你报的错会让下一位新人受益。

一句话总结：第 1 天读懂 Akke 现在的四条产线，第 3 天听得懂团队语言、工具能跑起来，第 5 天接下第一个任务并跑起任务 ＋ 日报 ＋ 沉淀的循环。收藏本页，其余都能从这里找到。
