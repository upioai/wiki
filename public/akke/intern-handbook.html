Akke 新人入职手册
第一周走完这条动线

写给刚加入 Akke 的实习生——尤其是非技术出身的你。不需要会写代码，只需要按顺序走完下面 5 步：第 1 天知道 Akke 是什么，第 3 天补齐 AI 通识，第 5 天知道自己该做什么。每一步都有明确的「完成标准」，走完就打勾。

适用对象 · 所有新加入成员（实习生优先设计） 预计用时 · 每天 1–2 小时 × 5 天 唯一入口 · 收藏本页即可，其余全部从这里跳转
▶ 从第 1 步开始 知识库目录 /learn 讲解中心
📌
怎么用这份手册：按顺序走，不跳步。每一步末尾有一个绿色的「✅ 完成标准」——做到了才进入下一步。看不懂的技术段落直接跳过，不影响主线；手册要求你记住的东西非常少，大部分内容只需要「知道去哪查」。

五步动线

  1. 1
    Day 0 · 入职当天上午

    准备好三样东西

    • 飞书（Lark）账号 — 团队所有沟通、任务、文档都在飞书上，向带你的同事（下文叫 mentor）索取邀请，加入项目群。
    • 收藏两个网址 — upio.ai/akke（Akke 知识库，项目所有文档的目录）和 upio.ai/learn（团队 AI 知识讲解中心）。以后遇到任何「这是什么？」，先来这两个地方搜。
    • 和 mentor 确认两件事 — ① 你的方向（触达运营 / 内容素材 / 数据案例，见第 4 步）；② 你的日常提问和汇报发在哪个飞书群。
    ✅ 完成标准：能在飞书项目群里发出第一条消息做自我介绍，并 @ 你的 mentor。
  2. 2
    Day 1 · 第一天

    认识 Akke：按顺序读三页

    三页都在本站，读的时候不求记住细节，只求建立整体图景：

    • ① 项目介绍 · 新人入门 — Akke 是什么、7 步业务流水线、术语速查。重点读「业务全景」和「术语速查」两节，架构部分扫一眼即可。
    • ② 能力地图 — 从客户视角看 Akke 能做什么。想象你是一个全屋定制商家老板，看完问自己：我为什么愿意付钱用这个产品？
    • ③ 新人完整指引（15 分钟） — 更完整的一版，含「一条评论的旅程」和「5 条最致命的坑」。技术章节（数据表、架构）跳过没关系。

    读完用这个模板向 mentor 口头复述一遍（这是第一周最重要的检验）：

    🗣️
    「Akke 是给＿＿＿行业做的获客工具。它先从抖音＿＿＿，再用 AI ＿＿＿，最后自动＿＿＿。客户愿意用它，是因为＿＿＿。」
    ✅ 完成标准：不看笔记，把上面的填空题向 mentor 讲通顺。
  3. 3
    Day 2–3 · 第二、三天

    补齐 AI 通识：/learn 精选阅读

    Akke 是一个「AI 驱动」的产品，你不需要懂技术实现，但需要听得懂团队的日常语言。/learn 讲解中心有几十篇讲解，全部为小白友好写作。第一周只要求下面 4 篇「必读」，每天 1–2 篇：

    优先级文章读它解决什么
    必读 大模型术语图鉴 给运营与产品的可视化术语手册。读完群里聊的「模型 / prompt / token」你都接得住。
    必读 表征学习 AI 怎么「读懂」一条抖音评论——理解 Akke 意向打分的原理，全员小白友好，含 Akke 业务例子。
    必读 Next.js · Node.js · Python 不写代码也能看懂技术同事每天在改什么。用「一条请求的旅程」讲 Akke 用了哪几种语言。
    必读 让 AI 像金牌销售一样说话 Akke 的 AI 替我们跟客户聊天——什么算聊得好？这篇是运营侧的核心方法论。
    第 2 周 芒格逆向思维 · 马斯克五步法 · WBS 任务拆解 团队共同的思维模型，开会讨论时经常直接引用这三篇的说法。
    第 2 周 Vercel × Supabase · Fly.io 是什么 我们的产品「跑在哪里」。听得懂「部署 / 上线 / 数据库」在指什么。
    按方向选读 AI 内容生成四件套 · 解构复刻产线 · SQL 与 Python 入门 内容素材方向读前两篇，数据方向读第三篇（见第 4 步分支）。
    ✅ 完成标准：每读完一篇，在飞书群发 3 行读后感（讲给完全没读过的人听）。4 篇必读全部发完。
  4. 4
    Day 3–5 · 第三到五天

    进入你的方向：按角色分支

    和 mentor 确认你属于哪个方向（也可能是组合），然后只读自己分支的材料：

    📱

    触达运营

    管抖音/企微账号、看私信回复、维护客户对话
    • 账号运营 SOP
    • 防风控指南
    • 云电脑上手
    • 复读 金牌销售，对照真实对话
    🎬

    内容素材

    选题、审素材、参与 AI 视频/图文生产线
    • AI 内容生成四件套
    • 解构复刻产线 · 动态图解
    • 图生视频效果不好，怪谁？
    • Workflow 子站（调研合集）
    📊

    数据案例

    整理客户案例、看数据看板、做汇报材料
    • 触达时效看板（实时数据长什么样）
    • SQL 与 Python 入门
    • 踩坑速查（只看运营/数据相关分类）
    ✅ 完成标准：mentor 给你派出第一个真实小任务，你能说出「这个任务在 Akke 业务流水线的哪一环」。
  5. 5
    Day 5 · 第一周结束

    建立你的工作循环

    从第二周起，你的日常按这个循环走：

    • 任务 — 所有待办记进飞书任务（Lark Task），不要只记在脑子里或私人备忘录。mentor 和你都能看到同一份清单。
    • 日报 — 每天下班前在群里发 3 行：今天做了什么 / 明天做什么 / 卡在哪里。卡住的事永远放第一行。
    • 沉淀 — 做出来的文档发飞书云文档或让同事帮你放上 upio.ai，群里发链接，不发文件附件。
    • 继续读 — 每周从 /learn 自选 1–2 篇继续补课，读后感照发。
    ✅ 完成标准：你有一份 mentor 看过的飞书任务清单，且已连续发出 3 天日报。

团队规矩 · 非技术同学也要遵守

🔍 先查再问，问就带上下文

遇到问题的顺序：① 在 知识库目录和 踩坑速查搜关键词 → ② 查不到再去群里问。提问时说清「我想做什么 / 我试了什么 / 卡在哪一步」，别只发一句「这个怎么弄」。

🔒 客户信息绝不外泄

upio.ai 大部分页面是公开可访问的。客户姓名、手机号、微信号、聊天截图、账号密码，绝对不能写进任何公开页面或发到外部。拿不准一律先问 mentor。

📎 链接文化

团队用链接传递信息：文档发飞书云文档链接或 upio.ai 链接，不甩 Word / PDF 附件。你收到的也大多是链接——点开读，别攒着。

🧾 说结论要带依据

汇报时区分「我看到的数据」和「我猜的」。说「客户不回复了」之前，先看过对话记录和看板；说「效果变差了」之前，先有对比数字。团队文化是：结论必须能指出来源。

⚠️ 碰账号先报备

抖音、企业微信账号是生产资料，有风控红线（详见防风控指南）。任何「在客户账号 / 公司账号上操作」的动作，第一次做之前必须先跟 mentor 过一遍。

🙋 主动是实习生最大的加分项

没活了不要干等：把读后感写完、把案例库补一条、在踩坑页找一个你能验证的条目。每天让 mentor「看得见你在推进什么」。

第一周自检清单

我能不看笔记用 3–4 句话讲清 Akke 是做什么的、客户为什么付钱。
我能大致说出业务流水线的主要环节（从抖音评论到触达客户）。
看到「DM / 开场白 / 意向分」这类词，我知道去 intro 的术语速查确认含义。
4 篇必读 /learn 文章读完，读后感都发过群。
我知道自己的方向，读完了本方向的分支材料。
我有 mentor 看过的飞书任务清单，日报已成习惯。
我知道遇到问题的求助顺序：知识库搜索 → 踩坑速查 → 群里带上下文提问。

常见问题

技术内容完全看不懂怎么办？
正常，手册就是按「非技术出身」设计的。所有指定阅读里，代码块和架构图可以直接跳过，只读文字和比喻部分——/learn 的文章都配了给小白的比喻。你的目标是「听得懂团队在聊什么」，不是「能自己实现」。
信息太多，记不住怎么办？
手册只要求你记住两个入口：upio.ai/akke（项目文档）和 upio.ai/learn（知识讲解）。其余一切都是「用的时候能找到」即可。检索能力比记忆重要。
我是技术背景的新人，也走这条动线吗？
是，前两步相同。从第 3 步起额外加读：系统架构详解、踩坑速查（百条）、Akke 技术全景 · 顾问速览、PR 与 Git Worktree，并向 mentor 申请代码仓库权限。
手册内容和实际情况对不上怎么办？
项目迭代很快，页面可能滞后。发现过期内容是贡献不是麻烦：截图发群里 @ mentor，注明哪一页哪一段。这份手册是全团队唯一标准版，你报的错会让下一位新人受益。
🧭
