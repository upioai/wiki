Overview

五条净结论（30 秒版）
结论 1 · 置信度 0.8

核心空位复验成立，但表述要收窄：「跨账号/竞品评论区意向挖掘 → 陌生人主动首触 → 企微承接 → 沉默召回」的合规 SaaS 全链路，42 家里没有第二家。

邻近者三类：被动承接进线私信的（美洽 / 螳螂 / 快商通）、评论收集了只给人看的（新榜矩阵通）、主动截流但违规的（灰产脚本带）。二轮深调发现的最近邻是来鼓「评论追粉」——自家账号评论区高意向 1 分钟内主动私信（厂商自述 0.85）——但仅限自家评论区、无陌生人冷触达，与我们「挖任意相关视频（含同行爆款）评论区」差 3 个数量级的池子。九家整合版「缝合带无人占领」的判断在更大样本下未被推翻。

零假设：若存在正面对手，"装企 抖音获客 SaaS / 评论区意向识别"类检索应命中其官网而非 PR 软文与灰产帖——四路独立检索均未命中。非穷尽证明，小厂漏网可能存在。
结论 2 · 置信度 0.85

功能②（AI 接待）是最拥挤战场，不能当主卖点。

客服系（美洽 / 快商通 / 智齿）、SCRM 系（微盛 / 尘锋 / 沃丰）、Agent 新贵（来鼓 / 句子互动）三路人马都在挤这个入口，百应正借联想渠道把它标品化压价。②是标配件；差异化要靠①的情报层和④的行业知识库。

结论 3 · 置信度 0.7

功能③（沉默召回）没有独立竞品，但处处有替身——替身全是「提醒人去跟」。

尘锋 SOP、微伴流失提醒、卫瓴激活话术，主流全是通知人类去发。「AI 自动去触达」是代际差。二轮深调修正：尘锋 2025「AI 员工」口径已宣称能 AI 自动激活沉默客户（厂商自述，全自动程度存疑 0.5，且渠道限企微/外呼私域内、非平台侧触达）——领先窗口在收窄，但「平台侧主动触达」仍无人做。海外佐证：AI SDR 全自主路线已实证退潮（11x 收入注水、品类年流失 50-70%）——人审 approve 流程是对的，别撤。

结论 4 · 置信度 0.8

最现实的威胁名单：三维家（渠道级）> 尘锋（SCRM 侧）> 美洽 / 螳螂 / 来鼓（私信承接侧）。

三维家「AI 慧引流 2.0」把抖音获客包进设计全家桶抢同一笔预算；尘锋是唯一把家装列为主打场景的头部 SCRM；美洽 / 螳螂 / 来鼓都点名家装，门店老板容易误以为「抖音获客机器人已有标品」。四家均已进入二轮深调。

结论 5 · 置信度 0.75

定价可以起草了：国内工具带 8k-30k 元/年，海外单店 AI 员工 ¥4-5 万/年，按效果计费国内外双向验证。

三个锚：微伴 / 销氪 / 来鼓给出国内 SMB 真实成交带；Podium 单店实付 $450-600/月证明「AI 员工」上限价位；Intercom Fin 按解决收费做到约 $100M 收入后被 Salesforce 以 $3.6B 收购。

来鼓 AI（laigu.com · 成都呼声科技）

新发现 · 打法最像

「Agent 时代」AI 数字员工：内容营销 / 增长获客 / 成交转化三 Agent 闭环，目标行业点名家居家装、教培、医美、婚摄。

机制
多平台私信统一接待（官方 API 聚合）+ 意向识别 + 留资推进。二轮深调修正：有「评论追粉」——自家账号评论区高意向 1 分钟内主动私信+定时追踪（厂商自述 0.85）。仍无跨账号/竞品评论区挖掘、无陌生人冷触达。小红书首家官方授权服务商；抖音侧依赖存量服务商资质。
定价
官网明码（0.9）：入门 ¥1,688/年（200 对话月）→ 企业 ¥16,888/年；预充值 ¥0.8/开口、¥2.0/留资（各 ¥5 万/年起充）——本批唯一明码「按效果计价」的国内玩家。注意口径：它的「留资」是用户自己进线后留的（承接口径），与我们的主动挖掘不同物种。
弱点
帮助文档（飞书 wiki）404、产品透明度低；三 Agent 疑似「一个私信接待内核+三张营销皮」（推断 0.5）；家装案例匿名、效果数字 0.4。
参考
效果计价 + 行业模板化打包是可抄的 GTM；¥2/留资的价格竞争力别低估（对家装客单价极便宜）。

新榜·矩阵通（matrix.newrank.cn）

代差证据

8 大平台 1000+ 账号企业矩阵管理，自称服务 50+ 财富 500 强，客户含房产/家居头部。

机制
官方授权接口聚合数据 200+ 指标；线索收集明确汇总「评论、弹幕、私信、表单」——但停在「收集汇总给人看」，无 LLM 意向打分、无自动 DM 追出去。
参考
「评论区=线索来源」已被企业级产品正式产品化，我们的「打分→DM→承接」闭环仍是代差；其客户画像即 Akke 未来上探对象。
灰产工具带 · 需求的反向验证

与功能①机制完全同构的产品确实存在：监控视频评论区 → 地区+关键词过滤 → 意向词识别（"多少钱""怎么买"）→ 自动关注/点赞/私信 → 推微信卡片，配随机话术/独立 IP 防封。但全是协议采集/模拟点击的违规脚本，几百-数千元/年，封号风险买家承担。三层含义：①需求被真金白银反向验证；②Akke = 这条链路的合规化 + AI 化 + SaaS 化替代（关键词规则 vs LLM 打分是代差）；③销售话术现成——「脚本封号 vs SaaS 长跑」。

抖音官方 · 持续监测项（二轮深调新增关键事实）

飞鱼CRM / 线索通 / 本地推私信留资组件是「花钱买线索再管理」的官方管道，不做自然流量评论挖掘，与我们互补大于竞争。但官方私信组件每次能力下放都在挤压第三方空间——需盯巨量引擎产品公告；同时有集成机会：Akke 挖到的线索回写飞鱼/企业号生态。关键新事实（第三方 0.8）：抖音开放平台 2025-04-14 起收回私信开放能力——新开发者永久停止申请私信/群聊 scope，90 天无调用的存量应用回收。走官方接口的对手（来鼓/美洽/螳螂）靠存量服务商资质运营，政策再收一档即断粮；我们的自有通道既是合规风险自担、也是不受此收口影响的自主性。

尘锋 SCRM（dustess.com）

SCRM 侧最贴身 · 已进二轮深调

唯一把家装列为头部场景的头部 SCRM——家装家居 / 汽车 / 教育 / 消费医疗 / 金融五大主打。

机制
AI 打标签、AI 生成跟进记录、AI 质检、AI 下一步行动建议、流失风险监测；销售 SOP 自动安排跟进。二轮深调修正：2025「AI 员工」已宣称可 AI 代发激活沉默客户（厂商自述，案例集中在教育/医美，家装场景 AI 代聊案例未查到；自动触达渠道限企微/外呼私域内）。
抖音端
只有承接没有开源（置信度 0.8）：抖音能力=广告落地页表单→一键加企微 + 广告线索回传，不碰自然流量评论区、不主动私信。
定价
第三方口径：标准版 840-1,200 元/人/年按坐席阶梯（会话存档另计）；小装企 5-10 席年成本约 5k-13k 起，AI 员工另售（报价未查到）。
打法
「我们把客户从公域捞进来，尘锋管的是已进私域的客户」；门店老板（无销售团队）vs 尘锋的多人销售团队客群；家装案例对比（它的爱空间案例停在 2023 素材转发量层面）。
商业化锚点 · 三个可直接引用的数字

① 微伴：SMB 企微工具心理价位 6,000-10,000 元/年/套——高于此档必须讲成「省一个人力」而非「多一套工具」。② 快商通「营销套电」验证家装老板愿为「拿到电话号码」付钱——按有效留资讲故事比按消息条数好卖。③ 智齿公开的「准确率 87% / 人工介入降 42%」指标框架，可直接借来做 Akke 企微接待的效果口径（我们对客叙事目前缺硬指标）。

Actions

给产品开发的七条动作建议
  1. 加速功能①的情报层（0.85）——Clay（ARR $150M）vs 11x（真实 $3M）证明赢家在情报层不在执行层。意向打分/号源挖掘做成可计价资产（按富化条数/线索质量），不做赠品。
  2. 功能②补「信任仪表盘」（0.75）——借 Megaview 会话评分卡思路：给每段 AI 企微对话打质量分给老板看，解决「敢不敢让 AI 替我聊」的信任卡点。这比堆对话能力更能促成交。
  3. 功能③召回触发器升级（0.7）——借循环智能方法论：用会话信号（客户提过的预算/工期/犹豫点）触发召回，替代纯时间间隔；按线索阶段配不同召回策略（卫瓴生命周期思路），替代统一模板二触。
  4. 功能④守住两个全行业弃权点（0.8）——知识库冲突消解与版本管理，第一批九家弃权、本批 42 家依然无人做。对外叙事抄 Gong：「你店里每天几百条对话在生产训练数据，Akke 把金牌话术沉淀成 AI 资产」。
  5. 集成而非对抗（0.7）——线索回写飞鱼CRM/企业号生态（降切换成本+对冲官方挤压）；对接云立方/亮宅等装企 ERP（它们管签单后，我们管签单前，同一个老板的钱包）。
  6. 竞争 FAQ 三张牌（0.85）——对美洽/螳螂：「它们接的是已经来私信的人（存量），我们挖的是评论区里还没私信的人（增量）」；对三维家：「它帮你发视频，我们把评论区的人变成客户」；对灰产：「脚本封号 vs 合规 SaaS 长跑」。
  7. 平台风险双源监测（0.7）——抖音官方私信留资组件每次能力下放都在挤压第三方；灰产泛滥可能引发平台风控收紧殃及池鱼——但灰产被清场同时也是机会窗口。
