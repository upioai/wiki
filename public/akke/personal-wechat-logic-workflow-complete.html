AKKE · 新人小白｜逻辑与工作流总图

个人微信自动化完整框架

执行端：Windows 电脑 + 安卓 APK。整条链路包含：真实客户首触（1 条话术 + 2 张图片）、真实客户新消息自动回复（根据用户内容调用企业大脑积木）、自动截屏提取历史画像、客户未回复自动召回。

1. 先看总工作流

客户进入好友通过/确认可联系
自动首触话术 + 图片1 + 图片2
客户发消息设备发现红点
自动截屏识别文字、方向、身份、历史
企业大脑组装按内容调取知识积木
自动回复发送并确认结果
超时未回复进入召回候选
自动召回再核验、再发送、再回写
一句话：事件触发 → 自动截屏 → 后端判断 → 企业大脑选积木 → 设备执行 → 结果回写 → 进入下一状态。

2. 参与角色和分工

角色负责什么不负责什么
Windows 电脑操作电脑端官方微信，识别新消息/首触任务/召回任务，发送文字和图片，回读结果。不决定客户是否有效，不自己编业务话术。
安卓 APK操作安卓官方微信，截屏、识别、首触、自动回复、召回和发送确认。不绕过安全规则，不自行修改企业大脑内容。
后端 API/Cron保存会话和画像，判断首触/回复/召回条件，创建任务和去重锁。不直接点击手机；不替设备伪造“已发送”。
企业大脑按用户问题检索和组合报价、环保、产品、流程、预约等知识积木与话术模块。不在没有用户内容时随意编造事实。
人工负责人配置账号、审核高风险话术、处理异常、决定放量和急停。不需要逐字抄录自动截屏结果。

3. 数据和状态框架

客户状态

新进入 → 待首触 → 已首触 → 已回复 → 跟进中 → 召回候选 → 已召回 → 停止/退订。

任务状态

created → claimed → executing → sent_confirmed；身份不一致、超时或失败则 skipped/failed/stopped。

画像状态

截屏采集 → 自动识别 → 候选事实 → 写入 customer_profile 和 context_summary → 回复/召回读取。

三条硬规则：同一客户同一动作要去重；没有发送证据不能记成功；客户回复、拒绝、退订或人工暂停后必须停止召回。

4. 首触逻辑：1 条话术 + 2 张图片

触发条件

  1. 联系人身份已确认，是真实客户。
  2. 没有成功首触记录，没有其他设备领取。
  3. 账号在线、未停止、未在黑名单/冷却期。
  4. 通过白名单或负责人授权范围检查。

执行顺序

  1. 发送欢迎/承接话术（单气泡）。
  2. 发送配套图片 1。
  3. 发送配套图片 2。
  4. 分别确认三件内容，再写入首触完成。

漏图、错图、错序、发送不确定或身份不一致时，不自动补发，整次首触转人工。

5. 真实客户新消息自动回复

发现新消息Windows/安卓 APK
自动截屏聊天区和联系人标题
读取上下文当前消息+最近对话+画像
调用企业大脑匹配知识积木和业务规则
组装候选回复按阶段和销售身份
发送确认右侧气泡+输入框清空

企业大脑积木示例

  • 用户问价格 → 报价/计价积木。
  • 用户问板材环保 → 环保/品牌积木。
  • 用户问什么时候量尺 → 流程/预约积木。
  • 用户要资料 → 对应资料卡片积木。

拦截条件

图片/语音、群聊、身份不确定、价格冲突、投诉、退款、停止联系或积木未命中时，跳过或转人工，不强行发送。

6. 自动截屏提取历史画像

  1. 设备自动打开目标客户会话并截屏。
  2. 识别文字、时间、左右气泡和联系人身份。
  3. 按时间顺序提取城市、面积、预算、户型、风格、已报价、资料和到店承诺。
  4. 自动更新 customer_profile、context_summary 和处理状态。
  5. 人工只确认客户身份、修正明显误读；不上传截图、不伪造消息、不补写没出现的字段。

7. 自动召回逻辑

判断顺序检查内容动作
1. 有效性未拒绝、未退订、未投诉、未停止否则停止
2. 时间上次我方消息后超过设定未回复时间未到期就等待
3. 配额每日/每小时/单客户次数未超限超限跳过
4. 去重无其他设备 claim，发送指纹未使用只允许一个执行端
5. 内容读取画像并调取企业大脑召回积木生成召回并发送确认

8. 部署工作流

Windows

  1. 登录官方微信，窗口保持可见。
  2. 运行 selfcheck.bat。
  3. 用 start.bat 开启演习 + 白名单。
  4. 测试首触三件套、真实客户自动回复、自动截屏和召回。
  5. 日志与真实手机结果都通过后，再由负责人切换真发。

安卓 APK

  1. 安装负责人提供的 APK，绑定销售身份和设备。
  2. 登录官方微信，保持联网和屏幕常亮。
  3. 先用安全模式测试截屏、企业大脑命中、首触、回复和召回。
  4. 确认 APK 能发送文字和两张图片并回写结果，再扩大范围。
ADB 只属于技术调试/设备连接层；新人按“安装 APK → 登录微信 → 绑定 → 空跑验收”操作。

9. 验收和异常闭环

首触：话术、图片 1、图片 2 都成功且顺序正确。
回复：企业大脑命中记录与用户问题对应。
召回：到期生成任务，设备只被一个端领取。
画像：自动截屏识别，匹配正确客户。
发送：右侧气泡、输入框清空、无错误标志。
异常：错人、错图、重复或不确定时立即急停。
Windows 急停：在 app\windows-weixin\state\ 创建 STOP。
安卓 APK 急停：在 APK 控制页点击“停止运行”。
内部培训资料：个人微信执行端为 Windows + 安卓 APK；业务动作包括首触（话术+2图）、企业大脑积木自动回复、自动截屏画像和自动召回。
