一、这是什么？

DailyLoop 是 Softie 的自动化数据监控管线，每天早上 北京时间 08:00 自动运行：

Meta 广告 数据库 Clarity 行为 PostHog 漏斗
↓
汇总分析 + AI 需求引擎
↓
飞书卡片推送 + Bitable 看板写入

你不需要做任何事情，它全自动运行。以下内容只在需要排查问题或手动触发时参考。

二、每天会收到什么？

在飞书「Softie 产品自动化群」中，每天会收到一张数据卡片，包含 6 个板块：

板块内容关注什么
一、广告投放Meta Ads 展示、点击、花费、CTRCTR < 1% 或状态非"投放中"需关注
二、核心业务新增/活跃用户、消息量、收入环比箭头，↓ 表示下降
三、用户行为Clarity 行为数据Dead Click / Rage Click 异常高需排查
四、付费漏斗PostHog 全链路转化订阅转化率 < 30% 或支付失败增多
五、产品需求AI 自动生成的优化建议REQ-P0 开头 = 紧急问题
六、代码提示词对应需求的技术修改建议给工程师看的，可忽略
卡片颜色含义

红色 = 有紧急问题（P0）   橙色 = 多项待优化   蓝色 = 一切正常

四、手动触发报告

如果当天没收到报告，或者需要随时手动运行：

方法 A：GitHub 网页一键触发 推荐

1 打开 GitHub Actions - Daily Data Monitor
2 点击右上角 "Run workflow" 按钮
3 在弹出的下拉框中保持 main 分支，点击绿色 "Run workflow"
4 等待 2-3 分钟，飞书群里就会收到数据卡片

方法 B：命令行（需要开发环境）

# 预览模式（不实际推送，只打印数据）
pnpm tsx scripts/daily-data-monitor.ts --dry-run

# 正式推送
pnpm tsx scripts/daily-data-monitor.ts

五、常见问题排查

Q: 今天没收到报告？
  1. 打开 GHA 运行记录，查看最近一次运行状态
  2. 如果显示红色 failure，点进去看日志找错误原因
  3. 常见原因：数据库连接超时、API Token 过期、PostHog 配额限制
  4. 如果状态正常但没收到卡片，检查飞书群是否被折叠/屏蔽
Q: 报告里某个板块显示"未配置"或"采集错误"？

说明对应数据源的 API Token 过期或缺失。需要到 GitHub Secrets 更新对应的密钥（见下方密钥清单）。

Q: 数据看起来不对？（活跃用户为 0、收入异常等）
  1. 先到 www.softie.ai 确认网站正常运行
  2. 检查 Fly.io 应用状态是否 running
  3. 如果网站正常但数据异常，可能是查询逻辑问题，联系工程师
Q: 广告数据一直显示"未配置"？

Meta Ads API Token 需要定期刷新（约 60 天过期）。需要有 Meta Business Suite 管理员权限的人重新授权并更新 META_ACCESS_TOKEN。

六、数据源密钥清单

所有密钥存储在 GitHub Repo Secrets 中，以下是各数据源需要的密钥：

数据源密钥名获取方式过期策略
数据库 DATABASE_URL Fly.io PostgreSQL 连接串 不过期
Clarity CLARITY_DATA_EXPORT_API_TOKEN Clarity Settings → Data Export API 不过期
PostHog POSTHOG_API_KEY PostHog → Settings → Personal API Keys 不过期
POSTHOG_HOST 固定值 https://us.i.posthog.com 不过期
POSTHOG_PROJECT_ID PostHog → Settings → Project ID 不过期
Meta Ads META_ACCESS_TOKEN Meta Business Suite → System User Token ~60 天过期
META_AD_ACCOUNT_ID 格式 act_xxxxxxxxx 不过期
META_CAMPAIGN_ID Meta Ads Manager 中的 Campaign ID 不过期
飞书 Bitable LARK_APP_ID 飞书开发者后台 → 应用凭证 不过期
LARK_APP_SECRET 同上 不过期
飞书推送 LARK_SOFTIE_AUTO_WEBHOOK 飞书群设置 → 机器人 → Webhook 不过期
⚠️ 需要定期检查的密钥

META_ACCESS_TOKEN 是唯一需要定期续期的密钥。如果广告数据板块突然变成"未配置"，大概率是这个 Token 过期了。

七、Bitable 数据看板使用

每天的数据会自动写入飞书 Bitable（多维表格），方便做趋势分析。

1 打开 Bitable 数据看板
2 每行是一天的数据，按日期排序，最新的在最上面
3 关键列含义：
  • 新增用户 / 活跃用户 — 核心增长指标
  • 消息总量 — 用户粘性指标
  • 当日收入_USD — 营收
  • 订阅转化率 — 付费漏斗效率
  • 产品需求分析 — AI 生成的优化建议（长文本，点击展开）
4 可以新建视图（仪表盘/图表），选择"新增用户"和"日期"列创建折线图追踪趋势
