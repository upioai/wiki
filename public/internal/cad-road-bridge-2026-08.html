01
Domain Walkthrough

一条路是怎么被设计出来的

五段业务链。经纬坐标在首尾两端都是刚需，中间全程泡在 CAD 里。

01 · 可研选线在 CGCS2000 地形上比选走廊带，经纬度→工程坐标
02 · 设计平纵横CAD 宿主 + 专业插件（纬地 / EICAD）完成线形与断面
03 · 交付出图DWG 图纸 + 逐桩坐标表 + 工程量清单
04 · 施工放样坐标反算 → 全站仪 / RTK 把设计钉到大地上
05 · 收尾竣工竣工测量、变更归档、资料移交
断点

03 与 04 之间没有数据通道——设计成果锁在桌面软件的私有格式里，施工员靠手工抄录曲线要素进手机和全站仪。坐标系转换（经纬度 ↔ 高斯平面 ↔ 独立坐标系）贯穿两端，是全链条共用的确定性内核。

为什么右上角是空的

没有公开的路桥图纸 / BIM 训练集，数据全在握有几十年图纸库的央企设计院手里——所以落地形态是「设计院自研 agent」而不是「通用大模型下沉」。可行架构已被两边验证：LLM 调专业 CAD 内核（中交 RD-Agent、Bentley MCP agent），而不是让模型直接吐图。

READY能直接站上去的

  • 线形几何内核：Clothoids + libOpenDRIVE / RoadManager，还能 WASM 进浏览器
  • 坐标系统：PROJ + GeographicLib，中国坐标系全覆盖
  • DXF 全链路：读写 + Web 渲染，MIT / MPL
  • IFC 4.3 交付：alignment API 已能程序化出成果
  • 验算引擎：Pynite；业务逻辑参考 BridgeLink

VOID完全空白 · 要自己长的

  • JTG 规范校核：超高过渡、视距、平纵组合——开源实现为零
  • 横断面工程化：边坡 / 路基 / 排水 / 土方参数化装配，无任何项目
  • 桥梁参数化建模：沿线形按里程布墩布跨，全是课程作业
  • 施工放样 / 逐桩坐标：测设工具链没有开源沉淀
  • 中文生态整体缺席：中文小仓几乎全部无 license、停更，法律上不可复用
结论

开源地基把「几何 + 坐标 + 格式」这三层白送了——自研成本从一支团队降到一个内核工程师。真正要投入的是 L4：JTG 规范逻辑与中文工作流，而这层恰好也是竞品的护城河与用户的付费点。

设计端：关系型采购，窗口关闭

路线「纬地 vs EICAD」、桥梁「桥博 + Midas」，加密狗模式二十年未变。新玩家直接卖桌面软件给设计院基本没有入场资格。

施工端：长尾但真付费

「几十万下载 × 几十元客单」的市场。测量员验证了免费圈量 + 按工程类型模块收费；头部之外产品普遍算不准。

平台层：国产替代正在换血

AutoCAD 律师函维权常态化 + 信创，让「中望 / 浩辰 + 国产插件」成为可采购现实；但适配有时滞——纬地官方支持的还是中望 2023 版。

AI 新势力：独立创业公司缺位

建筑领域有小库、品览，路桥领域零家独立初创拿到融资——AI 化被华设、中交等设计院系内部孵化垄断。

05
Product Entry Points

五个切入点，面向施工员和个人设计师

共同原则：避开设计端正面战场，从巨头不屑做、设计院系做不好的位置进。

E1 · 放样工具专业级测量放样 App

头部之外差评集中在「算不准、导不出」；桥梁高墩、钢构安装等高价值模块空白。以计算正确性 + 规范条文溯源立品牌。

免费圈量 + 模块收费（已验证）

E2 · 数据直通设计文件一键上手机

解析 DXF / LandXML / 纬地 EICAD 导出成果 → 云端 → 手机放样。两端厂商都没跨这条沟，施工员还在手抄曲线要素。

按项目收费 · 中间层

E3 · 生态填缝国产 CAD 细分插件

中望生态里路线双雄已入驻，但排水、交安、征拆图表、工程量清单等长尾细分稀疏。跟着信创换血潮进场，渠道成本低。

生态分发 · 插件订阅

E4 · 计算云轻量桥涵计算云服务

桥博 / Midas 是数万级加密锁，裁员潮下接私活的设计师只能用破解版。常规梁桥 / 涵洞验算是 AI + 规范库最可行的自动化对象，千元级年订无人做。

云端订阅 · 天然防盗版

E5 · AI 助手施工技术交底 / 规范问答

施工端 App 全部止步于「计算器」；规范查询、交底生成、变更台账是 LLM 现成场景，且可挂靠 E1 已有的下载量渠道卖第二件产品。

LLM 增值层 · 订阅
与 02 章空位的关系

E1–E3 是确定性工具（坐标转换、线形反算、图表生成——代码能答的不用模型）；E4–E5 才是 AI 层。先用工具挣现金流和渠道，再把 AI 空位（市政审图、桥涵计算 agent）压上去。

06
Commercial Feasibility

商业上有没有可能：有，但不在卖设计软件

行业分母在缩，但施工端相对抗周期，个人付费已被验证，正版化在制造换血预算。

TAILWIND结构性利好

  • 施工 / 运维端相对抗周期（存量路网仍要养护放样）
  • 正版化律师函 + 信创 → 设计院有真实换血预算
  • 个人付费已验证：¥30–45 买断有真实付费记录
  • 政策强推：2024 起新开工国家高速原则上交 BIM 成果
  • AI 审图在市政路桥是公认空位（房建厂商未覆盖）

CONSTRAINT关键约束

  • 只有云端计算 / 账号订阅形态能在盗版环境自保
  • 个人端客单价被盗版锚死在几十元，走量不走价
  • 设计端入场资格 = 院所渊源，外来者只能做生态位
  • 测量场景对计算正确性零容忍——错一次口碑归零
  • 关键竞品定价多未公开，测算需实地询价补全

RISK三大风险

  • 盗版天花板：从 3 万的纬地到 45 元的 App 全链条有公开破解版；历史上桌面交付均在数月内出现破解（观察口径）
  • 行业下行：公路固投连续两年负增长（−5.7%），设计企业 −3.1%、从业者 −5.2%
  • 巨头下探：广联达（收鸿业）、华设（狄诺尼）、中交设计（OSIS）三组「巨头 + 设计院系」向平台化下探
判断：中国市场有商业可能，但可防御位置不在「卖设计软件」——在施工端长尾 + 个人云端订阅。以设计院为付费方是在跟一个萎缩的分母抢钱；以施工员和个人工程师为付费方，是在一个盗版打不到的形态里做已被验证的生意。
07
Suggested Route · If We Build

如果要做：先工具，后 AI

六步递进，每一步自带现金流验证，不赌终局。

P1
滩头 做施工放样工具（E1）切入：复用测量员验证过的「免费圈量 + 模块收费」，以算得准立品牌
P2
内核 沉淀坐标 + 线形引擎：CGCS2000 / 高斯投影 / 七参数转换 + 平纵横线形反算，站在开源地基上（见 03 章）
P3
直通 打通设计→施工数据通道（E2）：解析 DXF / LandXML / 纬地 EICAD 导出 → 云端项目空间 → 手机与全站仪
P4
商业化 全线走云端订阅 + 账号体系：计算在服务端，防盗版是形态问题不是法务问题
P5
上探 用同一内核反向做中望 / 浩辰生态插件（E3）：排水、交安、清单等长尾细分，吃信创换血红利
P6
AI 长线 数据与渠道就位后压上 AI 层（E4 / E5）：桥涵计算 agent、市政审图空位、施工规范问答
