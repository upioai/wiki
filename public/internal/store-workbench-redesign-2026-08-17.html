02

现在长什么样，差在哪

当前是一套暖纸色的「教程式」界面：编号树导航（1 / 2 / 2.1 / 2.1.1）、大标题 + 一段说明 + 「预计用时 15 分钟」、右侧操作要点。排版本身是干净的，问题在于它把工作台做成了说明书。

维度现状参考里的做法
首屏落到「检查机器人与客户的聊天示例」——一上来就是一件活先看数据概览：今天做了多少、效果怎么样
导航四级编号树（2.1.1 / 2.2.3），23 屏平铺一级模块 + 模块内 2–4 个入口，编号不外露
数据散在 4 屏里（接待效果、跟进效果、任务看板、审核台），没有汇总一屏总览，模块屏只放该模块细节
客户客户信息散在「找出今天最值得跟进的客户」列表 + 聊天检查两处一个客户 = 一个档案页，聊天与画像并置
内容生成7 屏线性向导，每天都要从第 1 步走到第 7 步能力卡入口，想做哪件点哪件
视觉暖纸 #f0eeea + 黄铜色，无主色，状态靠文字紫色主色，状态靠色块/进度条一眼可读
要保住的东西

现在这套界面有三样别的产品没有的东西，改版必须原样带过去：①「真实数据 / 示例数据」逐屏角标；②机器人每句话下面的「出处 · 含 2 个企业大脑积木」可追溯链路；③后台没有的数字明写「本页还没接通后台」而不是补零。这三条是产品的诚实性底线，不是可选装饰。

水流那套的核心不是「紫」，是白底 + 单一主色 + 大圆角卡 + 足留白。主色只干三件事：选中态、主按钮、进度填充。语义色（绿好 / 橙注意 / 红风险）独立于主色，不混用。

哪些数字现在真的查得到

你要的「社媒平台发布的内容数量及数据效果」这一条，得先摊开说清楚。下面每一行我都在代码里核过，标了出处。

想显示的数字查得到吗依据 / 为什么
私信发出数 · 有回复数 · 跳过数（分渠道）查得到outreach_events，见 touchStats()，已分页取全
企微接待漏斗（新增→有回复→说需求→约到店）查得到receptionFunnel()，四级都有确定事件
实际到店永远查不到发生在线下，后台没有记录点。现在的实现就是显示「—」并写明原因，保持不变
今日新增线索 · 高意向 · 待检查查得到todayDigest()，东八区自然日口径
视频产出数 · 制作中 · 待审查得到content_posts / content_assets / sw_video_jobs
参考视频（选题池）的点赞/评论/收藏/分享查得到videos 表四列都在，取数层已 select
我们自己发的视频的点赞/评论/分享查不到content_posts 只存了 douyin_post_url，没有任何回流指标列。要做得先在 Akke 那边加抓取和列
播放量全链路都没有取数层注释写着：videos 表确实没有 play_count，抖音开放接口不给
新增粉丝 · 主页访客查不到没有对应的表
快手 / 小红书 / 视频号 / 头条没有链路本仓只有抖音 refs + 抖音发布，其余平台一条数据都没有
这决定了总览屏能长什么样

参考图一那六格 KPI（视频数 / 播放量 / 点赞 / 评论 / 分享 / 新增粉丝）里，我们只能真实填出「视频数」一格。参考图二那条五平台横条，我们只有抖音一条。

所以图 1 的总览屏我按能查证的口径重画了：把「平台触达」换成「私信有没有人理」，把「用户反馈」换成「客户走到哪一步」。这两栏的每个数字都能点到源头。

如果你要的就是参考图那种效果数据看板，那它不是一个改 UI 的活——得先在 Akke 侧加发布后的数据回流（抓自己账号发出去那条片的互动数），本仓才有东西可显示。这是一条独立的、跨仓的排期，我可以单独出方案。

08

怎么分期做

三期，每期自己能验收、能单独上线。推荐先只做 A 期——它是这三件里唯一能在一屏内讲完、当天能看到效果的。

A 期今日总览 + 主题切换✓ 已完成
  • 新增「今日总览」一屏，落成工作台首屏（图 1）；数据全部来自已有的 touchStats / receptionFunnel / todayDigest，不需要新建表、不需要动 Akke
  • 换掉 :root 那 87 行 token，全站一次性转到紫色语言；671 处硬编码 hex 先扫描列清单，只收敛首屏和导航能看到的那些
  • 侧边栏编号从四级（2.1.1）收到两级，编号不外露
  • 验收标准：打开工作台第一眼是数据不是任务；总览上每个数字点得到源头屏；旧的 23 屏一屏不坏
B 期客户档案依赖 A 期的视觉层
  • 把现有「检查机器人与客户的聊天示例」和「找出今天最值得跟进的客户」两屏合成一个客户档案页（图 2）
  • 新增：阶段进度条、三卡评分、下一步关键动作 / 卡在哪、跟进记录时间线
  • 评分与「下一步该干什么」需要一次 LLM 调用——走已有的工作台 LLM 封装，按屏计费入账（注意别写成 usd: null）
  • 不做：在这个页面上直接发消息给客户（那是 wecom-chat 仓的活）
C 期创作台 + 剩余 671 处配色收敛体量最大
  • 短视频获客首屏改成能力卡（图 3），7 屏向导保留为「家底没齐」的引导路径
  • 素材库 / 成片库拆成独立货架页
  • 把剩下的硬编码配色全部收进 token，消除夹生状态
另一条独立排期（不含在 A/B/C 里）

发布效果数据回流——让我们自己发出去的片子能查到播放/点赞/评论。这条要动 Akke 的抓取和建表，跨仓，跟本次 UI 改版没有依赖关系，可以并行也可以先不做。做不做取决于你多想要参考图那种效果看板。
