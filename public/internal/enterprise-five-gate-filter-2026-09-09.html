结论

两条，只读这一屏也够做决定

  • 主推

    把「线索生产 + 微信接待」打包成按有效对话结算的获客交付

    卖给家居建材连锁总部 / 工厂的门店体系，不卖给单店。计价单元不是线索（太水）也不是成交（周期长、归因扯不清），是交到销售手上、客户已回复且留了联系方式的对话。构件都在（客户回复有效性判定、抖音会话↔企微联系人的手机号桥、后台交接页）A，但还没有合成一个可直接对外结算的计数——这是要做的第一件事。五闸过 4 条，唯一卡点是规模经济（单客户交付成本），上线前必须先量这一个数。

  • 重新定位

    企业大脑别当「Agent 上下文层」卖，绑在有赔付单价的结果上卖

    按我们自己的五闸，「上下文层」是最弱的一条：没有客户已有的单价、钱在 IT 预算、且钉钉与飞书 2026-03 双双开源 CLI（10 项核心能力 / 2500+ API，原生支持 Claude Code）B正把它变成平台免费能力。六道证据链硬闸真正卖的是「不赔钱」：报价单 / 合同 / 方案书里每条数据可溯源——一次报错要赔多少，客户自己知道。

不做，以及为什么

通用 AI 客服 / SCRM 席位订阅——价格已被砸穿，没有定价权。 AI 外呼——四条侵略性判据全中，但《消保法实施条例》第二十四条把主战场判死。 数字人直播工具——卖铲子的赚钱，用铲子的近七成不赚钱。 招投标 / 财税 / 报关结果外包——五闸全中，是真好生意，但与我们现有资产零重叠，等于从零开始。

口径更正

口述框架与仓内口径的三处出入，外加一处漏项

内部口述的「三条业务线」框架和仓内落地物有出入，而且漏了最大的一条，所以先核框架本身再过闸。下面每条都指到对应的落地物，可以逐条推翻。

  1. 口述：抖音的自动化回复

    仓内口径是「抖音获客与线索生产」

    项目 README 第一行A。私信只是链路里的一环，且写的是「起草 → 人审 → 发出去 → 交给销售」，不是自动回复。这个差别决定了能不能按结果卖：按线索/对话卖得通，按「回复」卖不通——没人给「回了几条消息」定价。

  2. 口述：企业微信的自动化回复

    现役界面口径是「微信接待」，「自动」是团队自己删掉的

    门店工作台驱动界面的注册表里，销售模块的标签 = 「微信接待」A；README 那张表还写着「02 企微自动接待」，是它自己没跟上改名。删「自动」的理由是现阶段每天仍要人工逐条检查B。对外说「自动回复」等于把团队刚纠正过的过承诺又写回去。

  3. 口述：企业大脑

    有两套，能卖的是对外那套；且其中部分屏还是示例数据

    对外交付的在门店工作台里（其中部分屏读的是公开行业语料快照，页面上标着「示例数据」）A；另一套是内部 Agent 自用的知识库B。报价前必须知道是哪一套。

  4. 口述里没有的：

    还漏了两条可卖的，而且是「客户已有单价」最清楚的两条

    短视频获客和沉默客户跟进A。门店知道自己现在拍一条视频花多少、跟进一个沉默客户花多少——这正是第一条硬标准要的东西。反倒是「企业大脑」那条最难定价。

判据

在中国，「具备侵略性」是四件很具体的事

侵略性不是增长快，是能把别人正在收的钱直接吃掉，而不是让客户新增一笔预算。四条同时满足才算。

  • 一 · 钱从人力预算出，不从 IT 预算出走 IT 立项要排期、要比价、要过信息部；从人力预算出是业务负责人自己签。这是闸 3 的全部意义。
  • 二 · 客户内部已有这个单价不用教育市场。他知道一条线索多少钱、一个坐席多少钱、一次交付多少钱，你只需要报一个更低的数。
  • 三 · 验收数字长在第三方后台巨量本地推后台、到店核销、入职人数、平台成交额。不用扯「效率提升了 40%」——那种话客户听过太多次了。
  • 四 · 巨头不会免费做原因只有三种：伤自己的收入、有合规风险、太脏太重。第三种最安全，因为它不会随巨头战略变化而消失。

按这四条，最锋利的两种形态

  • 按有效线索 / 到店结算的获客交付——吃代运营公司和投放服务商的钱。我们在这条上。
  • 按成交 / 入职 / 案卷结算的专业结果外包——吃外包公司和中介的钱。与我们现有资产不重叠，不在本页范围。
窗口

这个时间节点独有的三件事

「最大杠杆」不等于最好的生意，等于此刻做比半年前做和半年后做都更省力的那件事。下面三条都有明确的时间戳。

窗口一 · 平台正在重组线索入口，家居建材在第二批

巨量把 AD 的「销售线索」能力分批下线，全部迁到巨量本地推：第一批 2026-01~02（婚纱摄影、体检、心理咨询），第二批 2026-03~04 覆盖家居建材、教育培训、旅游B。本地推按「兴趣 + 距离」找人，门店核销、到店打卡、好评、复购全部计入投放效果权重。

为什么是窗口：所有做家居建材抖音获客的服务商都得把投放链路重做一遍，客户此刻正被迫换供应商——这是抢客户成本最低的时刻。而「到店核销计入权重」恰好给了闸 2 一个第三方验收源。

这条必须自己核一次。六个来源口径一致但都不是巨量官方原文，且有一源说的是「3 月底下线、6 月底完成切换」，日期有分歧。开口报价前去巨量后台看一眼当前账户还有没有 AD 线索目标，这比任何转述都硬。

窗口二 · 合规刚补齐，「可审计」第一次能当卖点

三条法规在一年内先后落地：《人工智能生成合成内容标识办法》2025-09-01 生效A，而且2026-04-28 网信办真的执法了——对「剪映」App 等未落实标识要求的平台约谈、责令改正、警告、从严处理责任人A；《直播电商监督管理办法》2026-02-01 施行，AI 数字人主播必须持续显著标识，出问题由直播间运营者承担全部责任A；《人工智能拟人化互动服务管理暂行办法》2026-04-10 五部门联合发布、2026-07-15 已施行A。

为什么是窗口：同行在裸奔。我们手里那些平时算成本的东西——人审闸、演习模式、六道证据链门禁、可回滚可暂停的机队下行——现在是资质。而且这类东西没法临时补，只能提前有。

窗口三 · 按结果计费已被头部验证，不用教育市场

北森的 AI 应用产品签约 8700 万元，传统 SaaS 只有 2100 万元——AI 新签是传统产品的四倍B。客服市场客户本来就按结果买（按 case 0.3 元/会话起、GMV 提点、HC 计费）B。报价方式可以直接换。

反面参照，而且就在我们行业里：群核科技（酷家乐）2024 年收入 7.55 亿元，96.9% 来自十年前那套订阅；2025 年新的空间智能业务收入只有 520 万元、16 家客户、占总营收 0.6%A。家居行业最大的软件玩家，讲 AI 新故事换不来收入。这条数据的含义很直接：在这个行业里卖 AI 工具不成立，卖结果才成立。

三处必须自己再核一次，别直接拿去报价
