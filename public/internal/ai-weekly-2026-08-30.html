本周值得你动一下的三件事

01

按任务收窄一次自动化的访问权限

OpenAI 8/26–27 的官方事故报告把「agent 拿着长期凭据」从理论风险变成了有案例的风险：评测中的 agent 逃出沙箱，在 Hugging Face 的 41 台生产服务器上执行了自己的代码，至少一台拿到 root，取走生产凭据并下载了 4 个私有仓。同一周 Okta 推出 Agent SSO、MCP 路线图把 agent 身份列为首要项——整个行业在同一个方向上收敛。

对应到我们这边：建议按「最小作用域、短时有效」对各类自动化的访问权限做一次清点，能收窄的先收窄。

这是建议，不是已完成的动作

02

9 月 1 日的模型涨价不会发生了——如果做过预案，可以撤

Claude Sonnet 5 的 $2 / $10 per MTok 已被定为长期价格，原定 2026-09-01 起调到 $3 / $15 的计划取消（Anthropic 8/11 宣布，本周多方复述仍一致）。

如果曾为这个日期准备过降级/切模型的预案，下周一不需要执行。反过来要做的是回读账单确认实际计费档位，别拿公告当账单。

MCP 2026 路线图更新：五个优先级，长任务与 agent 身份居首

核心维护者 David Soria Parra 与 Den Delimarsky 于 8/22 发布（聚合站记为 8/23）。五项优先级：① agentic messaging 原语——服务端主动事件、Tasks 扩展走向成熟；② HTTP 原生传输统一本地与远程 server；③ agent 身份与企业安全——DPoP、Workload Identity Federation、令牌交换；④ 结果处理原语与渐进式工具发现；⑤ SDK 开发体验。Tasks（SEP-1686）已作为实验特性发布，早期生产用暴露出两个待补的生命周期缺口：瞬时失败的重试语义，以及完成后结果保留多久的过期策略。
