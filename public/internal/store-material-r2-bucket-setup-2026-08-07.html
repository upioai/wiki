开通门店素材私有 R2 存储桶 · 操作交办（2026-08-07）

一句话

在 Cloudflare 上建一个私有的 R2 桶，叫 <门店素材桶>，再生成一把只能读写这个桶的钥匙。 全程在网页后台点，大约 10 分钟。

这是干什么用的

我们做了一个给门店店长用的工作台。店长要往上传素材——门店实拍视频、出镜人的形象照、 录的语音样本。这些文件得有地方放，就是这个桶。

现在的状态是：功能写完了，桶还没有，所以线上点上传会提示「存储服务暂不可用」。 桶一开通就能用。

最关键的一条：桶必须是私有的

这条如果搞错，后面全白做，所以单独讲。

把桶想成一个仓库。我们的设计是：仓库大门锁死，谁也不能直接进。店长要看一段视频时， 我们的服务器当场开一张通行证给他，写明「只能取这一个箱子、10 分钟内有效」，过期作废。

如果桶设成了公开的，等于大门敞开——任何人只要拿到文件地址就能下载，而且永久有效， 没有过期这回事。文件地址会出现在浏览器历史、网页源码、服务器日志里，流出去太容易了。

而桶里装的是客户的人脸照片和录音。

所以：建桶时公开访问那几个开关一个都不能开（默认就是关的，别去点开它）。

注：我们账号下已有的 <已有公开桶> 是公开桶，不能拿来用。必须新建一个。

操作步骤

第一步：建桶

  1. 进 Cloudflare 后台 → 左侧菜单 R2 → Create bucket
  2. 桶名填：<门店素材桶>
  3. Location 选 Asia-Pacific (APAC) —— 用户都在国内，就近
  4. 建好后进这个桶的 Settings，确认下面三项（应该本来就是这样，核对一遍）：
    • Public access = Disabled
    • Custom domains = 空的
    • R2.dev subdomain = Disabled

第二步：配跨域（CORS）

还在这个桶的 Settings 里，找到 CORS Policy，粘贴这段：

JSON
[
  {
    "AllowedOrigins": ["https://<门店工作台域名>"],
    "AllowedMethods": ["PUT", "GET", "HEAD"],
    "AllowedHeaders": ["content-type", "content-length"],
    "ExposeHeaders": ["etag"],
    "MaxAgeSeconds": 3600
  }
]

（浏览器直接往桶里传文件需要这个，不配的话上传会被浏览器自己拦下来。）

第三步：加一条清理规则（建议做）

同样在 Settings 里 → Object lifecycle rules → 新建一条： 前缀留空，勾 Abort incomplete multipart uploads after 1 day。

原因：大视频是切成小块传的。传一半用户把页面关了，就会留下一堆碎片—— 列表里看不见，但照样按容量计费。没这条规则，这些碎片会一直躺着，谁也发现不了。

第四步：生成钥匙

R2 页面 → Manage R2 API Tokens → Create API token

填什么 值 为什么
Token name <素材桶专用 token> 将来要换或要停时，一眼认得出是哪把
Permissions Object Read & Write 别给 Admin。Admin 能建桶删桶，而这把钥匙要放在公网服务器上
Specify bucket Apply to specific buckets → 只勾 <门店素材桶> 万一泄漏，波及面到此为止，碰不到别的桶
TTL Forever 我们这边没有自动换钥匙的机制，设了期限就是埋一个「某天突然全挂」

创建完页面会给三样东西，只显示这一次，关掉就再也看不到：

  • Access Key ID
  • Secret Access Key
  • S3 API endpoint（长这样：https://<一串账号ID>.r2.cloudflarestorage.com）

做完之后

要发回来的东西

上面那三样。但别用微信或邮件直接发明文。

按方便程度选一个：

  1. 最好：如果你有这个项目部署平台的权限，直接你自己设，钥匙不用经任何人的手：

    BASH
    fly secrets set --app <应用名> \
  R2_ENDPOINT="https://<账号ID>.r2.cloudflarestorage.com" \
  R2_ACCESS_KEY_ID="<Access Key ID>" \
  R2_SECRET_ACCESS_KEY="<Secret Access Key>" \
  R2_MEDIA_BUCKET="<门店素材桶>"

    设完命令会自动重启服务，等它起来就行。然后告诉我一声「设好了」即可。

  2. 没有 Fly 权限的话：用 1Password / Bitwarden Send 这类一次性分享链接发过来， 或者当面 / 语音念。

怎么知道成功了

四个值配上去之后，服务会自己重启。然后：

  • 打开门店工作台的「素材上传」页，选个文件传一下
  • 传完刷新页面，卡片还在、点开能预览 → 成了

如果还是提示「存储服务暂不可用」，多半是四个值里有一个粘错或粘漏了半截， 让我这边看一眼服务器日志就能定位到是哪一个。

有个已知的不确定项

R2 走的是 Cloudflare 的网络。我们还没在国内实测过浏览器能不能直接连上它传文件。

这个项目在这件事上吃过亏：整站原来部署在 Vercel，本地测一切正常，国内打不开， 最后整体搬到了东京的服务器。所以「没实测过就都不算数」是我们的默认态度。

万一实测下来国内连不上 R2，我们代码里已经准备了备用通道（文件先经我们服务器中转再进桶）， 切换只需改配置，不用你再动 Cloudflare。所以这条不影响你现在的操作，先按上面做就行。
