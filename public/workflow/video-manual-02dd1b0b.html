视频制作标准手册

团队做一条获客短视频，从找爆款到交付复盘的标准做法。本页是总纲：先选做法，再走九步；每步的细节链到已有页面，不在这里重写。团队内部用，含内部花费，不直接转给客户。

先选做法九步流程分工红线技术规矩花费和用时现有材料请你定

1先选做法：这条片子怎么做

同一个行业，有的片子必须用客户的真货实拍，有的可以全部用 AI 生成画面。做法决定后面九步怎么分工、花多少钱。第①步找爆款时先初判，第②步拆完原片再定下来（看源片是不是对着镜头讲、评论区在意什么，要拆完才清楚）。

做法什么时候用怎么做成熟度
实拍 + 我们剪辑观众最在意货对不对版、质量、当场测试效果；客户至少有 2 人能拍（出镜 1 人 + 拍摄 1 人），而且主播愿意整条出镜我们写拍摄脚本 → 客户照着拍、原片全部发来 → AI 辅助整理原片、人来定用哪一遍 → 我们剪。用主播本人声音，跳过第⑤⑥步。见 实拍流程试行：渔具第一条正在拍，还没出成片
真人口播复刻源片是对着镜头讲的定点口播，我们有主播的真人底片和本人同意真人底片打底 + 重写口播 + 音色克隆 + 对口型（douyin-replica）已有团队 skill
AI 生成画面卖的是观点、知识、案例效果（如装修前后、设计方案），客户没人能拍按分镜生图 → 图生视频 → 配音、字幕、拼接。见 AI 生成画面 8 步产线已出片，见 案例视频复刻总览
混合有必须用真货证明的镜头，但客户出不了整条口播（没人愿意出镜、或口播要换语言）口播和衔接用 AI 主播（第⑤⑥步照做），测试和质量证据镜头让客户只拍手和产品试行：渔具做过一版样片
按顺序问三句① 观众要不要看真货证据（测试、尺寸、做工）？要 → 证据镜头必须实拍：客户能整条出镜走「实拍」，只能拍手和产品走「混合」。② 源片是不是定点口播、有没有主播底片？是 → 走「真人口播复刻」。③ 都不是 → 走「AI 生成画面」。
开工前先备齐客户的产品资料、价格截图、规格表；本条的花费上限和报价；要用谁的形象或声音，先拿到本人同意。

2九步流程：每步谁做、用什么、怎么算过

下面每步标了谁来做：产品同事 定方向、对客户、拍板验收；制作同事 用 Claude Code 和团队 skill 做片（skill 是装在 Claude Code 里的团队技能，在 Claude Code 里直接说「用 dy-hit-finder 找……」就会调用）；客户 出资料、实拍、发布。AI 做出来的结果都要人复核。

①找爆款产品同事制作同事
做什么
  • 在客户要发的平台上找同类产品的高播放视频，读评论区：观众在问什么、担心什么、有多少人想要
  • 挑 2–3 种客户做得出来的拍法
用什么
抖音 dy-hit-finder（按评论区想要的人数挑）· 小红书 xhs-case-filter · 抖音调研页 dy-trend-research（按 7 步评估能不能复制）· AI 热词 ai-trend-scout · 拆一个账号前 3 条 analyzing-case-accounts
产出
候选清单：链接、播放 / 点赞 / 评论、评论区想要的人数、拍法归类
怎么算过
按评论区想要的人挑，不按点赞挑；挑出来的拍法客户拍得出、我们做得出
②拆解制作同事产品同事
做什么
  • 取原片（去水印）
  • 出分镜稿和解说词，并判型：判断源片属于上面哪种做法，在这里定下做法
  • 原片里有测试动作的，逐镜列一张表：测试动作 / 证明什么卖点 / 怎么复刻，标出必须实拍的
用什么
video-dl 取片 · douyin-deconstruct 出分镜稿 + 解说词 + 判型
产出
分镜文字稿、判型结果、测试动作表
怎么算过
测试动作表先和产品同事对齐，再写稿；不在脚本里悄悄删测试
③写稿产品同事制作同事
做什么
  • 复刻片：写一页需求文档——原片靠什么火（核心流量元素 ≤3 条）、必须保留的（≤5 条）、红线一句话
  • 实拍片：写拍摄脚本——每个镜头在哪拍、怎么拍、说什么、拍几遍，标出必拍
  • 口播稿过一遍投放规范：价格、绝对化用语、AI 声明
用什么
拍摄脚本样例（渔具） · 抖音投放规范（家居定制）
产出
需求文档 / 拍摄脚本 / 口播稿
怎么算过
产品同事确认；实拍脚本由客户先试拍 1–2 个镜头，确认声音和构图后再拍全套
④备素材客户制作同事产品同事
做什么
  • 实拍：客户先发价格截图和规格表，测试用多重由我们按规格回复，回复之前不拍测试镜头（定错会断货、伤人）；每个镜头开拍前报镜号和第几遍；原文件走网盘或聊天软件的「文件」发，不从相册直接发（会压画质）；有安全要求的写进脚本（如渔具：周围 10 米内有电线不拍）
  • 客户拍完不挑不剪、原片全部发来（含拍坏的）；我们用 AI 先听写、把原片对到镜头、初筛，人定用哪一遍，缺的镜头一次性列给客户补拍
  • AI 生成：按分镜生图，先人看底图再转视频；改了提示词先试 3 张再跑全部
  • 字卡、数据图、价格表、封面这类不需要真人的镜头用代码画，不交给模型生成
用什么
实拍见 实拍流程 ⑤ · 生成见 AI 生成画面产线
产出
可用素材 + 补拍清单（如有）
怎么算过
每个镜头都有一遍能用的；补拍清单人确认后再发客户
⑤配音（实拍片跳过）制作同事产品同事
做什么
  • 克隆主播音色（经本人同意），或用合成配音；实拍片直接用主播现场原声
  • 同一主播克隆过的音色直接复用，不重复克隆（克隆一次 $1.5）
  • 送去对口型之前，每段音频测一下音量：静音的音频模型照样收费、照样返回，只是嘴对不上
用什么
douyin-replica 自带音色克隆
产出
逐句配音文件
怎么算过
人听一遍：字没念错、价格数字对、语气像真人说话
⑥对口型（只有口播类做）制作同事
做什么
  • 对口型＝让画面里人的嘴型和新配音对上。只有口播类（真人口播复刻、混合片里的 AI 口播、对白短剧）需要；实拍片和全程画外音的片子跳过
  • 数字人只做露脸那段，画外音部分不做
用什么
douyin-replica（真人底片 + 唇形）· realistic-host-gen（AI 真人口播）· douyin-short-drama（多人对白）
产出
口型对好的口播段
怎么算过
肉眼看不出嘴型和声音错位；分段做完拼回去后总帧数和配音时长对得上
⑦剪辑制作同事产品同事
做什么
  • 按爆款的结构排镜头，先出初版，人来调节奏
  • 加字幕、价格大字、购物车 / 商品提示
  • 渔具实拍片（发 TikTok）成片不加背景音乐，客户发布时从商业音乐库选，避免版权问题；别的平台按各自规则
用什么
实拍见 实拍流程 ⑥
产出
成片初版
怎么算过
节奏和字幕人看过；价格、规格和客户实价一致
⑧自查验收制作同事产品同事
做什么
  • 按验收单逐项看：技术基本面 8 项（清晰度、稳定流畅、AI 瑕疵、人物自然度、场景道具连贯、口型同步、声音、字幕）+ 爆款流量元素 10 项
  • 复刻片交付前再查三样：重复帧（卡顿）、字幕（每个出镜循环抽首、中、尾 3 帧看有没有被擦或残留）、空镜里有没有残留原主播
  • 按发布平台的规范自查一遍
用什么
复刻验收单 · 抖音投放规范（家居定制）
产出

⑨交付和复盘产品同事制作同事客户
做什么
  • 交成片 + 发布说明（要不要勾 AI 声明、挂哪款商品）；账号在客户手里的（如渔具），由客户自己发布，我们不代登

3分工：三种角色各管什么

角色负责
产品同事选做法、和制作同事一起写需求文档和拍摄脚本并拍板、对接客户和报价、看片验收、复盘定下一批
制作同事用 Claude Code 和团队 skill 找爆款、拆解、生图生视频、配音、对口型、剪辑、交付前扫描、出对照页；重复活交给 AI，每一步的结果由自己先看过再交
客户提供产品资料、价格截图、规格表；实拍片照脚本拍和补拍；核对成片里的价格和规格；账号在客户手里时自己发布、挂商品、选音乐
哪些环节一直要人实拍、测试用多重、价格规格最后核对、挑用哪一遍、补不补拍、发布——这些要人判断或要人在场，不能全自动。原因逐条见 实拍流程第 4 节。

4红线：碰了就返工或被平台处罚

  • 证明质量和效果的镜头只用本产品实拍（测试、实测、做工特写），不用 AI 画面顶替。AI 生成的「测试」是伪造的性能证据。
  • 测试不超过产品规格：同行超规格的暴力测试不学，测试重量由我们按规格表定。
  • 生成人物时不拿原片截图当参考图：实测会把原博主本人的脸复刻出来（肖像权问题），只用自有人像。
  • 未经本人同意，不用 AI 生成他人形象做推荐（抖音投放规范 其他规范第 19 条）。
  • 含 AI 生成内容的视频，发布时主动勾选「AI 生成内容」声明；不勾的，平台检测到会加「疑似使用了 AI 生成技术，请谨慎甄别」的标识。
  • AI 效果图不能叫「实景」「实拍」。
  • 同一套素材不剪几版同时发：10-29 三版同发被判内容同质、限流。
  • 画面里的二维码和完整联系方式逐张查：10-28 露出二维码，怀疑因此被限流。
  • 不用「最佳」「第一」这类绝对化用语，不贬低其他产品或平台。
  • 提到价格要和客户实价一致；家居定制类投抖加时，还要上传报价单、画面写定制单位、全程显示价格提示语（规范 第 1–2 条）。

二维码、同质限流、价格这几条出自抖音家居定制号的实际遇到，其他平台、其他行业发布前以当时的平台规则为准。

5技术规矩：做片的人必看

  • 切视频按帧数切，不按秒数切（ffmpeg 用 -frames:v，不用 -t）；分段对口型再拼回整条时，每段帧数＝「终点秒数×30 取整」减「起点秒数×30 取整」（先各自取整再相减，不是相减后再取整），否则越到后面嘴越对不上。
  • 拉伸画面时长只做小幅微调（10% 以内），拉得多会一顿一顿。
  • 不要声音的视频生成，要显式关掉声音（可灵 Kling v2.6 pro 实测：不关会自带音轨，5 秒按 10 秒收费）；视频时长按台词长度选，配音 ≤5 秒就交 5 秒。
  • 重跑之前先确认上一次真的停了、钱扣没扣：请求一发出就收费，结果没存下也照收。
  • 只修坏的那一镜，没问题的镜头直接复用，不整条重做。
