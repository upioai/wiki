可复刻的本地案例视频 · 本地高意向 > 50

同时满足四条才放在这里（完整标准可直接用作筛选 skill 的规则，见下方折叠）：① 视频；② 拍的是本地真实做过的一单（业主家、施工 / 交付现场、改造前后），不是工厂 / 展厅 / 门店；③ 本地高意向 > 50；④ 能按不同案例批量复刻：主体讲的是这一户，标题由这户的参数组成（小区 / 面积 / 户型 / 风格 / 总价 / 工期），画面从头到尾都是这一户的现场。把参数换成另一户，脚本照样能用，拍出来是一条新视频。门店服务广告、工艺讲解类即使评论多，也不放这里。

案例视频筛选标准（G1–G4，可做成筛选 skill）

先抽字段：类型、城市、这一户的参数（小区、面积、户型、风格、总价、工期、改了哪些空间、业主诉求）、按时间顺序的画面分段、视频主体（这一户 / 门店服务 / 工艺知识 / 设计理念）、评论（IP、文本、是否作者）。

G1 视频：图文不进本区。G2 本地真实一单：同一户的业主家、施工现场、交付现场或改造前后；完工实拍但没写小区，或改造前实拍 + 这套房的效果图，判「部分」，也算通过；工厂、展厅、样板间、门店判否。G3 本地高意向 > 50：同省 IP，问价、报面积求报价、要联系方式、问地址、问接不接或明确提出自家需求；按昵称去重，报保守下限。

G4 能按案例批量复刻：判法是把这一户的参数换成另一户，脚本骨架原样能用，而且拍出来是一条内容不同的新视频。三点都要满足：主体是这一户，不是公司流程、服务承诺或工艺科普；标题 / 开头至少带 2 个这户的参数；画面固定为同一户「前 → 过程 → 后」或「完工一镜到底」，不靠门店展板、通用讲解撑内容。

合格的 4 种复刻结构：时间戳跟拍一天（上海 1 天翻新厨房：小区门口开场 → 拆旧 → 安装打时间 → 保洁 → 完工）；交付日（郑州鑫苑城：进小区 → 对合同 → 逐间看）；一镜到底（长沙三室两厅：完工住宅边走边讲）；预算改造（上海 14W：总价 + 面积 + 户型变化开场 → 改造前实拍 → 户型图讲诉求 → 逐间效果图）。

不合格示例：上海 6 天局改厨卫（门店展板讲流程和赔付，案例只是穿插）、北京 7 天改卫生间（负责人讲工序，标题是通用问题）。这两条已于 10 月 20 日从本页移除。
