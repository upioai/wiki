抖加投放审核：我们遇到的拒审和要注意的点

整理于 2026-10-21 · 依据：巨量营销规则中心（ad.oceanengine.com/support）官方规则原文

先说结论
  1. 价格可以出现，但要同时做到三件事：后台上传报价单；画面上写清定制单位（平米数、米数或件数，我们用的「总投影面积」就是平米数）；整条视频全程显示提示语「具体价格以实际装修方案为准」或意思相同的话。我们核对的几条官方规则里，没有「不能出现具体价格」的说法。
  2. 「已装好」被拒，是因为没说清只做柜子。官方规则：只做家具、柜体的商家，用「全屋」「全包」「一站式」「装好一套房」这类说法时，要写明范围只限家具或柜体。审核员没点名是哪条规则，这是我们判断的对应关系。
  3. 原片能过、我们过不了，我们判断主要是审核场景不同（推断，见第三节）：普通发布不经过投放审核；家居建材的这几条投放规则，适用范围都写明包括 DOU+。
  4. 我们现在的投放版还有一处不合规：提示语只在出现价格的镜头里显示，规则要求「视频需全程显著体现」。

一、已经遇到的 3 次拒审

案例01 = 厦门海沧 7 个空间；案例02 = 厦门翔安自建房 9 个空间；第三条 = 厦门自建房 5 组柜子（内部叫「晋江」那条）。第 1、2 次拒审来自之前转来的拒审反馈，第 3 次来自审核截图（素材 ID 7698922661165927716）。

#拒审原因对应的官方规则现在的状态
1价格没带定制单位（例如只写「约3.3万」）《整装家具虚假一口价》第 2 条：提到价格，要在画面上显著写出定制单位，并和报价单一致已改价格同一句带上「总投影面积 xx㎡」
2缺提示语同一规则第 3 条：图片、视频、落地页都要加「具体价格以实际装修方案为准」或意思相同的提示语，视频要全程显著体现只改了一半已经加了「案例价格仅供参考，以实际上门测量报价为准」，但只在有价格的镜头里出现，没有覆盖全程
3画面、配音、字幕、标题里有「已装好」，被认为暗示软硬装全包（案例02，标题「9个空间已装好」）《家居建材整装定制服务内容要求》：只做家具、柜体时，用到「全屋」「全包」「一站式」「装好一套房」这类说法，要写明范围只限家具、柜体未改案例01、案例02 的配音、字幕、角标、标题里都有「已经装好了 / 已装好」；厦门自建房那条只有一句叙述「装好以后，业主说……」，风险较低，建议一起改成「柜子安装以后」

二、价格到底能不能出现

能，但有条件。规则原文（《素材规范调整—整装家具虚假一口价》，适用范围写明包括 dou+，2025-03-07 起执行）：

1. 素材宣传装修服务/全屋定制/家具的整装定制等，若提及价格，需提供报价单，且报价单需包含提供装修服务的主体、装修服务价格、定制单位（平米数、米数或件数均可），且主体、价格、定制单位此类信息需与素材宣传内容一致。
2. ……若提及价格，需在素材显著体现对应装修服务具体的定制单位信息（平米数、米数或件数均可），且需和报价单所含的服务价格、定制单位信息保持一致。
3. ……需在图片、视频、落地页添加【具体价格以实际装修方案为准】或相同含义提示语。（视频需全程显著体现）
官方举的可以通过的例子
  • 12999元搞定50平米家装
  • 几万左右，帮你装好10大家具
  • 不到几万的价格，定制60平米装修
  • 厂家活动，推出全屋定制，不到六百装修一平米
官方举的违规例子
  • 几万搞定全屋定制
  • 几万就可以装好一套房
  • 几万帮你定制几十平米

负责发布的同事说「不能体现具体价格」，我们核对的规则里没有这么写。下面两种情况都只是猜测，需要发布同事在后台确认：

  • 后台可能没有上传报价单。规则第 1 条要求提供报价单；如果没传，画面上带了单位也可能被拒。
  • 也可能是传话时说法被简化了。比如审核意见原本是「价格要合规」，转述成了「不能有价格」。

「约3.3万」这种约数本身不是问题：官方举的可以通过的例子里就有「几万左右」。规则的建议整改方案还写了：「单价不超过报价单提及单价」，也就是说，视频里宣传的单价不能超过报价单上的单价，主体、价格、定制单位都要和报价单对得上。

三、为什么原片能过，我们的不能过

这一节是我们根据规则做的判断，不是官方原话。

  1. 投放审核比普通发布多一道。上面两条家居建材规则的适用范围都写明包括 DOU+，也就是投放时会按这些规则审；普通发布不经过投放审核。原片作者如果只是普通发布、没有投放，就碰不到这些规则。另外，官方《DOU+内容加热视频场景内容管理规范》（2026-03-20 更新）的适用范围写着：「不包含DOU+直播场景及DOU+营销推广场景；如您有营销属性内容的加热需求，请先完成账号升级。」门店宣传自己的柜子和报价，我们判断属于「营销属性内容」，需要发布同事确认账号是否已经升级。
  2. 案例01 和厦门自建房那条的对标原片，来自小红书。这是我们之前筛选对标时的记录，它们不受抖音投放规则约束。
  3. 案例03 的福州原片是抖音上的普通作品（视频 ID 7636972155167314835）。我们看不到它有没有投放，所以不能拿它能过来推断我们也能过。
  4. 「已装好」这条规则比较新，2026-02-26 才开始执行。规则没说对之前发布的作品怎么处理，所以拿更早的视频作参照，不一定准。

四、其他要注意的点

标已核原文的，是我们打开官方页面逐字核对过的；标待核的，是调研时读到、还没二次核对原文的，先当提醒看。

1. 环保等级（我们的片子里有「ENF 级」）待核

家居建材行业审核规则（文档 128120）要求：环保、除醛率这类数据要有质检报告，不能写「0 甲醛」。我们 3 条投放版都说了「ENF 级」，投放前要准备好板材的检测报告或证书。另外，案例02 做发布文案时，门店资料里的板材写的是 EGGER / F★★★★，跟片子里的「ENF 级」不一致，需要门店确认。

2. 赠送、优惠、免费待核

宣传免费装修、抽奖要提供活动证明，写清活动时间和参与方式。这条出自 138812，适用范围写的是「AD-家居行业」，没写 DOU+。宣传半价、打折要上传活动证明。我们的「按每 3㎡ 投影送 1 个阻尼抽屉」属于赠送活动，官方没有专门写赠送这一项，建议按活动规则准备一份门店的活动说明。

3. 提示语要清楚可见待核

广告提示语规则要求：不能用大小字、低对比度、过小字号来弱化提示信息。我们现在的提示语约 32 像素高（1080 宽的画面），而且只在部分镜头出现。建议加大字号，并且全程常驻。

4. 效果图和 AI 生成画面待核

国家《人工智能生成合成内容标识办法》2025-09-01 起施行，要求对 AI 生成内容做显式标识。我们的效果图已经标了「效果图」，继续保持；巨量规则里没找到专门针对家居效果图的条文。

5. 没找到官方依据的几项

评论区「留所在区和墙宽」、前后对比、工期承诺、门店地址，这几项在巨量规则里没找到专门的规定，所以不在这里当成禁令。真被拒了，再按拒审原因去查对应的规则。

五、建议下一步

  1. 发布同事在后台确认两件事：① 账号有没有升级成可以投营销内容；② 有没有上传这几单的报价单。这一步决定价格能不能保留。
  2. 视频统一改三处：「装好」一律写明是柜子；提示语改为全程常驻，字号加大，文字建议直接用官方原句「具体价格以实际装修方案为准」；价格要和报价单对得上。
  3. 标题和正文同步改：去掉「已装好」；「ENF 级」等环保说法有证书再写。
  4. 如果确认后台已经传过报价单还是被拒，再出一版去掉金额、只保留面积的。
