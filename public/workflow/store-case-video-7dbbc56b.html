门店案例视频 · 怎么用

把一家装修 / 全屋定制门店的网盘资料（毛坯照、施工照、完工视频、平面方案、设计思路、报价单），照我们验证过的 8 个爆款剧本（结构一到八）之一，做成一条案例视频。原则：尽量照结构原样做，不加新花样；门店没给的东西不编。

启动口令 · Claude Code/store-case-video 网盘分享链接（带提取码）

不用飞书机器人、在自己电脑上用 Claude Code / Codex：先装一次

以下在「终端」里做；第一次建议找管理员陪你配，2–5 步可以直接让管理员配好。

  1. 装 skill（前提：装了 gh 并登录有 Akke-AI 仓库权限的 GitHub 账号，仓库是私有的）：gh repo clone Akke-AI/casecut ~/casecut && cd ~/casecut && ./install.sh 它会顺带拉下 dy-video-line（生图、配音、上传共用的工具），没有 Python 依赖就自己建一个。重开会话生效；Claude Code 一定装上，Codex 只有这台电脑装了 Codex 才一并装上。以后更新：cd ~/casecut && git pull。
  2. 开一个给它用的 Chrome（远程调试口 9222），在里面登录一次百度网盘（非会员就行），做视频期间别关：open -na "Google Chrome" --args --remote-debugging-port=9222 --user-data-dir="$HOME/chrome-casecut"
  3. 本机要有 ffmpeg、node、python3（opencv、Pillow 由上一步自动装）。
  4. 两组 key 找管理员要，放进本机配置文件，不进 git：FAL_API_KEY（生图、生视频、配音）、R2_*（素材存云端）。
  5. 体检：bash ~/casecut/doctor.sh 逐项打勾，打叉的那项后面写了怎么修；全打勾就能从口令一路出片。
  6. 之后的流程和飞书一样：确认页上生成的确认口令，贴回同一个 Claude Code / Codex 对话；成片和链接直接在对话里给。

你只要做 3 件事

其余都是 AI 和程序做。确认都在同一个确认页上，一共 2 轮（红色）。

1发启动口令

在飞书里给机器人发 /store-case-video 网盘分享链接（带提取码）（Claude Code 里输入同一句；Codex 里开头换成 $），顺带说一句报价、工期、公司名、小区名能不能写（不说就都不写）。第一次用前，用网盘 App 扫一下机器人发来的二维码登录网盘。

2第 1 轮：确认剧本

机器人发来确认页，页面上只有剧本：8 个可切换，标「推荐 / 可用 / 不适合」，默认选推荐的。选好点「生成确认口令」，把口令发回机器人。这一步同时批预算，点之前一分钱不花。

3第 2 轮：确认其他

机器人按剧本把议题、脚本、配音、效果图、分段、标题封面、整片都做出来，放进同一个页面。每项默认「可以」，不对的点一下写原因，再生成口令发回。有要改的只重做那几项。

三条硬规矩

花钱先报价、等批

预算列在确认页第 1 轮（按你选的剧本估：做什么、几张或几段、单价、合计），点确认就是批了这个总额度，第 2 轮要重做的也算在里面；超了停下来再问。第 1 轮确认之前不写脚本、不生图、不生视频、不配音。

不编

业主原话、价格、工期、公司名、小区名，门店没给就不写；口播里的每个数字都能指出出自哪份资料。

每版都发

成片按「第 N 版」发，同时说清这版改了什么、花了多少钱；制作页和成片一起换版。

每一步：谁做什么、你确认什么

下面按步骤号排；实际执行时配音（8a）和写脚本同时做，排在图片元素之前，见上面的流程图。底边红线的两步之后是确认页的第 1 轮和第 2 轮。

1

网盘链接 → 下载 → 存云端

发启动口令和网盘分享链接，程序把这一单的资料下下来、分好类、去重，存到我们的云端（R2），后面每一步都从云端取。

AI / 程序做

  • 程序在我们做视频那台电脑上、已登录网盘的浏览器里，把要的文件夹逐个「普通下载」：非会员也能下（北京680 实测，没弹验证）。一次只下一个（连点会被网盘限流，程序自动等一会儿再试）；非会员限速约 100KB/s，照片和文档几分钟，视频要一天以上，放后台慢慢下。中断后重跑，已下完的文件跳过；下到一半的那个文件要从头下
  • 程序下好的文件按文件夹和文件名分成毛坯照片 / 施工照片 / 完工视频 / 平面方案 / 设计思路 / 报价单等，完全相同的文件只留一份，传到云端，出一份素材清单；视频先传压缩版，原片之后补
  • AI读报价单、设计思路、聊天记录，登记这一单有没有总价、柜子尺寸、业主原话（第 2 步推荐剧本要用）
  • 程序网盘弹出验证就停下来交给人，不想办法绕。网盘用不了时的备用办法：飞书共享文件夹（要授权一次，还没试通），或把要用的文件插进一个专门的飞书文档发链接

你确认

  • 发启动口令 /store-case-video + 网盘分享链接（带提取码）
  • 顺带说一句：报价、工期、公司名、小区名能不能写进视频（不说就都不写）
  • 第一次用前，用网盘 App 扫机器人发来的二维码，登录一次网盘

AI / 程序做

踩过的坑（7 条）
  • 可灵任务提交后进程被杀：别删了重提（会扣两次钱），先按请求编号把结果取回来
  • 完工渲染别用 Seedream 4.5：会把机位拉远、凭空加吊顶
  • 统一渲染不写「不要任何灯」，模型会自己加吊灯和壁灯；暖斜阳、宣传册光感被否过
  • 字幕要在每个镜头里单独叠，整片一次叠几十段会不出字
  • 走代理传大文件会断：先试直连，还断就把文件压到约 2MB 以下再传
  • 片尾只有配乐时，转文字会凭空冒出重复的句子，引用前先看尾部
  • 页面发出前把页面里所有图片、视频地址逐个打开一遍，全部能打开才发链接
