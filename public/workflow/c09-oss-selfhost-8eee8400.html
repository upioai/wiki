开源自部署 GPU 能不能替代可灵？一镜到底实测

10-27 一天的实践记录：案例09 一镜到底的「真实质感」这一步原来用可灵（Kling O3 视频转视频，按秒付费），今天换成开源模型、在租来的 GPU 上自己跑，从 5 秒试片一直做到 85 秒整片，再和可灵版逐帧对比。本页按顺序讲：部署方案 → 生成效果 → 和可灵对比 → 最大的不足 → 评估结论。

$4.50开源整片 85 秒的花费（首帧出图 $0.90 + GPU $3.60）
$14–17可灵做同样一条：纯生成 $11.90（$0.14/秒 × 85 秒）+ 返工（事前估 $2–3，这次实际 $5.18）
3 处开源版画错的地方：2 处衣柜 + 卫生间隔断和窗，其中次卧二整面衣柜没画出来
不采用开源版不做成片，成片继续用可灵

几个词：白模＝只有形状、没有颜色材质的 3D 草模（Blender 手工搭）；深度图＝每个像素只记「离镜头多远」的黑白图，用来告诉模型房子的结构；视频转视频＝把白模走房视频整段交给模型，结构和镜头不动，只换成真实材质光影；首帧锚定＝先用 AI 出图工具（Nano Banana Pro）把白模第一帧画成一张真实照片，让模型照着这张照片的材质往后画；链＝从一个门洞开始、一段接一段连续往下画的几段视频。

1调研出来的部署方案

要做的事：把 Blender 白模走房视频换成真实质感，房子结构和镜头路线不能变。这是「带结构控制的视频转视频」。

选型：10-26 调研过的 7 项开源技术（3D 重建、单图生成走房、首尾帧补画面，见 制作过程页 第 1 节）都不是做这件事的。开源里能做的是阿里的 Wan2.1 VACE 14B：可以吃一段控制视频（深度图）决定结构，同时可以指定某几帧必须保留原图（用来做首帧锚定）。fal 上有它的托管版（$0.08/秒，85 秒约 $6.80），今天按要求改成自己租 GPU 部署（整片生成部分实付 $3.60）。

部署架构

本机 Blender白模沿路线渲出深度图，16 帧/秒，85 秒共 1361 帧
→
首帧出图Nano Banana Pro 把白模第 0 帧画成真实照片，$0.15/张
→
RunPod GPUWan2.1 VACE 14B 分段生成，每段 81 帧（约 5 秒）
→
本机 ffmpeg取回各段，拼接、调色、补到 24 帧/秒，加字幕和配乐

配置清单

GPU
RunPod RTX PRO 6000 Blackwell 96GB 显存（安全云，$2.49/小时）。选它是因为实测最高占用 68.8GB 显存（显卡内存），按这个推断 48GB 的卡跑不了 720p（没在 48GB 卡上试）
模型
Wan2.1-VACE-14B（diffusers 格式，约 75GB），每次开机从 Hugging Face 下载，3–8 分钟
加速
加一个加速插件（lightx2v），每段只算 8 步就出结果，原本要 30 步（步＝模型反复修图的次数，越多越慢越贵）。不加速的话估计每段约 30 分钟，比可灵还贵，没跑
运行脚本
自己写的脚本：模型只加载一次，按任务清单一段一段跑（底层用开源的 diffusers 库）
分辨率 / 速度
720×1280，每段 81 帧，生成 255–279 秒；按 $2.49/小时算，每段约 $0.18
控制方式
深度图（保结构）+ 首帧锚定（定材质）；每段用上一段最后一帧当第 0 帧，接着往下画
本机怎么控制它
本机开着 VPN，远程登录 GPU 服务器会被断开。改成服务器自己干活：开机时把脚本一起交给它，它自己下载素材、跑完任务，再把结果放在一个网址上，本机从网址取日志和成片。用完删机器，确认每小时花费回到 0

2生成效果：三轮

先拿开头 5 秒试控制方式，再试首帧锚定，最后跑 85 秒整片。

第一轮 · 5 秒试片：深度图结构准，但材质不听话 部分可用

同一段白模，试了三种控制：深度图 + 参考图、只给深度图、白模线稿 + 参考图。深度图那两版柜子、门洞的位置和形状都对（这一段玄关柜有凹进去放东西的格子和柜体边缘，深度图里看得出来；整面平板柜门就不行，见第 4 节）；但提示词写了「玄关是瓷砖」，照样画成木地板或水泥地，柜子上凹进去的格子也被改了。线稿那版自己编出带把手的玻璃门柜，直接放弃。5 秒开源每版生成费 $0.18–0.19（不含开机下载模型的时间），可灵 $0.70。

喂给模型的控制输入：左 深度图 / 中 白模线稿 / 右 白模原画面
从左到右：白模 / 可灵 / 开源 深度+参考图 / 开源 只给深度 / 开源 线稿（编出了玻璃门柜）

第二轮 · 9 秒：首帧锚定解决了材质 有效

光在提示词里写「瓷砖」没用。改成先用 Nano Banana Pro 把白模第 0 帧画成一张真实照片，交给模型当第 0 帧（这一帧原样保留），后面的帧仍按深度图生成。这样地面、柜子上凹进去的格子就都对了；第二段用第一段最后一帧接着画，接缝看不出跳。9 秒开源 $0.51（两段生成约 $0.36 + 首帧照片 $0.15，不含开机），可灵 $1.26。剩下的问题：颜色偏灰偏冷，生活感弱。

第三轮 · 85 秒整片：能做完，但结构错了 3 处 能出片 · 有硬伤

85 秒切成 4 条链（玄关→厨房 / 过道→次卧二 / 次卧一→卫生间 / 主卧），每条链的开头在门洞处，配一张首帧照片；链内每段接上一段末帧，一共 18 段。两台 GPU 并行，从开机到跑完各用约 38 分钟和 48 分钟（按账单计费时长）。首帧照片常常对不齐白模（把镜头推进房间、把关着的柜门画成没门的格子），C、D 两条链各重出了一次，必须和白模并排看过才能上 GPU。

4最大的不足：瑕疵和成本

瑕疵

致命柜子画错 3 处次卧二整面 4 门衣柜画成墙和门；次卧一衣柜丢了上下分缝；卫生间淋浴隔断和窗画成了白板 / 木格子。原因：深度图只记远近，平板柜门、窗户和墙在深度图里一样平，模型看不出这里有柜子，只能猜。可灵吃的是白模画面本身，柜门分缝看得见，所以没有丢柜子。我们卖的就是柜子，柜子画错等于卖点错。
修不掉墙面、柜门慢慢「流动」大概率是为了省钱用的 8 步加速造成的（没跑完整 30 步做对照），后期修不掉。换完整 30 步估计每段约 30 分钟，整片要 $20 以上（估算，没实测），就比可灵还贵了。
能补颜色偏灰、偏冷、偏暗链越往后越灰。整片调色能把平均亮度从 118 拉到 145，可灵是 159。
费人工误差会往后传每段都从上一段最后一张画面接着画，前面错一点后面跟着错；镜头绕开再回来的地方（玄关柜后面的客厅），抱枕、灯带等物件不延续。改一段要连带重画同一条链后面的所有段。
费人工首帧照片对不齐白模AI 出首帧时常把镜头推进房间、把关着的柜门画成没门的格子，每张都要和白模并排看，今天废了 2 张。
已处理补帧像果冻模型出的是每秒 16 张画面，成片要每秒 24 张。最初用算法补中间画面，运动的地方糊成一团、像果冻在晃（30 秒处厨房柜子），已改成把画面重复一次补齐，代价是轻微顿挫。

成本

可灵 85 秒（含返工）$14–17
开源完整 30 步（估算）$20+
开源 8 步整片（实测）$4.50
补那 3 处（估算）约 $1.5

「补那 3 处」：次卧二在 B 链、次卧一和卫生间在 C 链，按改一段要重画同链后面所有段算，最多重画 8 段（B 链 3 段 + C 链 5 段），生成费约 $1.4，加上开机下载约 $1.5；而且深度图看不出柜门，补了也不一定画对，没实测。

  • 绝对金额不大：一条大约省 $8–11（可灵 $14–17，减去开源 $4.50 + 补错 $1.5），但要人盯：出首帧、逐张对白模、开关 GPU、取回拼接、逐帧找错。今天整片这一轮从出首帧（12:2x）到 GPU 跑完出原片（13:2x）约 1 小时，之后还要调色、加字幕，前面两轮试验另花了一上午。
  • 要先充钱：RunPod 先充值、按小时从余额里扣，机器忘了删会一直扣钱（今天每次都删了，现在每小时花费为 0）。

5评估结论

不采用：开源自部署不做成片，成片继续用可灵。

  • 硬伤在结构：整面衣柜都能丢，这是深度图控制方式本身的问题，不是多花钱就能修好的。
  • 真实感和稳定性差一档（观感）：颜色调色能补；「流动」变形在 8 步设置下后期补不了，是不是加速造成的没验证。
  • 省下的钱不抵人工：一条大约省 $8–11，换来更多返工和盯梢时间。今天可灵版的返修（过道 3 次 + 过渡镜头 4 次）合计 $5.18，已经把可灵版修到能用（74 秒版干净；82 秒版卫生间镜子画成窗没修）。

什么时候可以再看

  • 开源模型能直接吃白模画面（看得见柜门分缝）做控制，而不只是深度图的时候。
  • 复测方法已经现成：同一段 9 秒白模 + 同一套首帧锚定 + 和可灵并排对比，一次实付约 $0.6–0.9（含开机下载）加首帧 $0.15，脚本都在。
