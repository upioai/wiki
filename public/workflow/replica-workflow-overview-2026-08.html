01 / End-to-end

生产一步，
独立审核一步

目标不是“片子做完后多跑几道检查”，而是每个阶段一完成就冻结版本，由另一套进程判定。生产者可以自检，但没有正式放行权。

02 / B-roll subsystem

B-roll 不是一个库，
而是一条闭环

它既包含进货、切段、标注与安全审，也包含真实生产里的检索、裁切、选择和回流。库里没有合格镜头时，正确结果就是“没有”。

01

入库

  1. 装修素材进货
  2. 按镜头边界切片、归并成段
  3. 写镜头主题与可证明内容
  4. 人脸、水印、授权与源片邻居安全审
  5. 生成语义向量并导出正式库
02

检索

  1. 从口播提取画面需求
  2. 向量召回 + 真实判例加权
  3. 同源打散与同片去重
  4. 安全过滤与相似度及格线
  5. 返回 Top-3 或明确报没有
03

使用

  1. 人工或规则选择实际使用镜头
  2. 按竖屏构图裁切，不擅自擦画面
  3. 检查原片复用、陌生脸与段内切镜
  4. 生成分镜与完整素材清单
  5. 冻结 B-roll pack 与哈希
04

回流

  1. 记录 used_good / rejected
  2. 缺货自动进入 gap log
  3. 错配进入常设回归考卷
  4. 人工判例校准阈值与排序
  5. 补货、重标或生成，再回到入库
R2 清单仍有 14 条增量漂移

技术入库不等于真实可用

安全放行、语义对题、竖屏可裁、没有源片复用，必须同时成立；真实匹配质量仍要由生产 E2E 证明。

没有合格镜头必须报没有

向量检索永远能排出第一名，但第一名不一定能给口播当证据；不能用弱相关画面填空。
