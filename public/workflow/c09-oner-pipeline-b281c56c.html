4走房路线 完成

在 3D 户型里规划一条只走真实门洞的镜头路线。镜头每次只往前走一小步，后面的模型就没有机会再「编」出不存在的门。红线是最终路线，蓝块是 5 处柜子，绿点是起点，红点每 10 秒一个。

房间顺序：入户 → 玄关·鞋柜 → 餐厅 → 客厅 → 厨房 → 过道 → 次卧二 → 次卧一 → 卫生间 → 主卧 → 主卫 → 主卧

程序路线脚本定 49 个关键点，镜头在点之间平滑移动；镜头高度、走路速度、转头速度都按真人拿手机设
人工夏夏提意见：要有卫生间；餐厅和客厅不能是一个画面（AI 按意见改路线）

5灰模审路线 完成

真实质感按秒收费，所以先发不花钱的灰模走房视频，路线、房间顺序、口播和配乐都在这一步定下来。

v2 / v3 反馈：音乐要轻松一点（选 C 尤克里里）；要有卫生间；去掉右上角的小户型图。
第一版真实质感出来后的反馈：还是太假；窗外风景假；凳子挡在门口人进不去；客厅镜头一转就变样。→ 写了一个「真人视角」检查脚本，按人拿手机走的标准逐帧查路线：旧路线 40 多处问题（穿过餐桌茶几、转头太快、倒着走、走太快等）。
程序检查脚本：查撞家具、穿墙、转头超过每秒 45 度、走路超过每秒 0.9 米、倒退横移
程序改路线：挪开餐桌、每个房间朝一个方向慢慢转、镜头换成接近手机 0.7 倍、加手持晃动
人工夏夏看灰模和第一版真实质感提意见

v4 路线复查：撞家具 / 穿墙 / 倒退 / 走太快 0 处，只有 1 处转头略快（每秒 46 度），全片 85 秒。

6真实质感 完成 · 留 2 处瑕疵

把灰模走房视频按过门处切成 8 段，整段交给 Kling O3「视频转视频」：结构和镜头运动全部来自 3D 白模，模型只换材质和光影。每段拿上一段最后一帧当参考图，前后不变样。

选型：三种做法对比（开头 10 秒）

从左到右：白模 / A Luma 紧贴白模（像效果图）/ B Luma 放开改（把房子改了）/ C Kling O3（结构不变、像手机实拍，采用）。更早的「逐张出图 + 首尾帧」做法镜头一转就变形，已放弃。
