01
The Coordinate System

一条内容变成一单生意，要过六道关

「AI 生成营销视频」和「AI 挖客户」听上去是两件事，其实是同一条链路的上下游。把这六道关摆出来，市面上每一家公司都能找到自己的位置——而且你会发现，没有一家公司占满整条链。

① 生成
内容 拍片或让 AI 出片。Arcads / Creatify / 即创 / 可灵 站在这里，也是热钱最多的一段
② 分发
投放 把片子推到人眼前——花钱投流，或靠自然流量。这一段完全属于平台（抖音 / Meta / TikTok），第三方插不进去
③ 有人
留言 观众在评论区留下「多少钱」「哪里买」「我家 120 平能做吗」——意图第一次公开暴露
④ 认出
谁想买 从几百条「沙发不错」里挑出那几条真想买的。这是判断题，也是本文的题眼
⑤ 主动
搭话 私信过去说第一句话。整条链最窄的一道关——窄不是因为技术，是因为平台规则
⑥ 聊到
成交 多轮对话、答疑、报价，最后留下联系方式或下单

// 读完全文你会看到：①②被平台和资本挤满，③是公开的，④⑤⑥是一道墙。而墙的位置，是 Meta 和抖音的 API 文档划出来的。

The 13× Gap · 全文最硬的一个数字

AdCreative.ai：约 2 倍 ARR 退出。Synthesia：约 27 倍 ARR，估值 40 亿美元。

同样是 AI 视频公司，估值倍数差了 13 倍。区别只有一个：AdCreative 做广告创意，直接站在 Meta 和 TikTok 的射程里；Synthesia 做的是企业内训视频——平台完全不感兴趣的地方。它 2026 年 1 月拿了 2 亿美元 E 轮，Alphabet 旗下 GV 领投、英伟达 NVentures 跟投，ARR 约 1.5 亿美元。

这个价差就是市场对「被平台挤压风险」的定价。同样躲开射程的还有 HeyGen——它最出圈的能力是视频翻译与口型同步，一个平台不管的跨境场景。

还活着的三家在卖什么

Arcads（法国巴黎，2024）：1000+ AI 演员库，35+ 语言。2025 年 12 月拿 1600 万美元种子轮，Eurazeo 领投。官网定价页返回 404，必须注册才看得到价。ARR 传闻在 1000–1500 万美元量级，但全部来自自称或转述，无第三方核实。

Creatify（美国，2023）：输入产品链接出数字人广告。2025 年 5 月拿 1550 万美元 A 轮（WndrCo + Kindred 领投），官方通稿称突破 900 万美元 ARR。定价免费版起，Pro $99/月。

Topview：定价 Pro 约 $16/月起，全线常年挂 44–68% 折扣——定价权很弱，获客靠打折。它官网明列自己调用的是 Seedance 2.0 / Kling 2.6 / Veo 3.1。这条很关键，下一段会用到。

平台下场 · 用的是同一个模型

TikTok Symphony 是官方的 AI 创意套件，官方原文写着「对所有已登录的 TikTok for Business 营销者全面开放」，而整个官方页面上没有任何定价。它的底座是字节自研的 Seedance / Dreamina 2.0。

请把这条和上一段连起来看：Topview 在向用户收费转售的 Seedance 2.0，正是 TikTok 官方随广告账户提供、且从不标价的同一个模型。第三方在这一层没有任何技术差异，只剩一层工作流封装。

还有一条实锤：Captions 在 2025 年 1 月转成免费增值模式，公开给出的理由就是「为了和字节的 CapCut、Meta 的 Edits 竞争」。2026 年 3 月它索性改名 Mirage、转型成 AI 研究实验室——从「和平台在同一个战场卖工具」撤退到「做模型」。

诚实标注

我们没有找到任何一篇公开报道，明确把某家公司的关停归因于 TikTok Symphony 或 Meta Advantage+。专门搜过，结果为空。上面列的是结构性证据和公司自己的选择，不是「已有 X 家倒闭」这样的因果断言。另：Meta Advantage+ 的各项数字本次只查到二手博客来源，未能拉到财报一手确认，因此本页不引用。

合规 · 这条是硬的

《人工智能生成合成内容标识办法》2025 年 9 月 1 日起施行（网信办、工信部、公安部、广电总局四部门联合）。对视频的要求是：

① 显式标识——必须在视频起始画面和播放周边的适当位置加显著提示；② 隐式标识——文件元数据里要埋服务提供者名称、内容编号等信息。两个都要，不是二选一。③ 发布内容的商家自己也有主动声明义务；恶意删改、伪造、隐匿标识违法，为他人提供洗标工具或服务同样违法。

抖音已上线 AI 内容标识与元数据标识功能：你不主动标，平台会用技术手段检测疑似 AIGC 内容并替你加上提示。所以「AI 生成的片子伪装成真人拍摄」这条路，在明面上走不通。

未证实

网上广泛流传的「即创免费、每账号每天 100 次额度」，只有 AI 工具导航站这类来源支撑，官网抓不到价格页，我们未能证实，因此本页不把「官方免费」当作事实前提。另外「标识须占屏幕 ≥10% 面积」「未标识限流 7 天」「数字人直播须真人实时操控」等说法，均只在 SEO 博客中出现，未能用官方信源核实，本页一律不引用。

04
The Missing Evidence

AI 生成的广告，到底打不打得过真人？

这是所有人最想知道的问题。我们两路调研（海外、国内）各自独立去查，得出了同一个答案——而这个答案本身，比任何一个数字都值得写下来。

结论

公开渠道找不到任何独立第三方做过的「AI 素材 vs 真人拍摄」效果对照研究。一份都没有。

市面上流传的每一个「AI 广告 CTR 高 X%」的数字，追溯下去无一例外全部来自卖相关工具的厂商自己，或它们的联盟营销伙伴。

整张表里，只有「CTR +10%」是一个平均值，而不是挑出来的单个案例——恰恰因为它不夸张，反而是最值得信的一个量级。

如果这个量级是真的，它指向一个和厂商宣传完全不同的结论：AI 素材的价值主要在「同样预算能跑更多条素材做测试」的数量优势，而不在「单条更能打」的质量优势。

最强的证据不是数据，是有人用脚投票

一家拿着顶级 VC 的钱、花 1200 万美元买下 icon.com、以「AI 广告制作者」为品牌的公司，现在把「100% real / not AI」印在定价页上，卖 $999 的真人拍摄广告。

如果 AI 素材真的能打，一家 AI 原生公司没有任何理由退回到雇真人、寄样品、指导拍摄这种又重又难规模化的模式。这一条的信息量，超过上面表格里所有数字的总和——因为那是一家公司拿自己的生死做的选择，不是一篇软文。

05
Outreach · Global · The Wall

断裂点不在技术，在 API 文档里

海外确实有一堆公司在做「社媒挖客户 + AI 自动聊」，但没有一家做成完整闭环。原因不是做不到，是平台不让——而且平台把这件事写在了公开文档里。

Meta 的三条铁律 · 官方开发者文档原文

铁律一：企业不能主动发起对话。原文是「Only after an Instagram user has sent your app user's Instagram professional account a message can your app send a message to the Instagram user」——用户先私信你，你才能私信用户。没有例外。

铁律二：24 小时窗口。用户发消息后开启 24 小时窗口，窗口关闭后 API 直接拦截。有意思的是，突破这个窗口的唯一例外叫 human agent tag——它要求有真人在回。也就是说，「人在环」恰恰是 Meta 认可的合规姿势。

铁律三：所谓「评论区转私信」的真面目。它靠的是一个叫 Private Replies 的窄口子，被锁死三条：只能回你自己内容下的评论（不能回别人帖子下的）、一条评论只能换一条私信（永久上限）、7 天内必须发完。

TikTok 的口子比 Meta 还窄

TikTok 官方公示的 Messaging Partner 全名单只有 9 家：Blip.ai、Halosis、Haravan、Pancake、Qiscus、Respond.io、Zwiz、Gupshup、Infobip。这份名单本身就是结论——9 家全部是客服会话管理／电商客服／CPaaS 类型的进站（inbound）工具，没有一家是评论区线索挖掘或主动外呼工具。

更直接的证据来自 HighLevel 的官方支持文档：TikTok 的 Interactive Messenger 不支持「Reply as DM」／「Reply to Comment via DM」，unlike FB & IG，并标注 pending TikTok API support。一家体量巨大的正规厂商，在自己官方文档里承认：Facebook 和 Instagram 能做评论转私信，TikTok 做不了，因为 API 不给。

KOLens · 竞品自己踩了刹车

  • 新加坡公司，做 TikTok / Instagram 评论区购买意向检测
  • 已经把「找到谁想买」这一步做出来了
  • 但主动放弃自动私信，只做告警，把人交给人工去点发
  • 理由写在自己博客里：「TikTok 没有官方 DM 自动化 API，非官方自动私信工具会让账号有风险」
  • 一家竞品用自己的产品决策，替所有人验证了这条路的终点

Devi AI · 同款机制，被赶到文字社区

  • 用 LLM 逐条读帖子判断 Buying Intent / 投诉 / 咨询 / 广告
  • 挖的是别人的地盘——官网明写「不用当 Facebook 群管理员就能监控它」
  • 生成个性化回复草稿，人点一下才发
  • $49/月，覆盖 Reddit、Facebook 群、LinkedIn、X、Telegram……
  • 唯独不覆盖 TikTok 和 Instagram——因为文字社区没有那道私信铁闸

Nectar · 拿了船票，就得守规矩

  • 2026 年 5 月 3000 万美元 A 轮，Menlo Ventures（与 Anthropic 合办的 Anthology Fund）领投，GV 跟投
  • 创始人是前 Meta 高管姐妹俩
  • 靠 Meta / TikTok / LinkedIn 的官方数据合作拿数据
  • 有 LLM 判意向 + 个性化触达 + 人在环审核，还覆盖短视频平台
  • 但只能在品牌自有域内做进站——合作协议的代价
一个漂亮的悖论

Nectar 拥有完整闭环所需的全部技术特征，却恰恰因为拿到了官方船票，所以做不了主动挖陌生人。而 Devi 能挖陌生人，是因为它待在 Reddit 和 Facebook 群这些管制弱的文字社区。

换句话说：在海外，你要么合规但只能接住自己找上门的人，要么去挖陌生人但只能待在管制弱的平台。你不能两者兼得。平台管制的强度，决定了什么物种能在哪里活。

顺带说说 AI SDR：看着像，其实是另一个物种

11x（Alice）、Artisan（Ava）这类 AI 销售代理融资很猛，但它们和「评论区挖线索」是两件事：它们的线索是买来的名单——11x 聚合 21 家以上付费数据供应商，Artisan 自建 3 亿+ 联系人库。AI 主要用在把冷名单写得像热的，而不是判断谁想买。渠道也只有邮件、LinkedIn、电话，不碰短视频。

一句话：AI SDR 是对着名单猛发，评论区挖线索是听见有人说想买才去搭话。这不是同一件事的两种做法。值得一提的是 TechCrunch 在 2025 年 3 月报道，11x 宣称的多家客户其实从未真正成为客户、logo 未经同意就挂在官网，员工称流失率一度达 70–80%——对着没有意向的名单猛发，AI 写得再花也还是骚扰。

06
Outreach · China

每家公司都只站一段

国内的规则形状和海外惊人地一致：入站可以，出站免谈。于是这条链在国内也是断的，每家有主体、有融资的公司都只站住了其中一段。

抖音开放平台 · 两条边界

评论 API：只能拿你自己视频的评论。官方能力页写得很清楚，可获取范围仅限授权用户自己发布的视频，回复评论同理。想拿别人视频评论区的数据，官方通道是零。

私信 API：只能被动回复。开放对象是认证企业号及其员工号等，限制是「私信消息仅支持消息回复，在用户未发送下一条消息前，24 小时内可向用户发送 6 条消息」。企业号自带的欢迎语也是每用户每小时 1 次的量级，且平台禁止通过官方私信接口发送站外链接或微信导流卡片。

所以「从别人视频评论区找到人、主动私信他」这条链，在官方通道里根本拼不出来。

只做「发现」

  • 蝉妈妈 / 飞瓜 / 千瓜 / 灰豚 / 新红
  • 抖音、小红书的数据分析工具，SaaS 会员制
  • 帮你判断哪些视频、哪些号值得盯
  • 但不给你评论区里的人，更不做触达
  • 站在链路第 ③ 关的上游

只做「接待」

  • 美洽 / 快商通 / 智齿 / 容联七陌 / 句子互动
  • 私信聚合 + 关键词或 AI 自动回复
  • 方向和「主动挖」正好相反——等用户先发消息
  • 句子互动官网确认：是在已有 IM 通道上接消息，不做主动挖线索
  • 站在第 ⑥ 关

只做「沉淀」

  • 微盟 / 有赞 / 探马 / 尘锋 / 微伴 / 微盛
  • 私域与企微 SCRM——人加到微信之后归它们管
  • 和挖线索不重叠，是下游
  • 行业信号见下方
官方工具也不碰评论区

巨量引擎的 飞鱼 CRM 是免费的线索管理工具，但它管的是你花钱投流买来的线索——线索进来之后去重、分配、跟进、外呼。它不做评论区挖掘。入口逻辑和「从公域评论区零投流捞人」完全是两回事。

一个值得注意的行业信号

微盟 2024 年营收 13.39 亿元，同比下降 39.9%；2025 上半年收入 7.75 亿元（同比 -10.6%），经调整净利 1690 万元，是 2021 年以来首次扭亏；订阅付费商户 59,149 家，同比减少 13.9%，高峰期曾突破 10 万。有赞 2025 上半年净利 7257 万元，此前经历过连续 8 个报告期的营收负增长。

双双扭亏、但收入仍在下滑、付费商户腰斩——一个被反复提及的归因是：部分企业买了工具却没有流量，空有交易场景，产生不了实际交易。工具不解决「人从哪来」的问题。

07
Where Akke Sits

我们站在第 ④ 关

Akke 是一套全屋定制行业的获客系统：从抖音评论里找出高意向客户，判意向、拟话术，经人工审核后把私信发出去，再接住回复继续聊。放到这张地图上，它的重心在第 ④ 关——「认出谁想买」，也是这张地图上最少人站的一格。

🎯

Difference 01把 LLM 用在最前面那个判断上

本次扫过的短视频平台工具里，触发几乎清一色是关键词：用户在你自己的视频下打「链接」「多少钱」，等于主动举手，机器人回一条预设内容。ChitChatBot 把 LLM 用在了后面的聊天上，但触发依然是关键词。

Akke 的做法是让 LLM 逐条读评论、给购买意向打分——处理的是「他没举手，但他透露了」。这是判断题，不是匹配题。

✋

Difference 02人审是硬性环节，不是可选项

LLM 拟好的话术进入队列，状态是 pending_approval，运营看过、点了，才会发出去。

这不是效率上的妥协，是设计取向：确定性判断交给代码，模糊判断才交给模型，而最终要不要打扰一个真人，交给人。前文提到 Devi 也是「一键生成草稿、人点发」——这套机制在海外被验证过，只是被平台规则赶去了文字社区。

✍️

Difference 03每条话术是写的，不是抽的

话术根据这条评论本身、这个视频的内容、这个人过往说过什么生成——跨会话的客户记忆会合并同一个人在不同对话里留下的信息，并以自然语言的方式带进下一次开口。

不是从话术池里随机抽一条，也不是模板填空。

🧭

Difference 04为什么是全屋定制

客单价高、决策周期长、地域性强——值得为一个人写一句话。

这类生意里，一条「我家 120 平预算 15 万能做吗」的评论，含金量和一条「沙发不错」差着数量级。而这个差别，关键词分不出来，模型能。这也是第 ④ 关在高客单行业里比在别处更值钱的原因。

说清楚边界

前面第 05、06 两节列的平台 API 规则，是这个赛道里每一家公司都要面对的客观条件，Akke 也不例外。本页的目的是把这张地图画准，不代表对任何一家公司（包括我们自己）的合规状况作出评价。

另外必须说清：第 04 节那个结论对我们同样成立——公开渠道没有独立第三方的 AI 效果对照数据，我们也没有。所以这页上不会出现任何「效果提升 X%」的数字。

① 决定赛道形状的是 API

方法与局限

档位说明：A = 官网／官方文档／法规原文等一手；B = 多个可信媒体交叉；C = 单一媒体或当事人自称；D = 营销号／榜单站／联盟返佣软文（本页一律不作为事实引用）。

已知盲区，如实交代：① 本次调研 100% 依赖公开可搜索的网页，无法覆盖不做公开推广的工具与团队，存在系统性幸存者偏差；② 「海外没人做完整闭环」有两种解释——被 API 挡住的真空，或有人试过悄悄死了没留痕迹，本次证据支持前者的机制解释，但无法排除后者；③ Meta Advantage+ 的各项数字、即创的真实定价、抖音数字人直播的官方规则原文，本次均未能取得一手证实，因此本页不引用；④ manychat.com 与 OpenAI 帮助中心对抓取返回 403，相关结论改用交叉信源替代。

一句话总括：这两个赛道看起来是「AI 能不能做出好视频」和「AI 能不能找到好客户」两个技术问题，实际上是同一个规则问题——平台把 API 的口子开在哪里，就决定了什么物种能活在哪里。生成端的口子开得太大，大到平台自己免费下场，第三方被挤成通道商；触达端的口子开得太小，小到「主动跟一个陌生人说第一句话」这件事，在公开规则里根本没有位置。看懂了这两个口子，这张地图上每一家公司为什么长成现在这样，就都解释得通了。
