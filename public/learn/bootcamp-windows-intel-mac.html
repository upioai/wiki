安装步骤
1
打开启动转换助理
在 macOS 中找到并启动 Boot Camp 安装向导。
Finder› 应用程序› 实用工具› 启动转换助理
2
选择 Windows ISO 文件
在向导界面中，点击"选取…"按钮，找到并选择之前下载好的 Windows 10 ISO 镜像文件。
提示： 确保选择的是 .iso 格式文件，而非压缩包或其他格式。
3
分配磁盘空间
拖动滑块，为 Windows 分区分配合适的存储空间。
  • 建议分配 128 GB，日常使用足够宽裕
  • 最少需要 64 GB，低于此值安装可能失败
  • 确认后系统会自动对硬盘进行分区，请勿中断
⚠️ 注意： 分区操作不可撤销，请确认分配空间后再继续。
4
安装 Windows 系统
Mac 会自动重启并进入 Windows 安装界面，按以下步骤操作：
  • 选择语言、时区和输入法（可选中文）
  • 点击"现在安装"
  • 安装类型选择 「自定义」（不是升级）
  • 在分区列表中，选择名为 BOOTCAMP 的分区进行安装
  • 等待安装完成，期间 Mac 会自动重启数次，属于正常现象
5
安装 Boot Camp 驱动程序
Windows 安装完成首次进入桌面后，Boot Camp 驱动安装程序会自动弹出。
  • 点击"下一步"按照向导完成安装
  • 此步骤会安装触控板、键盘、Wi-Fi、声卡等硬件驱动
  • 安装完成后重启 Windows，所有硬件即可正常使用
重要： 必须安装此驱动，否则触控板、声音、Wi-Fi 等功能将无法正常工作。

安装完成后 — 切换系统

macOS→Windows
重启 Mac，开机时按住 ⌥ Option 键不放，在启动菜单中选择 Windows 分区
Windows→macOS
重启并按住 ⌥ Option，选择 Macintosh HD；或在 Windows 系统托盘中点击 Boot Camp 图标选择"重启到 macOS"

注意事项

macOS 10.13 High Sierra 及以下版本，Boot Camp 助理界面略有不同，但整体流程完全一致。
如果 macOS 版本非常老（El Capitan 10.11 以下），可能仅支持安装 Windows 7，建议优先尝试 Windows 10。
安装前请务必使用 Time Machine 备份重要数据，分区操作存在极小概率风险。
整个安装过程约需 30–60 分钟，请保持电源连接，不要强制关机。
