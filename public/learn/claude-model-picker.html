Sonnet 5 / Opus 4.8 / Fable 5 怎么选

在 Claude Code 里写 Akke 代码时，手上有三档模型。这一页用一张图告诉你：什么活儿配哪一档。

💡
先分清：这三档是我们写代码时用的 Claude（在 Claude Code 里 /model 切换）。不是 Akke 线上给客户跑对话用的模型——那套是 Qwen / DeepSeek，两回事，别混。

一句话决策

先看这一个问题，就够了。

这活儿有多难？难度 + 值不值得多花钱 = 选哪档
简单、高频、机械
改改文案、修个小 bug、加字段、写测试
→ Sonnet 5
大多数正经开发
加功能、debug、重构、排障、一般的长跑任务
→ Opus 4.8（默认）
Opus 都吃力的硬骨头
最难推理、超长周期、要一次跑通整条链路
→ Fable 5

成本 · 速度 · /fast

按输出价（$/百万 token）横向比一眼。

Sonnet 5$15 /M 输出
Opus 4.8$25 /M 输出
Fable 5$50 /M 输出
Fable 5 每百万 token 输出是 Sonnet 5 的 3 倍多，还更慢——所以它是「最难才升档」，不是默认。
/fast 快速模式

Opus 4.8 可开 /fast：同一个模型、输出快约 2.5×，但按溢价计费。赶手感时开，平时不用常开。

effort 深度

Claude Code 默认 xhigh，编码/agentic 用这个最好；简单活儿降 high 更省、更快。

默认 Opus 4.8；琐碎降 Sonnet 5；硬骨头才升 Fable 5。

拿不准就用 Opus 4.8——它是默认档，覆盖绝大多数开发。活儿又小又高频，降到 Sonnet 5 省钱提速；只有 Opus 都啃不动的最难长跑任务，才升到 Fable 5，用完记得切回来。
