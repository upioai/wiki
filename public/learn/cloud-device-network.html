云电脑 / 云手机连不上？先查代理软件

云电脑、云手机时不时打不开、连不上网络，你以为是云端服务器出了问题，其实九成是你本机的代理软件（Clash / Shadowrocket / Surge）在作祟。这篇讲清楚它是怎么挡路的，怎么一眼认出来，以及三步把它修好。

篇幅 4 节 · 约 5 分钟 受众 全员（含不懂网络的同事） 适用 向日葵云电脑 / 阿里无影 / Parsec / 各类云手机

先说结论，方便你直接照做：云电脑 / 云手机连不上，第一件事不是重启、不是找客服，而是把代理软件关掉再试一次。能连上，就锁定是代理的问题，往下看怎么在保留代理的前提下彻底修好。

怎么用这篇 · 赶时间就直接跳到 第 3 节的三步修复照做。想搞懂「为什么是代理的锅」，再回头看第 1、2 节——理解了原理，下次遇到视频会议卡、游戏联机失败，你也能自己判断。
01

Section 01 · 一眼认出

符合这几条，基本就是代理软件的问题

不是所有「连不上」都长一个样。代理软件导致的这一类，有一组很典型的指纹：

现象说明
网页能开，云电脑连不上刷网页、发消息一切正常，唯独云电脑 / 云手机 / 视频会议 / 联机游戏连不上或频繁掉线。
串流卡顿、画面撕裂能连上但画面一顿一顿、声音断续、鼠标延迟大——连接建立了但数据流传不动。
DNS 显示 198.18.x.x最硬的证据。在网络检测页面看到 DNS / 出口 IP 是 198.18.x.x 开头，几乎 100% 就是代理软件在捣鬼（原因见下一节）。
为什么 198.18.x.x 是铁证 · 这是一段国际标准里专门留作「测试保留」的地址（RFC 2544），正常上网绝不会分到它。它出现在你的设备上，只有一种解释：代理软件的 fake-IP 模式给你伪造了一个假地址。看到它，不用再查别的了。
02

Section 02 · 到底哪里堵住了

代理会转发「网页流量」，却不转发云电脑要的「实时流量」

要理解这个问题，先记住一件事：网页和云电脑用的不是同一种「快递」。

刷网页、发消息走的是 TCP——像挂号信，一件件确认、丢了重发，慢一点没关系。而云电脑、云手机、视频会议、联机游戏这类实时画面串流走的是 UDP——像发弹幕，追求快、允许偶尔丢一帧，晚到的画面不如不要。

代理软件的 fake-IP 模式，会先把你所有的域名解析都拦下来、发一个假 IP（就是那个 198.18.x.x），然后自己决定怎么转发。问题就出在这里——它对两种快递的处理是不对等的：

TCP · 网页流量

代理正常接管、转发。所以你刷网页、发消息毫无异常，感觉「网络好好的」。

而

UDP · 云电脑串流

代理默认不转发（或需特殊配置）。云电脑的画面数据发出去有去无回，于是连不上、卡成幻灯片。

这就是为什么现象这么「反直觉」：你的网络明明没坏，偏偏就云电脑用不了。不是云端故障，是本机代理把云电脑要走的那条路给堵了。

一句话记住 · 代理放行网页（TCP）、拦住云电脑（UDP）。所以「网页能开 = 网络没问题」这个日常经验，在这里是骗你的。
03

Section 03 · 三步修复

从最快的临时方案，到一劳永逸的长期配置

  1. 先关代理，确认是不是它

    把 Clash / Shadowrocket / Surge 等代理软件彻底关掉，重新连云电脑。能连上——恭喜，问题锁定，继续往下做长期方案；还是连不上——不是代理的锅，直接跳到 第 4 节。

    这一步只花 10 秒，却能省下你几小时的瞎猜。任何排障都从「用最快的动作缩小范围」开始。

  2. 需要保留代理？改两个设置

    如果你的工作离不开代理（要访问外网），不用在「关代理」和「用云电脑」之间二选一。在代理软件里改两处，让它别再挡云电脑：

    改哪里怎么改
    运行模式从「全局 / Global」切回「规则 / Rule」模式——只让该走代理的走代理，云电脑的流量放行直连。
    DNS 模式把 DNS 从 fake-ip 改成 redir-host，不再给你伪造 198.18.x.x 假地址。
    分流规则把云电脑的域名 / IP 单独加一条 DIRECT（直连）规则，确保它绕开代理。

    前两项是通用开关，绝大多数情况改完就好；第三项是给「改完还偶发」的情况上的双保险。具体菜单名各家客户端略有差异，认准「模式」「DNS」「规则」这几个关键词即可。

  3. 还不行？换个网络排除干扰

    用手机热点连一次云电脑。如果换网就好了，说明堵点不在代理、而在你当前这个网络——通常是公司防火墙或路由器把 UDP 端口封了。这时候找 IT 开放对应端口，或长期改用手机热点 / 别的网络。

给不懂技术的同事 · 你只需要记住第 1 步——「连不上就先关代理软件试试」。九成情况这一步就解决了。剩下的两步，截图发给懂的同事，或直接把这一页链接甩过去。

Section 04 · 如果关了代理还是不行

那就不是这篇讲的问题，按这几条继续排

关掉代理、换了网络都没用，说明是另一类问题，简单过一遍：

方向怎么查
局域网封 UDP公司 / 酒店 / 校园网常封串流端口。用手机热点验证过就能确诊，找网络管理员开端口。
系统 DNS 被改Mac 上用 scutil --dns 看真实 DNS 服务器有没有被别的软件改掉；Windows 看网络适配器的 DNS 设置。
云端 / 客户端本身前面都排除了，才轮到怀疑云服务商或客户端版本——这时候找客服才有意义，而不是一上来就找。
排障的通用心法 · 永远从「一个动作能排除一大片」的检查做起：关代理（排除本机代理）→ 换热点（排除本地网络）→ 才到查系统、找客服。顺序反了，就会在最贵的方向上白耗时间。
网页能开不代表网络没坏——代理放行网页、拦住云电脑，连不上先关代理试一次。
