🎯产地商家最该走的路线：去当地办一张个体工商户营业执照（经营范围写上“食用农产品销售、预包装食品销售、散装食品销售”）→ 用它开个体工商户抖音小店 → 松茸走“生鲜/食用菌”报白，贡菜按“新鲜（生鲜蔬菜）/干货（食品）”分别处理。不要用“个人店”做生鲜生意，权限不够、容易踩违规。

01

概念扫盲：4 个必须懂的词

小白最容易卡在这里，先搞清楚
抖音小店（抖店）抖音官方的网店后台，卖货、上架、收款、发货、售后都在这里管理。电脑端登录网址：fxg.jinritemai.com。开通它，你才算“在抖音有一家店”。
类目 / 报白抖音把商品分成一层层“类目”（如 生鲜>食用菌>松茸）。部分敏感类目（生鲜、食品、酒等）属于“定向准入”——默认不让你直接上架，必须先提交额外资质、向平台申请开通该类目权限，这个动作行业里俗称“报白”（把类目从“发不了”变成“可以发”）。松茸、生鲜蔬菜就属于要报白的类目。
初级农产品指未经加工的天然农产品——比如整颗新鲜松茸、带泥的新鲜贡菜（莴笋苔）。这类通常可以免办食品经营许可证，但要提供产地/采购/种植证明。一旦经过腌制、切割、烘干、包装（如干贡菜、笋干），就变成“食品”，需要食品经营许可证。
保证金开店和开通类目时向平台预存的一笔钱，用于保障消费者权益。不是手续费，符合规则、退店时可退。金额按类目定，生鲜/食品一般数千元，以抖店后台实时显示为准。

🍄 新鲜松茸

生鲜 · 需报白
  • 归属：生鲜 > 蔬菜/食用菌（新鲜食用菌）
  • 属性：新鲜松茸是初级农产品，多可免食品经营许可证
  • 关键：属定向准入，必须报白，通常要 CMA/CNAS 质检报告 + 采购/采集证明
  • 特点：极易腐，必须冷链/空运次日达

🥬 贡菜（分两种形态）

看鲜/干走不同路
  • 新鲜贡菜（莴笋苔类鲜菜）→ 生鲜>新鲜蔬菜，初级农产品，需报白+产地证明
  • 干贡菜 / 苔干 / 响菜（脱水蔬菜）→ 属食品>蔬菜制品，需食品经营许可证（或供货方的 SC 生产许可）
  • 干货是预包装/散装食品，要有合规标签（名称、配料、生产日期、保质期、厂家、SC 号）
💡很多云南商家实际卖的是晒干的贡菜（苔干）——那就按“食品”准备食品经营许可证；如果确实卖鲜货，就按“生鲜蔬菜”走。两种都想卖，两套资质都备上。
02

第一步 · 先把资质办齐

没有这些，后面开店/报白都过不了

开店前，先把“身份证明 + 经营资质”备齐。资质不全是新手被卡的第一大原因。

A. 人人都要的基础资质

  1. 营业执照（个体工商户或公司均可）。经营范围一定要包含“食用农产品销售”“预包装食品销售”“散装食品销售”等字样；证件有效期需 > 3 个月，且企业不在经营异常名录。
  2. 法定代表人 / 经营者身份证（正反面清晰）。
  3. 结算银行卡（个体户可用经营者本人卡，企业用对公账户），用于货款到账。
  4. 一个能收验证码的手机号，和用来登录的抖音号（可新注册）。
📍没有营业执照怎么办？带上身份证去当地市场监督管理局 / 政务服务中心（或“个体户”线上通道）办个体工商户执照，免费或工本费很低、通常几天下证。经营范围记得让工作人员写全上面那几项。这是产地小商家最省事的选择。

🍄 松茸（生鲜食用菌）额外要

报白核心材料
  • 营业执照经营范围含食用农产品/生鲜
  • 第三方质检报告：由具备 CMA 或 CNAS 资质的机构出具，报告日期需一年以内
  • 产地 / 采购协议 / 采集（种植）证明：证明货源真实
  • 新鲜松茸多为初级农产品，一般免食品经营许可证（以报白页面要求为准）
  • 如带品牌名，需品牌授权书

🥬 贡菜额外要（按形态）

分鲜/干
  • 鲜贡菜：同上，产地/采购证明 + （生鲜类目常要）质检报告
  • 干贡菜/苔干：需食品经营许可证；若自己不生产、由厂家供货，需对方的食品生产许可证（SC）+ 采购协议
  • 预包装干货要有合规食品标签（名称/配料/日期/保质期/厂址/SC 号/净含量）
  • 不得夸大宣传（不能标“野生”“有机”而无证明）
⚠️质检报告要真做、别造假。找当地有 CMA/CNAS 资质的检测机构送检出报告；切勿 PS 或买假报告，平台抽检核验，一经发现直接清退/封店，得不偿失。

第二步 · 开通抖音小店

选对店铺类型，再照流程注册

先选店铺类型。这决定了你能不能卖生鲜、能不能报白，很关键：

个人店

不推荐做生鲜
  • 身份证即可开，门槛最低
  • 类目权限受限，很多生鲜/食品类目开不了、报白受限
  • 营销工具、结算方式也受限

个体工商户店

✅ 推荐
  • 一张个体户执照即可开
  • 可开生鲜/食品类目、可报白
  • 保证金较低，最适合产地小商家

企业店

规模化再考虑
  • 需公司营业执照
  • 功能最全、可做旗舰店/专营店
  • 适合有团队、走品牌化的商家

注册操作流程（电脑端）约 1–3 个工作日过审

  1. 电脑浏览器打开抖店后台 fxg.jinritemai.com，用手机号 / 抖音号登录。
  2. 点击「立即入驻」，选择主体类型 → 个体工商户（推荐）。
  3. 填写主体信息：上传营业执照、填统一社会信用代码、经营者信息。
  4. 完成法人 / 经营者实名认证（一般需本人人脸核身）。
  5. 填写店铺信息：店铺名称、logo、主营类目（最多选 3 个，选“生鲜 / 食品”相关）。
  6. 绑定结算银行卡。
  7. 按提示缴纳保证金（金额按所选类目，以页面实时为准，可退）。
  8. 提交，等待平台审核，一般 1–3 个工作日出结果；通过后进入店铺后台。
🧾手机上也能通过“抖音 → 我 → 创作者服务中心 → 开通小店”发起，但生鲜类资料多、要传证件，强烈建议用电脑操作，屏幕大、上传方便、不容易填错。

第三步 · 类目报白（开通生鲜权限）

这一步做完，才能真正上架松茸

店铺开好后，生鲜/食用菌属“定向准入”，需要单独申请开通——也就是“报白”。全程在抖店后台自助提交，官方不额外收费。

在哪里操作 & 具体步骤

  1. 登录抖店后台，找到「商品 → 类目 / 经营范围」或「店铺 → 资质中心 / 经营类目」入口（不同版本名称略有差异，认准“经营类目 / 类目报白 / 定向准入申请”字样）。
  2. 搜索并选择要开通的类目：松茸选 生鲜 > 食用菌；鲜贡菜选 生鲜 > 新鲜蔬菜；干贡菜走 食品 > 蔬菜制品。
  3. 按该类目提示上传资质：CMA/CNAS 质检报告、采购/种植（采集）证明、（食品类目）食品经营许可证 / 供货方 SC 等。
  4. 确认信息无误后提交。平台审核最长约 7 个工作日反馈结果。
  5. 审核通过 → 该类目权限开通 → 就可以到「商品 → 发布商品」里上架松茸/贡菜了。
🚫警惕“付费代报白”中介！报白是平台的资质审核，走官方后台自助申请即可，官方不额外收“报白费”。市面上收几百上千元“包报白”的中介，很多靠伪造资质蒙混，一旦被平台核出，轻则清退、重则封店没收保证金。资质自己按规准备最稳。
📖各类目的最新、最准确资质清单，以抖店后台报白页面的实时提示、以及抖音电商学习中心《生鲜行业管理规范》为准（政策会更新，本文为帮助理解的整理）。

第四步 · 上架商品与合规

卖生鲜，宣传红线尤其要注意

上架时怎么填才规范

  • 如实标注属性：初级农产品要标明“初级农产品”，写清产地（如香格里拉 / 迪庆）、规格（重量、开伞/未开伞）、采摘/生产日期。
  • 主图 / 详情页：真实拍摄、清晰，不用违禁词、不盗图；干货类要能看到包装标签。
  • 发货与保鲜说明：写明“冷链 / 航空次日达、下单后 X 小时内发货、坏损包赔”，让买家放心。
  • 价格与库存：松茸时令性强、货源波动大，库存要动态更新，避免超卖被判罚。
⚠️宣传红线（生鲜/食品最容易踩）：不得宣称治病、抗癌、增强免疫等医疗/保健功效；“野生”“有机”“绿色”等需有对应证书才能标；不得用“最”“第一”“国家级”等极限词。违规轻则下架扣分，重则罚款封店。

第五步 · 冷链发货与售后

生鲜的成败，一半在物流

松茸是“论小时保鲜”的极鲜货，物流做不好，退款和差评会直接拖垮店铺评分。

时效 & 冷链

  • 平台要求：非偏远地区约 48 小时内送达，易腐商品需全程冷链。
  • 松茸建议产地直发 + 顺丰航空 / 冷链次日达，采后 48–72 小时内送到最新鲜。
  • 包装：泡沫箱 + 冰袋/冰板 + 吸水纸，保温防压。

售后策略（提前设好）

  • 坏损包赔 / 缺重补偿：生鲜必备，写进商品说明。
  • 要求买家开箱验货、拍视频，便于快速定责理赔。
  • 及时处理退款、不拖延，护住店铺体验分（分低会限流）。
❄️干贡菜（苔干）不怕腐，用普通快递即可，但要防潮、密封；把鲜货和干货分开设运费模板，别用一个规则套两种货。
07

新手避坑清单

这些坑，几乎每个新商家都踩过
  • 别用个人店做生鲜——类目权限不够、报白受限，白折腾。用个体工商户店。
  • 营业执照经营范围没写“食用农产品/食品销售”——一定会被卡，办证时就写全。
  • 找“低价代报白”中介——官方免费自助，中介多造假，封店风险高。
  • 质检报告造假 / 过期——必须 CMA/CNAS 真报告、一年内。
  • 冷链省成本用普通快递发松茸——到货变质，退款差评连锁反应，店铺分崩。
  • 夸大宣传功效——“抗癌/野生/有机”乱标，轻则下架重则罚款。
  • 时令超卖——货源不稳还挂大库存，缺货发不出会被判罚、扣分。
  • 保证金误以为是被扣的钱——它是可退预存金，别为省这笔去开不合规的店。
08

常见问题 FAQ

点开看答案
完全没有营业执照，能先开店吗？
卖生鲜/食品实际操作中需要执照。最省事的做法：先去当地市场监管局办一张个体工商户营业执照（几天下证、费用极低），经营范围写上“食用农产品销售、预包装食品销售、散装食品销售”，再用它开个体工商户小店。
“报白”要花钱吗？多久能通过？
官方渠道自助申请、不额外收费，你只需按类目要求准备真实资质。审核一般最长约 7 个工作日。收费“包报白”的第三方中介务必远离，造假会导致封店。
新鲜松茸需要食品经营许可证吗？
新鲜松茸属初级农产品，一般可免食品经营许可证，但需要提供产地/采购/采集证明，且生鲜类目报白通常要 CMA/CNAS 质检报告。具体以报白页面提示为准。一旦做成腌制/烘干等加工品，就需要食品经营许可证。
干贡菜（苔干）和新鲜贡菜，资质一样吗？
不一样。新鲜贡菜按生鲜蔬菜（初级农产品）处理；干贡菜/苔干属脱水蔬菜、算“食品”，需要食品经营许可证（自产要 SC 生产许可，代销要供货方 SC + 采购协议），且预包装要有合规标签。
保证金大概多少？能退吗？
按类目而定，生鲜/食品一般为数千元级别，具体以抖店后台缴纳页面实时显示为准。它是预存的保障金，符合规则、正常退店时可退回，不是手续费。
店铺类型选错了能改吗？
主体类型变更较麻烦、部分不可逆，所以一开始就选个体工商户店最稳妥。切勿因图省事先开个人店，后面做生鲜会处处受限。
去哪学官方最新规则和运营课？
抖音电商学习中心（school.jinritemai.com）——查行业规范、入驻/上架/发货规则；巨量学（school.oceanengine.com）——学直播、短视频带货、店铺运营课程。开店操作在抖店后台 fxg.jinritemai.com。
