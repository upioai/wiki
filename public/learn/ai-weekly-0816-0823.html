07
What To Do

本周你该动的三件事

按「要不要动手」分三档，不按重要性排——重要但已自动生效的，不需要占你时间。

ACT建议动手

  • 复验 .worktreeinclude：开一个新 worktree，确认 .env 类文件真的被拷进去了
  • 确认用量自动续跑开关：/config 里「Continue automatically at usage limit」默认已开
  • 盯 OpenRouter 迁移公告：Stripe 接手后计费与账号体系可能变，别等断供才动

WATCH需要适应 / 留意

  • Todo 工具在 Opus 4.8 / Sonnet 5 / Fable 5 上已默认移除，要回来设 CLAUDE_CODE_ENABLE_TODO_TOOLS=1
  • 全屏下 Ctrl+L / Cmd+K 只重绘，双击触发 /clear 已移除
  • 斜杠命令打错字直接报错，不再模糊匹配跑最接近的那个
  • Anthropic S-1 公开后，用招股书口径更正本页财务数字

SKIP无需动作

  • claude-api skill 上下文已从 200k+ 降到 ~25k，白拿
  • 长会话内存泄漏、Bedrock 计费翻倍，升级即修复
  • Concise 输出风格、readline 键位、spellcheck——想用再开
  • 最新版 2.1.241（取自官方 changelog），开着自动更新即可
一句话总括：行业侧，钱从模型层往基建层与网关层移动，两家头部同时递表把「AI 什么时候赚钱」这个问题摆上了台面；工具侧，Claude Code 这一批真正值钱的不是新功能，而是两个不报错、不告警、只安静出问题的 bug 被修掉了——计费翻倍与文件静默不拷贝。
