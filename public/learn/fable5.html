Claude Fable 5

目前最强、最聪明的 Claude 模型——位于 Opus 之上的全新档位，专为最吃智力的长程任务而生。

定价（每百万 token）
$10 入 / $50 出

它是什么

  • 新的能力天花板
    不是 Opus 的小版本升级，而是 Opus 之上的独立档位，智力上限更高。
  • 长程自主任务王者
    大型重构、整夜运行的编码任务、深度知识工作、跨会话记忆——一次把任务说清楚、跑 high effort，效果最好。
  • 写作更清晰、更暖
    行文比上一代更顺、更少 AI 腔与套话，是更好的思考搭子。

接口要点（和 Opus 4.7 / 4.8 同一套，但有一个新坑）

  • 只有自适应思考
    thinking: {type: "adaptive"}。budget_tokens 已彻底移除，传了报 400。
  • 采样参数被移除
    temperature / top_p / top_k 一律不接受，靠 prompt 引导。
  • ⚠️ Fable 5 独有
    显式 thinking: {type: "disabled"} 会 400（这在 4.7/4.8 上是允许的）——要关思考就整个省略 thinking 字段。
  • effort 调深浅
    output_config: {effort: "low"|"medium"|"high"|"xhigh"|"max"}，默认 high。

最小调用示例（TypeScript）

// npm install @anthropic-ai/sdk import Anthropic from "@anthropic-ai/sdk"; const client = new Anthropic(); const res = await client.messages.create({ model: "claude-fable-5", max_tokens: 16000, thinking: { type: "adaptive" }, // 不要写 "disabled"，要关就删掉这行 output_config: { effort: "high" }, messages: [{ role: "user", content: "你好，Fable 5" }], });
💡 大输出（max_tokens 超过 ~16K）记得用流式 .stream() + .finalMessage()，否则容易撞 SDK 的 HTTP 超时。
